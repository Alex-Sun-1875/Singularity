# 白枝 · 蜂蜜金与深棕黑 UI 素材包 v4

当前色以 `skin.json` v4为准：主色蜂蜜金 `#DAAE65`、高光 `#F7DA9D`、暗边棕铜 `#8D6030`，按钮底 `#221810`→`#110D09`，主金属边3.4源像素。暖象牙覆层保持3.5%透明度；保留原内凹和角饰几何。

17 张原创 SVG 已重新栅格化，并同步到 `src/cocos/assets/resources/ui/quiet-bronze/` 的既有 PNG。文件名和 Cocos meta/UUID 保持兼容。当前 [静态样张](ui-kit-preview.png) 由既有 resvg 2.6.2 组合源矢量生成，另有可编辑的 [SVG 样张](ui-kit-preview.svg)；这不是引擎截图。

本轮按 BG3 参考对齐奇幻金属界面语言：烟黑/黑曜石渐变、微弧肩角、窄香槟金明暗包边、层叠内凹槽、四角原创卷叶刻线与底部微弱哑光刻痕。金色只用于细边，没有大块黄褐填色。悬停提高中性亮度，按下保持黑底并倒转阴影、加入细青蓝边，禁用降低金属明度。正文建议冷白 `#F1F5F5`、次要正文浅蓝灰 `#B4C5D4`，分隔为暖锡灰 `#979082`，香槟细边高光 `#E4CFA7`。生命填充用红莓，专注填充用蓝青。

面板的语义底色由父节点 Graphics 绘制，`panel-surface` 只作中性低透明抛光，使用 `Color.WHITE`；不要将它当作不透明底。面板、按钮、禁用遮罩的切片为四边24源像素，底条为 L/R=24、T/B=8。主金属细边2.4源像素在0.5倍显示时约1.2逻辑像素，内刻线约0.6逻辑像素，透明留白不裁切。

Cocos Sprite 子节点内容尺寸为目标显示尺寸两倍，局部缩放0.5，文字和点击区域不缩放。保持原触区和布局。按钮四态外形相同；持续选中有独立标记，触屏有按下反馈。皮肤不负责阻断禁用点击，运行时需设置交互状态。

条形填充在源坐标 x=12、y=10，宽为总宽减24，高12；按百分比裁切填充，两端帽固定在整条两端，零值仅隐藏填充。生命/专注名称和数值放在条外。冷却纹理是全幅半透明方片，径向起点和所属图标的裁切由引擎处理。
