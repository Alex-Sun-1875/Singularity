## 参考研究与本作选择

已实际查看本机 BG3 官方设定集的角色、聚落 Emerald Grove（44–45页）与地下 Underdark（56–57页），以及本地地图 banner、侧栏和图例。另只读抽取并检查 `HotBar.xaml`、`PlayerPortraits.xaml`、`Dialogue.xaml`：底部动作区、左侧人物信息、下方对话选择及独立提示层的布局关系。研究文件在 `src/cocos/temp/bg3-reference/`，仅用于参考。本目录无 BG3 原图、原始纹理、角色或图标。

- 游戏界面以烟黑/深褐为安静底面，暗黄铜只强调结构、选择和少量角饰；不能让每个控件都重复粗亮金边。
- 图册的浅纸页与实际游戏 HUD 分开：本作羊皮纸用于信件/手记，不铺满游戏画面。任务、物品说明和操作比边框醒目。
- 本作保留“白枝远征”的细枝角饰、现有 v5 人物色块与 v3 地理。组合板的插画、装饰与符号是本作设计示意。
- 地表自然绿、灰米石、灰褐木形成主体，酒红/苔绿/墨蓝用于衣物身份。暖灯集中生活和交互区域，阴影保留冷灰/青绿，不用全屏棕黄滤镜统一。

## 整体设计转化

| 研究对象 | 观察 | 本作设计选择 |
| --- | --- | --- |
| 信息布局 | 人物、动作、对话与提示各有固定阅读位置，画面中央留给场景 | 桌面底部紧凑动作栏、左侧人物状态、上角菜单；中央不摆大块按钮；触屏另排双拇指控件 |
| 面板背景 | 深色背景和局部装饰衬托内容，纸张主要服务书写/文献 | 探索用近黑皮革，文献才用浅纸；背景颗粒低对比，避免满屏旧纸黄 |
| 材质差异 | 金属、布料、皮革、头发与岩石具有不同光泽和尺度 | 先定中性基底，再分别做粗糙度与法线；不靠同一套纹理乘颜色包办全部材料 |
| 人物与装备 | 成人比例、服装结构和金属/布料分层维持辨识 | 保留v5青绿披肩、酒红长衣、墨蓝卫甲等色块；磨损集中接触处，不把全身做旧 |
| 场景与光 | 植物/水体提供绿青，石木承担中性面，光区有生活与叙事用途 | 村镇自然明亮、旅店暖灯局部、地下灰石冷影；不整章统一灰蓝或黄褐 |
| 战斗视觉 | 表现需突出动作、目标与反馈，背景不争注意力 | 斩击短促、奥术局部明亮、火光受控；保留本作即时战斗，界面不照搬回合制资源条 |

运行布局已按真实1280×720与844×390、915×412手机横屏检查：触屏采用独立排布，常用触控区域至少52px，主要正文及提示约14.5–16px以上。组合板仍只验证材质搭配和信息层级，不是最终HUD排版。最新字号证据是 `src/cocos/test-results/final-font-summary.json`。

## 后续资源规格

本轮已交付规格以`ui-kit/skin.json`为准：细框与按钮四态源图256×128，白枝角饰192×192，状态条源图512×32，实际显示按2倍源图规则处理。文字、图标、角饰和拉伸底分离，不能把组合板整张贴进界面。此前768×128角饰和128px按钮为旧规划，未沿用，不应照旧规格重复制作。

本轮17张UI资源不包含人物头像；角色管线已另行导出拉斐尔与弥菈透明头像。进一步的角色/装备UV细节及512px可平铺暗底仍可继续完善。原AI皮革色卡只是设计参考，未通过正式无缝导出。

世界材质继续优先复用兼容 Cocos 3.8.8、来源明确的 CC0 PBR 扫描基底；本次图用于确定色相、噪声与尺度。目标世界128–256 texel/m，近景装备/角色256–512 texel/m。建议干木粗糙度.62–.85、干石.78–.94、亚麻.84–.96；这是本作建议，不是对 BG3 引擎参数的测量。

## 检查结果与边界

已检查PNG可解码、尺寸、哈希与视觉组合。接边统计只是诊断，不等于无缝认证；橡木v1上下边平均跳变约25/255，v2约21/255，均明显高于各自内部相邻像素约7/255与6/255，不能标为已通过平铺。正式接入前还需2×2重复、正常镜头、mip缩小与中性光检查。草地密细线和亚麻规则织纹也需要在缩小时检查噪声及摩尔纹。

前述AI色彩/基底设计候选仍没有匹配Normal、Roughness、AO，不能把AI设计板当成PBR材质。新增来源库已提供配套通道，UI包已提供独立切图与九宫格参数；二者均尚未进入Cocos材质/控件，也未完成游戏内手机/桌面实际像素、mip、压缩、粗糙度强度与全章验收。正式接入时应从新增配套来源库选择整套材质，不把它们的法线套在AI基底图上。
