# 行路人：较高细节的 3D 结构研究（未批准成品）

本目录的 `models/`、`../../../source-art/player-refined/`、`sprites/` 和 `previews/player_refined_mesh.png` 是一次原创程序化三维建模研究。与上一版低模相比，重新制作了成人比例、曲面胸甲、弧面分层肩甲、腰带铆钉、手指、靴子、发束和披风网格。**它仍未达到指定概念图的写实人物与绘制质感，不应当作已完成或已批准的最终角色美术。** 面部、衣褶和皮革依旧明显程序化；不能通过简单增加面数就称为参考图同等质量。

## 具体文件
- `models/model_player_refined.glb`：可导入的单体静态分件模型。
- `../../../source-art/player-refined/player_refined.blend`：可编辑 Blender 4.3 场景。
- `../../../source-art/player-refined/build_refined.py`：完整原创几何与材质生成代码。
- `previews/player_refined_mesh.png`：900×1000 的**实际网格渲染**。
- `sprites/model_player_refined_*.png`：实际网格的四方向 512×512 透明渲染，非动画。
- `manifest.json`、`validation.json`、`sprite-validation.json`：模型统计、GLB 回导及透明图检查。

## 技术边界
- 约 2.5 万三角面；最终精确值见 manifest。261 个分件网格，尚未合批或验证移动端开销。
- 原点地面中心，米制，源场景 Z-up、正面 -Y；GLB 为标准 Y-up。
- 四向正交镜头：水平 45/135/225/315 度，俯视角 32 度。
- 无骨骼、蒙皮、正式关节枢轴、动作、UV 贴图、碰撞或引擎集成。所有材质为独立纯色 PBR。
- 不是把 AI 概念图贴在一个平面上，也没有把概念图冒充模型截图。

## 与设计图的区别
`../../concepts/` 中的图像是独立制作的高细节视觉方向图，不是上述模型的渲染。若游戏采用精细绘制的 2.5D 预渲染角色，应以批准的视觉方向为准；本模型最多作为未来人工精修、雕刻与绑定的结构底稿。尚不能从本包得到与概念图一致的动作资产。
