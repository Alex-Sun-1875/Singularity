# 剑与火精细角色方向

## 以用户确认的参考为准

角色采用自然成人比例与细致的皮革、布料和金属层次，避免积木形体、夸张五头身及显著三角面。`../../concepts/character-direction-v1.png` 为用户明确选定的原始造型参考。

## 当前高细节设计参考

- `../../concepts/player-four-view-v2.png`：主角静态多角度造型参考。
- `../../concepts/raider-detail-reference-v2.png`：围路兵正背面细节参考。
- `../../concepts/captain-detail-reference-v2.png`：路障头目正背面细节参考。

图像由内置图像生成工具以用户确认图片为参考制作。保留透明通道。它们用于确定服装、轮廓、配色与细节，不是从3D模型渲染出的图，也不是已经配准的四向动作精灵图集。部分角度接近，武器与服装的一致性仍需在正式动画制作时校正。不能把重复或接近的静态姿态当作动画帧。

## 模型研究不是最终角色

此目录的 `models/`、`../../../source-art/player-refined/`、`sprites/` 和 `previews/` 为单个主角的程序化结构研究。虽然增加了曲面和细节，仍未达到用户确认的写实手绘参考品质，未通过最终美术验收。它没有骨架、蒙皮、动画和引擎接入。详见 `MODEL-STUDY-README.md`。

## 下一步的制作验收

先完成主角一个方向的精细角色资源，在实际游戏尺寸中核对脸、武器手、肩甲和油壶轮廓；确定统一脚底锚点和视角后，再制作连续待机、行走、挥剑、施放火油、受击和倒地动作。其余角色复用同一相机、光照与制作规范。不要仅提高三角面数就声称画质达到参考。

该目录没有指定公开许可；源图不是从已有商业游戏中提取的素材。本包不声称独占权或已经完成平台兼容性认证。
