- 重新构建连续成人头部曲面，不再用独立球块拼接脸颊；但脸与短发仍不具有原参考的人物气质。
- 单侧钢肩甲、米色卷袖、青绿披布、腰壶及右手剑在同一三维模型中固定；四向不是镜像素材。
- 修改最明显的粗直条头发、肘部球关节断裂、过强钢甲反光和过圆鞋尖。新前臂连续延伸于袖口/护臂之下。

## 已验证的技术事实

- 212,197 个顶点中：199,028 为单骨权重，13,169 为多骨权重；0 个未加权顶点，权重和归一。
- 待机源帧 1 与 49 的采样网格顶点差为 0；源帧 13 的最大实际顶点位移约 0.05445m（主要是披布）。这证明不是仅对静态图做缩放/位移。
- 9 个源采样的地面根点漂移 0px，左右脚骨位置漂移 0m。投影根点约 `(256.00003, 432.00026)`；这些只验证待机，不验证行走触地或膝肘大角度变形。
- 8 张待机图的文件内容互不相同，RGBA 512×512，最小画布安全边距 55px。
- 保存后重新打开 `.blend`，重渲相同帧的 RGBA 像素与交付帧一致；20 张源纹理均打包，无丢失外部纹理依赖。
- GLB 实际含 1 个 skin、1 个 animation、63 个动画通道；这是结构检查，不替代不同引擎里的导入和视觉验证。

8 帧若按未裁 RGBA8 计：512² 为 8 MiB，256² 为 2 MiB，192² 为 1.125 MiB；不含 mip、图集空白和解码副本。本次没有制作图集，PNG 或 MP4 磁盘小不代表 GPU 预算通过。

## 改换路线前必须解决（不是继续生产授权）

1. 以原图单一自由剑士为目标做人工针对性头脸/发型雕刻和衣装结构修形，先用正面/背面静态渲染判断，不立即增加其他角色。
2. 制作关节友好的连续拓扑、身体衣服的形变权重和握剑接口；通过肘/肩/髋/膝极限姿态后再做 walk8/sword10。
3. 依照实际缝边、磨损接触区和布料受力绘制/烘焙材质，而不是给全身增加一层随机噪点。
4. 用同一个正交相机尺度解决四向注册问题，保留地面根点。只有静态风格与动作关都通过后，才扩展动作/方向。

**停止结论：本轮已验证的自动脚本建模方法不能达到获批参考，不应继续微调同类模型或用新概念图冒充模型改善。** Blender本身有雕刻、拓扑、绘制和绑定能力；失败的是当前自动生产方法的形体与美术判断，不是软件不具备这些功能。缺口是有针对性的高质量人体/衣装雕刻、关节拓扑、人工材质绘制，以及必要时经过明确授权和许可审核的高质底模。没有已经验证能跨过这个质量差距的自动替代路线。

停止前仅完成一份只读相机诊断 `revision-local-01/registration-diagnosis.json`，未开始新局部修形或新渲染。根点和尺度原本统一；14px原始Alpha高度差包含10px脚尖朝向投影差和4px顶部轮廓差。该技术解释不改变用户对造型的拒绝，也不能当成美术质量改善。

当前阻力是本次程序化造型方案的实际质量，不是缺少下载许可，也不是“只要加贴图就可以”。本机 Blender 4.3.2 无 OpenImageDenoise，已改为直接采样渲染；没有为此安装工具。若要采用外部人物资产、商用贴图或另行专业制作，需要另行明确来源/授权，不能默认为本任务已经批准。
