## 改了方法，但结果仍失败

没有导入、复用或修改被拒绝的 `hero-g1-motion-study` 网格。新样板试验了独立的解剖标志深度插值曲面，脸上有真实眼孔，头皮上为实际细曲线发丝，衣片和肩甲均为几何。与旧版球块、柱块和粗发条拼装不同，但仍属于没有经过艺术家针对性修形的自动生成面，不等于人工雕刻质量。

首张渲染暴露的错误足够明确，因此不做第二轮参数微调：

1. 眼球明显外露，眼眶和眼睑没有形成自然包覆；成人神态失败。
2. 面部转折、下颌和颧部关系失真，没有获批参考的人物气质。
3. 发量轮廓仍像帽子，额前几组发束过于均一；真实细丝数量没有修复发型。
4. 披巾像硬片，无自然重力褶和交叠关系。
5. 肩甲与袖子穿插，服装剪裁与材料层次没有成立。

**停止判断：没有形成足以值得扩做全身的明确美术改善。** 不把顶点数、真实曲线数、文件存在或渲染成功当作质量提高。

## 历史复现（生产已停止，不自动执行）

从项目根目录执行；这些命令只写本研究目录。复现失败样板不代表继续制作授权：

```sh
python source-art/studies/hero-static-remake/sculpt_landmarks.py
blender -b -t 8 --python source-art/studies/hero-static-remake/build_static_bust.py
blender -b -t 4 --python source-art/studies/hero-static-remake/inspect_saved_bust.py
```

`sculpt_landmarks.py` 保留解剖控制点和脸部曲面的构造；`build_static_bust.py` 保留实际几何/材质/灯光；`inspect_saved_bust.py` 只重开与检查，不修改模型或渲染。
