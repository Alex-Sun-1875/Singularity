# 《剑与火》内部占位资产（非最终美术）

**所有模型和静态渲染只用于内部占位与结构研究，未获最终美术验收。**

## 文件状态
这是能被引擎导入的**静态、分件模型基础包**，不是仅有概念图。6 个角色、9 个道具；每个角色有四个固定等距方向的 256×256 透明 PNG。`../../source-art/blockout/sword_and_fire_assets.blend` 可以编辑所有网格与材质；`../../source-art/blockout/build_assets.py` 完整记录生成方式。

**品质边界：**人物为约五头身的简化低多边形风格，使用几何层次与纯色 PBR 材质表现皮革、钢片、披巾。概念图中写实布料、面部和磨损细节并未烘焙进这些网格；概念图不是模型截图。阿禾、老周、罗铎由前三个原创基础网格模块化衍生，不是六个独立手工雕刻作品。

**尚未完成：**没有骨架、蒙皮、正式关节枢轴、待机/行走/攻击动画、UV 贴图、碰撞体或 LOD；没有伪造重复帧动画。模型在一个地面中心根节点下保留独立装备/身体网格。进入正式角色制作前需要关节拓扑、骨骼绑定、动作、轮廓与面部二次精修。

## 目录与资源 ID
- `models/model_player.glb`：行路人，青绿围巾短披风、分层钢片、皮甲、剑、油瓶。
- `models/model_raider.glb`：围路兵，铁帽、锈棕披风、圆木盾、铁箍木棍。
- `models/model_roadblock_boss.glb`：路障头目，非对称肩甲、方盾、重锤。
- `models/model_ahe.glb`：阿禾，长款土黄外衣、账本、挎包、发髻，无武器。
- `models/model_zhou.glb`：老周，灰发灰须、皮围裙、小锻锤，无盾。
- `models/model_luoduo.glb`：罗铎，蓝灰披风、低矮钢盔脊、方盾与剑；后续章节的静态占位衍生基础。
- `props/`：油桶、补给木箱、可破坏栅栏（外形）、石墙模块、营火（静态火焰几何）、战利品箱、钢剑、方木盾、木桥段；每个都有 GLB 与 PNG。
- `sprites/`：角色四向透明渲染；文件名方向指观察镜头相对于角色的位置，不代表动画帧。
- `previews/character_lineup.png` / `npc_lineup.png`：真实 Blender 网格渲染，而非 AI 概念图。
- `manifest.json`：资源清单、三角面数、路径和限制。
- `validation.json`：逐件 GLB 回导记录、三角面数一致性与包围盒。

## 坐标与 2.5D 导入
- Blender 单位为米，Z 向上、角色正面为 -Y；GLB 使用标准 Y-up 导出。根节点枢轴位于地面中心。
- 角色原点均为 `(0,0,0)`；可编辑合集场景中仅为审阅排开，不影响单体 GLB。
- 四方向正交镜头：水平 45° / 135° / 225° / 315°，俯视仰角 32°。角色图采用统一正交尺度 2.12m，透明背景，不含地面阴影。
- PNG 仅可用于内部占位测试，不是已批准的角色外观；GLB 需后续由目标引擎导入。此包不包含代码集成，也未在 Cocos 中验证。
- 各道具预览为了可读性使用单独取景尺度，不能据 PNG 尺寸推断实际尺寸。
- 每个道具只是独立模块，没有破坏逻辑、交互逻辑、粒子火或灯光组件。

## 来源与使用状态
本目录 `models/`、`sprites/`、`props/`、Blender 场景与 Python 生成代码均为本次原创程序化几何/材质，未下载外部模型、纹理或付费资源。为本项目制作，尚未选择任何公开许可；不含任何既有游戏的角色、徽章或提取素材。参考仅限成人冒险者的皮革/金属/布料分层美术方向。`../concepts/` 为独立概念设计流程的产物，来源说明以该目录/项目交付说明为准，不属于本生成脚本的输出。

## 重建
安装 Blender 4.3 后，从仓库根目录运行（路径自动定位，无需改 BASE）：

```sh
blender -b -t 4 --python source-art/blockout/build_assets.py
blender -b -t 4 --python source-art/blockout/validate_exports.py
```

脚本采用 Cycles CPU、64 samples，不开启当前环境不支持的 OpenImageDenoise。所有网格/颜色均保存在可编辑场景中。
