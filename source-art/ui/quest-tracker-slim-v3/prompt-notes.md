# 云端生图提示词记录

## 首轮

使用用户提供的实机截图作为唯一参考，制作包含完整横屏游戏画面和页脚三状态示意的高保真UI设计画板。保留角色、场景、状态HUD、小地图、摇杆、药品和技能位置；移除红色批注及绿色开发水印。将左侧三行厚框改为约195×34逻辑像素的单行任务签，仅显示箭头、`夺回断轮磨坊`、`35m`与`出发`。使用既有暗金、深棕与衬线字体，减少边框厚度。页脚单独说明常驻、点击任务名展开及寻路暂停三种状态；标注可见高度34px、触控48px。禁止扩大遮挡区域或修改其他HUD结构。

首轮生成成功；视觉检查发现主画面任务签高度与声明的34逻辑像素不一致，字号偏小，转入定向修订。

## 二轮定向修订

只修订首轮画板主游戏画面中的任务签，不改变画板、其他HUD与页脚。游戏图约占画板高度71%，对应393逻辑像素，因此主图中任务签可见高度须约为主游戏图高度的8.65%，宽度约为其宽度的23%。在1586×992预览下约为350×60像素；字号应约为22—24像素，不使用极薄小字条。任务签左边与状态框对齐，位于其下方并留足触控扩展间距。文案保持`夺回断轮磨坊  35m | 出发`，一行显示；继续使用细暗金边、低调深棕底与现有字体。

## 用户后续调整：确定性排版

用户要求高度再增加、使用公共双边框组件、移除前导箭头，并与头像状态框同宽。此轮无需再生成场景或边框：通过Pillow直接使用公共组件已有边框、内衬与字体素材，将所有状态的任务框改为同一风格，主图宽333像素、可见高度78像素，对应约180×42逻辑像素。按需展开层单独增加进度内容空间。没有修改游戏实现。
