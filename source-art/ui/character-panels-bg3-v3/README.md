本轮只有一块旧姓名牌背景使用云端内置OpenAI image_gen清字，输入为280×281局部，提示词见[prompts/identity-wall.txt](prompts/identity-wall.txt)，来源与验收见[generation-provenance.json](generation-provenance.json)。本地合成只覆盖左侧墙面区域并保护手部；人物、拱门和大剑使用原稿像素，未再生成。

字体沿用已安装的Noto Serif SC，以OFL 1.1子集化为500字重、改名并保留完整许可，无字体、模型或依赖下载。状态与品质颜色继续使用项目公共反馈配置；与概念稿不同的生命／成功绿保持项目内一致。人物中、右栏底边和强化面板底边也按原稿保留底栏上方的留白。

## 仍需区分的差异

原稿是紧凑位图概念图，顶部副导航及部分装备槽位不足以容纳48逻辑像素触控区和8像素间距。运行版对这两处保留必要间距；尤其技能目录首排不能完全上移到原稿位置；强化副页签相应下移，剑首下方留出少量净空以避免页签遮住剑首。其余可见素材、分栏、人物与武器、详情层级和主要操作尽量按原稿定位，不宣称整屏逐像素相同。

装备、品质、强化属性、血量、等级和费用来自实际存档，不强制抽中原稿的示例词条；完整词条与效果仍可滚动查看。审阅存档使用隔离浏览器，装备由现有任务／掉落取得，再配置审阅等级和资源，不修改用户存档。
