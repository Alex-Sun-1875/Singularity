# 人物、装备、技能与工坊整体整理 v9

2026-11-11，复查四个主面板、锻造配方、强化传承、外观和装备锻印。沿用已确认的背景、人物、插画、圆角装备框和神器四角纹饰，本轮没有新生图、下载或新增依赖。

修正内容：

- 背包、装备详情、强化候选等超长内容使用 Cocos 原生 ScrollView / ScrollBar，溢出时持续显示细金色滚动条，滑块放在内容外侧，避免挡住最后一列物品。内置白纹理的滑块禁止加入动态图集，避免 WebGL 上传错误。
- 双按钮底栏按同一逻辑比例缩放；状态说明根据长度在 12—14 逻辑像素间排版，保留长提示的换行空间。
- 装备页明确显示「外观 / 锻印」入口；装备部位文案由公共函数统一，来源文字均衡换行。
- 外观页统一使用已接入的衬线字体，重排筛选、物品格和底部操作的触控间距。移除与装备页重复且会压到发型、旋转按钮的穿戴槽，人物预览保留发型和左右旋转；装备主面板的主副手仍并排位于人物脚下。
- 装备锻印统一字体、公共状态颜色、金色主要按钮与深色次要按钮；武器奖励复用装备页插画，正文不小于 12 逻辑像素。「已获得」标签与图标分开，长装备说明可滚动查看，底部按钮间距至少 8 逻辑像素。
