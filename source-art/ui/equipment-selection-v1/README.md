## 当前实现的冲突来源

`features/equipment/runtime/EquipmentIconFrame.ts` 在管理页选择 `socket-selected` 亮金皮肤，再增加一圈金线。`EquipmentPanels.ts` 在没有显式槽位选择时默认将主手槽选中；普通长剑共用的原图还带紫红烟雾。这些信号分别与品质和穿戴状态重复，不能仅靠替换一处边框 RGB 解决。

后续若接入，应复用 `EquipmentIconFrame` 的共享状态绘制，在公共语义配置中集中管理，清除管理页的额外亮金选中皮肤，并将“当前查看条目”“当前槽位筛选”“实际已穿戴”分别读取真实状态。其他已确认的暗金页签、面板和按钮风格不在本稿修改范围。

本地预览已检查条目切换、详情更新、已穿戴标签保留，以及 736/620/390/320 宽度下的内容边界。此结果只验证设计预览。用户美术确认、Cocos 接入、844×390 横屏实际布局及 TapTap 真机触控均尚未完成。
