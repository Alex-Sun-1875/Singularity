## 已确认的展示规则

顶部弹窗默认展示24秒，满足20秒以上；拾取立即取消剩余展示时间，并同步隐藏顶部弹窗、地面光效、装备与名称。展示时长不构成拾取等待时间；未拾取装备继续留在地面，不随顶部提示计时消失。用户澄清的是“拾取后自动隐藏”，没有要求转移仓库。

## 美术方向与验收范围

复用原界面的深棕内衬与暗金双层金属边，品质、装备名称和局部光效分别使用紫色史诗与橙色传奇。v2去除贯穿上方空间的长直激光，以贴地暖光、短柔光和稀疏上升光尘表达掉落。静态检查已覆盖中文文案、三状态与编辑区外像素保护。细椭圆基线仍偏规整，后续以实际动效决定是否继续弱化。

原始稿中的生成装备图仅作设计参考，运行接入使用真实装备ID和已验收图谱，“最后一班岗”统一使用现有专用剑图。已检查844×390/3倍密度和932×430横屏、触屏靠近自动拾取、容量不足、连续掉落排队、24秒计时边界及Cocos前后台事件恢复。24秒边界使用现有提示更新器驱动验证，TapTap平台和目标真机表现仍待验证。本次只制作本地Web预览，未打TapTap包、未上传。
