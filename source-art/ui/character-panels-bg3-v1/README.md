## 视觉方向

参考《博德之门 3》人物表、物品栏与法术书的分区和信息层级，结合项目已有暖金方向重新绘制。深棕皮革、旧铜细框、象牙白文字、酒红织物与暖金选中态构成统一视觉；装备稀有度只用小面积颜色区分。

四屏共享顶部导航和底部操作栏。人物页突出拉斐尔的银白卷发与酒红马甲；技能页让出人物展示空间，优先排列技能与配置。强化页明确区分当前阶段上限和装备自身极限，费用与收益同时展示。

官方参考：[Community Update #15: Absolute Frenzy](https://www.baldursgate3.game/news/community-update-15-absolute-frenzy_49)，用于参考其 2022 年早期访问版的界面组织思路，不作为当前版本界面说明。未向生成工具提供官方游戏截图；实际图像输入为本项目角色参考板，以及首张生成稿。
