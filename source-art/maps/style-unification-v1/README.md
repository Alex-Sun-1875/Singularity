## 生成与审阅

只向云端提供一张必要的用户风格参考，通过内置image_gen完成一次生成，没有启动本地模型。提示词请求3072×2048，实际返回1536×1024，按实际输出保留，未放大冒称高分辨率。

九格分别为城镇、草甸、白桦林、湿岸、山口采场、遗迹、生活室内、地下居所和沉钟水道。内部初审认为自然低饱和配色、石木材质、局部暖光和边缘成组细节符合方向，适合用作后续代表样张的制作依据。该结论不替代用户评价或正式地图运行验收。

下一步生产应从P0七个代表区域的局部开始，先导出现有米制布局与通行边界，再制作地面、过渡、墙脚、前景与交互层。用当前角色和镜头验收后，才扩展同地形家族。
