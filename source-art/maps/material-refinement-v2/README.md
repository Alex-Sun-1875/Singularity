## 生成与处理

- 使用云端 OpenAI 内置 `image_gen`，九种最终地表分别生成。没有启动本地模型、CLI 生图或下载依赖。
- [完整提示词、生成来源与淘汰记录](generation.json)。第一次基于旧草地直接编辑的小样仍保留过强斜向枯草纹，未安装；最终九张重新按原材质身份制作。
- [原始输出](raw/)保持原始像素，各为实际 1254×1254 RGB；生成成功与下方美术/实景检查分别记录。
- [准备脚本](../../../tools/model-pipeline/refine_map_materials.py)复用已有 Pillow、numpy 和 `prepare_map_terrain.py` 的导入元数据/对边处理。缩到 512×512，减弱部分大范围亮度漂移，统一各自中间色与对比度，外缘 6px 使用已有对边混合。不是逐区域重新生图或动态光照。
- [处理、尺寸、SHA256、像素边缘与来源记录](processed.json)、[九材质预览](materials-preview.jpg)、[3×3 平铺审阅](tiling/)。边缘像素连续不等于图案完全无缝，固定纹样仍可能在大面积上重复。

## 接入

运行图为 `src/cocos/assets/resources/flat2d/terrain-v1/*-v2.png`，`MapArt.ts` 继续维护原九类材质选择，微调米制采样尺度及环境配色。植被恢复使用原自然色树冠，并仅对 oak/birch/pine 中的绿色像素增加饱和度与亮度，透明度、树干与其他物件像素保护；记录见[树冠处理](processed-foliage.json)。旧九张及旧树冠和原 UUID 保留作对照，TapTap 的 `painted-terrain` 分包通过现有 `excludeFiles` 过滤这些旧图，避免上传两套素材。分包路由保持。

地表采样继续使用 Repeat、线性过滤/线性 mip、4 倍各向异性及项目已有压缩预设；透明树冠沿用 Clamp 和无 mip。九张地表运行 PNG 共 3,714,643 字节；此数字是源图文件量，不是 TapTap 压缩上传包、首包、可玩前下载量或解码内存测量。加载仍由 `MapResources`、公共资源层和原引用计数管理。

室外手绘 Ground、Road、GrassCover 使用同一个世界坐标静态颜色场，23m/11m 的平滑亮度变化与轻微冷暖在建图时烘焙到现有顶点 RGB；道路/草边透明 alpha 保留。分块公共顶点取同一颜色，未改变顶点位置、索引、UV 或碰撞网格，也没有额外地面层、贴图采样、draw call 或逐帧计算。室内不加此颜色场。S01-T1 旅店的独立整图继续保持。
