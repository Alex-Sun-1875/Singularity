# 原3D模型的肤色、发型与服装细化

2026-11-09。用户否决新头部和替换式外衣后，明确要求以原3D模型为底，脸部先不改，只改肤色、发型及服装精细度。当前生产候选据此从上一轮已验收动作源 `3d-motion-tempo-v1/compact-jog.blend` 重新开始；`3d-appearance-v1/v2` 均为否决过程，不能视为当前外观或美术认可。

## 修改边界

- 原头部、眼睛、眉毛的顶点、面、UV与蒙皮权重逐项一致，没有使用此前MakeHuman新脸、脸部雕刻或新脸贴图。肤色只在原生底色上作轻微统一色调平移，保留原通道明暗对比，避免此前提白过度和局部红斑。
- 身体、服装、手、鞋、肩甲、皮带的原网格、UV、蒙皮权重保持一致；没有此前的箱形外衣、腰包、硬立领或改变腿靴形状的改造。
- 发型基于原Quaternius `Hair_SimpleParted`网格，细修上部体积和前额波浪，并用Blender原生一级平滑细分整理线条。没有使用被否决的整块发套或短发贴片帽。原头骨、脸型与五官不动。
- 服装沿用当前酒红、深色袖裤与棕色皮革的基础配色。只在原布料UV区域合成更细的织纹、叶蔓金绣、缝边；皮带、金属扣、皮革、空白区和透明通道受本地遮罩保护。金绣通过确定性的高度梯度近似法线和粗糙度变化补充细节，不冒称新建实体刺绣几何。
- 67节点骨架、65蒙皮骨骼与全部14条动作曲线一致，沿用刚调整好的正常步频、弓弦形变和24武器挂点。

## 云端贴图与本地处理

本轮使用 `imagegen` 技能与内置云端 `image_gen.imagegen` 一次，仅编辑原512×512酒红UV图谱，并提供2D衣料局部参考。完整[提示词](generation-prompt.txt)、[原始生成图](cloth-cloud.png)、[布料遮罩](fabric-composite-mask.png)与[贴图来源/保护记录](texture-provenance.json)保留。实际生成1254×1254，运行图1024×1024；没有声称输出为提示词要求的2048。

Pillow/SciPy只做尺寸配准、原布料区域合成、轻微肤色调整和法线/粗糙度适配。遮罩外像素以同尺寸原图核对一致；不把生成成功或遮罩保护等同于美术通过。没有启动本地生成模型、下载或安装依赖。既有Qwen/ComfyUI资源未改动。

`build.py`复用项目现有Blender原生角色/材质适配与导出能力，`preservation.json`记录原脸、身体和动作保护哈希。`raphael.blend`是编辑源；运行通过Cocos原生glTF加载 `raphael-polish.glb`，原有效FBX保留。此前新FBX曾触发编辑器转换器崩溃，采用引擎原生glTF导入避免该转换步骤；在导出参数中关闭材质节点自动生成的顶点颜色，避免Cocos不支持COLOR_1。没有改用另一套骨架。

## 实机检查

`capture-appearance.cjs`沿用原有Cocos RenderTexture方法，以相同摄像机、灯光和站姿录制前后8个身体方向、5个头部视角；检查13个身体蒙皮部件均有真实网格、14个动作完整、运行异常为0。当前以 `runtime/after/` 为准；模型真实绘制结果与云端UV图谱区分。

复用既有七弓瞄准/飞箭、24件行囊实际换装、走跑/暂停恢复和默认2D收持检查；类型、构建、当前源/构建镜像哈希与结果见 `runtime/final-verification.json`。这不是全部技能/场景碰撞、设备性能或用户美术认可证明。没有新增单元测试、测试依赖，也没有提交、推送或发布游戏。
