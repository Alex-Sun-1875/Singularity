# 3D主角动作节奏调整

后续[原模型的肤色、发型与服装细化](../3d-appearance-v3/README.md)保留本页14条动作曲线与骨架，当前外观改为原脸、原身体模型上的材质/发型细修；本页旧外观动图是当时证据。

## 实际改动

- 正常移速3.6m/s与原生Jog的5.87m/s步幅不匹配，原先为避免滑步把动画降至约0.613倍，完整循环需1.52秒。测量现有脚骨接地阶段的相对速度后，以Blender原生四元数插值收短完整大腿/小腿/脚链的摆幅，根骨只作竖向鞋底对齐；接地段速度适配为3.60m/s，以1倍速循环，周期0.93秒。腾空鞋底间隙缩为原来的0.65，减轻漂浮感。手臂、脊柱、手腕和挂点曲线保持原值；没有IK或独立移动手部。
- 3D主角攻击、翻滚和受击过渡由0.10秒缩短为0.035秒，走跑过渡为0.06秒。NPC的过渡保持原值。
- 普通挥剑保留0.12秒的接触时点，出刃、回势分段采样，在约0.32秒完成原动作；法杖保留0.20秒出手，在约0.50秒完成回势。动作的规则占用时间、伤害与碰撞仍由原GameSession控制。
- 普通拉弓约0.42秒进入完整瞄准姿势，敏捷手套约0.378秒；完整伤害蓄力仍由原0.8/0.72秒玩法时钟决定。松弦回势段压为0.16秒，未蓄满松手的原0.12秒出箭准备保留。弓弦、箭尾及双手按同一源动作时间采样，七把新弓继续使用已校准的Draw映射。
- 受击动画播放速度改为1.25倍，受击规则时间保留。其余技能的专属蓄力/命中时点及走路原曲线保留。

修改位于 `Actors.ts`，原生FBX仅替换 `run/run_staff` 两个动作。`tune-run.py`复用现有已验收Blender角色、原生 `Quaternion.slerp`、FK、求值后的鞋底网格和FBX导出；`compact-jog.blend`为新生产来源，`raphael.fbx`已安装至原资源位置。没有新增引擎、依赖、动画生成服务或下载资源。

## 证据

`stride-measurement.json`记录原步行/跑步实际脚部速度，`stride-adaptation.json`记录步幅参数与鞋底误差。`source-verification.json`确认网格、UV、权重、骨架绑定姿态一致，12个其他源动作逐曲线一致；新跑步的手臂、脊柱、手部和辅助挂点局部通道误差为0。导出仍是13个身体网格、67层级骨骼和14个动作。
