# 现有绘制场景中的3D主角对比 v1

2026-11-09。用户希望简化斜向射箭与连续转身的制作。本轮复用仓库已有原生人物，提供可操作的对比入口：

- [3D主角对比](http://127.0.0.1:7469/?view=2d&player=3d)：原绘制场景、原NPC/敌人，主角使用真实蒙皮模型，可连续转身、任意角度射箭。
- [现有2D入口](http://127.0.0.1:7469/?view=2d)：继续使用已验收的四向主角美术；本轮没有补画八向姿势，也没有修复原上视搭箭图朝左的问题。

两入口共用原有玩法与存档。没有更换默认入口，没有提交、推送或发布。

## 复用与外观

使用已安装的 Cocos Creator 3.8.8 `SkeletalAnimation`、骨骼挂点、原生PBR材质和现有角色预览。模型为现存 Quaternius Base Characters / Fantasy Ranger，65根蒙皮骨骼、67节点骨架、13个蒙皮渲染器；复用11条已接入动作以及 KayKit 弓箭、武器和拉弦形变。原资源、来源哈希和 CC0 许可证见[原生库记录](../../../docs/assets/native-library-runtime.md)。本轮无需下载、安装新依赖或重做骨骼与UV。

3D仍需要覆盖身体的UV贴图，但贴图随模型一起转动，可以在所有视角、动作中复用。这里直接复用全身底色、法线和ORM，只用 Pillow/NumPy 对原UV底色做确定性改色，新增三张512×512底色：银发、酒红躯干与深色袖裤。皮肤、皮革、原法线和粗糙度保留。脚本为 `prepare-textures.py`，来源与输出SHA-256见 `texture-provenance.json`。没有调用本地或云端生成模型。

当前是银发、酒红衣服的风格化3D近似，原生模型的脸型、发型结构和服装轮廓与已验收2D设计有差异，不能视为精确还原或最终美术验收。HUD沿用银发设计头像，行囊展示实际可旋转3D模型。未声称具有完整逐技能专属动作、2D同等背负表现或手机真机性能验收。

## 接入

`Player3DActors`组合现有 `Actors` 主角与省略主角的 `FlatActors`，复用场景和敌方表现。角色朝向读取连续瞄准角，释放后沿权威动作角锁定；移动继续区分输入幅度对应的大步跑与慢行。

原生满拉弓动作中的箭轴相对角色语义朝向偏转约25.369°。在主角manifest中记录 `bowAimYawCorrectionDegrees=-25.3694362`，仅弓动作应用该局部模型校正，其他姿势恢复原模型角度。搭箭和飞箭均从实际挂点衔接，飞箭沿显示轨迹定向；该校正也适用于原生3D基线主角。记录见 `runtime/bow-axis-calibration.json`。

对比入口沿用绘制场景的固定取景和手动滚轮缩放，瞄准/放箭不触发自动缩放或平移。主动冷却、等级、蓄能、伤害、射程和存档格式不因表现入口改变。

## 验证

游戏源码类型检查、既有 `check:core` 和 Cocos web-mobile构建通过，最终普通存档浏览器实按验证了斜射与银发头像。复用已安装 Playwright 和项目原生检查方式进行隔离运行采样，没有新增测试框架或依赖。

| 范围 | 结果与证据 |
| --- | --- |
| 每5°一次，共73次满拉弓转向 | 实际搭箭网格水平朝向误差最大约3.9×10⁻¹⁰°，根节点随连续输入旋转；原动作保留约1.88°俯仰，未将水平误差冒称完整三维轴误差 |
| 9个实际放箭方向，含四斜向与13° | 飞箭方向与实际显示轨迹一致；收招期间改变鼠标方向不转走已释放动作；镜头高度保持稳定 |
| 5场景重建 | S01-T1、S01、S02、H01、U1-04；每处56次跑步和56次慢行采样均正确，原生贴图引用稳定；Lv40和W07保存恢复成功 |

原始数据为 `runtime/report.json`、`runtime/scenes.json`，汇总为 `runtime/verification.json`。隔离采样并非自然通关全97地点。`runtime/rotation.gif`是8个采样视角组成的预览，不能用它代替连续转向数值检查。普通存档实按截图为 `runtime/ordinary-diagonal.png`；`runtime/aim-contact.jpg`供放大检查八个代表视角。

2026-11-09 按用户要求新增[实际动作动图](runtime/player-3d-turn-and-shoot.gif)：181帧、20fps、9.05秒循环，包含完整360°连续转身，以及45°右上/225°左下拉弓与放箭；射箭段以约2/3速度慢放。由 `capture-animation.cjs`从当前Cocos构建的独立试玩配置逐帧采集实际蒙皮模型和飞箭，`assemble-animation.py`仅缩放、加字幕并编码GIF。没有生成新动作或改游戏代码，未操作用户存档。逐帧来源与时长见 `runtime/animation/frames.json`；640×657输出约3.19MiB，代表转向/释放帧已目视检查，运行页面错误为0。
