# Qwen v2 游戏图集接入

复用上一阶段已经实际执行的本地 Qwen 遮罩补绘结果。接入脚本使用现有 Pillow、NumPy、SciPy 和 ICC-Lab 校色工具适配其余相位；不是把52帧重新交给模型生成，也没有调用云端生图、下载模型或新增依赖。

`install.py` 默认只计算候选与缩略图；`--install` 直接覆盖当前4张探索图集及 manifest 的3个探索动作记录，不另存原件、before 文件或回退副本。历史素材和已有模型运行记录不在此次删除范围内。重复安装同一修订会拒绝执行，防止剑长和腿部变换叠加。

范围是 `explore_idle_W01` 的4帧、`explore_walk_W01` 的16帧、`explore_run_W01` 的32帧。保留方向、速度、fps、循环相位、每相位原支撑/腾空锚点、世界像素尺度、原图集尺寸与 `.meta`；持剑和其他动作保持其原来的姿势语义。

打包按每帧原语义裁切和独立透明工作域处理，不能按名义网格读取邻帧：现有侧跑3处有效像素跨网格线。所有新帧独立计算alpha16裁切并留AA边，核验其裁切内不含其他相位的alpha16像素；再用二值支持域复制RGBA，避免把半透明边缘alpha乘两遍。

- 站姿背面、正跑p0和背跑p0直接采用本轮已审查的最终候选。
- 其余正背跑相位分别保护各自的手、靴、武器，调整衣料与腿部投影比例。
- 背向站姿/行走/跑步的剑分别定位原鞘与原帽；延长中段，原帽仅整数平移。
- 各运动相位按同向站姿校准背心、袖布和裤料，排除手、皮靴、金线、装备及透明边界。
- 侧跑p4代表图使用过旧裁切范围；只映回衣料修改并补偿裁切偏移，不整帧替换，不修改当前脚锚。

`installation-report.json` 记录实际安装的文件校验、相位几何与适配过程；`runtime-assets-report.json` 在构建后从游戏实际加载的 manifest 和纹理核对，而不仅检查源目录。`walk-cycle-review.jpg`、`run-cycle-review.jpg` 是处理后循环的小型视检表。

验证复用项目现有 `npm run check`、Cocos构建及 `locomotion-alignment-v1/capture-transition.cjs`。后者通过正常移动/攻击驱动探索与持剑切换，检查实际采样动作和材质。捕获是验证产物，不是原件备份。

扁平图中的材料与装备遮罩依然属于局部估计；数值保护、颜色中位数和程序检查不能代替游戏中的美术验收。必要的云端视觉检查仅使用小型循环表和局部，不发送完整源图集进行生成。
