# 图三挥剑模型统一 v5

2026-11-08，用户指定本次图三（`attack_sword_W01` phase0，竖剑准备姿势）为当前主角外观基准，并补充要求检查腿部大小。此要求取代此前“静立头身作为基准”的方向。

检查范围是当前主角 88 个动作配置、69 张共用图集、996 个独立物理帧，覆盖七种装备的探索/持用待机、行走、跑步、攻击、施法、互动、闪避、受击和倒地。不同 NPC 的身份设计不复制成主角。

## 发现的问题

- 探索待机、部分持用待机及特殊动作仍有短平下摆、小腰包或缺失腰包，挥剑却有长分片衣摆、高腰带、完整翻盖包与小瓶。
- 旧 v4 将躯干与大小腿总长度合并校准，不能保证股骨、胫骨分别一致；头身总高接近时，腿长、腿宽和靴筒仍会变化。
- 相同图像/物理帧的别名没有运行时几何冲突；问题来自独立绘图和旧比例约束，保持原战斗状态机。

## 资源与本地处理

`prepare_v5.py` 整理原文件哈希、全部物理帧、188 个衣型问题帧，以及既有 MediaPipe 测量到当前裁切的坐标映射。旧测量是代理数据，不是艺术骨架真值；区分原生像素位置与旧世界位置投影，倒地按完整裁切处理。

`static_edits.py` 以图三的头颈、腰带腰包、裤腿和靴子原像素建立放下手臂的待机候选。七装备全部探索/持用待机共 56 帧共用同一身体设计，保留装备身份、握持手臂和语义脚锚。`static_gear.py` 用完整几何区域保留深色剑身、杖杆、弓与弓弦，不能只保留材质高光。

`dynamic_edits.py` 对另外 148 个衣型问题帧，复用同方向、同相位且衣型已正确的现有动作局部。只接入腰带、腰包和分片衣摆，保护头、手、装备及原腿部；腿部校正随后单独叠加。源箭筒及其端帽单独剔除，最终倒地使用宽画布逐项检查。

`legs_edits.py` 单独约束股骨、胫骨与腿宽，使用既有三维姿态估计补偿投影，固定脚/踝与原接地或腾空关系，回算膝部；最终使用已有 SciPy Delaunay 连续逆向网格一次变形，检查三角不翻转。头胸、完整袖臂手、衣摆和装备作为唯一刚性前景，腿部源层排除这些区域，接触边界共用实际位移；上半身保持形状并作共同平移。靴筒沿小腿轴局部对齐。屈膝、迈步和投影缩短不会被当作整个人变矮处理。低可靠测量和限制幅度在报告里单列，估计器自身的数值一致不能代替视检。

最终同镜头实机复核发现：动作族中值校准也改变了作为基准的准备帧，使待机裤腿仍稍细。因此 `pin_reference.py` 将基准本身设为不可变：从原始 v4 候选（manifest SHA-256 `524da53186a5a4512a47c284a599100364c379ca696aa5e96be07f35c9284398`）取回四向 W01 phase0 的完整原像素、脚锚和世界像素密度；phase3 收招返回同一准备姿势。56 个静态待机沿用已修复衣缝和完整手指的中立母版，其裤靴直接来自同一基准，跳过动作族腿部变形。共锁定64帧，其他932帧保留连续网格校正。锁定后再执行保守头缘清理及重新打包；详见 `reference-lock-report.json`、`art-acceptance.json`。

`assemble.py` 合并局部编辑；`pack.py` 更新所有共用别名的裁切/原点，保留有效像素世界尺度和现有 meta/UUID。未改帧以原像素独立打包，保护相邻帧不混入裁切。候选与安装记录分开；直接覆盖已授权资源，不增加原件全图集备份。
