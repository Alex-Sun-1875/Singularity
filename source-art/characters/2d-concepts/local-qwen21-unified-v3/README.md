## 图集接入

`batch.py` 复用上一轮的语义帧打包工具。先生成 `candidate-runtime/` 的完整新资源和manifest，检查每帧完整alpha16裁切不混入其他相位。旧图集部分角色跨名义网格，不能按固定cell截断；换头后空间不足时，仅移动图集内坐标并增加透明间隔/外边，不缩放人物。相应裁切和origin一起更新，保持世界脚锚与接触/腾空差异。二值支持域复制RGBA，避免alpha被乘两遍。
