# 手部局部审计

此目录仅保存本地 Pillow / NumPy / SciPy 像素审计。未调用模型、网络或图像查看工具；未修改输入、现有候选或 `finalize-candidates.py`。四个候选均由现有脚本的函数及合成步骤在内存中精确复现，输出逐像素相同。本审计不是视觉验收。

**后续局部视觉复核纠正：** Root 实际查看 8 区 before/current 对比后，确认 run-back 屏幕右侧 `[228,263,260,330]` 是背心与斜剑鞘，没有可见手；原色彩分类为假阳性。JSON 已标记 `not_visible_or_false_positive`、`restore_enabled=false`，所有可执行保护/清理框置空，原始数值移到 `rejected_skin_candidate` 保留为误判证据。**不能把 `[208,240,280,356]` 整块当右手复原；run-back 仅恢复屏幕左手。** 其余 7 个肤色核心经 Root 视觉复核对应实际手部。

`hand-regions.json` 的坐标为 **512×768 原图 XY，右下端点不包含**。`original_skin_core_box` 是肤色证据核心，`source_protection_box` 包含指尖、腕部和边缘上下文；`union_erase_box` 覆盖 before、guide、当前 constrained-candidate 中的手部位置。raw-model 的独有移位只保留诊断，不计入当前需要清除的包络。

## 已定位原因

- `long_leg_guide` 缩放整个 y210..420 横带，躯干、手、腕同时被压缩。run-front 左掌的亮肤色核心从 y290..339 移到 y278..319。现有左侧保护多边形约止于 x229..237，手掌达到 x263，因此最终混合原手与压缩手。
- run-back 原判为“抬起暗肤色手”的区域经 Root 局部视觉复核实为背心与斜剑鞘；y263..330 到 y255..312 的数字反映暖色服装/装备的缩放，不能据此恢复手部。原保守包络已撤销，只作为分类误判证据保留。
- `palette_lock` 在原手/原臂保护合成之后执行。wine gate 的低色相条件同时覆盖大部分肤色，且 `.8px` 高斯羽化外溢。run-front 已保护区域后来仍有 19,467 像素改变（最大 RGB 通道差 7）；run-back 有 17,782 像素改变（最大差 12）。因此必须在所有调色和 RGB/Lab 转换完成后，最后复原手与必要上下文。
- clothing-side 原排除椭圆 `(170,302,215,351)` 未覆盖左掌完整位置 x195..244,y326..381。左手亮肤色核心 570 像素改变，最大通道差 28。右手当前保持不变。
- sword-back 新鞘局部模型合成覆盖左手，核心变化 84 像素、变化包围框 `[166,402,181,430]`，最大通道差 90。右手保持不变。新鞘穿过左手包络，不能把整个灰底矩形直接盖回去；需使用原始手/腕的前景遮挡关系，保留指间背景及新鞘可见部分。
- run-back raw-model 另有 x157..190,y285..317 暖肤色高举部件，但它未进入当前最终候选，不需要把该 raw-only 位置算入当前清理范围。

## 文件和边界

- `hand-contactsheet.jpg` 为 704×1158 的局部标注对比。四列是 before / guide / raw-model / constrained-candidate。青色标记亮暖色候选边界，稀疏黄色显示任意通道发生变化的像素；它们不是最终保护蒙版。
- 最后一行 run-back / screen-right 是已否决的暖色材料候选，不能据图中原标注当作手部。按 Root 要求，原标注图与审计脚本保持不动；JSON 与本说明记录后续语义纠正。重新运行初版脚本不会自动包含这项纠正。
- `*-all-changes.png` 是所有变化像素的精确二值图，任意 RGB 通道差大于零即置白，没有忽略轻微变化。JSON 同时记录差超过 8 的像素数和最大差。
- 肤色统计限制在 y230..469，使用 8 连通域、RGB 色差、HSV 色相/饱和度及局部手部窗口，排除头部、灰底并减少金线干扰。暖皮革仍可能通过色彩门限，尤其是剑左手与背面抬手；肤色计数不能等同于解剖学手部面积。
- before 是灰底 RGB。若把它再次用软 alpha 混合，可能重复混灰；亚像素边缘应复用原始前景颜色与 alpha，或明确采用保守原像素支撑。剑左手的原 alpha=0 指缝要留给新鞘。
- 复原完成后应核对保护区与 before 的 RGB 一致性，并检查包络外是否仍残留被压缩的旧手轮廓。整个包络直接恢复 before 会回退少量袖口/躯干上下文，这是保证完整手形的取舍；剑左手必须按遮挡关系处理。
