## 具体纠正

1. **剑鞘末端**：旧线段提取偏离真实鞘轴，且在(200,373)过早截止，导致原帽先被截平、再被模型改变。现在完整提取原帽，仅做整数平移(-31,+65)，保持原长宽、角度与覆盖轮廓，延长中段。完整原帽的484个覆盖像素及RGBA均与平移后的图层相同；金属帽可见末端由约(198.016,380.206)移到(167.016,445.206)。手指按原前景alpha遮挡剑鞘，指缝允许新鞘显露；抗锯齿边缘先去除旧灰底再合成，避免白边。
2. **手部**：旧比例引导压缩整条躯干横带，正跑保护多边形漏了半只拳头；后续衣色门限还把部分肤色当酒红布料。现于所有校色之后恢复完整原手、腕部与原图上下文，并清理已进入候选的错位旧轮廓。保护实心手部像素逐像素相等，头部不变。背跑中心暖色区域经视觉核实是衣料/剑鞘，已撤销肤色算法的假阳性保护。
3. **裤子**：此前只约束衣身和袖色，腿部生成像素的裤色遗漏。现在以对应方向站姿裤料为基准做保褶皱、保阴影的分区ICC Lab校准。侧跑Lab8亮度中位数124→97（站姿97），正跑90→95（站姿95），背跑104→103（站姿104）；a/b色调亦对齐。靴子、手、衣摆、腰带排除在裤料范围之外。不同姿态的局部阴影和高光仍可不同，不声称像素色值逐点相同。
