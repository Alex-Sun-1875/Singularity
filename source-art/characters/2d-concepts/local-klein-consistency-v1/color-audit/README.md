# Raphael W01 站立／跑步服装颜色审计

此项只读取当前 manifest、三张源 PNG、运行副本、纹理 `.meta` 与既有导入脚本；未调用网络、模型、图片上传或视觉预览，未重绘、调色或改动正式素材。四向站立各 1 帧、跑步各 8 帧，共 36 个帧记录。结果用于定位和本地小样，**不是美术验收**。

## 结论

当前差异已经存在于源图 RGB。跑步 B（第 4–7 相位）四向红衣胸腹候选的 L* 比各自站姿高 **7.8–10.6**，饱和度低 **4.9–6.3 个百分点**；袖区候选的 L* 高 **9.2–16.3**。跑步 A 红衣变化为 **−0.4 至 +4.9 L***，袖区背向差异较大。扩宽 ROI 后，B 的红衣与袖区仍全部更亮，方向不变。

没有发现按动作设置的 gamma、材质 tint、混合模式差异。三张源图与各自运行副本 SHA256 一致；全部没有 `gAMA`、`sRGB`、`iCCP`、`cHRM` 块；纹理导入参数相同。`FlatActors.ts` 使用共享的 `builtin-unlit` 路径及白色 `mainColor`，动作切换改变图集、网格和 UPP；相同根级 alphaThreshold 为 16/255，edgeWidth 为 0.008。袖区测量只取 alpha>=250 且向内腐蚀 2px 的区域，透明边缘与轮廓描边不足以解释这些内部色差。

站姿 UPP = `0.003191794871794872`；跑步 UPP = `0.0043342618384401115`。UPP 影响显示尺寸和采样密度，不修改源像素颜色。没有运行引擎渲染验证，因此这里的管线结论限于源码、元数据与 PNG 证据。

## ROI、误差与复现资料

- `audit.json` 保存 36 帧统计、每相位 RGB/Lab 分位数、HSV、样本数、宽 ROI 敏感性、源图/运行图 SHA、导入设置、保护文件前后哈希。`roi-config.json` 保存全部裁切及绝对 atlas ROI 坐标。
- 坐标基于当前 manifest 的 `perFrameRects` / `frameRectsByImage`。红衣取裁切高度的 20%–56%，袖候选取 17%–48%，横向取整帧；它们是胸腹／上臂的几何带，**不是手工描出的语义遮罩**。
- 先要求 alpha>=250，再用现有 SciPy 默认十字邻域腐蚀两次；红衣按 H∈[345,360)∪[0,15]、S=22%–80%、V=10%–86%、R>=B+5 筛选；袖候选按 B>=R+2、B>=G+2、S=1.5%–40%、V=10%–70.6% 筛选。
- Pillow ImageCms 按 sRGB 转 Lab D50。PNG 未内嵌色彩空间，sRGB 是明确记录的测量假设；8bit Lab 量化精度约 0.4 L* 和 1 a*/b*。
- 阴影、皮革带、金属肩甲、武器遮挡、跑动褶皱与相位姿态影响分布。袖区尤其可能混入冷灰金属，B 的低色度筛选会减少样本量；因此将其命名为候选。不可把这里的 ROI、颜色阈值或 ΔE 直接用作自动修图／合成遮罩或验收门槛。
- 扩宽 ROI：红衣 16%–60%、袖区 15%–60%；B 红衣所有相位/方向的 ΔL* 仍约 +7.5 至 +10.2，袖区仍约 +8.2 至 +18.0。A 的侧面/背面数值更受姿态和遮挡影响。

## 给本地 Klein 小样的建议

1. 以当前 `W01-explore-idle.png` 对应方向的原始衣身／袖区作为颜色权威。先选跑步 B 正面单帧，提供同方向站姿胸腹与两袖局部，加当前跑姿待改局部；保持原有阴影/纹理/褶皱，提示“精确匹配参考的暗、低饱和酒红皮革衣身及低饱和蓝灰袖，不提高曝光”。RGB 中位数用于复核，不作为整片平涂值。
2. 衣身和袖子使用独立的语义局部遮罩，只覆盖确需修复的布料/皮革。脸、头发、手、腰带、包、肩甲、武器、腿、透明轮廓和脚锚全部保留当前源图。胸腹颜色遮罩应避开背剑/肩带；剑长处理应另用剑的遮罩，避免一次模型编辑同时改变身体。
3. 本地模型输出只是候选：放回同一源像素坐标和尺寸，使用经本地确认的语义遮罩合成，必要时只在布料内部羽化约 1–3 个原生像素。当前数值 ROI 太宽且颜色阈值会形成孔洞，不能拿来替代语义合成遮罩。
4. 冻结参考、工作流、种子、尺寸与局部光照描述。单帧通过后再扩展同方向/相位；每个方向用自己的站姿参考。核对合成遮罩外 RGBA 完全相同，并复测同样 ROI 的 L*/色度分布；还需本地查看材质、身份、动作、装备边缘与跨帧连续性，指标通过不能替代美术验收。
