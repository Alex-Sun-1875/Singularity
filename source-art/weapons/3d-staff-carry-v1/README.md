# 法杖背负贴合修正

用户截图中的法杖在跑步时悬在身体后侧。实际 Cocos 场景复现确认：现有挂点能正常随骨骼运动，但六款法杖共用的侧向、后向偏移过大。

另外，初始持剑选择实时动画时，`sample()` 先写入引擎的延迟混合缓冲，原先立即读取挂点矩阵会拿到尚未更新的参考姿势。现改为校准期间短暂使用烘焙待机帧，固定背负参考矩阵后恢复原动画模式；继续复用 Cocos 公共动画与挂点 API，不在逐帧更新中增加模式切换。

按用户明确要求，法杖与剑一样从肩部斜向对侧腰部背负。复用现有 `SkeletalAnimation.createSocket` 和 `spine_03` 挂点，六款法杖沿用已校准[背剑](../3d-sword-carry-v2/calibration.json)的同一斜线；法杖正轴指向杖头，因此轴向取背剑刃方向的反向。W11 中心设为 `[0,1.34,-0.202]`，其余较长的 W12、W13、W14、DR2-03、DU1-04 设为 `[0.06,1.23,-0.192]`，避免原有直立侧挂的悬空观感。尺寸、模型及手持参数沿用原配置。候选位置参照既有衣服表面数据，并在实际 Cocos 场景中对照待机与跑动视图。

[校准数据](calibration.json)经[公共导出适配器](../../../tools/model-pipeline/weapon_carry_calibration.py)应用到运行清单与当前人物源清单，人物或武器重新导出时保留本次调整。复用现有 Cocos 网格与材质，无图片生成、新增依赖或资源下载。

构建与画面检查结果记录在 `src/cocos/release/staff-carry-validation.json`；85 次状态与角度检查、25 张独立截图位于 `src/cocos/test-results/staff-carry/diagonal/`，覆盖六款法杖待机、行走、跑步、实时施法、收回、换地图保留角色与全新持杖载入。背剑、双手剑与背弓的参考位置回归通过。
