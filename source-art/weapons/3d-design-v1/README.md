## 制作与复用

先检查项目已安装Blender 4.5.15、Cocos Creator 3.8.8、已有导出/UV/材质恢复脚本及资源库。现有通用道具与新设计的刃形、鹿角、镂空弓臂、月牙和杖头差异较大，无法仅靠换色还原，因此新增轮廓和局部结构；不另写三角化、曲线填充、形变或FBX转换器。

`prepare.py`使用已安装Pillow、SciPy、contourpy和Matplotlib进行确定性测量、朝向整理、轮廓提取和贴图适配。原2D图像没有覆盖或重绘。Blender原生封闭曲线填充、挤出、倒角、圆截面曲线、加权法线、切面宝石和局部实体结构组成网格：剑刃与护手有实际厚度；握柄与杖杆为圆截面；灰木杖为立体枝叉，灰烬杖为开放灯笼笼架，沉钟杖为中空钟体，冷焰杖为开放晶石架。2D雕纹复用为表面颜色、微表面法线和粗糙度近似，不冒称每条雕花都重新雕成几何或使用了扫描PBR材质。

用 `build.py`保存来源和FBX；`verify-export.py`直接复用已有 `cocos_v5_weapon_redesign.py` 的FBX往返检查，并导出GLB。官方组件机制见[Blender几何与倒角](https://docs.blender.org/manual/en/latest/modeling/curves/properties/geometry.html)、[原生对象/形态键操作](https://docs.blender.org/api/current/bpy.ops.object.html)。没有下载、安装依赖或调用生成模型。

Cocos继续使用现有 `NativeActorMaterials` 恢复PBR。新道具在原绘制场景的无环境反射照明下以0.5的金属度系数保留银雕与纹理可读性；GLB保留制作场景的源材质。边缘木纹/皮革复用项目已有图像，主表面来自对应2D设计，微表面图是该图像的确定性近似，不是新生成美术。

## 握持、弓弦与背负

所有模型原点统一为实际圆形握持截面的中心，继续挂在原手掌或作者的弓箭辅助骨骼上。保留已经修复的完整肩、肘、腕动作及箭轴校准，没有平移角色手腕、重做身体FBX或引入IK。

新弓臂使用Blender原生Surface Deform继承既有Bow Draw形变。旧FBX有硬边重复顶点，直接按松散部分分离会破坏形态数据；最终使用NumPy坐标归并与SciPy连通分量提取包含实际弦扣的原弦网格，保留其拓扑和Draw数据。弦端通过Blender原生BVH贴到新弓梢，静止弦扣重定位到新弓弦的直线位置；逐件仿射映射Draw权重，使拉弦阶段的弦扣继续跟随现有手指与箭尾轨迹，释放后回到新弓的静止位置。`stock-string.json`、模板和 `models/*-string-contact.json`记录制作来源与端点；最终运行校准以 `models/*-draw-calibration.json`为准，七件中部轨迹的计算误差不超过1.12e-16米。源网格只有Draw一个有效形变目标，不用贴图弦代替真实拉弦。

背负沿用实际待机姿态校准的 `spine_03` 挂点。刃器使用新模型的原尺寸剑柄和相应剑鞘；战锤整件背负；弓、杖也按对应2D家族位置背负。W07/L02弓在一侧、箭筒在另一侧，W08方向相反；其余同类装备沿用相应家族规则。弓进入手持后箭筒继续留背上。共享原2D收持状态逻辑，转身不拔武器，探索翻滚不切持握，攻击结束后延续原有2秒表现时间再背负；本轮未增加拔剑/插鞘的专属伸手动作。

灰木短杖W11收短为1.02米，匹配2D短杖设计及背负比例。六件法杖背负时使用共用空手待机/走跑，持握时使用原持杖动作，避免杖已经收起、空手仍举着；行囊预览也按实际收持状态选择待机。

暂停换装会先同步实际演员，再创建行囊预览；预览武器类别改为读取装备目录，新增弓/杖不再被误当成剑。弓的效果出口继续取原箭辅助挂点，其他武器取原手掌，避免新增背负挂点影响发射位置。

## 验证与证据

- `geometry-review.json`：24件FBX往返通过，网格、UV、Draw目标保留；同时输出24件GLB。
- `install-record.json`：实际安装路径、FBX哈希、三角形数、纹理数量与身体FBX哈希。
- `runtime/report.json`：真实Cocos构建、隔离浏览器与GameSession指令，24件×4方向共96个背负视图，24件×58帧共1392个攻击/释放/回势样本。逐帧检查正确家族、仅一组可见武器、挂点误差、弓的箭筒与其他类别无箭筒；最后均返回背负。页面错误与失败请求为0。
- `runtime/gallery/`：真实Cocos RenderTexture的各模型12个旋转视角；不是概念图或贴图冒充的旋转。
- `runtime/all-bows-review.json`：七件弓共56个角度采样、七次放箭及301段飞行方向检查；水平搭箭偏差低于2.55e-14度，飞行方向偏差低于0.00000121度。保留原动作的纵向俯仰，不冒称所有姿态的完整三维轴线零误差。
- `runtime/inventory-review.json`：实际行囊点击24件换装，均显示对应模型、13个身体蒙皮部件和单个预览场景；六件背负法杖使用空手待机，手持法杖使用原持物待机，关闭后无残留预览场景。默认2D收持回归见 `runtime/flat-regression.json`。
- `runtime/final-verification.json`：最终类型检查、构建、源资源/镜像构建一致性与以上证据汇总。F盘Cocos启动时偶发无法写入引擎设置文件，因此最终使用C盘临时目录的真实源资源副本、原有依赖和原 `Build-Local.ps1` 完成web-mobile构建，再复制回7469原试玩目录；没有使用此前缺类的失败镜像构建。
- 运行验证仍按实际记录限定范围，不声称已经完成所有武器、所有技能、所有场景的碰撞或手机性能验收。
