# 雷系原稿轮廓动态审稿

本轮继续对齐用户指定的首版 2D 雷系原稿，覆盖主弧轮廓、粗细起伏、长分叉、白亮核心与蓝紫外光、施法手连接和立体电网。

按用户随后提出的“太粗了一点”，出手主弧基础宽度从 0.652 收到 0.510，目标间主弧从 0.452 收到 0.350，约收细 22%。原稿宽度起伏的最高倍率从 1.60 压到 1.35，减少局部过粗的鼓包。细分叉和电光纹理沿用本轮来源。对照动画左侧为刚才的粗稿，右侧为收细稿。

[三招原速对照](media/previous-vs-revised.mp4) · [本轮单画面动画](media/revised-full-size.mp4) · [雷网动图](media/thunder-comparison.gif) · [原稿对照板](media/reference-comparison.jpg)

主弧直接从原稿白亮核心的像素中提取，使用 65 个轮廓采样与 65 个粗细采样。长回弧和向外延伸的分叉分别提取 49 个采样。提取来源、原图指纹和坐标保存在 [reference-profile.json](reference-profile.json)，定位示意见 [reference-trace.png](reference-trace.png)。金色标记主弧，青色标记两条长分叉，标记只用于来源核查。

内部白芯、相邻细丝和蓝紫晕光也从同一原稿中提取，沿主弧展开为 [电光纹理](approved-thunder-strip.png)。处理仅包含像素采样、石地背景估计与减除、白热核心中性化和边缘渐隐。纹理用在原有网格池的 UV 上，随真实 3D 电弧转向与缩放。黑色区域是加法发光的零能量区域。

这些轮廓映射到当前 Cocos 的实际施法手和既有连锁路径。终极雷网从施法手连接到当前图中的首个落点，沿用已经解析出的目标和连锁关系。手部连接随当前骨骼动作更新。现有 `ThunderArcField` 动态网格池继续负责电弧，外侧采用渐隐发光截面，命中光沿用现有的 `ThunderContactLights`。

录制保留实际 3D 模型、现有施法动作、场景、时间步与真实战斗事件。比较收细前后的贯雷长矛、连锁雷弧、万钧雷潮，核对全部事件、伤害、目标、判定几何和机位。每招包含完整的蓄力、出手、连接、命中和消退过程。

原稿是较暗的石地，当前审稿使用当前游戏的较亮 S04 地面，两者在对照板上分别标注。审稿图片保留真实场景输出，没有调暗场景或在录制帧上后画闪电。GIF 为电弧颜色单独保留调色板，避免颜色在压缩后被地面挤掉。

当前产物是设计动画，本目录的审稿脚本只在录制响应中替换呈现模块。用户美术确认与正式接入分别记录。正式接入时另做 TapTap 真机效果和性能验收。法阵规则仍为陨石 `FIR_02` 专用。

来源、录制输入和媒体验证见 [provenance.json](provenance.json)。
