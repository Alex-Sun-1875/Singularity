# 统一护盾：脚部包覆修正

用户反馈：“应该把脚包进去”。本轮直接修正已接入的四系共用护罩，不重新生成美术素材。

原中心高 1.16、壳高 2.36，底部尖端接近脚底，脚边的横向空间不足。中心改为 1.00、壳高 2.68，保持上沿 2.34 的高度和原 1.88 的宽度，让脚底附近拥有足够的半径。主角锚点、护罩中心高度和预热位置共用同一个常量；透明度、纹样、颜色、动画时长及玩法数值保持原方案。

本轮以 Cocos 正常 test Web 构建录制：四系站立对照，以及火系实际施法后的真实行走。弓系和雷系沿用先前的已有护盾状态外观检查，不新增主动技能。行走输入进入原生移动与动画流程，未合成脚部、护盾或地面图像。

每帧采样原生角色的脚部／脚趾骨骼世界位置，用实际椭球变换计算包覆关系；同时查看真实画面中的鞋底轮廓。骨骼点检查不单独冒充整只鞋子的美术验收。类型检查、Web 构建、运行错误和骨骼点结果分别记录于 `verification.json`，TapTap 真机未在本轮测试。
