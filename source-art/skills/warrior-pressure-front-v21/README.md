本轮只修改 `warrior-pressure-wave-v2.effect` 中两行波峰参数：宽度约为上版的1.56–1.66倍，波峰密度系数从0.70调至0.78，并向内调整波峰中心，让加厚后的外缘仍保持柔和。颜色、透明度上限0.82、流动密度、疏松尾流、局部侵蚀及消散时序保持原值；没有增加金属明暗、倒角或实体表面。

已将修改后的波峰参数还原再逐字比较，确认其余材质文本与v20相同。三招实录中每一帧的流动时间与消散状态均与v20一致，见[调整与保留记录](front-adjustment.json)。范围、伤害、段数、冷却、动作、护盾技能及护盾被动未改。

默认test Web预览重新构建通过。核对了实际加载的EffectAsset中的新波峰参数，避免仅凭JS哈希判断材质是否更新；普通地面和深色靶场均已检查。八项技能录制无页面／控制台错误和资源池溢出，实际命中及暂停恢复沿用原结果；护盾代码、材质、纹样哈希与保留记录一致。

两份视频均完整解码为195帧、30fps、6.5秒，三份GIF保留所有实际帧。录制来自未修改的编译产物快照，没有模块、纹理或人物动作替换。材质运行记录：[靶场](runtime-shader-training.json)、[普通地面](runtime-shader-field.json)；事件和媒体哈希见[溯源](provenance.json)。

本轮没有TypeScript、规则或数值修改，未重复运行既有规则测试。未制作TapTap ZIP、未升版或上传；TapTap目标真机不在本轮验证范围。
