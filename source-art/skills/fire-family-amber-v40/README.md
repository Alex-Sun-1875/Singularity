# C 琥珀金焰：整套火系接入 v40

用户于 2026-11-17 选择 [v39 的 C 方案](../fire-family-colour-options-v39/selection.json)，并强调四个普通技能颜色对齐。本轮将赤焰枪、烈焰喷流、焰心护盾、焚焰火域与陨星天坠接入同一组暗琥珀、橙、金黄与浅黄亮芯；技能图标沿用既有原色和身份。

统一来源为 [palette.json](palette.json)，取自已选择的 C 色阶：`#9B3D07 / #D95C06 / #F98A0B / #FFC544 / #FFF7A1`。`install_palette.py` 复用 Pillow／NumPy 对当前实际引用的 10 张纹理做确定性 RGB 映射，按整张图集的加权亮度分布映射到同一色阶，不逐帧独立拉伸；源纹理、候选结果和哈希分别保留。所有尺寸与 alpha 通道逐字节不变，包括 v38 已加密的火域和已有陨石法阵的通透底光。未新增生成图片、纹理、灯光、火苗节点或纹理采样。

运行公共颜色为 `src/cocos/assets/scripts/shared/assets/FirePalette.ts`。火焰、余烬、亮核及火系细线使用同一公共配置；喷流法阵去掉旧的偏黄逐通道补偿，底光由公共琥珀低色和火身色生成。火系护盾使用同一显示色阶，保留原透明度、两面绘制、脚部包覆、击中纹波和解散；其他职业保持原有颜色输出分支。生成脚本维护纹理与 shader 中的同源参数，记录见 [provenance.json](provenance.json)。

## 实际运行验证

- [整套 C 实景](native-C-kit.png)：原始画布仅裁切、缩放和排版，未对录制画面校色。
- [实景前后对照](native-before-after.png)：每招使用同一机位、同一帧比较。
- [详细验证](verification.json)：空地与五靶各 5 招，共 10 段、每段 8 秒。每段的技能事件、火焰／地面／护盾状态、几何与冷却逐帧完全一致，结束无残留；群靶原生结果为火枪 7 次／279 伤害、喷流 8 次／368、护盾 0／0、火域 20 次／692、陨石 5 次／1525，前后相同。这是固定独立靶场的本轮记录，不改写之前不同施放顺序的数值记录。
- 原正常旅程从 1 级开始，进入既有临时 80 级技能靶场，原成长和装备保留；没有向正常旅程写入靶场加速。录像使用冻结构建，源码目录后续更新不会替换正在录制的资源。
- 10 张实际导出纹理均与生产纹理逐像素相同，尺寸及 alpha 与原件逐字节相同；没有额外 GPU 绘制对象或采样。全场计数包含原生粒子，逐帧／峰值差异以验证记录为准，不据此宣称手机帧时间、耗电或温升通过。
- 类型检查、181 项现有测试、正常 test Web 导出通过。构建副本逐文件校验见 [snapshot.json](snapshot.json)。本次没有制作或上传 TapTap 包，没有递增版本。
