# 战士纵横交错动态稿

**2026-11-16 用户已否定此稿，要求完全重新设计并停用本效果。此目录仅作历史存档，不作为后续视觉或接入依据。**

基于当前 Cocos 3D 角色、骨骼动作、钢刃纹理与原有技能事件制作。将本轮“纵横交错、可以同时展现”解释为两个切割平面有先后、有共存时间。横斩先展开，纵劈稍后切入，两道刀面在命中区域短暂交汇，随后分层收尾。

[完整原速动画](media/warrior-cross-motion.mp4) · [上一稿与本轮同机位对照](media/warrior-cross-comparison.mp4) · [普攻动图](media/warrior-combo.gif) · [突进十字斩动图](media/warrior-cross.gif) · [截帧总览](media/crossed-cuts-overview.jpg)

| 动作 | 设计重点 |
| --- | --- |
| 普攻三连 | 横刃先到，纵刃随后切入，保留短暂的双平面共存。第二次反向挥砍，第三次突出纵向收尾。 |
| 断空斩 | 沿用现有两次挥剑，让前一道残影与后一道刀面衔接。 |
| 破军突袭 | 沿用实际突进终点，在命中区形成胸线横斩与向下纵劈。 |
| 裂地审判 | 保留现有落刃与触地裂纹，落地时补充短促横向冲击。 |
| 破晓裁决 | 三段交错，横向余刃与末段纵向重劈共同完成收尾。 |

沿用现有银金钢刃图像，通过刀身暖金中间调、银亮刃线、较宽的刀面和前后平面区分体积。横刃与纵刃错开约 25–50 毫秒起势，保持短暂共存。实际持续时间和同帧共存记录见 [provenance.json](provenance.json)。战士不使用装饰法阵，双层纹样法阵仍仅用于陨石。

本目录是动态设计候选，尚待用户美术审阅。候选模块只由 `capture.cjs` 在本机临时审稿服务的响应中替换。对照左侧是上一轮 v4 的刀面纵深稿，右侧为本轮纵横交错稿，两边使用同一份冻结 Web 导出、同一靶位与斜向机位。

复用项目现有 Playwright、TypeScript、Cocos 网格与材质。逻辑和骨骼按 60 Hz 推进，以 30 fps 原速输出。逐招核对完整战斗事件、命中对象、伤害、判定范围、靶位、骨骼和相机，同时登记双平面共存帧。媒体由 Pillow 与 PyAV 确定性排版编码，未新增生成图像。当前记录属于本机 HTML 设计审稿，TapTap 真机性能需在正式接入后验证。
