# 陨石法阵与地火统一色系 v36

用户反馈：v35r2法阵的底光和光晕过红，应与法阵里面实际火焰的明亮橙色一致。本轮只校色，不重新设计外观。

保留v35r2完整同心圆、纹路坐标、线芯清晰度、透明通道、亮暗变化和双纹理5MiB预算。只替换1024彩色纹理及512光场的RGB，复用原 `fire-seal-v35r2.effect`；`FireGroundEffects`仅替换两条纹理资源名称。陨石、中心点燃、地火、落地后保留到3.3秒及4.55秒渐退时序均沿用既有实现。

校色参照是v34无红色法阵覆盖的真实 `.65s` 地火画面，并以现有burst图集核对。采样扣除同机位实际背景，分别对应暗、中、亮火焰；避免把白热中心或一种纯色铺满整圈。确定性处理和采样参数、素材哈希、通道保持证据以 `assets/` 的实际记录为准。

没有新的模型生成或下载。几何纹样仍来自v35已记录的云端精修源与确定性正圆校准；本轮不把材质计算样张冒充游戏截图。修改前实景以 `../meteor-complete-sigil-v35/final2-r1` 和 `final2-empty-r1` 为准。

验证采用既有类型检查、标准test Web导出和不可变构建快照，录制同镜头FIR02正常训练与空地各9秒。最终证据及实际检查结果完成后另记于本目录；用户美术确认与TapTap真机显示／性能验收独立记录。

标准test Web导出已成功，编译标记 `f6e5cdff201d`，每日经验不限为false、冷却正常、经验倍率1。不可变快照主文件SHA256为 `068d3bf3bc8a19c26bc46ce6c0a5a895a8f9f1add0876c5e926372d7b2d2efbf`，4040个运行文件逐项复制前后及副本一致；快照索引为 `snapshot.json`。类型检查再次通过。首轮导出曾遇到并行制作中的锻造界面缺少导出，原修改方补齐后重新构建；本轮未修改该界面或规则。具体记录为 `root-build-review.json` 与 `build-attempts/`。

根代理已实际查看 `final-empty-r1/early/` 的预警法阵及落地后 `.65 / 2.8 / 3.5s` 原帧：偏红底光已消除，法阵与中央火焰为同一橙色系，纹样仍清晰完整、深浅分明并持续叠加。独立美术判断和原帧SHA记录在 `root-native-review.json`；材质计算样张与这些实际原帧严格分开，不声称透明辉光混合后的像素RGB完全相同。其余12项受保护渲染／玩法源文件与本轮开始时一致，`FireGroundEffects`字节反替两条纹理名称后精确还原基线。
