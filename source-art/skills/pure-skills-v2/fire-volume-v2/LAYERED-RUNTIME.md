# 五层火体派生与审阅（2026-11-08）

本次不新增概念图、不重新生图。复用本目录保存的云端 OpenAI image_gen 四相原图与现有 `phase0..3.png`，以 Pillow 提取五个不同的翻卷区域：后左高卷、后右卷冠、中心压力火体、前左低卷、前右低卷。没有重复五遍完整爆炸云，没有添加完整圆环、白色圆核、人物或地面。原图、原阶段纹理、原提示词与来源记录均保留。

可复现脚本：[derive-lobes.py](derive-lobes.py)。裁切、原始 SHA256、每张画布及共同脚锚见 [lobe-provenance.json](lobe-provenance.json)；[派生小样](lobe-source-review.jpg)展示五种裁片的四相。各裁片只做源区域裁切、等比缩小、透明留边和确定性 alpha 羽化；内部裁边使用较宽且略不规则的透明过渡，避免亮矩形接缝。源比例不会被拉伸来填满目标宽高。

`SkillFireSprites.drawVolume` 在实际 AOE 圆盘内放置五个不同 XZ 脚锚，后两层最高，中心压力层中高，前两层低。脚锚按地形独立采样；与角色使用相同的透明 unlit pass 和 priority 0，交给引擎按真实深度排序，因此角色可以穿插在不同火层之间。最大地面横向端点为实际半径的 0.970，未增加伤害、目标或碰撞。画面中的向上卷焰属于体积高度。

四相继续表达开始压缩、爆开、翻卷和散去。五层相位错开 0.050 个进度，单次交叉淡化宽 0.090 个进度，在当前 0.48 秒爆燃中相当于约 43 毫秒，不再只有一帧切换。最多两层同时交叉，一次火体最多七张卡片。共享一个 quad mesh；材质随池分配后复用，上限 64；逐帧只改纹理、颜色和变换。旧 `draw` 接口保留，但宽高改为 768×432 画布的 contain 边界，不能再用不同比例横向拉扁主火。

实现检查：现有 TypeScript 检查通过；在 0..1 进度按 0.0001 采样核对最大七张卡片；20 张区域纹理合计约 2 MB。上述检查只证明实现约束，不构成美术验收。

小样审阅：五种卷层具有不同的卷冠、压力前沿及低焰构图，保留橙黄热边与红褐暗腔；阶段 3 只保留较稀的散焰。局部裁边已经羽化，仍须在正常相机、正常光照与角色同屏实际渲染中检查接缝和穿插。实际运行审阅状态尚待集成后的代表帧与原速序列；用户验收未宣称通过。

首轮实际审阅（`index.6e061.js`）：[桌面翻卷帧](../../../../src/cocos/test-results/vfx-art-redesign-v3/iteration-6e061/after/fire-rank5-roll.png)与手机帧显示火体过高、后卷像树冠，整体形成塔状，未通过美术审阅。原因是两个高窄裁片的自然高度接近 1.1R，再叠加后排位置；保比例本身不能保证构图正确。第二轮将来源裁区改成宽翻卷区域，保持新区域自身比例，而非压扁旧图；后两层最高为 0.642R / 0.638R，中心压力层 0.508R，前两层 0.372R / 0.348R，并收近后排深度、展开低前沿。首轮截图保留为迭代证据；第二轮实际审阅另记。

第二轮实际审阅（`index.a39fc.js`）：使用同一真实 GameSession 技能施放、原生 Cocos 相机与敌人位置，独立证据见 [运行记录](../../../../src/cocos/test-results/fire-volume-layered-v2/fire-actual-render.json)、[桌面翻卷](../../../../src/cocos/test-results/fire-volume-layered-v2/fire-rank5-roll.png)及[手机翻卷](../../../../src/cocos/test-results/fire-volume-layered-v2/phone-fire-rank5-roll.png)。树冠/塔状剪影已消除，宽翻卷贴近地面、前低焰与后卷有高度差，角色可在层间显露身体；正常手机画面保留暗红腔和热亮边，未见明显矩形接缝。代表空间形态方向通过，未声称完整技能/全部阶级或设计稿逐像素验收。运行无浏览器错误；本次六帧中池最多 16 项，单次开始 6 张、主翻卷 5 张；rank5 第二拍出现时会与上一拍散焰共存，这是原技能的实际第二次爆燃，不能把 1.0 秒画面误标成单次散焰。

随后仅延长交叉淡化到约 43 毫秒并增大逐层错相；空间布局、裁区与比例不再更改，最终原速时间序列待统一构建复核。以上是代理代表样例审阅，不代替用户美术验收。

时间序列复核（`index.86c8e.js`，与随后统一包使用相同火体代码）：[60fps 两拍原速 GIF](../../../../src/cocos/test-results/fire-volume-final-sequence/fire-two-beats-live.gif)、[接触表](../../../../src/cocos/test-results/fire-volume-final-sequence/fire-two-beats-contact.jpg)、[运行统计](../../../../src/cocos/test-results/fire-volume-final-sequence/sequence-review.json)。78 帧由真实 GameSession 每次推进 1/60 秒，四相均出现，单体最多七卡，两次真实爆燃交叠时最多十四卡，最后归零，0 个浏览器异常。原速 GIF 使用 20/20/10 毫秒交替帧时长，总计 1.3 秒，避免 GIF 的 10 毫秒时间精度把动画加速。火体时序代表审阅通过。

同轮额外检查发现：把上述五层爆燃复制到火墙/波前的每个段，会形成分离的小完整云团，炎墙/锋面这两项未通过美术审阅；不能将爆燃审阅结论外推到全部火系。随后新增专用 `drawRibbon`：压力低前沿与两种前低焰组成交错重叠的两排，长轴沿实际矩形的 side 方向；不同画布仍保原比例，内片重叠 40%，外片停止于实际端点；80 毫秒在翻卷 1/2 相间交叉，最多九常驻加两临时，共十一活动卡。它读取整条真实矩形一次，而非每段生成完整五层爆燃。新火带实际审阅另记。

火带方向修复与实际审阅（`index.b5871.js`）：当长轴接近朝向相机、普通竖直片会侧向消失时，两排原有片在实际 depth 内相向倾斜。脚锚分别在 ±0.30D，顶部横移最多 0.60D；最大理论倾斜 47.7°，仍保至少 67% 垂直高度；不额外叠卡、不把长轴转出真实矩形，也不把整个材质铺成地毯。
