# 人物间连锁电弧设计预览

基于用户选择恢复的上一版，人物之间的连锁电弧采用与施法主弧相同的白亮核心、蓝紫柔光和电光纹理，宽度单独缩小。施法者到首个目标的主弧沿用恢复版。

[新版动画](media/chain-design.mp4) · [原速前后对照](media/chain-comparison.mp4) · [雷网动图](media/chain-preview.gif) · [人物间连接局部](media/chain-detail.jpg)

主弧宽度为 0.510，人物之间的主连接为 0.300，约为主弧的 59%。两者使用同一电光图集、同一主弧纹理区域、同一材质和透明发光方式，装饰性细分叉继续使用细分叉纹理。

连接类型单独传递，纹理选择和主弧轮廓对齐按类型处理。人物之间的连接直接沿实际目标的世界坐标展开，两端保持贴合实际落点。

重新录制当前 Cocos 的真实 3D 角色、施法动作和连锁事件。核对事件、命中、伤害、判定几何、机位、原稿纹理与轮廓数据，检查每帧主弧与连接线的显示记录、材质纹理区域和端点位置。额外检查单体技能完整回放的像素差异，以及两招连锁技能主弧的实际可见像素，防止再次出现主弧消失。

当前仍是设计预览，正式游戏代码未修改。来源与本机 Web 录制的验证记录见 [provenance.json](provenance.json)，TapTap 真机效果和性能待正式接入时另验。
