# 战士冲击波剑气 · 整套动态设计稿

**用户随后明确剑气应有透明状态。当前半透明修订见 [warrior-aura-v9](../warrior-aura-v9/README.md)，本目录保留此前较实的波前稿。**

按用户最新要求，将颜色调淡，保留不透明的剑气亮芯，表现为向前推进的冲击波。结构由弧形波前、带厚度的回卷气流和逐渐消散的尾流组成，横向与竖向气浪在目标处短暂交错。

动态画面使用当前 Cocos 3D 角色、真实骨骼动作与实际技能事件。新的卷曲波面沿攻击方向推进，前后折叠产生纵深；亮芯峰值不透明，外缘与尾流逐渐消散。颜色变淡采用低饱和色彩处理。保护气幕同样由流动剑气组成。战士没有装饰法阵。

原速合集为 30 fps，半速细节标注 0.5×，单招循环动图按 15 fps 保留实际时长。四种配色对照在同一个模拟帧内替换纹理后以零时间步渲染，人物、目标、动作与镜头一致。

新的剑气画稿通过云端 OpenAI image_gen 内置工具生成，提示词见 [generation-prompt.txt](generation-prompt.txt)，原图保存在 `aura-original.png`。本地对画稿进行确定性裁切、流纹整理、透明边缘处理与淡色映射，记录见 `processing.json` 和 `palette-candidates.json`。波前与尾流的动态由独立审稿渲染器产生。

本目录是设计候选，未接入正式游戏。媒体解码、技能事件、重叠帧、来源及输出指纹记录在 `provenance.json` 与 `palette-provenance.json`。用户尚未验收本轮效果；TapTap 真机性能未验证。
