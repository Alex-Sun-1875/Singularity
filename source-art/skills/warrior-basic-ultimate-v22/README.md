# 战士普攻与最终技：流动月牙冲击波 v22

本版已接入实际 Cocos 战斗渲染。沿用 v21 加厚的银色波前、流动波身及局部消散；美术最终验收仍由用户确认。

- 普攻三连：短横扫、反向回斩、较强下劈；回斩角度兼顾当前俯视镜头可见度。视觉尾流分别为 0.34／0.34／0.42 秒。
- 最终技「破晓裁决」：大幅横扫、竖向上挑，接 120° 交叉月牙收尾；前两段尾流 0.52 秒，收尾 0.62 秒。视觉残留不增加攻击次数或伤害。
- 复用既有原生网格、流动材质和有界池，无新增依赖或贴图。移除已无调用的旧实体波片绘制。
- 真实动作、输入、范围、命中、伤害、冷却、消耗及护盾规则保持。断空斩、突袭、旋风斩及被动的共用绘制方法保持。
