# 火系技能组合修订 v7

本轮由用户提出扩大陨石、合并两个铺地火技能并新增火系技能；用户选择了“烈焰喷流：定向持续输出”。沿用已完成的火系动态图与当前 Cocos 3D 角色、场景和动作，只制作设计候选，没有改动正式源码、资源、发布配置或构建产物。

## 本轮方案

| 技能 | 职责 | 候选调整 |
| --- | --- | --- |
| 赤焰枪 | 单体远程 | 保留。 |
| 烈焰喷流 | 定向持续输出 | 新增，占用合并后腾出的主动槽；约 7 米连续火柱，从施法手掌喷出，末端变宽，短时维持施法姿态。 |
| 焚焰火域 | 地面伤害与减速 | 将炎墙封路与焚天火海合成一次施放：火浪展开，随后固定在地面持续燃烧；候选范围 6×3 米，约 4 秒有效期。 |
| 焰心护盾 | 自保 | 保留。 |
| 焚星坠落 | 大范围终极技能 | 本次对比用半径 2.8→3.8 米，直径 5.6→7.6 米；半径约增加 36%，面积约增加 84%。主爆燃维持至命中后约 1.2 秒，随后回落与余烬渐退。 |

范围成长暂拟 3.8/4.2/4.6/5.0/5.5 米，尚待平衡。只有陨石使用用户确认的橙红双层刻纹法阵，预览中为透视合成层。该层和原生爆燃、残焰均按同一候选半径扩展。

合并后的火域继承原火墙的控制定位：区域内普通敌人减速 35%、首领 10%；不生成实体障碍，不改变地图通行。同一施法者最多保留一个火域，重放替换。伤害采用一个统一预算，不能把两个原技能的伤害直接相加。伤害、冷却与成长数值尚未定稿。

喷流与火弹、地面火域分工不同：短时持续指向前方，要求站定施法；被打断应停止输出，不能穿过地形。本轮只制作连续火柱、起手、持姿和收回的动画。伤害节拍、转向、遮挡和打断规则留待设计确认后接入。
