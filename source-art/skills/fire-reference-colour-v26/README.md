# 烈焰喷流：原稿颜色、亮度、透明度与光晕对齐

> 用户指出此版中央亮线仍像闪电，火苗形态与法阵色彩未达到要求。请以 [v27 原稿细火舌修正](../fire-reference-wisps-v27/README.md) 及其实际动态对照为准；以下保留当时处理记录，不代表用户美术认可。

用户要求颜色和其他表现也与选定稿对齐。v25 只恢复纹样像素，仍把所有线条统一染成固定金色并额外叠光晕；材质又将颜色通道平方，导致原金橙色变红、变暗，底部填色也偏厚。

本次同时处理素材与实际材质输出：

- 法阵从选定原图分离地面底色，保留每个像素的原有 RGB 明暗变化及对应透明度，不再统一染色，也不添加额外模糊或光晕。双环、可见侧曲纹和前侧小纹沿用原图，前后朝向沿用 v25 修正。
- 原图法杖遮挡只影响底色估计，穿过该区域的原有发光环线继续保留。原图后部被火苗遮住的地面线条不擅自重画。
- 火苗保持现有连续帧、原有轮廓和上涌动作，颜色与透明度按选定原图实测前景分布校正；亮芯的绿／蓝关系一并采样，避免独立调色造成黄绿亮芯。亮芯保留原稿的明亮，薄雾继续透光；后层透明度降低，减少叠厚。
- 当前原生透明材质直接合成这些美术显示颜色，取消再次压暗绿色／蓝色的变换。底部填色复用原图火苗的中段／高亮色值，降低覆盖度，包含前半圈，保留流动和渐隐。

火苗亮线另按原图最亮部分的实际中位 RGB `255 / 228 / 110.5` 保持金色亮度，避免运动采样时与薄雾一起被压暗。该处理只作用于已有亮线，周围透明火雾继续沿原稿色彩和透明度分布变化。

## 来源与验证

唯一色彩和造型基准为 [最终选定原图](../fire-selected-reference-v18/user-selected-effect.jpg)，SHA-256 `52b78fa21809693c830796ed479eb42acb545258f19286c0ff80f1d4acc20b36`。本轮只用 Pillow／NumPy 做确定性像素处理，没有生成新画面，没有使用云端或本地生成模型。原图为带地面的合成图，前景透明度依赖局部背景估计；见 [分离参数与来源](provenance.json) 和 [实测原图色彩](analysis.json)。

`analyse.py` 估计原图局部地面并分离火光；`prepare.py` 生成原色法阵和校色后的现有火焰图集。用估计底色合回原图，检查原图不透明亮芯的重建误差；这项检查是素材分离验证，不能代替实际游戏颜色验收。`colour_review.py` 从原图、上一版和本版未修色实录中采样十个前侧环带方向，结果见 [实际颜色采样](colour-review.json)。法阵按实录采样的通道残差做小幅补偿，避免只对齐贴图而最终画面仍偏暗。

`capture.cjs` 继续使用正常训练场、完整游戏更新和实际技能输入，保留默认镜头与 HUD；`media.py` 只将画布帧编码成视频并生成对照排版。视频编码复用现有便携 Python 的 PyAV，不启动 ComfyUI 服务或本地模型。法阵的实际地面投影与原稿镜头不同，对照只对齐外圈宽度，不扭曲实际录像。

原稿石地与靶场底色不同，透明区域露出的背景随场景变化；对齐对象为火光本体的颜色、明暗层次、透明度与光晕。未通过修改地面或后期修色让实录伪装成原图。

类型检查、Web 构建与实录核验见 [verification.json](verification.json)。五个喷发点、真实范围、伤害、持续时间、冷却、存档规则和陨石法阵保持。未新增依赖或测试脚手架，未制作发布包或升版。用户最终美术验收与 TapTap 真机画面、性能验收分别登记。
