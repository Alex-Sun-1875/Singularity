# 战士最终技：恢复自然勾弧 v36

按用户纠正恢复刀气自然弧度：**尾尖从脚边起，刀腹自然悬起，形成连贯勾弧**。本轮以平滑几何高度包络替代压平底边的处理，不再要求整段刀腹贴地；尾尖仍贴近地面。

只调整曲线几何，保留 v35 已确认的等级映射、连续波数、节奏和材质：1 级 1 道，2–3 级 2 道，4–5 级 3 道，约间隔 0.22 秒，每道独立推进和消散。原角色动作、实际伤害、护盾及其他技能保持。

## 验证

删除刀腹离地不超过 0.20 米的旧断言，仅要求尾尖保持离地 0.06–0.20 米。成形年龄大于 0.1 秒后，测量外下缘参数 u=0.125、0.25、0.375、0.5、0.625、0.75、0.875 的实际世界高度；排除末尖，只看前五项，其最大值与最小值须相差超过 0.30 米，确认下缘没有被压成平底。

继续保留逐波索引、1／2／3 道数量、0.22±0.04 秒间隔、独立向前位移、收招后继续推进、竖立波面、端点共点、尖端朝上及原生动作连贯检查。命中事件按相同实际技能等级逐项匹配，不把低等级命中数量套用于高等级；视频与 GIF 完整解码核对帧数和时长，结果在 `provenance.json`。
