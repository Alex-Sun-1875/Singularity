## 实现与判定

旋风斩复用原生持剑动作，人物回旋、月牙网格、真实扫掠接触共用 `WhirlwindSkill.ts` 的时间轴。每段每个敌人最多命中一次，总伤害按 28%／28%／44% 分配；前两圈保留受击动作而不推走目标，收尾沿用原击退。遮挡、打断、暴击、破势、装备和被动继续经过原战斗逻辑。

保留 WAR_04 技能 ID、解锁、五级成长、资源消耗、冷却、总伤害系数和第五级护盾联动。只调整此技能的形态、范围与实际接触方式；其余攻击技能本次调整表现。银白波身有实心亮刃，边沿和尾流自然淡出，没有另加范围法阵。

特效复用 Cocos 原生网格与材质，按职业加载，池上限 64 层。修正复用节点在赋予网格前未激活导致的首次显示缺失；实录逐帧检查活动特效的实际子模型和包围盒。按项目规则使用现有资源加载层，没有新增依赖或灯光。
