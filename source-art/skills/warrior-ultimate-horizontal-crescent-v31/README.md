# 战士最终技：水平双尖·不规则月牙刀气 v31

按用户最新纠正更新第三段：飞出的刀气改为两端都尖的不规则月牙，波面与地面平行；前厚后细，持续向前推进并消散。此版本覆盖此前竖立刀气的设计方向。

仅调整飞出刀气的轮廓和朝向。原角色的下劈动作、120°交叉斩、v29 已确认的前进方式、银色流动材质及第三段约 1.05 秒视觉时序保持。角色向下劈，释放的刀气水平飞出；两者朝向分别处理。

## 本轮形状与位置

- 月牙外、内轮廓采用两条不同的三次曲线，保持不对称厚薄与不规则弧度；首、末端分别完全共点，形成两个尖端。
- 成形过程缩放完整轮廓，不通过截断月牙端部来展开。噪声及尾迹位移在两端收敛，保护双尖形状。
- 两端分别在最后约 18%／22% 区域提前收细，避免材质端部渐隐后露出宽截面；前方外弧保持，内侧带宽与尾流同步收敛。
- 释放波面平行地面，离地约 0.18 米；脚边仅作出生位置，随后离体向前推进。人物收招后，刀气继续前进、拉细尾流并自然散去。
- 当前轮廓参数保存于 `crescent-profile.json`，可以追溯。本轮不再以旧竖直刀身参考作为轮廓硬约束。

本目录仍是 Cocos 原生渲染的独立动态小样，未接入正式代码、材质或资源引用。复用实际游戏角色、三个原生动作、既有交叉斩及流动材质；推进尾段属于视觉余波，不新增伤害、碰撞或玩法规则。

## 验证范围

保留 v29 的运动和命中验证：两场景的提案与当前版真实命中事件逐项相同，仍为五次技能目标命中；推进距离单调增加，实际世界位移与施法方向一致。人物动作结束后、第三段视觉年龄小于 0.85 秒时，主波继续前进超过 0.3 米。动作期间不切回 idle，没有渲染缺失、控制台错误或特效池溢出。

水平与双尖采用真实渲染层及网格测量：主层局部 Y 轴变换后的法线绝对 Y 分量须大于 0.99999；主层网格首、末行两边缘之间的距离均须小于 0.00001 米。交叉投影约 120°。旧版屏幕 X 轴的 90° 检查已删除，因为它不能判断水平波面。

视频与 GIF 完整解码核对帧数、播放速度和时长；运动、法线、尖端几何和媒体结果记录于 `provenance.json`。本轮没有生成式重绘、插帧或修改人物动作素材。最终用户美术验收待确认；隔离 Web 小样不代表正式接入、TapTap 真机或手机性能通过，未制作新包。
