# 雷系电弧参考修订稿

这轮以用户指定的首版 2D 设计为准，修正上一版 3D 动态稿的电弧颜色与弯折。上一版将蓝色实体层加宽，白芯比例偏小，形成了硬边色带。

[原速动态对照](media/previous-vs-revised.mp4) · [修订版单画面](media/revised-full-size.mp4) · [连锁雷弧动图](media/thunder-comparison.gif) · [2D 参考对照板](media/reference-comparison.jpg)

本轮方向是白亮主干、浅蓝过渡、蓝紫柔光，外缘透明渐隐。主干保持清楚的宽度，长短不同的弯折与相连分叉沿原有放电路径展开。颜色和透明度使用同一截面，减少分层实体条带对白芯的遮盖。

动画沿用当前 Cocos 的 3D 角色、施法动作、手部锚点、技能事件和连锁目标。复用现有 `ThunderArcField` 动态网格池呈现真实主弧路径。录制器只在本地审稿响应中替换呈现模块，审稿代码保存在本目录。

对照涵盖贯雷长矛、连锁雷弧和万钧雷潮。两边使用同一导出、机位和时间步，逐招核对完整事件、目标、伤害与判定几何。帧画面来自真实 3D 场景，没有在录制帧上后画闪电。2D 设计参考在对照板上单独标注。

法阵使用规则沿用用户指定的陨石技能 `FIR_02` 专用规则。火系与战士的上一轮审稿内容保留在 [v4 稿](../current-vfx-refinement-v4/README.md)。

当前为设计动画，等待用户美术审阅。验证限于本机 Web 审稿录制，TapTap 真机效果与性能在接入时另验。来源、录制输入与媒体验证见 [provenance.json](provenance.json)。
