# 战士银色十字斩 · 三段冲击波

**后续增加了电视剧《风云》雪饮狂刀的亮刃与气流参考，修订见 [warrior-snowblade-v13](../warrior-snowblade-v13/README.md)。本目录保留银色十字冲击波稿。**

本轮采用银色：银灰波身、银白亮弧，不再使用上一轮彩色候选。用户“透明度低一点”按更实、更清楚处理，单层峰值不透明度由约 55% 提高到约 78%，内侧和尾流继续柔化消散。

[整套原速动画](media/warrior-all-skills.mp4) · [断空斩半速细节](media/shockwave-detail.gif) · [突袭十字斩半速细节](media/triple-cross-detail.gif) · [三段连续截帧](media/three-wave-stages.jpg) · [上一版与本轮对照](media/design-comparison.gif) · [整套总览](media/all-skills-overview.jpg)

造型回看[之前的十字斩关键帧](../warrior-impact-v6/keyframe.png)，恢复“横向前冲＋纵向落刃”的清楚交汇。保留弧形、尖端和流动感；横斩拉长，纵劈收窄。参考稿的金铜配色和实体材质没有沿用。两道能量面在审稿镜头里分别接近水平与竖直，表现为十字交汇，取代上一稿两条近平行的月牙。

主要攻击每次视觉释放有三道前推的冲击波，依次起势、接续、加强；主攻技能相邻起势约隔 0.10 秒。三道波前沿攻击方向保持前后间距，第三段更强，波前接近目标位置时短促亮起，再分开消散。灰银波身有两三条宽缓流纹。裂地审判改为触地后连续推出三道低位气浪。普攻节奏更紧凑，护身与被动反馈保持短促。

使用同一冻结 Cocos 3D 场景、真实骨骼动作、实际技能事件、目标和镜头。仅在独立审稿响应中替换表现模块，没有增加玩法伤害段数。每帧登记三道可见波前的不同位置，核对三段推进与横纵交汇；录制没有丢弃波面。原速视频为 30 fps，细节与对照标注 0.5×。

能量面用带内凹空缺的弧形网格和银色顶点渐变绘制，中心在 3D 空间推进，朝向镜头以保持轮廓可读。本轮没有新增生成图像；旧 `blade.png`、`guard.png` 只供兼容初始化，当前能量材质关闭纹理采样。战士没有装饰法阵。

这是设计动画，未接入正式游戏。媒体、技能事件、波前间距与输入指纹记录在 `provenance.json` 和 `comparison-verification.json`。生成与录制验证完成不代表美术验收；本轮仍待用户审阅，TapTap 真机性能未验证。
