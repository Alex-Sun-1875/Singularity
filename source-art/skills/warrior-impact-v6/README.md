# 战士攻击重新设计 · 单招动态小样

**当前交付状态：新关键帧和全新刀锋素材已生成并保存；独立动态小样首次录制暴露了纵劈朝向问题，已调整代码，最终录制因本机工具持续无响应而未完成。动态链接为计划产物，当前不可作为已交付或已验证动画。用户尚未确认新的美术方向。**

上一轮 `warrior-cross-v5` 已被用户否定。本目录重新设计刀锋造型、材质、前伸方式、纵劈朝向与交汇反馈。

[新关键帧概念图](keyframe.png) · [新刀锋原始图集](atlas-original.png) · [关键帧提示词](imagegen-prompt.txt) · [生成与录制状态](review-status.json)

先以当前 3D 战士的断空斩制作代表小样。横斩从持剑手附近形成，沿目标方向切入，随后纵劈向下落到命中处。横向刀锋残留时，纵向刀面进入同一画面，最后以紧凑的碎锋与薄尘消散。银金刃线与银铜中间调表现锋面和厚度。

关键帧与原始图集由云端 OpenAI image_gen 生成，提示词分别保存为 `imagegen-prompt.txt` 和 `atlas-prompt.txt`。图集采用本地确定性透明边缘清理和排版，处理记录见 `atlas-processing.json`。新的独立渲染器使用这些图格、两种 3D 切割平面与连续位移和缩放，不复用上一稿的钢刃纹理及扇面网格。

动态画面使用当前 Cocos 导出的模型、真实骨骼动作与实际技能事件，输出 30 fps。它是审稿用的独立预览，未接入正式游戏。静态关键帧是造型目标，动态小样仍需用户美术审阅；两者的生成与验收分别记录。帧数、重叠帧、来源指纹和事件记录见 `provenance.json`。

视频生成插件要求绑定 Maker 工程，当前 Cocos 目录未绑定，因此未发出远程视频生成任务，也未初始化 Maker 工程。动态小样由本机 Cocos 预览录制，未进行 TapTap 真机性能验收。
