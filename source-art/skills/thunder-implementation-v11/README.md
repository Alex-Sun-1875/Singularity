# 雷系实际接入 v11

用户于 2026-11-16 授权按推荐方向实现，并明确要求技能完成后地面仍有雷晕。本轮修改当前 Cocos 主工程；本目录录制器只设置靶场、相机和会话时钟，直接提供构建输出，不注入替换版玩法或特效模块。

## 实际变化

- 连锁闪电优先延续最近的有效节点；雷网优先稀疏近邻分叉。去掉额外装饰闭环，拥挤节点和交叉是布局代价，不以“度数二／禁止交叉”硬限制漏掉合法目标。
- 连接保持原选中集合、等级目标上限、半径、LOS、命中率、每目标伤害与实际伤害拍数。MISS 不再晋升为后续中继；合法的其他目标继续处理。
- 每个真实伤害拍只播一次约 0.18 秒的空中放电，使用由近及远的亮度前沿和快速衰减。它是接触后的表现层次，未另行延迟真实命中时间或重复伤害。
- 雷网沿用真实三拍时序，第二拍略弱，第三拍加强并在首目标上加短促竖向接触强调；没有雷系范围法阵。
- 地面雷晕复用 `ThunderGroundAura` 的雾状贴地遮罩与残留细电纹。每个真实接触单独保留约 2.6 秒，留在实际落点，不随敌人移动，也不因空中弧线或人物动作结束而立即清除。它不造成额外伤害或眩晕状态。
- 雷网地面局部雾斑半径约 0.98–1.30 米；普通雷电较小。柔雾略高于残留电纹，避开地形微小起伏造成的裁切。不添加硬边圆圈，雾斑自然叠加。
- 普通雷矛命中时移除原来重复叠加、继续穿过目标的完整弹道表现；未命中时保留合法方向的空放轨迹。

## 素材与运行接入

`thunder-reference-strip-v1.png` 逐字节复用已恢复并认可的 v8 主干／细分叉图集。主干仍为白亮核心、蓝紫外缘，一级主干宽度 0.510、目标间 0.300；五级沿用 0.550／0.340。

素材通过公共 `GameResources` 加载并成对管理引用，使用 Cocos 原生动态网格和既有地面雾池，不新增依赖或运行时网页路径。已修正池中停用节点扩容换 mesh 时，渲染模型仍引用旧缓冲导致电弧消失的问题。曲线摆动按相邻路径间距限制，主干保留参考轮廓。

没有生成新图，也未调用本地模型。输入为用户已确认设计中提取的电光、已有地面遮罩与当前 3D 模型／骨骼动画。
