# 战士最终技：按等级连续 1／2／3 道冲击波 v35

按用户确认的五级技能映射：**1 级释放 1 道，2–3 级释放 2 道，4–5 级释放 3 道**。每道先后接出、独立前进和消散，约间隔 0.22 秒；末道略强。保留短尖向上、弧腹和细尾贴地的关系，使用较清楚的发光锋线、淡刀腹和低亮副影增加层次。

本轮是基于当前游戏角色、原生三动作和真实技能等级的隔离动态小样，未接入正式代码或资源引用。额外波数仅为视觉呈现，不新增伤害或碰撞，护盾与其他技能保持当前版本。

## 本轮设计

- 以已确认的竖立刀气和贴地尾部为基础，收整刀腹和短尖，强调细亮前锋与柔和透明波身；弱副影只补流动层次，不计作独立波数。
- 连续多道的真实出生时间分别错开，推进与溶解各自使用独立年龄；最后一道略放大，人物收招后仍继续向前飞行。
- 每道视觉寿命约 1.02 秒，整体呈现窗口约 1.52 秒；角色原生动作不增加等待、不为后续刀气重复回待机。
- 等级到道数映射由 `swoosh-profile.json` 的 `rankWaveCounts` 维护，录制上下文根据真实 `learned.WAR_05` 读取，而非只靠演示按钮指定波数。

## 验证范围

每个提案都配有**相同真实技能等级**的当前版对照。逐项比较命中目标、时间、阶段与数值；不同等级的真实命中数量可以不同，不把低等级的五次命中硬套给所有等级。

- 逐个主波索引核对不同波数为 1／2／3，出生间隔为 0.22±0.04 秒。弱副影不计入波数。
- 每道独立核对推进距离单调、世界位移与施法方向一致，收招后仍继续推进；不要求每道累计位移固定成同一个常数。
- 核对波面竖立、两端收尖、短尖高于弧腹和细尾、弧腹及尾尖贴地。新材质标识为 `Isolated:RankedPressure:v35`。
- 保留原生三动作、动作期间不回 idle、实际渲染模型完整、无控制台错误或特效池溢出等检查。
- 视频与 GIF 完整解码核对帧数、速度和总时长，逐道检查及实际命中数量记录于 `provenance.json`。
