# 破晓裁决：最终技增强方案 v23

本轮仅提案，未修改游戏代码、素材引用、技能规则或本地预览。基于 v22 实际最终技，按用户最新意见取消蓄势，三段改为横扫 → 上挑 → 从上往下劈斩终结。保持银色月牙冲击波方向。

## 推荐方向：层次气浪，下劈爆发

增加前后层次和终结瞬间的力度，亮度集中在短促波峰，人物与目标保持可读。

| 阶段 | 拟增强表现 | 节奏约束 |
| --- | --- | --- |
| 横扫 | 保留厚月牙主波前，内侧增加一道低亮、稍迟的压缩气浪，尾部向后拉散 | 弱余波滞后约 0.06–0.08 秒；主波峰仍跟随真实首段命中 |
| 上挑 | 较集中的竖向月牙自下而上掀起；前段横扫尾流压暗，让新一斩露出来 | 保留原第二段动作及命中；用高低层次表现纵深 |
| 下劈终结 | 上挑顺势接双手向下斩，主月牙在竖直平面由高向低压落；上方拖出弧形尾流，落点短闪并向前翻出一小道低位气浪，伴随 6–10 条短银色冲击线 | 下劈波峰对齐原第三段真实结算，落点亮闪约 0.06–0.08 秒；前两斩仅留低亮余波，不能抢过终结主形 |
| 消散 | 波前先减弱，尾部先断开，再形成少量不均匀薄气丝；保留空隙 | 终结视觉余留约 0.6 秒，采用当前自然消散方向 |

不增加蓄势动作或施法等待。第三段由交叉主形改为下劈主形，前两段形成交错的低亮残留，旧版 120° 交叉不再作为最终主形的硬约束。下劈与上挑衔接，动作中途不回待机。以上为拟议视觉时长，未通过运行时验证。余波是同一攻击的视觉残留，不增加攻击段数；拟保留当前范围、目标、数值、冷却与操作节奏。

## 视觉控制

- 主色保持银灰，瞬时高光为银白；波身透明、内缘柔软破碎，不出现实体金属刀片的硬质明暗。
- 下劈的厚月牙承担最终主形，前两段各留一层低亮余波；弱层亮度约主层的 20%–30%，避免多层叠白。
- 落点亮闪要小、短，冲击线集中朝下和朝前；不以全屏泛白强化威力。
- 使用弧形波前与上挑的立体方向表达纵深，地面保持可见。战士仍不使用法阵。
- 护盾与其余已确认技能保持当前版本。
