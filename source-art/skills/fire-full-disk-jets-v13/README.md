# 全圆填充与外浅内深喷焰 v13

本轮按用户补充修订：前半圈也要填充火焰与颜色；火焰由外向内逐渐变深，外侧比 v12 更浅；整体稍微增高。

- 火焰覆盖整个圆形法阵，包括面向镜头的前半圆，保持底边与法阵直径同宽。
- 采用有颜色的通透火焰体积，前方也有火舌和薄色层，减少空心线框感；法阵仍应能透出。
- 色彩方向明确为径向：浅金外缘 → 金橙 → 琥珀 → 更饱满的透明橙色中心。避免把中心画成白芯或不透明红块。
- 候选高度比 v12 增加约 25%，约 0.7–0.75 米，保持竖直向上、下宽上尖的轮廓。
- 五个喷发点的位置、当前场景与角色、陨石及合并火域提案保持。
