# 战士最终技：竖向勾形劈浪动态小样 v27

此为历史候选。用户随后明确「不一定是勾，应该是弯刀的形状」，当前推荐已更新到相邻 `warrior-ultimate-saber-drop-motion-v28`，本版未获得用户最终美术确认。

按用户最新口述「类似 Nike 的勾形」「和刀的形状有点像」「底部和人的脚对齐、长度很长」修订第三段。第三段采用贴主角脚边的勾底、向前上方伸出的长尖、厚弯腹和短回勾；保留银色气浪的透明层次、流动和消散。替代 v25 的规则月牙与 v26 的不规则气帘提案。

本轮只制作独立动态方案，未接入正式游戏。基于现有战士编译版本，在一次性浏览器中复用实际角色、三个骨骼动作、交叉斩网格、银色流动材质和真实游戏时钟。

## 形状与衔接

- 前两段横扫、上挑保持。终结的两道约 120° 交叉月牙保持，第三道勾形气浪在同一收尾窗口内向下展开。
- 外、内轮廓使用两组独立三次曲线：上端细长，主臂向下劈落，弯腹逐渐加厚，底部短勾向前收出。勾底锚点与主角脚下 X/Y/Z 相同，外轮廓最低点距地面约 0.02 米。长尖相对脚底高约 4.8 米，向前约 3.9 米，构成约六米长的斜竖劈痕；水平最远点仍在当前技能距离以内。该网格不使用月牙的圆半径或对称角跨度。
- 竖向波面固定，轮廓从上端依次展开到弯腹、短勾；一层低亮尾迹随原流动材质自然消散。落点只有小幅柔和的前翻气浪。
- 原生三个动作与短交叉淡化保持；仅在录制上下文中关闭该技能的呈现接触停帧，动作期间不回 idle。不增加蓄势或额外等待。
- 伤害、命中次数、目标、范围、消耗、冷却及动作时长保持。护盾与其他技能保持当前版本。
