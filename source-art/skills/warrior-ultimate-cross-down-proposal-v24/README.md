## 最终动作

保留现有前两段横扫、上挑，终结内安排「交叉成形 → 下劈贯穿交点 → 集中爆发」。两道约 120° 交错的月牙先展开，纵向厚月牙紧接着由高向低压入交点。三道波前在终结瞬间同时可见，前两道交叉月牙仍承担清楚的交错构图。

- 不增加蓄势或额外等待；上挑顺势接下劈，动作中途不回待机。
- 交叉波约为中心下劈亮度的 60%–70%，前两段残留尾流降到约 20%；三种层次有清楚主次。
- 主波前保持厚而弯曲的银色月牙，波身半透明，内侧柔软破碎；不用金属明暗表现厚度。
- 交点短促亮闪，少量冲击线向下和向前散开，低位气浪前翻；余波约 0.6 秒内不均匀散去。
- 第三道月牙是现有终结段内的视觉加强，拟不增加伤害次数、范围、目标、消耗或冷却。精确动画、命中同步与视觉时长需在获准制作小样后验证。
- 护盾与其他技能保持当前版本。战士不增加法阵。
