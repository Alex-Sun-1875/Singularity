# 雷系普攻：短电矢 v14

按 2026-11-17 用户要求，为雷系普攻制作轻快、可连续施放的短电矢，并接入当前 Cocos 主工程。

1. 抬手：伸出的施法掌心收拢两股细电丝，规模小于主动技能。蓄电与出射共用实际掌心，并沿用绘制前的骨骼锚点同步。
2. 飞行：白亮细芯、蓝紫外缘，约 0.78 米以内的短电矢配一条细短分叉；每发由真实弹体 ID 改变小折点，尾部只存在于已经飞过的距离。沿用实际弹体与碰撞，不画贯穿手掌和目标的长连线。
3. 命中：只在真实命中时迸开几道局部电花，约 0.14 秒内消散。落空没有目标爆闪；普攻不积累地面雷晕。

保留原有普攻节奏、射程、飞行速度、伤害及附雷／被动规则，音频复用现有雷系蓄电和释放反馈。仅复用既有雷电图集、动态网格与有界批次，没有新增图片、依赖、灯光或生成模型。常规飞行／命中共用一个网格批次，掌心蓄电单独跟随角色。

本次验证为正常 test 档 Web；在实际二维绘制场景及原生 3D 主角中录制连续命中、减少动态、落空和雷矛回归，录制器只设置训练目标、相机、输入与会话时钟，没有替换运行模块、手造命中或补发伤害。最终完整构建固定于 `src/.tmp/thunder-basic-v14/web`，原生逐帧记录在 `src/.tmp/thunder-basic-v14/final/implemented/`；临时录制和审核脚本在同目录上级。

`checked` 为发现普攻仍从旧握柄出口发射时的中间诊断，不作为最终展示。交付动画、分阶段图及验证数据均来自修正掌心出口后的 `final`。类型检查和 66 项既有战斗、技能、输入检查通过；最终画面检查、用户美术验收和 TapTap 真机验收分别记录于 `verification.json`。
