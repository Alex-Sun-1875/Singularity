# 烈焰喷流：细长、通透、向上流动的原稿火舌

用户指出 v26 中间亮线像闪电，火苗与选定设计稿不同，底部法阵颜色也仍有差别。本次不再沿用带粗弯亮芯的生成火柱：直接从最终选定原图提取细火舌，排除地面圆环，减弱长中央高亮，保留两侧分散的细焰。

原图火舌制作成 32 帧循环。两组原图细焰只向上移动，交替平滑消隐，根部固定；移除蛇形噪声扭曲、贯穿亮芯的提亮与不透明度强化。火苗使用轻微提亮的半透明合成，地面和角色仍能透出。网格保留前后深度，但水平纹理按均匀比例展开，取消原先放大中心线条的正弦映射和整体弯摆。

用户随后指出中间不应有空心。此前削弱亮芯的透明遮罩已取消，改用两侧原始细火舌补入中央，使体积连续、柔和、半透明；法阵内圈也完整覆盖柔和填色。未用一条透明缝替代原来的亮线，未采用会使根部过曝的强叠加发光候选。

法阵保留已恢复的双环、可见侧曲纹和前侧小纹样；减少被重复印在地面的后部火苗亮纹。环线仍为金色，低透明度光晕与圈内填色向原稿橙金色调整，保持前半圈填充、轻微流动与渐隐。
