# 战士最终技：尖端朝上·弧腹贴地 v34

用户明确纠正上下关系：短尖应朝天空，弧形下缘应贴地，尾部也应贴近地面、不要翘起。本版覆盖 v33 将整片刀气铺平的方向；刀气竖立在世界上方向与施法方向构成的平面中，短尖在上、最低外弧和细尾尖均靠近地面，整体仍沿施法方向离体前飞。

本轮保持前两段效果、原生三个动作、已有气浪密度、流动纹理、1.05 秒视觉时序及推进方式。原素材与正式 shader 均不改；修正只在本目录的一次性渲染上下文中生效，尚未接入正式游戏，护盾和其他技能保持当前版本。

## 形状与动态

- 短尖抬向天空，厚弧腹位于下方；下缘随地表采样，向前飞行时保持贴地关系。
- 细尾朝身体后拉，尾尖保持贴近地表、不向上翘，厚前头向前冲。出生后脱离人物，收招后继续推进并自然消散。
- 保留 v33 密度片元和确定性流动纹理的气浪质感，只纠正竖立朝向及上下映射；不新增伤害、碰撞、范围或施法等待。
- 参数由 `swoosh-profile.json` 追溯，片元为 `swoosh.frag`，流动纹理为 `swoosh-flow.png` 及 `swoosh-flow.rgba`。纹理来自 `build-flow.py` 的确定性生成，不使用生成式重绘或插帧。

## 验证范围

不再使用“全网格离地不超过 0.20 米”或“波面与地面平行”的旧检查，因为上方刀尖必须升起。改为测量：

- 实际波面法线的 Y 分量绝对值小于 0.00001，且与施法方向点积近零，确认刀气竖立在上方向／施法方向平面内。
- 所有顶点均不低于地表 0.06 米；最低外弧离地不超过 0.20 米，尾尖离地保持在 0.06–0.20 米。短尖始终至少比弧腹高 0.25 米；成形年龄超过 0.1 秒后，短尖高于地表 1.5 米，并至少高于细尾 0.4 米。
- 端部仍共点，前头领先细尾、厚截面清楚；推进距离单调增加，实际位移与施法方向一致，人物收招后继续前进超过 0.3 米。
- 提案与当前版、v33 提案的五次实际命中事件一致；原生三动作齐全，中途不回 idle，无渲染缺失、控制台错误或特效池溢出。
- 视频及 GIF 完整解码核对帧数、速度和时长，实际高度、法线与推进结果记录在 `provenance.json`。用户美术验收待确认。

“当前游戏效果”的基线复用 v32 的真实 current 实录，同一稳定编译产物、角色、机位、视口和游戏时钟，编码前再次核对编译哈希；没有改帧伪造对照。新方案另行以实际原生渲染录制。
