# 陨石法阵淡橙填色与透明度 v37

用户要求中央偏黑区域补类似火焰的淡色，法阵本身再增加透明度。本轮沿用v36已校准的火焰橙色、完整正圆、清晰纹样与落地保留时序，只调整贴图透明度和内圈底光。

中央填色应是连续、半透明的橙色光层，地面仍可见；借既有火焰图集的低频强弱保留自然深浅，避免增加火焰堆、花纹或中心空洞。主纹、光晕和填色分层，降低实心感后仍保持纹路清晰。

复用既有双纹理材质与同一网格，不新增实时灯、粒子、绘制层、模型生成或依赖。`FireGroundEffects`仅更换两条纹理资源名称，`mainColor.a`与只读opacity继续表示原游戏时钟的0.9保留／渐退曲线；纹理的透明度是本轮用户明确授权的独立调整，不能把该逻辑opacity当成纹理逐像素alpha。

来源及工程样张记录在 `assets/`。修改前实景为 `../meteor-flame-colour-v36/final-r1` 与 `final-empty-r1`。材质计算样张、标准test构建、真实实景录制和用户／TapTap真机验收分别记录，不用计算合成冒充实际动画。
