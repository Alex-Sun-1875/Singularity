# 雷系原稿配色与层次对齐稿

继续对齐用户指定的首版 2D 雷系设计。本轮修正亮地面上的过白叠加与细分叉层次，随后按用户“还是粗了一点”的反馈，将主干及蓝色外缘整体再收窄一档。

[三招原速对照](media/previous-vs-revised.mp4) · [本轮单画面动画](media/revised-full-size.mp4) · [雷网动图](media/thunder-comparison.gif) · [原稿对照板](media/reference-comparison.jpg)

主弧轮廓、粗细变化、长回弧、外伸分叉和电光纹理沿用从用户原稿提取的数据。提取定位见 [reference-trace.png](reference-trace.png)，来源指纹和采样记录见 [reference-profile.json](reference-profile.json)。素材使用确定性像素处理。

白芯、蓝色主体与外围柔光使用不同的透明覆盖率与发光强度，保留原稿的蓝紫色过渡。雷网继续显示实际连锁图，减少额外的平行细丝。按第二次收细反馈，出手主弧从 0.510 收到 0.370，目标间主弧从 0.350 收到 0.270，粗细起伏最高倍率从 1.35 压到 1.20。对照保留相同纹理、动作、靶位与机位。

贯雷长矛命中后，原有全长提示弧与命中弧会同时显示。本轮合并为通向最远实际命中点的一条主干，保留全部实际命中点的接触光，减少重复叠加造成的过粗观感。未命中时沿用原有全长放电提示。

主弧与细分叉在同一图集中使用各自的原稿纹理。主弧保留窄的白热中心，分叉保留纤细的蓝白电光。细分叉的能量与覆盖率单独处理，便于在当前亮地面上辨认，并减少粗主弧纹理反复叠加形成的白片。

使用当前 Cocos 的原有网格池、内置材质、3D 角色和实际施法动作。施法手到首个落点的连接跟随骨骼，后续沿已有目标关系展开。录制日志核对施法、释放、命中、连锁和伤害事件，并比较判定几何、靶位、机位与实际骨骼。

本目录仅保存设计审稿素材和录制器，候选呈现模块只在本地录制响应中替换。正式游戏未接入。当前为本机 Web 审稿，TapTap 真机效果和性能待正式接入后验证。范围法阵仍为陨石 `FIR_02` 专用。

生成及处理来源、原生录制输入和媒体验证见 [provenance.json](provenance.json)。美术自检与用户确认分别记录。
