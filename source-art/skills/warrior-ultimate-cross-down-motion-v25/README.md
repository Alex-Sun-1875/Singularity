# 战士最终技：交叉斩结合垂直下劈动态小样 v25

本轮仅制作隔离动态方案，尚未接入正式游戏。基于当前编译产物，在一次性浏览器上下文中复用实际角色、三段原生骨骼动作、银色流动材质、网格和游戏时钟；没有使用生成图片制作动画，也没有插帧或重绘角色。

## 动态方案

前两段沿用现有横扫、上挑。终结先展开约 120° 的交叉月牙，约 0.045 秒后叠加第三道垂直月牙。第三道月牙固定世界竖直轴，中心只沿 Y 向下移动 1.28 米，水平位置不动；没有前倾转向或横向甩动。下落约 0.17 秒，保留一道低亮上方尾流，收尾有短促接触光和小幅贴地气浪，原有流动材质负责自然消散。

交叉月牙在下劈出现后压低约 28% 亮度，维持可辨的交错轮廓。整个终结仍放在当前第三段的 0.62 秒视觉窗口内，不增加蓄势或施放等待。

角色复用 `attack_sword`、`attack_sword_2`、`attack_sword_3` 和原有短交叉淡化，不修改动作素材。小样仅对该技能关闭呈现层的短接触停帧，使原生动作持续采样；不修改游戏逻辑、伤害时间或动作总时长。`preview.js` 的两处局部覆盖仅存在于录制浏览器，关闭该上下文即消失，默认游戏预览保持原状。
