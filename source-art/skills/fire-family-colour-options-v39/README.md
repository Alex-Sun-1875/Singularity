# 火系整套统一配色候选 v39

2026-11-17 用户已选择 **C 琥珀金焰**，见 [选择记录](selection.json)；运行接入及实景验证维护于 [v40](../fire-family-amber-v40/README.md)。下文与生成记录中的候选状态保留为选择前的历史说明。

用户要求火焰颜色更深、更亮，以本轮截图红框内的火焰为参考，先给可选示例；随后强调四个普通技能的颜色必须对齐。本目录仅制作配色候选，不修改运行资源、材质、玩法或构建，不代表已接入或通过美术确认。

最终 [三方案整套对照](fire-colour-options-A-B-C.png) 覆盖赤焰枪、烈焰喷流、焰心护盾、焚焰火域，以及同一色系的陨星天坠。每列使用一套共享色阶，不能将五个技能分别选成不同颜色。

- [A 熔金炽橙](option-A.png)：浓橙火身、明黄亮芯，作为接近用户参考的推荐候选。
- [B 赤焰熔芯](option-B.png)：赤红外焰，整体更偏深红橙。
- [C 琥珀金焰](option-C.png)：琥珀橙底，整体更偏金橙。

示例由原生实景画面局部进行确定性 RGB 校色和排版，没有新生成图片。红框参考只保留必要 [局部](reference-crop.png)；来源、裁切、原始截图哈希、色阶和像素检查见 [provenance.json](provenance.json)。每项均使用同一帧、同一裁切和相同尺寸比较，造型与密度不作为本轮候选变量。HUD 图标沿用原色用于身份对照。

校色先隔离暖色效果、估算深色地面贡献，再按统一亮度分层将旧材质的黄色、棕色或淡橙色归入同一套色阶；为亮芯保留少量明黄。四个普通技能使用同一映射和色阶位置，亮度归一化只平衡原画面的强弱。人物附近使用保护区域，亮度较高的前景火焰仍参与校色；未纳入遮罩的像素逐像素保持。此方法服务于视觉选择，不替代选定后在真实运行材质上实现统一配色。

历史原生截图用于候选展示，不宣称它们来自本轮新增导出。火域使用 v38 的最终加密实录，其余来自记录中的已有技能实录；原始来源明确保留，不把静态校色图写成 Cocos／TapTap 验收结果。

`make_options.py` 可重建总图、三张独立方案和处理记录。已检查图文布局、同源图像、共享色阶以及遮罩外像素；用户选择、运行接入、动态表现和 TapTap 真机均待后续实际工作。
