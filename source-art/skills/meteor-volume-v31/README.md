# 陨石落地：厚体积翻卷火浪 v31

本轮依据用户对 v30 的反馈：落地效果仍像地面几条光线，要求从中心向外爆开、立体翻卷、显著提高火焰密度并对齐批准稿亮度。v30 陨石保留为被否定的历史对照，不能作为本轮美术通过依据。

## 本轮改动

只调整陨石落地后的大爆燃与退火。使用专用连续厚火浪纹理，构成从同一爆心向外扑出的开放宽火舌，并填实中央低火体。旧七条细火矛带和短接触瓣不再作为陨石主体。火矛、火域、五点喷流、护盾、陨石下落和法阵保持。

前锋使用真实落地事件年龄，一次向外扩散，在约0.32秒达到真实半径；不再用 `.22–.35` 往返的表现进度计算扩散。主燃保留至1.2秒，1.65秒收低为连续余火，并在既有4.55秒总表现窗口内渐退。纹理及卷面细节继续流动，减少动态只降低流速与扰动，保留关键外扩时序。

采用项目已有有界网格和透明粒子材质的方式：中央3个交叉火浪片、内侧6片、外侧9片在纵深上交错重叠，随同一冲击前锋由中心向外扩散。各片从地面竖直抬升、向径向外倾后回卷，横向主要面向战斗镜头并错开角度；没有闭合环壁、横向拱帽或独立地面法阵。UV纵向从固定地面根部走向原图参差火尖，横向边缘软化，保留原纹理自然轮廓。主燃高度参数约1.6–2.2米（随现有等级），中央另有0.35–0.5米连续低火体，后期一起收低。一个共享材质、一个有界动态网格，峰值1801顶点、2880三角。真实范围、伤害、段数、目标、消耗、冷却和存档规则未改。

第一轮 `after-r1` / `after-empty-r1` 使用三层闭合卷面，实景呈现同心碗壁和空心；第二轮 `after2-r1` / `after2-empty-r1` 改开放横向弧帽，但实景仍像透明伞瓣，纹理横向铺放缺少自然火尖；第三轮 `after3-r1` / `after3-empty-r1` 恢复根尖UV，但仍像长扇叶，中央暗且前侧显帘状；第四轮 `after4-r1` / `after4-empty-r1` 改交错火浪片后，中心、密度和亮度改善，但出现硬矩形边和水平断层；第五轮 `after5` 的像素级侧边与底部羽化仍未消除前沿亮截面；第六轮 `after6` 对实际网格收身并打散底部横向纹理后，仍发现范围夹取生成的亮圆柱截面。上述轮次均保留为失败记录，不能作为最终效果或本轮美术通过依据。

第七轮另存 `after7`：将实际径向距离写入浮点顶点通道，片元对0.72–0.995倍真实前锋做连续退隐，范围夹取形成的侧截面在最外缘完全透明；保留内部密度和亮度。火舌自身还有连续侧边与根部羽化，物理横宽随高度收身、边缘不对称，卷面轻微错高，底部火体用两个旋向纹理混合来消除长横向接缝。

## 美术来源

内置云端 OpenAI image_gen 参考批准稿必要局部生成专用火浪素材；未使用本地模型。原图、提示词、透明通道处理脚本、处理小样和来源记录在 assets/。Pillow/NumPy 仅作确定性缩放、周期衔接与透明边缘处理。

生产纹理 `fire-meteor-roll-v31.png` 为1024×512单图，U周期，源图rootV=.9375，保留连片橙金主体与宽亮褶。主体alpha中位约.78；开放扇形火浪沿V向上输送火纹，根部保持固定，中央另用连续火体填充。最终通透度由顶点权重与材质控制，未通过高频掏空来伪造细节。生成完成、素材检查、实际游戏检查和用户美术验收分别记录。

## 验证方式

复用现有 Cocos 训练场录制流程，只录陨石正常靶阵和空地各9秒，使用真实输入、默认镜头与完整HUD。before / after采用相同独立施放序列；阶段图按真实落地年龄选取0.05、0.25、0.65、1.25和4.60秒，检查冲击、外扩、卷起、收势与退尽。录屏和图表不后期叠加技能。

这是正常 test 规则的 Web 验证，不升版、不制作交付包、不上传。TapTap真机显示与性能仍待设备验证。实际效果不能以贴图生成成功、网格层数或静态亮度指标替代验收。

## 本轮实景状态

`after7-r1` 与 `after7-empty-r1` 均录制9秒、270帧，正常镜头4.3、完整HUD；无运行报错，末帧清空，暂停恢复、减少动态和雷／战／火切换清理完成。与紧邻 `after2` 的独立施放序列结果一致：正常靶阵4命中、740伤害、1未命中、0暴击，空地0伤害，冷却与释放时间一致。原始v30视觉基线为4暴击、1556伤害；期间其他工作修改过核心规则，不能把最初基线与本轮宣称为伤害完全相同，原始差异与源码哈希另存verification。
