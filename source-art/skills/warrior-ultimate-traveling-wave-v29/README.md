# 战士最终技：前厚后细的弯刀冲击波 v29

本轮按用户最新要求修订第三段：前方是厚实的弯曲波前，后方收成细尾；释放后脱离人物，持续向前推进，并在移动中消散。脚边只作为出生位置，放出后不再固定在人物脚下，也不跟随人物收招停止。

本目录仍为独立动态小样，未接入正式游戏代码、材质或资源引用，未制作新包。基于当前战士编译版本，在一次性浏览器中复用实际角色、原生三动作、前两段效果、120°交叉斩及银色流动材质；第三段仅作局部呈现覆盖。

## 形状与连续动作

- 横扫、上挑后保留交叉斩，第三段以竖直波面形成弯刀冲击波，厚波前与细尾有清楚主次。
- 冲击波从脚边成形后沿施法方向前进；人物收招回到待机时，它仍继续推进、拉开尾流并散去。
- 尾段延长仅用于展示视觉余波。原来的命中时间、五次目标命中、目标、数值、范围、消耗和冷却保持；推进尾段不新增伤害或碰撞。
- 继续使用原生三个动作及短交叉淡化，录制上下文中关闭该技能呈现层的短接触停帧。不增加蓄势或施放等待。

## 验证范围

录制后由 `media.py` 核对两个场景中提案与当前版的真实命中事件逐项一致，每个场景仍为五次技能目标命中；活动层有实际渲染模型，无控制台错误或池溢出。交叉投影约 120°，第三段波面基准竖轴为 90°，动作期间不切回 idle。

位移检查以实际渲染层的位置和出生点为准：推进距离单调增加，世界位移与施法方向一致；人物动作结束后、第三段视觉年龄小于 0.85 秒时，主波仍须继续前进超过 0.3 米。脚边对齐只约束出生，不再要求整段固定锚点。视频和 GIF 完整解码核对帧数、播放速度和时长，结果见 `provenance.json`。

形状、运动与最终美术验收仍待用户确认。录制使用游戏实际帧，没有生成式重绘或插帧；同机位对照使用相同角色和相机。隔离 Web 小样不代表正式接入、TapTap 真机或手机性能验收。本轮复用现有录制流程，没有扩写与呈现方案无关的规则测试。
