# 当前技能特效局部优化审稿

这轮使用当前 Cocos 实现的动作、模型、弹道和材质入口，录制当前版与局部优化版。两个版本使用同一个 Web 导出和斜向机位，便于观察技能沿攻击方向的纵深。新增审稿文件位于本目录，候选模块只在录制器的响应中替换。

## 本轮调整

| 部位 | 当前实现中的原因 | 本轮局部调整 |
| --- | --- | --- |
| 战士刀面纵深 | 刀面主要沿扇形外缘分布，径向较浅 | 沿用当前扇刃网格和钢刃纹理，增加径向厚度并收窄侧弧 |
| 雷系出手 | 手部充能粒子较散 | 缩小现有手部充能与释放闪光，聚集在真实手部锚点 |
| 雷系主弧 | 主弧较细，旁边叠有平行细丝和多处分叉 | 主干加粗约两倍，保留蓝紫外层和亮芯，减少次要细丝 |
| 连续放电 | 三次显示脉冲之间存在空档 | 同一次命中的显示包络连贯，保持原有连锁关系和伤害事件 |
| 火弹比例 | 方形图格被压为宽度 52% 的高度 | 恢复图格比例，保留既有火核、尾焰和物理弹道 |
| 爆燃纵深 | 中央贴片与前排焰层距离较近 | 保留现有一个主焰团和两个前排焰团，拉开前后距离，并扩大层间衔接 |
| 火焰材质 | 透明提取挖掉了部分暗部，底缘存在平切痕 | 从该图集原始画稿恢复内部明暗，柔化底缘，并提高低位焰团图格分辨率 |
| 火海衔接 | 相邻焰片存在间隙，播放相位差较大 | 在原有条带铺火方法中增加重叠，并缩小相邻格子的播放相位差 |

法阵使用规则继续按用户指定的单个技能登记在 [陨石专用规则](../reference-seals-v3/usage.json)。本轮特效调整的入口是现有 `SkillEnergyStrokes`、`NativeSkillVfx`、`Effects`、`SkillFireSprites` 和 `MeleeBladeSurfaces`。

## 记录方式

复用原有录制夹具和真实战斗事件。逻辑与骨骼按 60 Hz 推进，输出 30 帧/秒。比较普攻三连、贯雷长矛、连锁雷弧、万钧雷潮、赤焰枪、焚星坠落和焚天火海。

逐招核对完整事件日志、实际受击者、伤害、判定几何、靶位和相机。输入与输出指纹、动画片段和伤害事件见 [provenance.json](provenance.json)。这些结果属于本机 Web 审稿记录，TapTap 真机性能在正式接入时验证。

火系图片处理复用既有 `fire-runtime-v7` 的原始画稿和生产图集，处理步骤与来源见 [fire-processing.json](fire-processing.json)。生成模型的原始来源沿用该素材已有记录，本轮采用确定性像素处理。
