状态：用户反馈本版仍像实体刀刃。范围与连斩修正继续沿用，视觉已由[v20月牙冲击波](../warrior-pressure-wave-v20/README.md)取代；本目录媒体保留作前后对照，不作为当前已确认美术。

## 实际改动

| 项目 | 修正 |
| --- | --- |
| 银色波身 | 用银灰明暗与窄亮刃口替代接近纯白的大面积顶色；保留厚度，内沿和尾部自然消散。旋风斩保持原双圈和收尾时间轴。 |
| 断空斩 | 改为约159°的尖端半月轮廓，依挥砍方向交替前推；一级真实距离从3米扩大至3.9米，五级为4.5米。前段保留受击动作而不推走目标，最后一段恢复原击退，使边缘目标能接上后续斩击。 |
| 破军突袭 | 落点以两道半月交叉，屏幕投影钝角保持120°；真实交叉条带长度由1.6–2.08米扩大至2.88–3.744米，宽度扩大35%。突进距离和碰撞停止沿用原值。 |
| 伤害与护盾 | 保留各级伤害系数、段数、单体目标预算、资源、冷却与联动。护盾技能、护盾被动、统一护罩代码及素材未改。 |

范围同时更新在设计数据、实际判定和技能说明中，不是单独放大渲染。主数据为 `tools/design/warrior-crescent-revision-v2.json`，通过原导出工具生成 `PureSkills.ts`；旧V2/V3/V4目录保持冻结。

复用现有 Cocos 网格、纹理、材质和资源池，无新增依赖、动态灯光或生图资源。半月复用原旋风月牙网格，区分弯曲波身和收束尖端；原生骨骼动作与真实释放事件继续驱动连招。
