# 发光法阵与垂直短喷流 v10

用户要求修正 v9 的深色地圈与三角形燃烧形态。本轮只重画造型：地面改为明亮的橙金法阵，参照先前选定的火系阵纹保留双层外圈、少量圈间刻纹与连贯内纹；喷焰集中在阵心，沿世界竖直方向向上，短而有厚度，避免铺开成火堆。

候选比例为直径约 1.2 米的法阵、约 0.5–0.6 米高且 0.22–0.30 米宽的短喷流。五个喷发点沿前方成列。此为造型比例，不是正式数值。陨石终极定位、扩围与合并火域提案保持原样。
