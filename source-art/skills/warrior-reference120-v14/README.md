按本轮要求，取消整层 55% 的半透明折减，亮刃主体不透明：核心顶点透明度为 1，原有波身纹理对应区域 Alpha 为 255，稳定出波阶段材质透明度达到 1。保留原图的柔化轮廓、起收势和尾流消散；原有波面网格与顶点轮廓不变。银白色与原图一致，没有新增生成图像或重新配色。

“120°”明确按画面里的交叉钝角计算，对应另一侧锐角为 60°。横向波前保持原来的空间朝向，只调整另一道波面绕攻击方向的倾斜。录制时直接测量最终相机投影后的两条长轴，核对钝角为 120°；标注图单独显示辅助射线与角度，原速视频和动图不带辅助线。

沿用真实挥刀、技能释放、命中和原生多段节奏，包含普攻三连、断空斩、破军突袭、铁誓壁垒、裂地审判、破晓裁决、战艺精通、铁誓不屈。战士没有装饰法阵。

这是独立 Cocos 3D 设计预览，未接入正式游戏，未新增玩法伤害段数。复用冻结场景、原生角色骨骼、相同靶位和相机，逻辑与骨骼按 60 Hz 推进，原速视频为 30 fps，细节与对照为 0.5×。来源、事件、主体材质与角度核对见 `comparison-verification.json`、`provenance.json`，被动局部的实际触发时刻与裁切记录见 `showcase-focus.json`。造型方向已获确认，逐招展示待用户审阅；TapTap 真机性能未验证。
