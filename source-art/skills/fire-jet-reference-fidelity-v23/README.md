- 保留选定图片里的细长火舌、橙金亮线和间隙，去除叠厚的火焰层与实心底部亮团。
- 恢复双层外环、前后菱形与成对内部曲纹，火焰底宽、高宽比例随法阵保持一致。
- 小法阵沿真实地面细分贴合，避免原四角平面与地面相交造成断线。
- 使用普通透明混合保留橙色；五个出火点、定向排列、持续四秒与结束后的渐隐沿用现有方案。没有改伤害、范围、冷却、解锁、技能槽或存档。

## 来源与复现

源图为 `../fire-selected-reference-v18/user-selected-effect.jpg`，SHA-256 为 `52b78fa21809693c830796ed479eb42acb545258f19286c0ff80f1d4acc20b36`。只用 Pillow/NumPy 从该图提取火舌，去除中性底色、恢复软透明度；十六帧轻微摆动沿用同一束火舌。小法阵按选定图中的双环、曲纹与轴向菱形描出，没有另做三叶纹样。没有调用生成模型。

`prepare.py --preview-only` 先生成本地素材预检图，去掉该参数才更新生产纹理；沿用已有资源路径与 UUID。源图与美术对照保持显示色彩，生产 PNG 的 RGB 按当前 legacy-forward 实录校正传递曲线，避免橙色被抬成黄色；火焰另校正光学透明度，保留亮线并打开火雾间隙，法阵透明度保持。`capture.cjs` 复用实际游戏录制器，仅选择 FIR_04 并记录法阵投影，用于原图与游戏画面按相同直径对照。`media.py` 排版录像帧、生成视频并检查编译哈希、纹理像素、五个喷发点、单层火焰网格、回收与暂停恢复。

类型检查、Web 构建和实际游戏检查见 [verification.json](verification.json)。本轮没有玩法变更或新增测试依赖。TapTap 真机画面与性能仍待验证，最终用户美术验收待确认。
