# 战士最终技：贴地交错刀气 v32

用户红框指出上方弧线仍悬在腰部。本轮定位到它来自第三段保留的旧交错分支，其锚点约高 1.4 米；v31 新增的主行波已水平放置并离地约 0.18 米。本轮仅把旧的两道交错分支改为贴地：节点朝向保持水平，锚点离地约 0.10 米，网格按各顶点地形高度贴合，保留原 120° 投影交错关系。

主行波的水平双尖、不规则月牙、前厚后细、持续推进与移动消散保持。原角色下劈动作、时序、银色流动材质、护盾和其他技能保持。第三段收招后的推进尾段仍只是视觉余波，不新增伤害、碰撞、范围或其他玩法规则。
