# 战士最终技：厚前头、细尖尾的纵向勾形冲击波 v33

用户本轮推翻旧 C 形方案，要求细尖尾指向身体、厚前头继续前移，按类似 Nike 勾形的方向重新设计。本版第三段沿施法方向纵向展开非对称勾形，波面仍与地面平行；将两道旧交错分支和原月牙主波整体替换为一张新轮廓网格，不再叠加旧 C 形或要求原 120° 交叉。

本目录仍为基于当前游戏角色和原生动作的独立动态小样，尚未接入正式代码或资源引用，护盾与其他技能不调整。

## 本轮重新设计

- 一端为朝身体后拉的细尖尾，前方为宽厚勾腹与短收尖；厚前头相对原构图进一步前移。
- 水平原生网格采用全新非对称轮廓及地形顶点贴合，不拘旧素材形状；出生后脱离人物，继续向前推进并散开。
- 使用新的气浪密度片元、透明层次与 256×256 流动纹理。新纹理由 `build-flow.py` 确定性生成，没有云端生图、模型推理或生成式重绘。
- 前两段效果、原生三动作与既有短淡化保持；第三段新视觉约 1.05 秒。推进尾段不新增伤害、碰撞、范围或玩法规则。

轮廓参数在 `swoosh-profile.json`，密度片元在 `swoosh.frag`，纹理及原始像素为 `swoosh-flow.png`、`swoosh-flow.rgba`。项目原素材与旧 shader 保持；新 shader、纹理与轮廓仅供本轮录制上下文使用，没有替换正式材质。

## 验证范围

本轮不再保留旧版 120° 交叉、旧主波几何或逐帧主波不变的验证。新的检查以实际主层网格、材质和位移为准：

- 主层水平，端点共点；前端局部深度须领先尾端超过 1 米。成形年龄大于 0.1 秒后，厚前头所测截面宽度须超过 1 米，细尾保持在行进方向后方。
- 实际网格顶点离各自地表约 0.06–0.20 米；实际材质与 Effect 均为 `Isolated:SwooshAir:v33`，避免录到旧材质。
- 推进距离单调增加，真实世界位移与施法方向一致；人物收招后、波龄小于 0.85 秒时仍继续前进超过 0.3 米。
- 提案与当前版、v32 提案的五次实际目标命中事件保持一致。原生三动作齐全，中途不回 idle，无渲染缺失、控制台错误或特效池溢出。
- 视频和 GIF 完整解码核对帧数、速度及总时长，来源哈希与结果在 `provenance.json`。

用户美术验收待确认。隔离 Web 小样不代表正式接入、TapTap 真机或手机性能通过；本轮未制作新包，也没有扩写与呈现方案无关的规则测试。原始记录在 `src/.tmp/warrior-ultimate-swoosh-wave-v33/`，默认游戏预览和正式代码保持当前版本。

“当前游戏效果”的对照基线复用 v32 两场景的 current 实录，因为编译产物稳定副本、角色、相机、视口及固定游戏时钟均相同；编码前再次核对编译哈希一致。复用的是完整真实渲染帧，没有重绘、合成或改变画面内容来伪造对照；本版提案另行通过原生渲染器重新录制。排版与裁切仅用于媒体展示。
