## 法阵时序

`NativeSkillVfx` 复用FIR02现有segment0爆燃cue、真实落点与同一法阵key。触地后透明度仍为0.9，正常4.55秒cue中保持到3.3秒，再用smoothstep渐退至结束；预警与触地不重新缩放，不用独立墙钟、伤害事件或新玩法计时器。未来cue较短时，保留期不会超过其75%。
