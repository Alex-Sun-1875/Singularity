# 火系原稿对齐 v32

本轮依据用户再次附上的“火系技能·造型区分稿”。v31 的多片厚火浪已被用户否定，不作为批准稿或美术验收基线。当前目标是原稿的完整陨石：深褐尖长岩核、橙金包焰与斜落长尾、同一法阵落点、单中心放射爆燃和低矮余火。

## 实际改动

- 陨石落线改为原稿的画面右上向左下；保留实际目标、既有加速曲线与落地事件时间。最终视觉落线为 `(-4.42,-8,3.06)`，默认相机实际投影倾角47.598度；额外抵消原图尾部相对鼻端的9.3917度偏角，让可见火尾与岩核沿同一飞行轴。现有岩核几何按真实领先顶点重锚，长轴顺飞行方向，仅绕该轴慢滚；材质压深、外形收进包焰内。
- 从原稿陨石直接提取独立包焰长尾，16帧流动图集，固定原图鼻端UV。包焰向镜头偏移只解决岩面遮挡，正交战斗镜头下的鼻端投影不变。岩尖、法阵和爆燃均注册在真实目标的 `height+.045`。
- 既有下落cue随动作释放结束，过去没有实际画到鼻尖接触地面的帧。现在在原本命中事件后的前0.045秒复用同一陨石、同一落点画接触姿态，使岩尖触地后由中心爆燃遮住；不提前命中、不增伤害事件，也不增加独立计时器。
- 移除v31的18片重复卷浪，直接提取原稿完整的单中心、中央上卷与不规则放射主形。一个884顶点、1650三角的连续浮雕面承载完整形状，中央在世界Y抬起，外围低火贴地；按相机投影补偿纵深，保持原稿轮廓和唯一爆心。16帧向外/向上流动，保留原有1.2秒主燃、1.2–1.65秒收势及4.55秒总表现窗口。
- 法阵保留既有原稿双环与曲纹，改正与镜头的朝向；纹理升至1024并提高线边清晰度，仅从对侧已出现的重复曲纹补齐原稿被岩体遮住的小段。不压扁真实地面圆形或更改预警范围来追求概念图的相机轴比。
- 原稿石块、人物、标签和底图不直接进入火焰动画；少量石块遮挡处做邻域像素插值，细小地砖暗缝做局部闭合清理。未调用生成模型，也没有后期给游戏录像叠加技能。

火矛和火域维持各自已选轮廓；喷流、护盾及玩法数值不因本轮陨石呈现改变。图像处理脚本、来源、纹理hash及鼻端诊断在 `assets/` 与 `meteor-body/`。

## 验证与状态

类型检查与正常test Web构建已完成。原生录制使用默认镜头、真实输入与完整HUD，单独检查下落20%/60%、最后可见触地前帧、同帧岩尖触地与爆燃、后续余火。最终陨石录制与逐帧事件、材质导出hash见 `contact-final-r1/` 和 `contact-final-empty-r1/`。`after`、`after2` 为鼻端包焰／倾角修正前的中间记录，`final` 保留为缺少实际触地帧的中间记录；`regression-r1/` 保存火矛与火域，另记独立编译hash。

正常test新旅程从1级开始；通过既有入口进入独立临时训练会话，退出恢复同一原旅程和装备/进度。本轮期间其他工作将 `CAMPAIGN_MAX_LEVEL` 改为80，最新实录训练角色因此为80级；不强改回旧40级，也不将历史40级伤害740与当前数值宣称完全相同。

本地原生画面复核与最终用户美术验收分开记录。完整动态与其余两招回归记录随交付保存；TapTap平台和目标真机显示/性能另行验收。

最终陨石正常/空地各9秒270帧，真实命中段4命中、812伤害、1未命中、0暴击，空地0伤害；所有鼻端/法阵/爆燃事件落点一致，暂停恢复、减少动态、切换职业、末帧清空和录制期间源码导出资产稳定检查完成。火矛回归为6秒7命中279伤害，火域为8秒20命中692伤害。回归与最终陨石来自两个独立编译产物，按段保留证据，不宣称同一build或与旧40级伤害相同。
