## 技能与规则

| 技能 | 当前分工与表现 |
| --- | --- |
| FIR_01 赤焰枪 | 单体弹道，尖锐火核、通透尾焰，命中残焰自然退去；保留原伤害、冷却及目标数。 |
| FIR_04 烈焰喷流 | 四级解锁的普通技能；五个小法阵在前方排成一列，竖直喷焰四秒。位置和方向在释放时固定，普通等级长 7–8 米、宽 1.2–1.6 米。 |
| FIR_05 焚焰火域 | 六级解锁的普通技能，合并原火墙与火海的区域燃烧和减速；同一施法者最多保留一处，持续四秒，宽 6–8 米、深 3–4 米。 |
| FIR_03 焰心护盾 | 沿用已确认的统一立体护罩与火系纹样，继续完整包住双脚。 |
| FIR_02 焚星坠落 | 十一级解锁的终极技能，12 秒冷却、消耗 45 终极资源；双层纹样法阵预告，范围半径 3.8–5.5 米，主爆燃约 1.2 秒，冲击后余焰约 4.55 秒内逐渐消散。 |

普通槽为 `FIR_01 / FIR_04 / FIR_03 / FIR_05`，终极槽为 `FIR_02`。火域沿用既有持续伤害分拍，普通敌人减速 35%，首领与队长使用已有减速限制。喷焰以定向持续伤害为主，不再继承旧火墙减速；自动战斗使用正常朝向，不再沿用横置火墙的九十度转向与近距离限制。合并技能没有叠加两份原技能伤害，新的普通技能预算低于终极；高级陨石沿用真实次级伤害拍，不再重复启动整场主爆炸。

按用户明确要求，直接采用当前规则，未增加火系旧存档迁移、旧版技能目录快照或新的存档版本。既有存档文件没有被删除。

## 美术来源与实现

地面喷焰以用户最终选择的 `../fire-selected-reference-v18/user-selected-effect.jpg` 为准，保留橙金、通透、竖直上喷的火舌。`prepare.py` 使用 Pillow/NumPy 提取必要火焰局部、去除灰色地面对色彩的影响，生成十六帧细微摆动；小法阵用确定性路径重建双环和三道粗卷纹。没有新调用生成式模型，提取与来源记录见 [provenance.json](provenance.json)。

喷焰由前后火焰层与低透明度贴地火光共同组成，填补圆面前半部分；火焰采用引擎现有加法混合以保留浅色地面上的发光，法阵保留普通透明混合。五处火焰和五个法阵合并为两个有上限的原生网格表面。大陨石法阵复用已确认的首版火系纹样。其余火焰生命周期、低矮翻卷与弹道资源复用此前火系素材。范围法阵只用于陨石；喷焰的小圆阵是该技能已确认的出火口。

表现层读取真实技能范围与释放事件，通过现有 `GameResources` 加载，只在火系资源启用时预载。未引入依赖、动态灯光、伤害判定或平台专用接口。结束后火势降低、亮度变弱，地面技能额外有约 1.8 秒的视觉冷却消散，不延长真实伤害。
