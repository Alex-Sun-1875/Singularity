从原图周边未发光石地估计背景，分离真实雕纹与局部彩色光场；主彩色1024纹理保留原稿前景RGB及coverage，512光场保留原稿暖光的强弱变化。两张RGBA共5MiB，替代上一张4MiB法阵纹理；同一网格／同一材质双采样，无实时灯或额外绘制层。材质使用原RGB雕纹覆盖加原RGB光能，光场仅有 `.006` 系数的微弱吸收，避免叠成不透明深色圆盘。纹理角色、精确公式、SHA与发布记录见 `seal/reference-r2/provenance.json`。

原稿陨石遮住的后圈局部使用可见原纹对应片补全，隐藏内盘只用周边原光场平滑过渡；未知雕纹不能声称逐像素还原。`seal-v34r2-reference-reprojection-cleared-final.jpg` 上排是同椭圆回投诊断，特意覆盖原图陨石以便比较可见纹样；下排为材质公式计算。它不是游戏截图，最终颜色与投射须看实际Cocos预警帧。首轮单色mask及较早清理过程保留为历史失败证据，不作为交付效果图。

## 中心点燃

`FireImpactEffects` 的完整火面从真实触地起就保持 `2.20×radius` 宽度和完整UV，移除旧 `width=front×2.20` 造成的整幅缩放。爆心约 `.12R` 即刻点亮；前锋在 `.020–.280s` 向外传播，各点到达后22ms达到原有密度，并带短暂局部新燃亮部。已经燃起的纹理不随前锋再缩放或重新淡入。

仍是原v32连片爆燃图集、同一884顶点／1650三角曲面和共享材质，后续1.20秒主燃、原单调收势及4.55秒总时窗保留。0.36秒后点燃及新燃边缘都已完成，shader跳过早段正弦／幂运算。独立小接触分支保持原样。来源、参数与实现哈希在 `impact/provenance.json`。

`supportWidth`／`supportDepth`描述固定承载，`frontRadius`描述点燃前锋，`geometryScale=1`仅为实现检查；可见火焰是否还有整片放大感，要看实际前0.65秒各帧。`peakHeight`为完整几何的最高点，不能冒充已经显现的火尖高度。旧版真实inspect抽样在 `impact-before.json`。
