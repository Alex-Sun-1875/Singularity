# 内层金橙提亮 v14

用户指出 v13 内层颜色太深。本轮仅减淡内层深橙，靠近更轻、更通透的金橙色，减弱内外色差。保留前版全圆填充、向上喷射的轮廓、高度、明亮外缘和法阵。

[近景造型稿](media/light-interior-jets-closeup.jpg) · [整列效果稿](media/light-interior-jets-scene.png) · [提示词与来源](provenance.json)

先由云端 OpenAI image_gen 做内层颜色修订，再把结果作为颜色参考，仅对原图已有的高饱和橙色内层做局部正向提亮。没有替换火焰形状；浅色外缘、法阵与其他区域像素保留。内层绿色、蓝色分量增加，颜色从浓橙向金橙移动，检查记录在来源文件中。

本地仅做确定性色彩混合、缩放、裁切和排版，没有本地生成模型。当前仍为静态候选造型稿，没有改动正式游戏源码、资源或发布配置；用户美术认可状态仍为待评审。
