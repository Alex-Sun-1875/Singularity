# 已确认火系造型稿的 Cocos 接入 v30

依据用户已批准的 [v29 造型区分稿](../fire-distinct-shapes-design-v29/fire-distinct-shapes-v29.png)，在当前三维战斗表现上接入三种独立轮廓。v28 将火苗分堆复制的方向已被否定，不能作为最终交付。

- 赤焰枪：从批准稿提取集中穿刺的火矛，尖端固定于真实弹体；尾长受已飞距离和施法手锚点约束。真实命中在目标胸口产生短促定向散焰。
- 焚焰火域：整片互连火流映射实际矩形宽度与纵深，沿地形低起伏，配两道低矮相连曲面；一个有界网格承载完整火面，停止输出后继续运动并降低高度与透明度。
- 陨星天坠：保留原落线、命中时刻与终极定位；有纹理暖岩核带尾焰落下，单中心径向火流与弯曲薄火带向外展开，主爆燃后收为连片余火，按原时长渐退。

共用原稿橙金、通透和连续流动的材质风格。已有五点喷流及统一护盾保留。没有改动伤害、判定范围、目标数量、消耗、冷却、存档或动作时间。

## 资源与实现

生产火矛、火面和短命中散焰由已批准设计图的必要局部确定性去底、重采样和循环输送生成。陨石复用清洁的火面与去尖端火矛纹理，通过低矮圆盘、向外卷曲薄带和单个中央火瓣组织独立爆燃形状；短散焰纹理另用于亮核。已停用早期从爆炸画面提取的地面纹理，避免烘焙暖雾或暗裂纹。来源、参数、小样及当前运行纹理清单见 assets/、impact/runtime-sources.json；暖岩核复用匹配UV的原有CC0自然岩石纹理，来源见 ../fire-family-wisps-v28/meteor-core。

复用 Cocos 3.8.8 MeshRenderer、动态网格、原生 shader 和 GameResources 资源层；新曲面适配用于承载项目已确认的轮廓，不引入依赖、平台API、灯光或限帧。纹理在单次绘制内预乘插帧。火域、爆燃与弹体分别使用有界池，清场和切职业后释放或隐藏。
