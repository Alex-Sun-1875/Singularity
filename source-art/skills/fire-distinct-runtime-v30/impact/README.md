# 陨石爆燃：连续径向火流

当前 `FireImpactEffects` 复用已批准 v29 设计提取的清洁素材，不再加载这里早期实验生成的 `fire-impact-flow-v30.png` 或 `fire-impact-wisp-v30.png`。两张旧图、旧小样与 `prepare.py` 仅保留为待复盘的历史提取实验；不能把 `texture-sample.png` 当成当前实景或当前材质。

当前来源及精确哈希见 `runtime-sources.json`：

- `fire-field-flow-v30`：4×4、16 帧、每格 256×128。地面使用同一连续曲面，清洁火面直接铺在圆盘 XY，U 横向重复两次；两相 UV 沿中心到外侧的方向缓慢输送，外缘软化，避免极坐标引入同心火环。RGBA 在 shader 内先预乘再跨帧插值，亮度和透明合成复用已实景复核的火域标准。
- `fire-lance-v30`：4×4、16 帧、每格 256×96。七道窄曲带只取 U=.03～.86 的流动火丝，排除火矛尖端；沿曲带长度映射到 U，横截面映射到 V。纹理持续正向播放，不是静态高频裂纹。
- `fire-contact-fan-v30`：512×192 单图。小命中仍独立使用精确胸口锚点；陨石另用一个 kind=3 的中央上翻火瓣，1.55～1.95m，峰后收低渐隐。
- `fire-flow-noise-v24`：既有小噪声，只用于轻弯与流动；不改变范围、命中、伤害或时钟。

真实判定半径、下落、1.2 秒主爆燃、余火渐退继续读取原进展。单次爆燃仍只有一个有界动态网格，同一实例的多个施放共享材质，只有全局动画时间进入共享 uniform；每次施放的透明度与进展保存在顶点和几何中。

此前空地实录中出现的浓雾和随后过暗细纹均未获得美术验收。本次清洁材质接入仍须由新的 Cocos 实际录制及用户评审确认；贴图小样不能替代实景。
