# 法术抬手衔接 v13

在当前 Cocos 3D 人物、原生动画与已确认火／雷素材上优化抬手；不生成替代设计图，不更换角色，不调整技能数值、前摇、伤害时刻、拍数或冷却。覆盖五个火系与五个雷系手动技能；雷霆战印保留自动附雷逻辑，不另做手动抬手。

## 实现

- 复用现有 `Spell_Simple_Enter / Shoot / Exit` 动作，以每次实际 `releaseAt` 对齐源动画进入出手段的时刻。连续雷系打击在原动作中短促收放，最后一拍后连续收势，不按完整动作时长提前进入退出段。
- 区分实际左侧施法掌心与右侧持杖握柄。技能蓄能与发射共用掌心出口；雷霆战印三次附雷仍留在握柄上，普通法杖弹的原有发射点保持。
- 火系以现有火焰／点火图集呈现向掌心聚拢的短火苗，释放时向出手方向打开、快速收尾。雷系为三股向内收束的短电弧，复用白核蓝紫电光；不增加散碎粒子、地面法阵或大光球。
- 抬手能量只在真实前摇及首次释放后约 0.12 秒内绘制，不随每个状态／连击通知重复产生。原有弓、战士与通用技能的手部表现保持。
- 在 `Director.EVENT_BEFORE_DRAW` 跟随当帧实际掌心，避免实时骨骼／动作混合完成后手部特效仍滞后一帧。火焰只移动已有卡片，雷弧只平移该手部批次的根节点，不增加网格上传、灯光、图片或依赖；清除／销毁会撤销状态与监听。

## 本地复现

```powershell
pwsh -NoProfile -File src/cocos/Build-Local.ps1 -Platform web-mobile -OutputName spell-windup-v13 -Profile test
node source-art/skills/spell-windup-v13/capture.cjs --before
node source-art/skills/spell-windup-v13/capture.cjs --shots FIR_01,FIR_02,FIR_03,FIR_04,FIR_05,THU_01,THU_02,THU_04,THU_05,THU_06
& F:/Models/ComfyUI_windows_portable/python_embeded/python.exe source-art/skills/spell-windup-v13/review.py
```

调整前来自 v12 已固定的完整构建副本 `src/.tmp/thunder-family-v12/web`，调整后来自独立目录 `src/cocos/build/spell-windup-v13`。均提供未替换的编译模块，使用同一真实人物、镜头、场景与训练目标。录制器只设置靶场、驱动实际会话输入和时钟；不制造伤害、命中或技能释放。

靶场每条录像从相同会话时刻开始，因此调用已有渲染器的区域重置入口清除上条录像的命中定格，防止录制台时钟倒退后遗留未来的定格时间；不修改玩法状态。全部动画由当前原生骨骼与 Cocos 渲染。

`review.py` 核对十招实际抬手姿势持续变化、前摇未提前进入发射段、蓄能掌心锚点和释放后清除；五段前后对照还逐条核对实际玩法事件完全相同。输出原速＋半速视频、前后局部对比及原生释放序列。

本次十招各录制 66 帧，共 660 帧；五段调整前基线另有 330 帧。绘制前同步后的掌心距离误差通过 1.5 厘米门槛，所有前摇与短释放段均有真实蓄能绘制，到期没有手部批次残留。五段对照的原始玩法事件逐条完全一致。`media/spell-windup.mp4` 为五种代表技能的原速＋半速，`all-spells.mp4` 为十招原速，`before-after.mp4` 为同机位放大的前后抬手对比。

本轮镜头与单靶用于观察抬手；扇雷横扫在目标中心施放，没有真实命中，因此本轮只核对其抬手与清除，不把该片段当成两段命中验收。群体横扫的真实两段命中演示见 v12，本轮没有调整其规则。

类型检查、核心检查、155 项现有测试与本地 test Web 构建通过。素材和动画的最终美术验收待用户反馈，TapTap 真机效果与性能待实测。本次不打包、上传或发布，不递增版本。
