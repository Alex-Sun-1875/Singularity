# 战士月牙剑气 · 造型修正与配色候选

**用户随后选择银色、降低透明程度，并要求回到之前的十字斩与多段冲击波。当前修订见 [warrior-silver-cross-v12](../warrior-silver-cross-v12/README.md)，本目录保留此前月牙与四组配色候选。**

本轮修正上一版在画面里仍然张开过大、轮廓像卷曲波面的问题：剑气改为真正的月牙形，外侧连续弯弧、中段较宽、两端收尖、内侧留出明显凹口。厚度指月牙中段的宽度，能量面保持轻薄与半透明。两道月牙的长轴在实际镜头中的交叉锐角为约 24°，录制逐帧测量投影后的角度，不再只按模型空间的角度推断画面。

四组配色在同一模拟帧、相同角色姿态、相同场景和镜头下替换月牙顶点渐变后以零时间步重绘。形状、位移、透明度与交叉角度保持相同，只比较配色。颜色仍待用户选择，未默认视作确认。

[整套月牙技能原速动画](media/warrior-all-skills.mp4) · [半速交叉斩细节](media/shockwave-detail.gif) · [整套总览](media/all-skills-overview.jpg)

整套演示包含普攻三连、断空斩、破军突袭、铁誓壁垒、裂地审判、破晓裁决、战艺精通、铁誓不屈。整套视频暂用造型审稿的银青渐变，最终配色待本轮选择后统一。原速视频为 30 fps，细节与配色动图标注 0.5×。

参考《BLEACH》[月牙斩击的官方说明](https://bleach-anime.com/keyword/)和动漫画面中的弧形能量轮廓，提取“离剑前推、月牙两端尖、短暂叠交”的视觉语言；24° 小夹角为本项目的设计选择。图片来源、访问情况和用途见 [参考记录](references/sources.json)。没有把动漫画面用作游戏纹理。

复用冻结 Cocos 3D 场景、真实角色骨骼和实际技能事件。月牙用带真实内凹空缺的网格和顶点渐变绘制，能量面朝向审稿镜头以保持轮廓清楚，中心沿原有攻击方向在 3D 空间推进；没有新增生成图像。旧的 `blade.png` 和 `guard.png` 仅保留供预览初始化兼容，月牙材质关闭纹理采样。峰值单层不透明度约 55%，内侧及尾流继续减淡，交叉时自然叠亮。战士没有装饰法阵。

这是独立设计预览，未接入正式游戏。技能事件、投影夹角、媒体和配色核对分别记录在 `comparison-verification.json`、`provenance.json`、`colour-verification.json`；美术效果待用户审阅，TapTap 真机性能未验证。
