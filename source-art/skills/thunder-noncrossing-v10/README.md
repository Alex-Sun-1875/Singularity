# 雷系连接规则：12 怪物诊断对照

**评审结论：不推荐把本目录的“最多两条＋禁止交叉＋无路即停”试验统一用作最终雷系方案。** 用户随后要求重新判断设计方向。本目录保留真实录制和审计，作为规则取舍的证据；正式游戏没有改动。

同一场景的原行为命中 11 个目标、1 个 MISS；严格规则试验命中 8 个、1 个 MISS，另外 3 个候选因无法合法延伸没有命中。连锁闪电也从原行为的 7 个受伤目标下降到 5 个。不能让视觉排线约束减少原本应命中的目标。

## 推荐方向与资料依据

当前画面的主要问题是所有连线长时间同亮，形成发光线绳，缺少“出手—到达—命中—消散”的动势；只改图的度数和交叉数量不能解决质感。

- **连锁闪电 THU_02：快速逐目标跳跃。** 从瞄准的首目标出发，优先近邻。一个目标通常一进一出，旧电弧随前沿前进迅速变暗，不让整条路线持续等亮。最终命中集合和原有预算先确定，视觉规划不能静默漏掉合法目标；若路径约束与完整覆盖冲突，应调整传播设计并明确机制变化，不能假装只是换特效。
- **雷网 THU_05：一次主雷进入，少量分叉向外展开。** 允许关键节点一进两出，以稀疏树形覆盖原命中集合，删除纯装饰闭环。近邻和避交叉是布局目标，不把所有节点硬压成度数二的长蛇。同一时刻只突出当前传播层，避免十余条线同亮。
- **三拍不同强弱。** 沿用当前约 0.23–0.27 秒的实际伤害拍间隔设计视觉节奏；第一拍建立主路径，第二拍向外分叉，第三拍强化终结命中。保持每拍应命中的目标与伤害预算，不按“某一层没亮”就取消对应伤害。命中反馈与视觉到达必须一致，不能怪物先受击、闪电后到。
- **保留已认可的主干宽度、白亮核心和蓝紫外缘。** 白亮峰值先试 2–3 帧，蓝紫余辉先试 2–4 帧；这些是新的动画设计起点，不是已验收参数。通过前沿、峰值和衰减建立力量感，不再来回改整体粗细。
- **加强接触与纵深。** 首目标给集中的电击爆点，后续目标小一档；配合原有受击动作和短促的局部反光。雷网最后一拍可试一束竖向短雷，普通电链不添加。没有雷系范围法阵；装饰范围圈仍只属于陨石。
- **路径清楚优先。** 主要传播路径尽量不交叉，交汇只在真实目标发生；自然细分叉属于装饰，强度和长度应足够克制，不能看起来命中了未受伤目标。若有 MISS，不能把它画成有效命中或后续中继。

## 诊断试验采用的约束

- 从首个目标继续寻找最近的合法未连接目标；玩家明确瞄准的首目标保留。
- 每只怪物最多两条连接，首目标来自施法者的入线也计入，一进一出。
- 新连线不得穿过已有路径，可以在同一目标处汇合。用当前战斗相机投影检测地形高差造成的可见交叉。
- 不重复回连，不再补充闭环或与传播无关的游离电线。保留受击电光。
- MISS 不晋升为中继；从上一有效目标继续寻找下一个合法目标。
- 沿用原目标集合、等级上限、作用半径、连接半径、LOS、命中计算和伤害拍数。不为了连满目标强行跨线；没有合法延伸就停止，因此实际命中数可能低于目标上限。

## 视觉来源

主干贴图和轮廓参数逐字节沿用已恢复的 v8：白亮核心、蓝紫外缘。一级主干宽度 0.510、怪物间 0.300；五级沿用既有等级增量，分别 0.550、0.340。没有再次收窄主干。

原录制器在同一池中从小网格切到大网格时，停用状态的 `MeshRenderer` 会保留旧模型。预览修正为启用节点后再绑定扩容后的 mesh，避免显示引用已销毁缓冲；没有修改正式渲染器。验收同时检查原生帧中的闪电像素与绘制数据，不能仅凭 draw call 判为可见。

12 只真实训练靶使用当前 3D 敌人模型。录制雷网 1 级、雷网 5 级和连锁闪电 5 级，包含原有命中／MISS 判定；不手工伪造伤害或骨骼事件。`nearest-chain.ts` 仅覆盖这两招共用的预览连接方法，其他招式不作为本轮验收结论。

原生帧和完整事件保存在 `src/.tmp/thunder-noncrossing-v10/validated/refined/`；`final/` 是发现曲线交叉后的早期诊断录制，不用于交付。`review.py` 核对输入哈希、半径、重复连接、最大度数、近邻候选、MISS 中继、事件几何交叉、实际电弧投影交叉及主干可见像素，随后输出动画和编号诊断图。

电弧的折线摆动也受相邻路径的间距限制，防止出现“连接线不交叉，但弯曲后的闪电仍交叉”的情况。允许同一受击节点的接触光相接，不把主干上的细小分叉算作额外目标连接。
