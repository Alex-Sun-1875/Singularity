# 全弓箭青绿配色统一

2026-11-17，按用户要求将弓箭手所有飞行箭矢统一为新版青绿色，复用已确认的[连穿箭 v5](../archer-polish-v5/README.md)配色。

普攻、蓄力箭、穿云箭、连穿箭、自动疾风连射、万箭齐发和疾风撤射共用 `SkillEnergyStrokes.ARROW_COLORS`，覆盖飞行箭体、尾迹、手部蓄力光与真实命中火花。原有箭型、线宽、尾迹长度、连穿转向残光、发射节奏、目标与伤害规则保留。玩家与敌方共用箭体池时按归属切换共享材质，敌方弩箭保留原钢色。

实现入口为 `Effects.ts`、`NativeSkillVfx.ts` 和 `SkillEnergyStrokes.ts`，使用已有网格、线段、粒子和材质缓存，无新增运行资源、依赖或生成图片。

- 疾风连射由穿云箭实际命中后接普攻触发，未手动施放自动技能。连穿箭保持一支实体箭及一次真实转向；万箭齐发最多六支同时在途。
- 同一箭体执行玩家 → 敌方 → 玩家复用，三部分材质均正确恢复，清理后无残留活动箭体。本轮最多使用 34 条线段，保留原有有界池上限；此计数不代替性能验收。
