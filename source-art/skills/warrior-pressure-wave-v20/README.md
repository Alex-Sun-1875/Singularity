## 具体改变

- 去掉横向金属明暗和厚实的弯曲表面。月牙前缘由一条宽度略有变化的亮波峰组成，后方保留较淡、能透出场景的气浪。
- 复用已选剑气图和项目已有128×128流动通道场，用连续移动的密度纹理表现尾流。通道场仅作数值数据，最终仍为银色，不绘制火焰色彩；战士资源独立持有。
- 尾部向后拉伸、轻微漂移，再按局部密度逐步消散。波峰先减弱，尾流稍后散掉，取消整片表面统一淡出的处理。
- 断空斩、突袭的视觉尾流延续到约0.5秒；旋风斩回旋结束后保留约0.12秒残留气浪，与前甩衔接。残留没有额外伤害。
- 范围、伤害、命中次数、单体目标预算、冷却、消耗和原生动作不变；沿用v19的范围与连斩衔接。护盾技能、护盾被动及统一护罩代码和素材保持原样。

资源和代码：`WarriorSkillEffects.ts`、`Effects.ts`、`NativeSkillVfx.ts`，以及 `warrior-pressure-wave-v2.effect` / `warrior-flow-v1.png`。复用项目现有Cocos透明材质、资源加载和有界对象池，无新依赖、点粒子系统或灯光。流动时钟读取实际游戏时间，暂停期间不会继续播放；降低动态效果设置减小流动速度和漂移。

- 八项战士技能复用既有实录流程，无活动特效缺少实际子模型或资源池溢出。断空斩仍完成两次真实命中，突袭仍命中近处和扩大范围内的外侧目标，旋风斩仍为三段、三名目标合计七次真实命中。
