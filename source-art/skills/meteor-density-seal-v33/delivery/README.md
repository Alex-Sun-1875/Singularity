# 陨石 v33 实景候选

本轮恢复原稿卷纹长回旋与规则同心圆边界，法阵采用更暖的橙金线纹、近纹柔光和轻薄底光；陨石外焰加浓，岩核隐约可见，地火略浓。退火使用连续曲面收势，原先后侧深V缺口已修复。状态为本地实景候选，用户美术反馈与TapTap／真机验收仍待确认。

实录来自经过逐文件核验的冻结标准test构建，完整原片保持默认4.3镜头、人物与HUD。局部和颜色对照只裁切、等比缩放，保留各自透视及场景底色，没有补色或调亮。正视PNG直接复制自实际服务构建的native纹理，暗底版仅展示同一RGBA。

每段270帧／30fps／9秒，保留真实触地、1.2／1.4／1.6／1.8／2.2／2.8／3.5秒及1.2至2.4秒每一帧。动画由Cocos连续曲面和纹理驱动。实际事件、落点、触地、释放／冷却、暂停恢复、减动态、切职业及清理分别记录；正常1级旅程进入独立合法满级训练后恢复同一原旅程，进度与装备未变。
