## 已接入的表现调整

- 陨石头部使用同一原稿火壳增强透明光学密度，岩核透过包焰隐约可见；每帧左半段原尾像素保持。沿用16帧序列、原鼻锚、斜落轴、真实岩尖接地点及触地衔接帧，没有新增火壳绘制层。
- 飞行火壳长度按原稿与人物的相对高度提高32%，取 `4.818 × size`。爆心主焰高度提高20%，取 `2.46 + (tier−1) × .144`。岩核大小、落点、路径及真实技能范围不变。
- 落地仍为同一个原稿连片浮雕火面，透明密度指数1.35、颜色增益1.10。保留单中心外扩、中央上卷及4.55秒总表现窗口，没有恢复重复浪片。
- 修复收势阶段后侧缺口：原局部压缩在约1.515秒使投影映射反折；改为整片正比例收低并仅对中央做正向扩张。整体透明度继续按原时序渐退，后侧不再单独挤出空洞。实际逐帧证据与最终图集记录分别保存，池计数不能代替视觉检查。
- 法阵沿用真实圆形地面网格、既有半径和相机投影；四条圆形边界严格同心，圈间卷纹及内部长回旋按原稿可见纹样描摹。R4用暖橙金亮芯／笔身、轻薄全盘底光与刻纹附近16／34px柔散光，覆盖前半盘并保留地面。取消全色1.15倍增益，避免红色先截断后将亮纹推黄。R3过度规则化的三叶线圈和偏褐满盘底色保留为中间失败证据。

## 实际录制与可复现性

`capture.cjs` 使用正常 test 的1级新旅程，经既有合法满级临时训练会话施放 FIR_02，退出后恢复同一1级旅程。正常训练场和空地轮廓各录9秒／270帧；保留原HUD、人物、默认4.3镜头与真实时间，不用 `test=max`、修改seed或后期叠加效果。特写仅裁切实际画面。

`freeze-build.py` 在真实标准构建完成、构建锁释放后，逐文件复制全部运行产物到新的忽略目录；核实复制前／后与副本SHA相等。后续录制仅服务该不可变副本，避免其他聊天重导出共用 `concept-2d` 造成录像混源。来源清单保留在 `snapshot.json` 及其引用的复制记录中；冻结副本不是手工修改的bundle。

`after-r1`／`after-empty-r1` 是带R3法阵的中间实景证据，保留用于说明偏黄亮纹、偏褐底盘及图案偏离问题，不是最终交付。最终实录为 `final-r1`／`final-empty-r1`，编译主文件 SHA256 为 `87f5be67d2edcb73b4b33c536d9b67573ee4d8365d457830a7956fb7280c7022`；PNG、effect、导出资源与不可变副本绑定见各目录 `shader-asset-evidence.json`。真实触地误差、伤害／命中、逐帧收势检查及媒体验证汇总到 `delivery/manifest.json`。

根代理已查看最终空地预警和原稿／R3旧实景／R4新实景的同圈宽对照：暖橙刻纹、轻透盘底和长回旋已实际接入。对照只裁切／等比缩放，不改颜色、亮度或各自透视；不声称CG和不同地面背景的实景像素完全相同。类型检查、标准test Web导出与两段技术检查通过，正常训练场4次命中／812伤害、空地0次命中，与相邻版本一致；均真实返回同一1级旅程。暂停恢复、减少动态和职业切换清理另有记录。

## 验收边界

本轮使用既有 Pillow／NumPy 进行确定性纹理处理和几何描摹，没有云端生图、模型推理或新增依赖。动效由原生 Cocos 岩核网格、透明动画纹理与连续曲面完成；不是流体模拟。Web实景检查、用户美术反馈和TapTap目标真机显示／性能分别记录；用户与真机验收仍待完成。
