# 与法阵同宽的通透喷焰 v12

用户进一步明确：三角火焰的底边应等于法阵圆的直径，颜色应接近前面的通透火苗，不能是实心不透明红块。本轮据此修订造型。

- 火焰从整个法阵圆面向上喷起，底宽覆盖圆的直径；候选底宽约 1.2 米，高度仍约 0.5–0.6 米。
- 多股上升火舌形成低矮的三角轮廓，中心较高、两侧较低。
- 恢复 v10 的橙金色与轻盈材质，保留火舌之间的空隙，能看到后方的法阵纹路和地面；底部只稍深，不再使用 v11 的浓重红色块。
- 明亮法阵、五个喷发点的排列及其他火系提案保持。
