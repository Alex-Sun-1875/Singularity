## 改动

| 职业 | 主体与收尾 |
| --- | --- |
| 战士 | 减弱尖亮钢击与切入碎声，用180–700Hz左右的短阻尼身体增加接触重量，钢片余振更暗。保留刀刃材质，不加入低频扫音或锤鼓。 |
| 弓术 | 重点放在弦扣、弓臂、穿刺身体和短箭杆回振。移除v5约210毫秒的后置余风，独立气流包仅约50–65毫秒，最晚在接触后约83毫秒结束；随后只留较暗材质回振。 |
| 火焰 | 重新分配起爆层和翻卷，增加140–600Hz左右的有限压力主体，弱化尖亮点火颗粒与细火星；保留渐弱燃烧余音。 |
| 雷霆 | 加厚短电击与雷体，滋滋保留为独立、较暗的密集放电尾层，低于主击；没有变成持续低鸣或长风噪。 |

源音频的变化来自主体层重做、分层平衡和空气包络缩短，不是简单整体降调、提高音量或对整条声音加低通。重量主要放在低中频，限制过深次低频。事件起点和v5接触／准备声增益沿用，准备声仍在释放时收住。

新版演示按各职业的峰值余量设定试听音量；前后对照另行用纯线性增益匹配，不使用压缩或限制器制造差异。不同职业演示音量不代表最终游戏混音。

## 来源与验收

14类、每类3变体，共42个24-bit单声道源素材。使用既有原创材质建模与已安装NumPy/SciPy/FFmpeg，复用前几版的时间编排、PCM写入、编码和匹配工具；没有实录、第三方采样、下载、云音频模型、本地AI推理或新增运行依赖。

`manifest.json`记录文件哈希、长度、峰值、解码削波/单声道折叠、对照响度与事件截止，并补充全事件频带分布和80–300毫秒的高频带RMS。后者包含所有材质，不能当成单独风声测量；弓风缩短还需结合真实源包络检查。数字说明声学参数发生变化，不替代沉重感、辨识度和舒适度的试听。

本轮为离线试听，所有旧版本和游戏运行音频保留。新v6、手机外放、游戏内混音与TapTap真机仍待验收；未改玩法、存档、音乐或运行资源，未打包和升版。
