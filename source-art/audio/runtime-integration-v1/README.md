# 职业音效与《余烬与誓言》运行时接入

2026-11-16，按用户“这版可以了，接入游戏”的指令，采用已确认的 v7 战士／弓术声音及其中原样沿用的 v6 火焰／雷霆声音。音乐采用此前推荐的 A《余烬与誓言》方向，扩编为真正用于游戏的探索、战斗循环。

随后按“参考武侠电影武器碰撞”的反馈，将六类战士／弓箭接触换为[以CC0实录刀刃为主的v8](../impact-wuxia-v8/README.md)，再按“与前面稍微结合”调整为[实录钢刃与旧版重量融合v9](../impact-fusion-v9/README.md)。当前运行路径为`audio/combat-v9/`，18条接触融合、27条其余短音及全部音乐字节保留；旧v7/v8源仍保留但排除发布资源图。各次来源、响度匹配试听、技术及Web证据单独保存，下方早期记录为接入基线。

## 游戏中的行为

| 职业 | 出手与接触 |
| --- | --- |
| 战士 | 短挥刃、厚实接触；实际盾挡／金属目标使用钢刃撞甲，重击保留低中频重量 |
| 弓术 | 拉弦、短促放箭；命中与撞甲分开，保留箭头金属碰撞，不增加长风尾 |
| 火焰 | 克制蓄势、较厚的爆燃尾；火墙成功生成时播一次底声，持续伤害不反复爆炸 |
| 雷霆 | 短蓄电、重裂击和闪电滋滋；连锁／雷网按一次施法去重，避免每条边重复叠响 |

接触声来自真实可见命中／盾挡。挥空、未命中的箭不播放命中声，暴击和击杀小幅增强原职业声音。武器、职业和金属材质随事件记录，已释放弹体不会因为之后换职业而变声。燃烧、宠物、环境及附加伤害不重复抢占主接触声。

使用六个可停止的 Cocos `AudioSource` 管理短音；每类三种变体轮换，首次进场等待当前职业资源准备，其他职业按需加载。取消操作收住准备声；死亡、切图及后台清理短音，加载失败允许继续游戏并在明确恢复时重试。

《余烬与誓言》按用户截图的“探索 → 交战 → 战后”调整。探索、战斗两版仍为 80 BPM、D Dorian、32 小节／96 秒，字节保持不变；另加入原示范最后 5 小节／15 秒的独立战后段，移除鼓点，用弦乐、大提琴、竖琴、木笛与少量古铜收回 D 小调主题。持续交战约 0.7 秒后进入战斗版，平静至少 4 秒且现有战斗规则确认脱战后，战后段从头播放一次，尾部约 1.5 秒淡回探索；再次交战立即打断战后段。探索／交战时长随实际玩法变化，不按试听示范固定每段 15 秒。

仅两首长循环之间切换会对齐一次乐曲进度；战后段不循环，收束后从探索主题开头进入。菜单／对白压低音量，静音和后台暂停保留进度；死亡、加载、切区、回标题和靶场重置取消收束资格，避免误播战后。复用原有音乐偏好，Boss 当前使用战斗版，撤离完成后的战后段也是平静收束，不表示击杀或发奖。

## 资源与实现

- `sfx-assets.json`：首次v7的45个运行时单声道 PCM16／44.1 kHz WAV 基线，共 2,981,376 字节。当前v9保持总字节数和cue时长，来源、融合参数与保留哈希见`../impact-fusion-v9/manifest.json`，同样使用独立短音，不把试听合辑作为音效。
- `music-manifest.json`：两首长循环 MP3 各 1,533,807 字节，战后 MP3 为 240,696 字节；战后母带约 −23 LUFS、无削波，来源及测量见 `music-aftermath-technical.json`。无损母带、乐谱、响度与边界测量同目录保存，无新增运行依赖或第三方音库。
- 当前 48 条运行音频合计 6,289,686 字节，分别进入 `combat-audio` 和 `background-music` 资源包。旧《破晓余烬》保留源文件，但不进入新的背景音乐包。
- 接入 `CombatAudio.ts`、`CombatAudioCues.ts`、`BackgroundMusic.ts`、`ChapterGame.ts` 及现有命中反馈链。加载复用 `GameResources`，播放复用 Cocos 音频适配，不新增浏览器专用音频后端。
- 转换工具：`src/cocos/tools/prepare-combat-audio.py`、`src/cocos/tools/audio-runtime-v1/make_music_loops.py`、`src/cocos/tools/audio-runtime-v1/make_music_aftermath.py`。
