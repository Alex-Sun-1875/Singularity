# 《余烬与铁誓》音乐融合版

用户已明确选择最早《余烬与誓言》的笛子／拨弦版，当前游戏已恢复该原版；本目录为历史融合试作。当前配乐及验证见[原版恢复记录](../restore-embers-v1/README.md)。

用户后续反馈本版偏高昂、更喜欢之前一版；当前游戏按最近上下文恢复[《铁誓进军》原版](../iron-rally-v2/README.md)，另提供[内敛叙事v4](../music-narrative-v4/README.md)独立试听。本版保留为历史试作，不代表已获得用户听感认可。

2026-11-17，用户试听原《余烬与誓言》与新《铁誓进军》后要求“应该结合一下”。本版以原曲为主题主线，将新版的重量和节奏作为配器基础。

- 原曲：保留其前8小节主题动机、D Dorian和声、笛子／低笛、拨弦和少量竖琴的暖色与空间。
- 新版：使用已有实录大提琴断奏、低弦、弦乐、圆号、长号、大鼓与巨鼓，战斗时增加推进，铜管以原旋律回应而不另叠无关主题。
- 平衡：统一104BPM，收敛新版的军鼓、镲和齐奏密度，探索留出旋律呼吸，战斗保留厚度与活力。
- 编排：共用原曲和声网格重新制作乐谱，不把80BPM与120BPM的成品混音，也不整体变速旧MP3。

[38秒连续试听](audition/embers-iron-showcase.mp3)：0–10秒探索，9–29秒战斗，28–38秒战后，交界各1秒淡化。这是按新音乐片段编排的离线试听；实际自动切曲另做工程验证。

[上一重管弦版 → 融合版，同响度对照](audition/rally-fusion-matched.mp3)：前15秒上一版，1秒留空，后15秒融合版，均为−22 LUFS；各自从第9小节开始，截取起点、标量增益和来源记录在 `matched-comparison.json`。

## 资源与复现

探索／战斗：各32小节，104BPM，约73.846秒；战后：8小节，约18.462秒。循环尾音与房间余音按原流程折回开头，战后以一次性有限尾音收束。

制作入口 `src/cocos/tools/music-fusion-v3/make_fusion_music.py`，复用原原创音色与旋律API、最新管弦采样适配及既有FFmpeg／Cocos输出，不增加下载、模型调用或运行依赖。完整乐谱、母带、哈希、响度与边界记录见manifest及技术记录。

实录来源复用[VSCO官方录音与CC0凭证](../iron-rally-v2/sources/vsco/source-manifest.json)和原作者许可／署名；没有重复下载或改变已验证的采样。原曲音色和旋律来自项目 `audio-direction-v2/music_samples.py`。上一版制作器仅将标题、调式和战后时长参数化，默认仍保持上一版配置。

## 接入及验收

运行路径 `audio/music/embers-iron-explore|combat|aftermath`；两条循环共享相同网格，沿用原三音源切曲、音乐偏好、菜单压低、后台与静音恢复。原《余烬与誓言》、新《铁誓进军》的源音频及v12仅出手呼啸均逐字节保留，运行包只包含当前三曲。

技术生成、实际Web加载与切曲、用户融合比例听感、TapTap目标安卓真机分别验收，后两项不由数值或Cocos播放状态代替。实际编码时长含MP3额外样本，不宣称设备端样本级无缝；验证记录另见 `integration-validation.json`。本轮不升版、不打包上传ZIP、不上传或发布。

类型检查、正常test网页分包导出和10项实际Cocos播放检查通过，脚本／控制台／网络错误均为0。三首融合曲和12条既有出手呼啸的包内映射及哈希匹配，历史六曲未进入导出；新音乐共3,325,383字节。实际MP3解码无削波，单声道折叠约−0.21至−0.26dB；循环与战后分别多约42／47毫秒编码样本，目标设备间隙另验。
