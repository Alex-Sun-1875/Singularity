# 职业打击音效 v7：刀刃与箭头金属接触

2026-11-16。按用户“战士和弓箭手打击应该有金属碰撞感”的反馈，在v6低中频重量和短弓风基础上，增加明确但短促的钢刃、箭头与甲片回振。火焰和雷霆直接沿用v6。

## 试听

- [普通接触／撞甲](audition/material-contacts-v7.mp3)，16秒：每4秒一组，依次战士普通接触、战士撞甲、弓箭普通接触、箭头撞甲。实际起点为0.35、4.35、8.35、12.35秒；同职业共用演示增益，材质强弱没有单独拉平。
- [战士→弓箭新版](audition/physical-v7.mp3)，32秒：战士0:00–0:15，弓箭0:17–0:32。各段均为普攻0–4秒、代表技能4–8秒、暴击8–11秒、击杀11–15秒。
- [v6／v7无损匹配对照](audition/physical-v6-v7.wav)，64秒：战士旧0:00／新0:16，弓箭旧0:33／新0:49。各版本完整15秒，前后匹配响度；另有[MP3便携预览](audition/physical-v6-v7.mp3)。
- [完整四职业版本](audition/four-classes-v7.mp3)，66秒，战士0:00、弓箭0:17、火焰0:34、雷霆0:51；[叠加既有音乐](audition/in-music-v7.mp3)，45秒，15–30秒依次加入四职业攻击。

以上均有同名WAV。匹配以PCM WAV为准；MP3可能带编码填充或稀疏瞬态响度测量漂移。精确事件见`demos/*.cues.json`和`manifest.json`。

## 声音结构

| 接触 | 处理 |
| --- | --- |
| 战士普通斩 | 保留v6厚主体，加较轻的刀刃金属共鸣和短刮擦，挥空仍只有挥刃运动。 |
| 战士撞甲 | 更明确的非谐钢片共鸣，保留低中频重量；阻尼让“铿锵”短收，不拖成长铃。 |
| 普通箭头接触 | 保留穿刺/箭杆主体，职业默认命中带少量箭头共鸣；材质对照中的soft则呈现普通软接触基线。 |
| 箭头撞甲 | 比战士更小、更集中的硬接触与短“叮铿”，金属回振和短风分开。弓的拉弦、放箭及空气包沿用v6。 |

主要金属层放在中高频有限区域，同时保留原低中频身体；没有靠削空主体或抬高尖亮click来制造金属，也没有恢复长弓风。源音色为噪声激励的非整谐阻尼材质模型，不是实录金属。

连续演示沿用v6事件起点与增益，准备声继续在释放时收住。战士沿用原先撞甲接触；弓箭第三发普攻在此次离线演示中明确指定为撞甲，其它箭仍呈现较轻的默认命中，因此前后对照第三箭包含材质场景变化。`material`和`sourceApi`记录该指定，不代表游戏已自动识别材质或增加了新伤害段。

## 保留与验收

音源库仍为14类、各3变体，共42个24-bit单声道文件；本轮调整战士和弓箭物理接触。火雷18个源文件、两套WAV/MP3及cue共24个文件，与v6逐字节一致。完整四职业合辑和音乐混音重新组装，单独火雷演示保持原样。

`manifest.json`保存源/输出哈希、复制来源、峰值、解码削波/时长/单声道折叠、对照响度、材质事件和频带变化。新编码文件沿用已有实际解码检查；复制的火雷文件复用其原报告并核对哈希。指标只能核实文件和声学参数，不能替代对金属感、重量与舒适度的试听。

制作仅用既有原创建模及已安装NumPy/SciPy/FFmpeg；无实录、第三方采样、下载、云音频模型、本地AI推理或新增依赖。仍是离线试听，所有旧版及游戏运行音频保留；未改音乐、技能规则、存档、运行资源，未打包或升版。新v7、游戏内材质触发与TapTap真机仍待验收。
