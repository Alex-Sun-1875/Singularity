# 游戏化击打 v10

本版试听后用户反馈“太脆，更厚重一点”；当前接入版本已更新为[厚重版v11](../impact-weighted-game-v11/README.md)。本目录保留初版声音、制作参数、对照和Web播放记录，不代表最终听感验收。

2026-11-17，依据用户“当前击打太写实，需要更符合游戏”的反馈，重做战士与弓箭六类接触，共18条。以现有原创声音与制作工具为基础，不新增运行依赖。

- 主层：集中的低中频冲击、清晰短促的斩切／箭尖前沿，加少量迅速收束的能量余劲。
- 材质：普通命中收敛钢响；撞甲保留更清楚的短金属回振；重击主体更厚，余劲稍长。弓箭的能量层在65毫秒内结束。
- 实录：原v9接触退到低音量纹理，战士最多65毫秒、弓箭最多45毫秒；不再以粗糙钢擦和实物碰撞为主。
- 混音：按原活动窗匹配RMS并保留峰值余量，运行音量与触发保持。三变体变化来自独立激励与层次，不是同一条复制。

- [v9 → v10同响度对照，18秒](audition/v9-v10-matched.mp3)：0–8秒旧版，8–9秒静音，9–17秒新版。两段使用相同动作编排，仅用标量增益匹配；无损WAV与精确时刻、测量、源哈希见同目录及 `manifest.json`。

## 接入与来源

运行使用 `audio/combat-v10/`，45条单声道44.1kHz PCM16 WAV总计2,981,376字节。18条武器命中更新，其余27条（挥空、拉弦、放箭、火焰、雷电）与三首音乐逐字节保留。旧v7／v8／v9保留在仓库，排除发布资源图；继续复用Cocos AudioSource、真实命中、材质选择、三变体、取消收声和六声部管理。

使用已有NumPy／SciPy／FFmpeg及项目v5／v7的分层、带限噪声与阻尼响应工具。v9短接触纹理沿用[StarNinjas CC0来源凭证](../impact-wuxia-v8/sources/starninjas/LICENSE-SOURCE.md)，不重复下载；原资源、源哈希和独立层能量占比分别记录于manifest。未调用音频生成模型。

可复现入口：`python src/cocos/tools/audio-impact-v10/make_game_contacts.py`。生成器只生成声音与试听，不改源码路由、玩法、版本或打包。

## 验收边界

生成与客观检查已经完成：45条时长保持，18条新变体互异，无削波，边界样本检查通过；新旧试听PCM均为−23.71 LUFS。数字、能量占比和播放器状态不能替代听感验收。工程接入验证另记于 `integration-validation.json`；用户听感及TapTap目标安卓真机的外放、连续战斗和系统音频中断仍待验收。
