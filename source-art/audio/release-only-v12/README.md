# 仅挥剑与释放呼啸 v12

2026-11-17，按用户最新要求：“整体去掉命中声音，只保留挥剑和释放呼啸，并调大一点”。

## 当前声音

仅4类出手声音、每类3个变体：挥剑0.26秒、放箭0.22秒、火焰释放0.36秒、雷霆释放0.30秒。挥剑保留既有原创空气声，播放增益从0.31改为0.62（约＋6dB）；放箭0.46→0.64，火雷0.18→0.40。后三类重制为平滑短空气声，不含穿刺、弓臂敲击、金属碰撞、爆裂和雷击前沿，不整体放大背景音乐。

职业专属命中、通用命中、受击、护甲吸收、破防、打断、失衡、反击等均不再播放音效；移除准备／拉弦摩擦和持续火墙底声。没有目标也能正常听到出手；蓄势取消不会假播释放。火墙仅在施放时播放一次呼啸，后续灼烧、连锁、附加和地面命中不补播声音。原命中视觉、镜头、受击动作、伤害及规则保持。

[12秒四职业试听](audition/release-only-v12.mp3)：每3秒一组，依次战士、弓箭、火焰、雷霆，各有一次单发和三次连续出手。该离线试听按实际播放增益排列，没有追加响度归一化；精确时刻见manifest。

## 资源与来源

`audio/combat-v12`仅12条44.1kHz单声道PCM16，共302,172字节。旧v7至v11保留源资源并排除发布资源图，旧通用碰撞文件同时排除；原音乐、剧情和非战斗交互音保留。`hit.wav`仍用于非战斗检定失败提示，不进入战斗接触播放链。

制作入口：`python src/cocos/tools/audio-release-v12/make_release_audio.py`。复用项目已有空气分层、带限噪声、PCM写入、Cocos元数据及FFmpeg预览导出；无需下载、生成模型、第三方录音或新增运行依赖。三条挥剑原始WAV逐字节沿用，其他9条为原创确定性空气声。
