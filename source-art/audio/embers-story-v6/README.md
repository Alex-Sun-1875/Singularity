# 余烬叙事融合：中低弦减弱 v6

后续用户要求继续降低中低弦比重，当前使用[轻弦v7](../embers-story-v7/README.md)，相对本版再降2dB。本目录保留本轮首次调低的素材与验证记录。

2026-11-17，用户要求“中低弦声音小一点”。以v5为基准，只降低相关大提琴声部3dB（线性幅度约0.708）：低弦长音底层、中低弦回应、短弓低弦脉冲。

笛子、拨弦、竖琴、小提琴、铜管与鼓的音符增益保持。两曲总输出增益固定使用v5清单的原数值，不作响度归一化补偿，避免弦乐又被整体抬回；没有对整曲低通或全曲降音量。逐音符比较确保除大提琴音量外，音符、音色、时刻、时值、声像均不变。

[调整后38秒试听](audition/embers-story-soft-showcase.mp3)，沿用原编排：探索0–10秒、战斗9–29秒、原战后28–38秒。

运行使用 `audio/music/embers-story-soft-explore|combat`，原版 `embers-oaths-aftermath` 15秒保持。沿用96BPM、两条80秒循环、现有音乐状态机和偏好；历史音乐与当前出手呼啸均按哈希保护。`balance-check.json`记录精确声部差异和固定总增益，manifest记录制作与保护哈希。

制作入口：`src/cocos/tools/music-embers-story-v6/make_low_string_balance.py`。复用v5乐谱和已核实来源的声音，仅将v5生成器的文件名前缀／标题参数化，并为原导出流程添加可选固定总增益；既有生成器的默认配置保持。无新下载、模型调用或运行依赖。

原版战后、配器／播放规则未改，本轮优先检查声部差异、解码、资源映射、游戏加载及真实进入战斗播放，复用已有播放检查，不重复扩展成长或玩法测试。记录另见 `integration-validation.json`；用户音量比例听感及TapTap目标安卓外放仍待验收。未升版、未制作上传ZIP、未上传或发布。
