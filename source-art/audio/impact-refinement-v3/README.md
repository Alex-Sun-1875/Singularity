以上均有同名WAV。响度匹配以PCM WAV为准；MP3仅作便携预览，稀疏雷声经编码和响度绝对门限后，测量值可能漂移，不能据此直接判断主观听感差。MP3还存在少量编码填充，精确事件时间以WAV、`demos/*.cues.json`与`manifest.json`为准。

## 本轮改动

| 职业 | 音源与演出调整 |
| --- | --- |
| 破军 | 移除下滑低频鼓点和扫频钢边；使用短空气运动、切入、布甲/身体压缩和快速阻尼的钢片共鸣。重斩只适度加厚接触，护甲尾音缩短。 |
| 弓术 | 减少持续有音高的拉弦与拨弦嗡鸣；使用安静的不规则摩擦、短张力释放、弓臂共鸣与纤维穿刺。重箭保留刺入身份。 |
| 火焰 | 移除纯音压力层和固定周期颤动；以小点燃、短压力接触、不规则火舌与少量余烬表达小规模燃烧。火墙底声和蓄势降低存在感。 |
| 雷霆 | 删除连续上扬哨音、锯齿蜂鸣和长低鸣；用短电弧、快速阻尼的接触与少数弱分支。网络后续组低于首击。 |

沿用旧版主要接触点和15秒分段，降低准备动作相对命中的音量，去掉暴击与击杀中额外叠加的装饰接触，结果强调限定在原职业音色之内。新音源逐类重做，不是单纯把旧文件变小声或加低通。

前后对照采用纯线性增益匹配响度，不使用压缩、均衡或限制器来制造差异。各职业旧／新15秒成对匹配到保留足够峰值余量的目标；8秒对照片段再各自测量并对齐。职业之间不强制同一响度，也不代表最终游戏混音。全段及片段实际响度、增益、峰值和旧版来源哈希均记录在清单中。自然动态和瞬态形状保留；常用音源各有3个生成变体，共14类、42个素材。

拉弦和火雷蓄势会在各自动作释放前收住，必要时在末尾8毫秒淡出；不让准备声延续到放箭或爆发之后。事件清单分别记录源素材时长、实际播放时长和释放时刻。

## 来源与验收

制作复用已安装的NumPy、SciPy和FFmpeg，无下载、第三方采样、实录、云端音频生成或本地AI模型推理。`physical_cues.py`、`elemental_cues.py`是本轮音源；总制作脚本复用v2时间编排、PCM写入和编码检查。

技术报告见`manifest.json`：包含素材长度、峰值、四倍过采样、削波、变体哈希、MP3解码时长、响度、单声道折叠，以及旧/新代表音的频带能量、有效余音与周期性。能量和周期性数据只证明具体声学参数改变，不证明自然度、爽感或耐听程度。

听觉、手机外放、耳机、游戏内触发和TapTap真机验收仍待完成。此轮不改变音乐设计、游戏技能时序、玩法规则或运行资源，也未打包或升版。
