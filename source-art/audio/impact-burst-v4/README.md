# 职业打击音效 v4：火焰与雷霆爆发增强

2026-11-16。用户对v3表示“基本可以”，本轮保留其材质方向，重点增加火焰与雷霆的爆发。剑、弓沿用已接受的源音色，只将接触相对准备声的增益提高约0.55dB。这里仍是原创合成的离线试听修订，未替换游戏内资源。

所有试听均保留同名WAV母带。精确事件时间以WAV和`demos/*.cues.json`为准；MP3存在少量编码填充，稀疏瞬态经编码后响度门限测量也可能漂移，无损WAV作为匹配对照基准。

## 本轮声音结构

| 职业 | 保留与增强 |
| --- | --- |
| 火焰 | 保留不规则火舌和稀疏余烬，增加更集中点燃前沿、有限低中频压力身体，以及随后70–250毫秒的翻卷。蓄势和火墙维持低于直接命中的存在感。 |
| 雷霆 | 保留干脆电弧主裂，补入约20–100毫秒内的低中频冲击与快速阻尼短雷体，减少仅有点击的单薄感。雷网仍按0／0.25／0.5秒分组、首击最强。 |
| 破军、弓术 | 8类24个源文件与v3逐字节一致；仅微调接触与准备声比例，保持原来的短钢刃、弓弦与穿刺材质。 |

火雷通过重新组织音源层和包络增加爆发，未恢复v2连续上扬哨音、蜂鸣、长低鸣或规律调幅。普通攻击、代表技能、暴击和击杀保留层次，火墙不会按持续伤害反复爆炸；准备声仍在释放前淡出。

新版试听按各职业自身的峰值余量设置演示音量。旧／新对照另行采用纯线性增益匹配，不使用压缩、均衡或限制器来制造差异。因此新版试听与对照中的v4可能有不同整体增益，具体目标、实际响度与增益均记录于`manifest.json`。职业之间的演示音量尚不代表最终游戏混音。

## 来源与验收

火雷新制作6类、各3个变体，共18个源素材；另外复用剑弓8类、24个素材，交付音源库合计14类42个文件。复用已安装NumPy、SciPy、FFmpeg以及v2/v3的时间编排、PCM写入、响度匹配和编码检查。未下载音源或依赖，无第三方采样、实录、云音频模型或本地AI推理。

`manifest.json`记录源文件与输出哈希、变体与峰值、解码时长/削波/单声道折叠、对照响度、事件与释放时刻、v3来源哈希，以及包络和频带变化。指标证明源结构和文件状态变化，不代表实际爆炸感、设备表现或最终听觉验收。

v3得到的是基础方向认可；新v4、游戏内触发与混音、手机外放和TapTap真机仍待试听验收。本轮未更改音乐设计、技能规则或运行资源，未打包、升版、上传。
