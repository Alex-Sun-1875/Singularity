# 兵器接触 v8：实录刀刃与武侠拟音方向

2026-11-16，依据用户“可以参考武侠电影里面的武器碰撞声”的反馈，将战士和箭头接触的主要材质从稀疏模态合成，改为真实刀刃碰撞／擦刃录音的剪辑与混合。声音小样与技术接入分别验收，不把波形检查或播放成功当作用户已经认可听感。

## 试听

- [新版单发与连击](audition/weapon-contacts-v8.mp3)，18 秒；[无损 WAV](audition/weapon-contacts-v8.wav)。0–8 秒依次呈现战士普通接触、撞甲、重击及弓箭普通接触、重箭、撞甲；9 秒起为战士短连击，12 秒起为弓箭短连续接触，15 秒起补充两个硬接触。精确起点见同名 `markers.json`。
- [v7／v8 响度匹配对照](audition/v7-v8-matched.mp3)；[无损 WAV](audition/v7-v8-matched.wav)。v7 为 0–8 秒，8–9 秒留空，v8 为 9–17 秒，同样的接触与时序；PCM 分段响度分别为 −23.50／−23.51 LUFS。匹配是为了比较质地，不能证明哪一版更符合用户偏好。

## 接触设计

| 接触 | 当前处理 |
| --- | --- |
| 战士普通斩 | 真实刀刃接触与短钢擦为主，少量旧低中频支撑；减少稳定纯音暴露，不将软目标假装成重盾 |
| 战士撞甲／重击 | 不同录音片段经固定变速调整刀身体积，保留前沿、粗糙接触与有限钢尾，避免长铃和下滑音 |
| 普通箭头接触 | 更短、更局部的实录接触，保留穿刺身份，去掉旧箭头模态的纯音倾向 |
| 箭头撞甲 | 短促集中硬接触；比战士少刀身余振，不增加长风声 |

18 个接触文件（6 类 × 3 变体）重做，沿用原 cue 时长：战士 0.40／0.48／0.56 秒，弓箭 0.30／0.42／0.30 秒。其余 27 个 WAV 逐字节保留，包括挥空、弓拉放和火雷。原 v7 音频及全部音乐保留，三阶段音乐不改。

主接触能量集中在前几十毫秒，后续保留较弱的自然钢尾；不是将 80–220 毫秒整段维持同样响度。以实录层为主，旧合成层仅少量支持低中频。数值测量、来源片段、变速、包络、源层与运行文件哈希见 `manifest.json`。

## 来源与制作

使用 [StarNinjas 的原作者音效包](https://opengameart.org/content/20-sword-sound-effects-attacks-and-clashes)，作者说明以两把刀接触录制并在 Audacity 编辑，页面声明 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)。原始 ZIP、原页、授权说明、下载与解压校验、全部文件哈希保存在 `sources/starninjas/`。衍生音效已加入 Web／TapTap 共用的第三方声明来源。

源 OGG 浮点解码部分峰值超过 0 dBFS，先以浮点保留、处理和衰减，再转运行时 PCM16，未直接转整数削平。运行时仍为单声道 44.1 kHz WAV，45 条共 2,981,376 字节。没有新增游戏依赖或音频后端。

制作工具：`src/cocos/tools/audio-impact-v8/make_wuxia_contacts.py`；使用已有 NumPy／SciPy／FFmpeg。源包已单独下载并取证，工具本身不联网，不调用模型。

## 游戏接入与验证

运行路径为 `audio/combat-v8/`，复用 `CombatAudio` 的事件、六声部池、变体轮换、可见真实命中及材质选择。普通命中与盾挡／机器目标分别选择软／金属接触；不新增虚构对拼判定，挥空不发命中声，取消只收准备声。保留旧 v7 资源，但从发布资源图中排除，防止重复打包。

完整 TypeScript 检查、test档Web分包导出通过。实际Cocos播放的8项检查通过：战士／弓箭软、金属四场各一次真实KeyJ，触发对应v8接触；已观察播放器状态和时间推进，无旧通用打击叠音，45条短音加载成功、最高并发2／6；空挥和拉弦取消正确，控制台、页面和网络错误均为0。包内45条v8及3曲音乐映射／哈希匹配，旧v7 UUID／路径未进入导出，无重复音频，来源声明已随预览复制。证据分别保存为 `web-check.json`、`web-asset-check.json`。

Web 采用独立受控场景，不替代正常进度验收、用户听觉选择或 TapTap 目标 Android 真机听感。此轮没有升版、制作 TapTap ZIP、上传或发布。
