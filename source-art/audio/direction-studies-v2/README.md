# 剑与火：声音方向小样 v2

制作日期：2026-11-16。范围为用户同意的第一轮试听：四职业各15秒、同主题三种30秒配器、45秒探索→交战→战后混音。它们是离线编排的方向小样，尚未替换游戏资源或接入运行时切曲。

## 推荐试听顺序

1. [三种音乐方向合辑](audition/music-abc.mp3)，共94秒。A **余烬与誓言** 0:00–0:30；B **暗色远征** 0:32–1:02；C **明亮冒险** 1:04–1:34。三版沿用80 BPM、4/4、D Dorian和同位置的D–F–E–D短主题，匹配响度便于比较。
2. [四职业声音合辑](audition/four-classes.mp3)，共66秒。破军 0:00–0:15；弓术 0:17–0:32；火焰 0:34–0:49；雷霆 0:51–1:06。各段内部固定为普通攻击0–4秒、代表技能4–8秒、暴击8–11秒、击杀11–15秒。
3. [探索→交战→战后混音](audition/journey-mixed.mp3)，共45秒。0–15秒探索；15–30秒交战，依次穿插四职业攻击；30–45秒收束。音乐在状态交界处有过渡；这里的攻击是离线排布，不能据此宣称运行时触发已经完成。

MP3可能含少量编码前后填充；精确时间以WAV母带、cue和`audio-validation.json`为准。以上合辑均另存同名WAV。

## 声音意图

| 职业 | 主体身份 | 结果强调 |
| --- | --- | --- |
| 破军战技 | 短挥刃、紧实斩击、阻尼钢振与重量 | 连斩、重斩、暴击和击杀仍保留钢刃身份 |
| 逐风弓术 | 木弓张力、弦弹、箭杆与干燥穿刺 | 重箭和终结强调穿透与木质共鸣 |
| 烈焰秘术 | 压缩聚火、低中频爆燃、粗糙余烬 | 爆发与火墙分开，避免持续伤害不断爆炸 |
| 雷霆秘术 | 短蓄电、瞬时电裂、稀疏分叉与短低鸣 | 雷网以一次主释放组织，不按每条电边叠满声音 |

音乐A以温暖拨弦、气息木管和古铜共鸣表达余烬与希望；B用低弦、气息质地和更重节奏表达远征压力；C用更轻盈的拨弦与木管表达亲近和启程。三者是同一主题的配器方向比较。推荐先评估A是否适合日常游玩，再判断B/C适用场景。

`sfx/`保存14类声音、每类3个生成变体，共42个短素材与4条演示；变体不另计为42种独立声音设计。具体事件、变体和时间见`sfx/manifest.json`及各段`.cues.json`。`music/`保存三版和连续音乐示范的母带、压缩试听、乐谱、分轨与技术报告。

## 来源与验收

- 制作方式：原创乐谱与确定性声学建模合成，复用现有NumPy/SciPy和本机FFmpeg；不是实录乐器、云端模型生成或本地AI模型推理。未下载音源、模型或依赖，未使用许可不明的系统音色。
- 与旧曲关系：沿用《破晓余烬》的Dorian基调和开头短动机，重写小样编配。旧音乐和游戏音效保持原位。
- 云端能力：只读核验时，Maker音乐/音效入口要求绑定项目，当前Cocos仓库未绑定；未为制作音频初始化Maker工程。独立fal插件尚未连接，本轮未调用。
- 技术检查：母带长度、峰值、非有限值、削波、变体哈希、压缩文件实际解码时长、响度与单声道折叠等结果见`audio-validation.json`、`sfx/manifest.json`及各音乐`technical-report.json`。
- 听觉验收：待用户试听。技术指标不证明音色自然、战斗爽感或长期耐听；尚未做手机外放、耳机、TapTap真机、游戏内混音或系统中断验收。

试听时重点比较：小音量下四职业是否仍易辨；暴击/击杀是否保留职业底色；雷霆是否刺耳、火焰是否浑浊；音乐A是否适合重复探索；进入战斗是否自然、职业声音是否清楚。可只回复例如“A适合，弓声偏弱，雷声再柔一些”。

## 重建

在仓库根使用已安装的Python和FFmpeg，无需添加运行依赖：

```powershell
$audioFfmpeg = 'C:/Program Files (x86)/Lenovo/LegionZone/2.0.30.11033/SEGamingAI/services/editor/ffmpeg.exe'
python src/cocos/tools/audio-direction-v2/sfx_samples.py --ffmpeg $audioFfmpeg
python src/cocos/tools/audio-direction-v2/music_samples.py --ffmpeg $audioFfmpeg
python src/cocos/tools/audio-direction-v2/assemble_studies.py --ffmpeg $audioFfmpeg
```

前两步生成各自小样，最后一步按`study-inputs.json`匹配试听响度、制作合辑和混音并测量输出。不会打包、升版、写存档或替换游戏运行资源。
