# 职业打击音效 v5：材质余音与闪电滋滋

2026-11-16。按用户“时间稍微长一点，雷霆加闪电滋滋，战士和弓箭手也一样”的反馈，保留v4的攻击主体，延长四职业各自的材质余音。这里延长的是单次声音的实际衰减和纹理，演示段落仍保持原来的时间编排，方便比较。

- [完整四职业新版](audition/four-classes-v5.mp3)，66秒：破军0:00、弓术0:17、火焰0:34、雷霆0:51。每段15秒，依次为普攻0–4秒、代表技能4–8秒、暴击8–11秒、击杀11–15秒。
- [v4／v5 无损前后对照](audition/four-classes-v4-v5.wav)，130秒：破军旧0:00／新0:16；弓术旧0:33／新0:49；火焰旧1:06／新1:22；雷霆旧1:39／新1:55。每个版本完整15秒，前后匹配响度；另有[MP3便携预览](audition/four-classes-v4-v5.mp3)。
- [雷霆单独试听](demos/thu-15s.mp3)，15秒；[叠加既有音乐](audition/in-music-v5.mp3)，45秒，其中15–30秒依次加入四职业攻击。

以上均另有同名WAV。匹配对照以PCM WAV为准；MP3存在少量编码填充，稀疏瞬态的响度门限测量也可能随编码漂移。精确事件时间见各职业`demos/*.cues.json`和`manifest.json`。

## 各职业余音

| 职业 | 延长的内容 |
| --- | --- |
| 破军 | 保留短促切入，后接较弱的阻尼钢片回振与刃过余风；不同接触有各自衰减，不套用统一混响。 |
| 弓术 | 保留放箭和穿刺主体，增加短弦/弓臂回振、箭杆颤动和短掠空。 |
| 火焰 | 保留v4点燃、压力与翻卷，后接更长但渐弱的火舌和零散余烬。 |
| 雷霆 | 保留主裂和短雷体，加入命中后逐渐变弱的密集微放电“滋滋”纹理，分组带短缺口，雷网后续组再较弱地激发余电。 |

准备声仍在对应释放时淡出，延长的命中余音可以继续。v4的主要事件起点、职业接触与准备声比例沿用；没有增加伤害段数、自动命中或额外成功提示。尾音低于主击，不把每个细小分支都当成完整爆炸。

新版演示按各职业自身峰值余量设置试听音量；旧／新对照另行采用纯线性增益匹配，不靠压缩、均衡或限制器制造差异。职业演示间的音量尚不代表最终游戏混音。

## 来源与验收

14类、每类3个生成变体，共42个24-bit单声道源素材。制作复用v3/v4的原创材质建模、v2的PCM和FFmpeg输出以及既有响度/动作窗口工具；无实录、第三方采样、云音频模型、本地AI推理、下载或新增依赖。

`manifest.json`记录源/输出哈希、变体、削波、解码时长与峰值、单声道折叠、匹配响度、事件及释放截止，并记录100–350／350–650／650–1000毫秒的尾段能量、短窗纹理占比及有效收束。它们用于核实余音真实增加而非仅补静音；指标不能替代对“滋滋”、材质自然度和叠音舒适度的试听。

本轮为离线试听。所有旧版素材和游戏运行音频保留；未修改音乐、技能时序、玩法、存档，未打包或升版。新v5、手机外放、游戏内混音与TapTap真机仍待验收。
