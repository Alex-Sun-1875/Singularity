# 厚重游戏化击打 v11

用户后续明确要求整体去掉命中声、只保留并调大出手呼啸；当前接入已更新为[仅出手呼啸v12](../release-only-v12/README.md)。本版保留为历史试听及制作记录。

2026-11-17，按v10试听后“太脆，更厚重一点”的反馈，进一步重做战士与弓箭六类18条接触，保留游戏化方向并增加厚度。

- 将偏脆的高频前沿单独降低，战士约为前版28%、弓箭约24%；这只是分层增益，不等于整段高频声压降到同一比例。
- 加入主要落在155／180–760／950Hz的有限压力层，轻度软饱和增加密度；主体在手机能发出的低中频，不依赖超低频。
- 起点保持，前2.2毫秒柔化；重击压力衰减略长于普攻，撞甲仍有较明确的短金属响应。保留短能量余劲，弓箭不增加长风声。
- 按前版活动窗RMS匹配；没有整体降调、增加运行播放音量或改命中时机。

- [v10 → v11同响度对照](audition/v10-v11-matched.mp3)：0–8秒是被反馈偏脆的v10，8–9秒留空，9–17秒为本版。两段同一动作编排，PCM为−23.71／−23.72 LUFS；无损WAV及测量见manifest。

## 接入与来源

当前运行路径 `audio/combat-v11/`，45条44.1kHz单声道PCM16共2,981,376字节。18条接触更新，另外27条和三首音乐逐字节保留。v7至v10原文件保留，排除发布资源图；继续使用原Cocos播放、真实命中、材质选择、三变体和六声部管理。

制作入口：`python src/cocos/tools/audio-impact-v11/make_weighted_game_contacts.py`。复用v10制作、导出、匹配与验证流程，在v10声音上重平衡前沿和主体，并新增确定性低中频压力层。NumPy／SciPy／FFmpeg已安装，无下载、生成模型或新增游戏依赖。少量实录纹理由v10沿用v9的[StarNinjas CC0录音](../impact-wuxia-v8/sources/starninjas/LICENSE-SOURCE.md)，历史源文件和哈希链保留。
