# Grass007 官方来源档案

2026-11-04。保存 [ambientCG Grass007](https://ambientcg.com/a/Grass007) 的官方 1K PNG ZIP、API v3 快照、下载记录、ZIP 清单，以及解出的四张原始 PNG。许可：[CC0 1.0](https://docs.ambientcg.com/license/)。

下载记录以官方服务器 `x-bz-content-sha1` 校验 ZIP；条目以 ZIP CRC32 校验。没有官方逐图 MD5，`entry.json` 对应字段为 `null`，逐图本地 SHA-256 单独记录。候选副本在 `assets/materials/chapter-one-v3/terrain-library/green-grass/`。

实际只比较 Grass005、Grass007 两套官方 1K Color，选择过程见 `selection.json`。Grass007 以较鲜的橄榄黄绿阔叶、苔草块面为主，带少量枯枝；不冒充扫描草坪。官方制作方法为 `surface-procedural-bitmap-elements`，物理尺度 unknown，2m 仅为设计比较建议。

原 PNG 未修色、缩图或改绘；四通道来自同套。`entry.json` 的 `maps.file` 相对 source-art 的 `terrain-library/`，`exportFile` 是候选副本仓库路径。本目录以外的主清单、下载脚本和运行时未由此任务修改。
