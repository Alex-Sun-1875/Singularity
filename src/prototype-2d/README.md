# 剑与火 · 白枝前厅 2D样片

已被用户后续方向替代：人物必须直接使用前面的设定图，原Cocos HUD全部保留。当前交付入口为仓库根目录 `npm run start:2d`，地址 http://127.0.0.1:7469/?view=2d ，实现位于 `src/cocos/`。本目录保留为早期独立原型记录；其中旧3D预渲染人物不是用户接受的人物方案。

这是用于比较制作路线与操作手感的独立小场景，尚非第一章的2D迁移。原 Cocos 3D 工程及其存档继续保留。

从仓库根目录运行 `npm run start:2d`，打开 `http://127.0.0.1:7468/`。

手机横屏：左摇杆移动，右侧攻击/闪避/武器技/符咒/交互；弓按住蓄力、松开射箭。入口营火旁可以切换剑、弓、杖。电脑用 WASD、J、空格、R、Q、F；鼠标指向并按下攻击，Esc 暂停。

击败两名守卫后，前往右上方封印匣并交互。保存使用独立的 `sword-fire:prototype-2d:entrance-trial:v1` 浏览器键，主页可继续上次样片。

## 实现与来源

- `core.ts` 复用现有 `GameSession`、`Navigation`、装备与存档验证；没有另写伤害、敌人AI、掉落或闪避系统。试炼场景是明确隔离的小样，不会设置完整首章通关标志。
- `main.ts` 使用本地随附的 Phaser 3.90.0（MIT）进行图片渲染、输入、音效和特效显示。官方来源 https://phaser.io/download/release/v3.90.0 ，许可见 `vendor/PHASER-LICENSE.txt`。未改动 Cocos 依赖或引擎。
- 人物来自已有角色源与原生动作，Blender 离线渲染为透明多方向精灵；游戏运行时不加载3D模型/骨骼。精灵 manifest 记录方向、锚点、动作、源文件哈希和作者。渲染入口是 `tools/render-sprites.py`，沿用项目已有 Blender，无新工具依赖。
- 场景及道具由内置 imagegen 生成，提示词与源图见 `assets/IMAGE-PROMPTS.md`。未对生成图做程序绘画或换色，运行时只按精灵框选取道具。
- 音效复用 `src/cocos/tools/make-audio.py` 生成的本作原有合成 WAV。
- 暖金界面复用本作原创 UI 切图。

素材及人物署名见 `THIRD_PARTY_NOTICES.txt`。预渲染精灵继承原素材许可；角色并非全部 CC0。

## 验证与边界

复用现有 TypeScript、规则检查和浏览器实际操作检查；不新增测试框架、用例或测试依赖。实际桌面/手机尺寸操作证据保存到 `evidence/`。浏览器触屏模拟不代表实体手机帧率、发热或内存验收。

当前目标是验证2D路线。完整剧情、全地图、全装备外观、多章节美术和真机适配仍需在选定路线后实施。
