2D concept presentation (2026-11-06):
Transparent character direction/pose sheets, the painted inn and environment cutouts were generated with OpenAI imagegen from the project's approved original v5 character/environment references. No third-party character model was rendered for these 2D character images. Original generated PNG bytes are retained; Cocos SpriteFrame/quad UV regions provide runtime framing. Prompts, source file hashes, selected/rejected outputs and known limitations are recorded under source-art/characters/2d-concepts/ and docs/assets/flat-world-v2.md in the source repository.
2D tiled ground/road/bridge surfaces reuse the project's existing licensed surface albedos; all original source attributions above remain applicable. Physics/navigation still reuse the existing Cocos scene; preserved 3D comparison resources remain in this local test build.

Natural world / equipment v3 (2026-11-06):
Six neutral-material environment sibling images, the seven equipment progression boards, and updated run/weapon pose atlases were generated with built-in OpenAI imagegen from approved project character art and user-provided palette references. No third-party equipment pack or character model is rendered into these new images. Generated PNG bytes are preserved; Pillow reads alpha/metadata only and Cocos SpriteFrame UVs provide all runtime slicing. Prompts, input/output SHA-256 and rejected variants remain in source-art/maps/natural-v3/, source-art/equipment/v3/ and source-art/characters/2d-concepts/player-actions/. Existing licensed surface albedos, Cocos renderer and inventory/save rules are reused. User-provided color references are study inputs and are not distributed in this Web build.

Hero proportions / readability v4 (2026-11-06):
Updated adult hero pose atlases and the cool weathered inn sibling were generated with built-in OpenAI imagegen from the approved project identity and character material master. Weapon variants reuse the project-authored equipment v3 designs. Original output PNG bytes, prompts, failed candidates, dimensions and SHA-256 are retained under source-art/characters/2d-concepts/hero-v4*/, and source-art/maps/readability-v4/. Pillow only reads geometry/alpha metadata; it does not resave image pixels. Native Cocos SpriteFrame UVs, the bundled unlit alpha test and shared quad geometry provide runtime framing and a subtle player contour. Existing inventory, combat, physics, navigation, HUD layout and licensed source attributions above remain applicable.
