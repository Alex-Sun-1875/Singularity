# 探索携行与战斗持握设计

状态：用户确认长剑背负并要求继续后，探索站走跑/闪避和自动战备规则已接入本地试玩。当前收拔为即时完整姿态切换，专门收拔过渡帧尚未制作；具体交付与验证见[运行记录](../../assets/weapon-carry-v1.md)。基于现有Cocos2D、七种主武器、当前银白半束发与柔和脸型，保留衣装、身体比例、界面和玩法规则。

## 行为

| 场景 | 主武器 | 身体动作 |
|---|---|---|
| 安全区域站立、步行、奔跑 | 收入剑鞘或固定在背架，具体装备始终可辨认 | 双手自然放松，手臂与对侧腿交替；奔跑肩臂摆幅适当，身体不被武器拖矮 |
| 发现近处可见敌人、遭受攻击或主动攻击/蓄弓 | 立即进入持握/备战 | 战斗中的移动、撤步和追击仍持武器，不能一跑就收起 |
| 敌人仍在威胁范围、正在蓄弓/施法或有来袭投射物 | 继续备战 | 停手不等于脱战，不反复收拔 |
| 危险解除且连续约2秒无新战斗意图 | 收纳主武器 | 回到旅行的放松步态；2秒是外观防抖时间，不改变战斗数值 |
| 探索闪避或攀越等急动作 | 保持当前收纳状态 | 背架和绑带跟随躯干，不出现武器凭空消失或拖地；若已备战则延续持握 |
| 交谈、阅读、捡取或开门 | 安全时保持收纳，交互手空出 | 手部执行实际交互，不一手穿过长剑或法杖 |
| 暂停/检定 | 保持当前姿态和收纳进度 | 不在暂停时继续收拔或回跳蓄弓阶段 |

## 收纳位置

- 长剑：按用户期望采用有剑鞘的斜背携行，肩带和腰侧固定点限制晃动，剑柄在肩外侧，避开后脑与半束发。较短的副武器适合腰侧鞘；不能把所有尺寸都硬塞同一背位。背负长剑使用可侧向释放的固定结构，取用时有明确手部路径，不让剑刃穿过头发或肩膀。
- 法杖：采用肩部与髋部两点固定的背架，略倾斜或近竖直；杖头在肩外侧，杖尾高于小腿的摆动范围。移动时是杖随躯干小幅摆动，不是杖头甩来甩去。灰木短杖的白珠与枝状杖头保持识别度。
- 弓：与箭袋分侧固定在背部快取皮扣上，保留完整弓弦；弓弦不绕脖子，弓角不插进银发和箭羽。进入战斗后取弓，箭袋仍留背后。三种弓各自的木弓、绿宝鹿角银饰、蓝星月饰保留。
- 盾：常态持在非惯用手/前臂，走跑时低收并贴近身体，战斗时转向威胁；“一直拿着”不等于一直举到眼前或每步挥盾。确需双手完成的特殊动作可以用盾带短暂固定，动作结束恢复持握。
- 剑、弓、杖都只出现一件：收纳图中手为空，持握图中背架/剑鞘可留空，但背后不能再复制一把。

## 切换与操作响应

采用“探索收纳 / 战斗备战”两套动作，而不是按走跑速度决定是否拿武器。玩家接近可见敌人时可以提前取用；玩家主动按攻击、技能或开始蓄弓的当帧就切换到可攻击姿态。收拔动画服务于现有准备段，不能新增强制等待、吞掉首次攻击、改变箭/法弹释放时点。

收纳的手部顺序为：握稳武器→靠近固定位置→剑刃入鞘或背架锁定→松手→恢复自然摆臂。取用反向执行。急迫攻击、受击和闪避可打断外观过渡，攻击/取消/消耗仍由原核心处理。移动时用对应的移动过渡，不能让脚突然停住而身体在地上滑行；没有合适过渡时直接切到正确姿势，优先保证响应与装备位置。

鼠标移动只控制朝向，不视作战斗。取消弓、油、符咒准备不会因外观状态切换而发射或消耗；过渡不修改输入和存档。

收拔过程中换装备，应立即丢弃旧武器的显示过渡，按新装备ID与当前探索/战斗状态选择完整姿态，避免旧剑留在背后而新杖出现在手中。一个换装帧结束后，只显示当前装备对应的一套武器。换区域、重载和暂停恢复同样以当前真实装备和状态重新核对。

## 接入现有项目

当前`FlatActors.ts`已有Texture2D、SpriteFrame、原生quad、逐格脚底锚点与A/B八相位跑图。适合保留现有60个战斗动作键，新增七武器各自的`explore_idle_ID / explore_walk_ID / explore_run_ID`，仍使用既有渲染能力，无需新库、骨架引擎或换项目。每件武器独立保留外形，不能通过隐藏手中的图像来代替真正背负。

方案比较：只在移动时隐藏武器会丢失装备、摆臂仍僵硬；按探索/战斗选择完整姿态图最适合当前已烘入身体的武器素材；独立武器层需要逐帧附着点和遮挡，目前没有可直接复用的纸娃娃绑定。建议采用完整姿态图，先用普通长剑验证收纳、自然步态、进入战备与脱战，再扩至全部七武器。

显示层沿用核心已有约7米察觉距离、实际视线与高度差，识别存活敌人、受击、战斗action和来袭投射物。约2秒缓冲仅存在FlatActors，不进入GameState/存档；换区域时重置。ChapterGame先advance再更新actors，已经能让首次攻击当帧进入正确姿态。

素材优先分开制作放松idle、四方向walk、八相位runA/B，每武器4张共28张；若首列能同时保证中性站姿与行走周期，可复用walk首格减少到21张，但不能为省图牺牲步态。28张仅覆盖探索站走跑，不包含收拔、探索闪避与交互。后者应补齐保留收纳装备的对应姿态，不能把现有空手/持握闪避图接上去就宣称全场景完成。实现应先以普通长剑完成一致的端到端演示，再逐武器扩展。没有匹配过渡时可立即切到最终正确完整姿态；没有匹配闪避/交互图时不得悄悄丢弃背负装备。现有战斗姿态继续使用最新hero-v6，不重做脸、头发或衣服。

当前玩家数据虽然有offhand空槽，但没有可装备盾牌条目，player.shield是数值护盾。现有盾兵、队长和洛恩已经有手持盾，应保留；本稿的玩家盾携行原则不代表已新增盾牌物品、格挡系统或纸娃娃能力。

## 验收

探索时站走跑能清楚看到收纳装备，手臂自然摆动；战斗中移动仍持握，首次攻击和蓄弓立即响应；无敌人安全区域约2秒后恢复收纳。盾与主武器状态分开。前后左右都不能出现重叠双武器、无固定带的悬空武器、头发/箭袋穿模、拖地和因背武器扩大alpha边界而缩小身体。暂停、取消、换装备、换区域及已有存档行为保持。实现验证复用现有规则检查、构建和实际键盘/触控复核，不新增测试依赖或脚手架。
