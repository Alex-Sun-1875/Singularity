# FairyGUI 地图与 MPFB 人物接入

用户已要求直接采用上轮候选 FairyGUI、MPFB2，并继续参照《博德之门 3》设计风格。采用现有 Cocos 3.8.8 工程，不更换引擎。地图用 FairyGUI 官方 Cocos 3 分支的组件、控制器与输入能力；人物使用 MPFB2/MakeHuman 官方工具和可编辑资产，保留十名角色身份、骨架与十组动作。

2026-11-05 状态：FairyGUI接入及手机触屏地图已完成；后续暖古铜/烟黑UI资源现已应用，取代下文初始深墨方案。当前十名生产人物均为53骨骼/**11动作，包含walk**，以 `source-art/characters/cocos/library-integration-record.json` 和真实发布报告为准。下文十组动作指初始契约，不是最终数量。

视觉：地图保持大幅地形插画，顶部区域标签，右侧地点与路线信息，底部缩放工具。深墨色 `#10181d`、旧黄铜 `#ba9b62`、羊皮纸文字 `#e9dec7`、风化石色 `#7d8177` 与队伍青绿 `#8fc5b5`。字体沿用工程支持中文的衬线字体；装饰限制在标题分隔与边框转角。人物以天然皮革、粗亚麻和钢甲形成不同剪影，沿用既定配色。参考本地 BG3 美术设定及地图结构，不分发其素材。

方案选择：直接使用官方 FairyGUI 组件和 MPFB2 资产流程；只安装依赖而不调用无法满足用户要求。现有纯 Cocos UI 和已有 MakeHuman FBX 保留为迁移基线，以便验证行为和动作。无需重造通用 UI 框架、人物生成器或渲染器。引擎兼容修正、项目布局和游戏数据接入属于必要适配。

验收：地图切层、拖动、缩放、筛选、选点、标记、路线、键盘、触屏及重复开关可用；人物更新有可见效果且不损失身份、骨架和动作。记录固定版本、来源、许可和重建方法；优先现有检查、构建及实际引擎验证，不新增测试代码。不提交或发布远端。
