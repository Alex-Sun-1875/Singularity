# Maker 本地单机小章节

2026-11-03。用户已选择 TapTap Maker，指定在当前仓库的 `src/` 下开发。当前要求：真实3D场景、实体人物模型及动作；先使用本地资源完成，不依赖Maker云端模型生成，不把登录、Token或云端绑定作为本地开发前提。

## 当前视觉验收要求（优先于下文旧的2D实施描述）

- 采用倾斜俯视的真实3D场景：起伏地形、道路、石墙、建筑、植被、光照和阴影，参考MOBA地图的层次与可读性。
- 玩家、弥菈和守卫必须是实体人物；主角以v5造型为准，在本地制作或适配模型。待机、移动、攻击、受击必须有实际动作，不能用头像位移替代。
- 模型、骨骼与动作在本地制作和导入。未取得合格模型时明确报告缺口，不回退到早期低模或头像棋子，不把可选云端服务变成必要条件。
- 已有规则与存档可以复用；旧2D画面和对应截图不计为完成证据。

## 目标与范围

首个可玩片段取 v5 的 M1：石桥旅店接约、穿过野路、在劫车隘口夺回遗物匣，读到近期求援信后收尾。地下重逢、完整第一幕和后续地区留待扩展。场地是制作样板，不替代 v3 世界地理，也不把 S10 的灰披队长和其固定奖励提前搬到 S04。

包含移动、瞄准、剑/弓/杖三种免费普攻、闪避、有限火油、油桶连爆、敌人预警与碰撞、检查点恢复、任务对白、可选支路宝匣、本地存档。首批随机传奇为「风暴王的遗嘱」与「阿斯特拉的回信」，各自改变攻击机制。首批未实现的其他传奇继续作为设计候选。

初始有三种基础武器；接约预支60币、救车20币沿用原来源。当前片段不发 S10 抬杆的固定钢剑。符咒、完整护甲/套装、商店、合成和完整第一章不计入本片段交付。样板存档使用独立版本，不读取或迁移旧浏览器存档。

## 工程与素材

Maker 本地工程根为 `src/`，Lua 入口为 `src/scripts/main.lua`，素材在 `src/assets/`；既有四个 JS 文件保留。官方开发套件目录与 Runtime 为本地辅助文件，忽略提交。基于官方 `scaffold-2d.lua`，规则、绘制、UI和保存分模块；沿用1280×720横屏设计。

用户已明确禁止继续使用截图中的早期低模人物。不得使用 `assets/blockout/` 的角色PNG/GLB，亦不得把已被否决的角色研究作为回退素材。角色采用当前 v5 的 `hero-v5-balanced.png`、`explorers-v5-recast.png`、`rivals-v5-balanced.png` 为造型与立绘依据；地理和场景方向采用当前恢复后的 v3 图册。概念板可用于立绘/肖像，战斗精灵与动作需依据新版另行制作，不把概念板或静态图位移冒充完整动画。美术质量与功能分别报告。

## 状态与规则

- 普通世界敌人与宝箱一次结算，死亡重试不复制金币、材料或传奇。随机结果随击败事件记录，已提交结果读档不重抽。
- 普攻不消耗箭或专注；火油数量有限，耗尽仍能完成主线。冲刺有短无敌与冷却。
- 折返箭出程/返程分别最多命中同一敌人一次，墙体会阻挡；雷电追加不能递归触发自己。
- 对话中询问信件会留下对应知情状态，取得原信后的回应与之相符。未接约不能跳过整个任务；已清敌/已领取事实持久保存。
- 本地保存只用引擎 `File` 与 `cjson`；损坏或未知版本不静默覆盖原存档，展示恢复状态。前后台/暂停与退出显式保存。
