# 第一章视觉与可玩表现重做

用户明确否定当前画面质量，要求第一章人物、走路姿势、技能效果、武器装备及场景细节达到实际可玩的效果。先前绿色检查只证明流程与资源兼容，不能证明美术完成。本任务保留完整目标，后续验收以实际正常镜头、运动录像和 v5 方向为依据。

## 方向与范围

继续使用 Cocos 3.8.8，复用 FairyGUI、MPFB/MakeHuman、Poly Haven、Kenney 和有明确许可的成熟图标/动作。参考 BG3 的服装功能性、材质层次、自然环境与克制的界面。保持自然成人比例、v5 身份、v3 地理及所有首章任务和装备规则。

- 正常 1280×720 镜头人物高约 100–132px，脚底与交互可见；桌面不被大块触控按钮遮挡。
- 桌面 HUD 使用紧凑底部动作栏，手机保留可用双拇指控件。界面按上轮建议的深褐黑、皮革棕、旧黄铜、羊皮纸配色实施；此为执行默认，不冒称用户逐色批准。
- 场景用真实可复用模型取代主要箱体家具、重复球/锥植物与石头；开场旅店必须有明确的空间、家具组合、灯火和生活细节。其余地理仍然可通行。
- 人物替换明显管状头发，改善衣物与装备材质/轮廓；优先使用成熟 mocap/动作资源改善奔跑及走路观感，保留骨骼兼容与战斗时序。
- 技能使用引擎粒子能力和现成纹理，显示攻击、受击、蓄弓、奥术与燃烧反馈；不能仅靠彩色几何体表示成品。
- 界面装备名称/数量/冷却/武器外观与真实状态一致，任务、存档、触控与完整通关继续可用。

## 实施边界

场景、人物资产、HUD/特效分工，避免交叉覆写；主代理统一接入相机、灯光及加载。所有外部资源逐项记录来源、版本、哈希、许可；不分发 BG3 素材。自定义代码以接入和适配为主。复用现有检查、构建、浏览器与 Blender 验证，不新增测试代码/依赖，不远端发布。

## 完成证据

同镜头开场旅店、聚落、林地、地下、战斗和人物近景前后对照；真实键鼠/触屏操作与动作/技能录像；身体脚底、握持武器、动作衔接、交互遮挡与界面文字逐项检查。完整通关与存档恢复证明功能，正常游戏画面和录像证明视觉表现。未证实或明显粗糙的项继续工作，不能仅凭资源数量/绿色检查宣称完成。
