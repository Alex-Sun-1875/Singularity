# 清亮色调重整实施计划

**Goal:** 对齐用户两张BG3参考的自然户外色、冷暖地下层次和精细金属点缀，消除现版界面与场景的大面积黄褐浑浊，手机横屏优先。

**Architecture:** 保留Cocos Creator3.8.8、现有PBR资源和原生UI/FairyGUI。统一语义色；面板、按钮与空装备槽采用BG3方向的烟黑/黑曜石内底、内凹层叠、细金属包边与古典角饰，正文冷白，淡金仅作细边/少数重点。草木、石材、皮肤保持本色，以中性日光和冷色填光消除黄色叠染；地下保留冷暗与局部暖火光。复用引擎及现有控件，无需新库；既有皮肤无法满足色彩时，使用原生Graphics或可编辑SVG绘制。

**Design choices:** 直接提高全局饱和度会连土黄一起放大；全部改为荧光紫蓝不符合参考。首轮蓝灰平面按钮被用户明确纠正为“按钮面板参考博德之门”“整体对齐一下博德之门”，所以最终采用烟黑内凹与细金属层次，不以通用应用卡片替代。场景采用中性材质本色、冷暖分离及少量清亮强调色。

**Palette contract:** background #0A0D13；panel #16191F；dark #090D13；button #1C2128；active #1C3542；hover #2B323C；gold #E4CFA7；line #979082；ink #F1F5F5；muted #BFCAD3；green #7BDEB4；unknown #A9B5C2；route #83CDE6；purple #C4A5ED；danger #5E273C；red #F18E9F。允许运行画面复核后微调。

## Tasks

- [x] Root：统一UiTheme、Hud、LoadingScreen和残留菜单/图标色；对比旧画面与新画面，控制暖金面积与正文对比。
- [x] UI skin：检查既有皮肤资源/生成入口，重做中性蓝灰按钮、面板、状态条和状态反馈；保留原触区/布局/资源身份，无新增库。
- [x] Character/maps：消除人物/技能/行囊/地图/小地图/图例中的硬编码黄褐、地图泛黄乘色和人物预览黄色灯染，统一到palette contract。
- [x] Environment：检查场景、环境资源及光照的黄色来源；调整室内/户外/地下色调，保持自然草木/灰石/皮肤，暖光局部化，保持现有灯数预算和玩法碰撞。
- [x] 正式构建与运行复核：手机915×412和桌面，加载/旅店/HUD/行囊/技能/地图/自然户外/地下均保存真实引擎截图；检查红/绿/蓝状态仍可区分、文字可读、预览/地图关闭回收与触控。
- [x] 复用TypeScript检查、已有发布输入/触控/存档检查；不为改色扩展规则测试。重新打包并记录体积/CRC/来源/实际截图及仍有的美术差距。

## Acceptance

本轮完成要求界面大底/按钮/正文不再泛黄，户外有可辨的绿植/灰石/暖土，地下冷暖有层次且手机能读清主体；参考仅用于研究，不打包截图。不能仅修改UiTheme或仅交付配色稿。最终以实际发布版多场景截图及操作证据证明。
