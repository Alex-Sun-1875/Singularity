# 剑与火 寻宝对白与物件文字

> **版本状态 2026-11-02 09:42后** 用户已否决区域v2仍过小及过度寻宝的定位。本页保留的12子区/4宏路径、尺寸、212候选资源、20—40/35—60分钟及新增实例/铁料，均为**被否决的v2候选记录**，不是当前认可愿景、实施授权或v3预算。下一版由真实BG3地图研究重审，剧情、战斗与探索同等重要；单人演示只约束制作批次，不约束世界规模。现有40永久装备加8消耗符类型、稳定ID和唯一来源记录不因此次状态修正而重发。

本文为可拆字幕稿，尚未接入。对白应同时承载人物动机、关系和冲突，以及探索/战斗所需信息，不只服务宝箱。旧切片曾限开场与收尾各两句，这不是完整剧情的表达上限。`story_dlg_*`、`story_text_*`是设计ID，文案可跳，任务摘要与奖励不依赖听完。

## 通用规则

- 世界字幕不锁镜头、不暂停移动，战斗开始让位预警；模态选择按界面规格暂停，关闭清输入。
- 每条一个说话人。不要把三句塞成一大条；同伴自动提示只触发一次，重试用主动查看。
- 物件全文一般不超过三行，第一行必须有用。日志只写已发现事实，不列未发现宝箱和所有秘密。
- 选择必须显式确认，普通“跳过字幕”不签约、不拆装备、不采用默认值。

## 检查底线

每章需要让人物为何行动、面对什么冲突与可参与的战斗/探索清楚成立，不只检查宝物清单；避免无关长讲述不能等同削弱剧情。关键证据自动记摘要；物件全文和人物秘密可跳，掉落不缩水。首章队长拿锤但剑来自架；二三章是复用身体的具名精英Boss；终章开库不是分粮。选择与配装分别确认，所选古物不因换训练而变成另一件。

新增可选隐龛的短提示：“两枚旧钉，指的不是路，是墙后的夹层。”不自动定位所有秘密；玩家也可通过近距离看见板缝找到插销。演练入口写“演练不改变主线，只发指定普通材料”，不伪装成队长复活。装备比较页显示等级、品质、9永久装备槽与2符快捷栏合法性、双手冲突、套装2/4档与训练来源；不再显示一个全局效果槽。剧情字幕不代替制造、整备或符咒施放确认。

终章传奇侧格可选发现句`story_dlg_ch04_oath_vault`：“主箱后面，还有一卷。”保留原对白和`design_reward_ch04_oathfire_sword`历史ID，奖励卡实际显示“T08葬誓长卷 L5 传奇，仅此1张、成功释放即消耗；W06誓火铭文外观已发现”，不再发旧誓火长剑、不复制主箱W06，也不插入新强制结局。

## 四路整备短提示

这些是界面辅助文案，不追加强制剧情字幕或职业选择：

- 初始整备：“铁剑、短弓、短杖已在装备册，刻痕符页6张已入库存；安全点可整备。”
- 弓：“按住瞄准，松开射击；普通箭无限，R箭式使用专注。”
- 杖：“普通杖弹不耗专注，R武器技另计；双手长杖会卸下副手。”
- 双符：“Q/E各引用一种符咒，成功释放扣1张；取消或前摇未发出不扣，冷却结束不补张。”
- 试装台：“隔离试装，不把后章装备、材料或冷却写入旅程。”
- 训练：“一次启用一项传承训练；合法永久装备和套装不会因此被停用，符咒快捷栏不算套装。”

四个配装范例沿用装备规格的反击守桥者、风径猎人、沉钟织法者、双印巡秘者；都是自由剑士的打法，不新设四个人物。武器技R、符咒Q/E、交互F分开提示，触屏热区与战斗可读性仍待测试。

空符提示：“符咒已用尽，改用免费主武器；休整不会补符，可检查已学制造配方。”T08预先提示“本旅程唯一，使用消耗”，不在已确认战斗输入后追加弹窗；用后提示“葬誓长卷已使用，发现记录保留”，不能再显示“未领取”或引导玩家重刷侧格。双印巡秘者的提示写“有限符咒爆发，免费杖弹补空窗”，不能写零资源无限放符。

## 安全交易短提示

五商人包括艾妲、布兰与新增蕾萨、墨伦、娜薇。交易页直接显示实际商品、价格、限量stock与已购买状态；“灯油古物商”不表示可买游戏火油资源。旧J03/A13/W15/A10/J06/A07已领或拥有记录沿用，不因首次见商人补一件。

有限符补售提示：“按张数与价格购买，库存有限；休整不补符。”传奇提示：“葬誓长卷不出售，本旅程只在原侧格取得一张。”不写缺钱卡主线或必须逛遍五店才可通关；六件专售来源与其他确定奖励分开。

货摊短句按[商人与买卖](../interactions/merchants-and-trade.md)采用：布兰说明“装盾后，主手武器技换成格挡”；墨伦说明“三张是三次，用了就少”。对话可跳，购买资格、免费线索与主线金币不依赖听完；两个旧剧情选择都不暗加涨价或封店。

地图短提示：“听说过，不等于走到过。”“这里只看已知位置，买卖要到商人面前。”“传送不等于休整，符纸与货摊不会补满。”四章路线可混走，主动求提示不扣币或符；未理解记号只显示“目前还不明白”，不记永久失败。W14线索指环道外沿侧龛，T08线索指主箱验货后V内誓火侧格，不能用同一句话把二者混成一个宝箱。空间与信息显隐见[地图探索逻辑](exploration-map-logic.md)。

## 被否决v2的区域提示底稿

以下方向短句来自现已被否决的[区域尺度第二版](../maps/regional-scale-v2.md)，只保留历史，不将其35—60分钟或藏宝导向作为当前目标。它们不替代真实道路，也不能挤掉人物关系、冲突与剧情所需的表达。首章道标提示在O，废驿收条在S；旧H相邻台词只可作为历史，当前从P到H、H到S都经W中继，不能一句“旁边”让远端地点贴在一起。

探索辅助句可复用为非强制提示：“塔下有两条坡，林子那条能绕回废驿。”“地窖另一头回林地，不是军械台。”“墓室坡门从里面开，没开也能沿干壕退。”它们分别对应已定义空间，不赠新装备、不要求先听再开门。新地牢旁证只入日志，材料匣铁2独立领取；读文字本身不额外奖励。
