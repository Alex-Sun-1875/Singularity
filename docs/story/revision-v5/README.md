# 剑与火 角色与剧情第五版候选

人物等级与战斗采用[角色成长](../../design/character-progression-v1.md)和[纯技能](../../design/combat-skills-v1.md)最新设计；本目录继续定义人物身份与关系，不用旧道具战斗或消耗符规则解释当前技能。

2026-11-08：当前完整主线摘要、地区/远征命名与丰厚奖励已更新到[《剑与火：破晓之战》v6](../../design/campaign-v6.md)。本目录保留人物身份、关系和详细因果，v6明确修改处以后稿为准；历史图像、旧标题不无差别替换。当前可玩工程是Cocos首章，完整故事与奖励未全量实现。

2026年11月3日。按本次要求同时优化人物塑造、外观、主线与选择后果，并制作三张新角色概念板。参考《博德之门3》的人物独立目标、个人线与主线交织以及选择回响的方法；保留本作的白枝远征、昼核与四地表两地下世界。剧情与外观仍为评审候选，尚未接入0.1原型；本轮姓名按用户已选名字与授权补名更新。

**当前阵容**：拉斐尔（主角）；弥菈、洛恩、夜祈、瑟维恩（四位核心探险者）；凯尔、伊芙琳·灰、艾莉丝·夜歌、阿德里安·洛斯（其余关键人物）。[人物稿](characters.md)列出旧名对应、身份与命名来源。主线、六条支线、六段对白及结局中的称呼已按同一对应更新。

**你为了遗库与名声进入地下，发现阵亡者仍在吃晚饭。你的雇主认得他们，教你破门的人曾参与封门，而最懂遗迹的学者改过证明自己理论的那一笔。与你争夺昼核的守备长，刚刚救了一群人，转头又把他们扣走。**

本轮外观进一步按用户反馈修订为年轻、俊朗、浅肤色的成人阵容，女性金发大波浪、男性保留深发；当前核心四人板依最新反馈恢复第二位洛恩的此前形象，并以盖尔、阿斯戴伦官方图为面部参考，重塑弥菈、夜祈和瑟维恩。剧情主体延续本稿。

## 本版取舍

本次采用“保留世界和核心谜团，重写人物关系与关键事件，同时出外观概念”的改稿方式。只润色台词无法解决原稿人物趋同；推倒昼核与地图重建世界会丢失已有奇幻发现和空间设计。这里保留冒险地点，改变人物为何到场、先做了什么以及玩家要承担什么后果。

每人仍有专业本领和生活趣味。凯尔不被强行配上一桩隐藏罪行；伊芙琳不为全体决定继续值守；反派真实救人也不抵消扣押责任。人物可以合作而不和解，最后可以带着不同理由分路。
