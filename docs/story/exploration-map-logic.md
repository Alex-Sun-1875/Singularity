## 一 参考博德之门3的探索逻辑

要保持一致的是**探索因果**：空间先于任务菜单；陌生入口、可见高处、遮挡与环境物让玩家提出“能不能从另一边过去”；文字和人物给出可行动信息；实际操作和路线选择能改变遭遇，不只是换一段对白。官方介绍强调手工世界、垂直探索与秘密；官方更新中的移开画作再操作隐藏按钮、信件提供入口线索，也是“观察 → 推断 → 动作 → 发现”的具体例子。[官方游戏介绍](https://baldursgate3.game/about)、[Patch 5 环境秘密与信件线索](https://baldursgate3.game/news/patch-5-now-live_99)。

| 保持的探索原则 | 本作落地规则 | 不照搬的部分 |
| --- | --- | --- |
| 多入口与相连支路 | 每章有共同目标、12个内容子区与4条宏路径、多处横接和室内回环；原三route可混走 | 不复制 BG3 地图轮廓、地名、人物、原任务或整张地下地域 |
| 高差改变观察和接敌方向 | 坡台能看见敌阵背面；上下层有确定连接，实体遮挡决定射线 | 不增加自由跳跃、攀爬、飞行、传送解谜或属性距离计算 |
| 发现先于地图答案 | 走到、看清或读到线索才记地图；未知秘密不预铺金色宝箱 | 不做全图扫描、自动最短路导航或付钱买全地图 |
| 对话和文书能提供入口知识 | 每个核心秘密至少有两种独立提示，另能直接看懂现场 | 不要求集齐线索、带指定队友、职业专长或过 D20 才准打开 |
| 地形与物件提供不同解法 | 推箱/破栏/切弩线/开水槽/短路插销都改变可走空间或接敌面 | 不把所有物件物理化，不加完整潜行犯罪、挖掘、游泳系统 |
| 世界保留探索后果 | 已败敌、已开的门桥、已读线索、已取宝物和商人账户持续 | 不因睡觉复活 Boss、刷宝或补钱；复演是另一个显式隔离模式 |

实时单主角战斗要求预警、脚下安全边界和可读退路优先，所以高差不直接给隐藏命中加值，不能跳坑秒杀 Boss，不用队伍回合制暂停链或随机骰子支撑通路。四章仍按线索推进，**不是声称已实现 BG3 全部自由系统**；一致的是上述空间和发现逻辑，不是每一条规则逐字相同。

## 二 通用地图语言

### 节点和连接

下文 `chNN_X` 沿用旧地图锚点；新增区域节点采用 `chNN_v2_X`，共12个明确白名单，见[区域合同第七节](../maps/regional-scale-v2.md#七-稳定id与旧图映射)。18个 `obj_*`、12个 `route_*`、12个 `cp_*` 不改名、不新增；旧12个 `area_*` 是父级任务归属，不是整个游戏只有12块小平台。一个子区可有数个房间/坡台，`ch01_N`、`ch03_L`、`ch04_V` 是子区内微点，不各凑一座区域。第4宏路径是空间串联，不是新增路线任务或新奖励。图中 `↔` 为双向步行；`→` 为有明确条件的首次前进；`⇢` 为首次从一侧操作、打开后双向的近路。图只表达设计拓扑，玩家未探索前不会看见全部内容。

每条连接必须在灰盒中存在连续可走的实体路面，不能画在地图上却靠空气墙隔开。路线标签仍沿用原ID，作为入口和遭遇索引，不把玩家永久锁定在某条路线；从高道转仓道不重开“选择路线”任务，也不多领一次到达奖励。

### 高差和视线

- 区域山脊、谷地和城墙可以有较长缓坡与连续海拔变化，不把整片山谷限制成2米台阶。`0/+1/-1`只表示当前局部的地面、可进入上层、地下层，不是全区域绝对海拔；原2—3米坡台和1—2米低廊是局部灰盒起点，区域高程另测。高低必须有坡道、固定阶梯/梯道或已卡稳木板连接；不自由攀爬/跳跃，不让地图上下投影误导同层可达。
- 玩家/敌人的视线和箭、杖弹都由实际空间遮挡判定。能从坡上看见箱顶不等于能隔楼板捡箱；看见人物不等于能隔栏交易。屋顶、墙体与完整矿车挡射线；低栏只按实际高度遮挡，不统一当透明，也不悄悄给高处“必中”。
- 每个远程接敌面至少有一个可达硬掩体；高道是侧面路线，不是敌人永远上不去的免费射击台。高处开战的敌人能沿已有连接追近或退到遮挡后，不允许卡导航让 Boss 白挨打。
- 镜头可剖去遮住主角的前墙，但剖去仅为看清当前空间，不把墙后敌人、秘密和商货一起透视。敌方察觉仍用原范围与可见性，不因读文书瞬间拉整图敌人。
- 边缘继续沿用0.35m安全界，主通路净宽至少1.2m、回转面1.8m；没有玩家必须跳落、落水或被推下悬崖才能发现的关键路径。掉落搬到可达锚点，不从地图外消失。

### 雾区与知识

地图有三种信息强度：**未知**为遮罩；**听闻/远望**只给大致方向、地标轮廓或带问号的小范围；**亲历**才记录可走轮廓、已验证连接、当前楼层和实际交互状态。听到“梁后有匣子”不会立即揭开整座废棚的墙线。

亲历范围由当前位置和无遮挡可见空间推进，不穿厚墙或另一楼层；地图揭示可比战斗镜头简化，但不能抹掉尚未发现的房间边界。已探索几何保留，离开视野的敌人不持续显示；不在地图画实时巡逻轨迹或未交战敌人数量。玩家知道有一条路，不等于知道路上现在安全。

已知宝物标记分“看见但未取”“已取”“入口仍未验证”；地图不显示总宝物百分比，不以缺一只箱暗示坏结局。商人标记只有实际见面才建立，离场/迁移状态与[商人规范](../interactions/merchants-and-trade.md)一致。商店售罄不能误显示为从未探索。

## 七 线索和检视不得成为隐形钥匙

每个秘密使用三个层次：**人物或文书说明一件具体事实；环境让这事实可验证；操作打开真实路径或拿到真实物品。** 不把“搜集三枚发光线索”写成探索。日志记录玩家实际知道的句子，不提前展示正确答案步骤表。

| 发现对象 | 对话/文书路径 | 环境与直接操作路径 | 未触发提示时仍能怎样做 |
| --- | --- | --- | --- |
| 首章 W08 隐匣 | 艾妲提双钉梁；道标说明位置，收条背图说明导槽 | 双钉贴花、拖痕、背板接缝；推箱或从坡后破栏开同一插销 | 直接走到背板检视，不必补读两页；请求日志提示只指出双钉梁与拖痕 |
| 二章 J02 干槽 | 墨伦提退水后石槽；旧检修短记画低廊方向 | 墙上旧水位线低于台阶、两侧坡面和石槽亮边 | 未理解水位也可从任一短坡进D；无须装备钟坠或开付费水闸 |
| 三章装卸箱安全接近 | 娜薇谈湿线；装卸图标出水槽清出的通路 | 水纹与木板导槽；开阀或搭板改变进路 | 图没读或被略过，阀轮和固定卡槽仍可操作；无油可走干路 |

| 四章 T08 侧格 | 主箱内装箱短记提“长封压在誓火铭牌后”，自动记已知线索 | 主箱验货后侧壁铭牌存在可辨接缝，主动检视再开格 | 不读长背景也可仔细看接缝；不要求拥有W14、燃烧符或完整六套装备 |

首轮不实现随机察觉骰或技能点。若 UI 使用“检视”字样，它指一次可主动执行的观察，不是隐藏成功率。基础线索在可见、同层、接近的条件成立时给轻提示；条件未满足只是**尚未发现**，不会写入永久失败旗标。装备 A12 的开箱轮廓提示、寻宝客套的提示距离只降低发现成本，不获得开门特权，不穿未开门揭答案。

可选“辨认”需要相关已知信息时，未有信息只显示“目前还不明白这个记号”，保留场景与交互；玩家可后来补读，也可用另一入口或直观操作完成。不得让一次失败封掉主线证据、配方保底、商人资格或唯一奖励。主动求提示不扣金币、不扣符纸，不把阅读速度当挑战。

## 八 自由顺序和明确边界

1. **区域内自由，章节入口有因果。** 第一章验货给矿桥线索，第二章拓印给河湾位置，第三章清单给堡库入口；四章先后不靠随机钥匙。旧区域能返回，未来未制作区域不能提前传送。没有一条可选支路以“任务尚未接”锁死本来能走到的普通门。
2. **抵达与任务结算分开。** 玩家提前看到水槽、放下梯道或辨认封签，可先保存有效世界事实；只有原目标前置成立才按原顺序结算一次，不强迫再拉同一机关，也不提前发整章奖励。
3. **主线机关不看清图率。** 公共近路只检查其局部安全；矿桥检查桥组与手柄；吊臂检查水槽与接触点安全；城外检查两台守兵。都不要求另两条可选路线清光。
4. **坏操作失去优势，不失去旅程。** 桶爆了仍能破栏、绕行；矿车错位可复位或走侧带；木板未卡稳可取消，主路仍在；买不起猎具仍有起始弓。不会因少一张一次性符咒而永久错过门或机关。
5. **战斗可退但不白打。** 已败敌保留；未败Boss按检查点规则重试满血。敌人追击不能进入商人/检查点安全锚点制造交易软锁，脱离规则与[遭遇规格](../interactions/enemy-encounters.md)统一，不在本页额外发撤退奖。
6. **玩家只做明示不可逆选择。** 首章队长、三章古物沿原确认卡；烧普通桶、破脆栏和开近路是普通世界事实，不暗挂声望罚分。行前只提示真正待确认的古物选择，不以“还有17个秘密”阻止离章。

## 九 地图和日志的可用界面

`ui_region_map_journal` 是一套暂停的区域页，四章共用：左侧当前区域、层级切换与已发现检查点；中央地图；右侧选中地点的已知线索、可达状态和来源。四个区域各画自己已实现的布局，不做整大陆无缝地图，也不按四张图重复建设四套UI。区域页可缩到聚落/树林/堡垒的地理关系，再放大看室内与局部连接；不能把旧小图拉大冒充区域地图。入口为暂停菜单“地图与日志”；PC的M键是同一入口的安全快捷键，触屏用暂停页“地图”按钮。仅附近3m无敌、无弹体威胁且没有交易/奖励/机关正在提交时可展开并暂停；开关页清除本次输入，不能把关页点击穿透成施符或攻击。

- 地图默认当前楼层。上/下层连接用带箭头的阶梯符号；点击另层只切视图，不让主角走向不可达投影。当前位置永远有层级与朝向。
- 已见商人显示姓名与可交易状态，图标复用一类；未知商人不提前标。在地图点商人只查看已知地点，不能隔空打开其交易页。
- 线索侧栏列“听谁说/在哪页读到/已现场验证”，允许玩家手动加一个兴趣点。手动兴趣点不自动解雾、不读取秘密坐标；不新增自动追踪收集品系统。
- 已完成宝箱可收起图标，未领完资源仍显示剩余；永久装备、训练、配方、金币与材料待领分别读取原账本，不用一个打勾吞掉全部类别。
- 地图不持续覆盖战斗，不显示墙后实时敌人。安全时暂停查看；战斗中按地图键给“不宜展开地图”的短提示，保留即时移动/闪避，不打开模态菜单挡预警。
- 首章版仅显示 `ch01` 已实现区域与已发现检查点；后章标题可以在故事日志写“下一处：沉桥”，但没有可点击的空地图或假传送。

### 返回已发现区域

首次必须步行到达并解锁检查点，才能从安全检查点的地图页选择前往；仅远望、听说、拿到线索或通过楼层投影看见不算发现。出发、到达都需安全，战斗、弹体、机关移动、交易/领奖提交中不能传送。确认传送不自动休整，不补符、不补金币、不补商货。

首章只允许当前章已解锁点间回访。完整四章版按逐章已实现并验证的出入口和检查点开放跨章回访；可从安全点选曾到达的旧区域，不要求为回购装备重演章节。原拓印与清单开启的是下一章旅行资格，不把前章入口从世界删掉。交通尚未实现时如实限制到已经制作的步行返回口，不宣称完整跨章已完成。

没有休息日夜循环或时限离店；商人剧情迁移须在地图/旧便条说明位置，物品保管仍随账户。没有商人、金币或一次性符纸是返回路线的必要钥匙。

地图只保存**已知信息**，不另建一份会与游戏世界冲突的门、箱、敌人状态。地图中“桥已放”“箱已取”“商人在何处”分别读取原机关、奖励和商人账；移除地图图标不是删除宝物实例。

新地图记录随原完整快照提交；保存失败只重写同一结果，不重复发“发现奖励”。恢复后若雾区缓存与真实已开门矛盾，重建可达标记，保留真实世界事实；不能为了贴合旧雾区重关门。位于被调整的旧地形或半空位置时回最近合法已解锁安全锚点，保留已得物和证据。
