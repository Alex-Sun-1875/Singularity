# 剑与火 剧情第四版候选

2026年11月2日。当前评审候选，未采用、未实现。地图方向保留v3；剧情按用户“更复杂、有深度、有趣”和“核心应该是探险家”的最新反馈重写。前一轮过重的居民事务不再作为主线中心。

## 核心冒险

**你与几位各有所求的冒险者，寻找白枝第七远征的遗库，却发现传说中的神器会害怕、会拒绝，也一直在学习人的声音。**

艾妲是寻宝佣兵与远征经纪，布兰是懂封炉剑阵的退役誓卫，蕾萨是追踪古兽的游侠，墨伦是能在现场显影金属记忆的秘术学者。玩家也是主动选择财富、力量、知识或救同行的遗迹探险者，不是替居民跑腿的快递员。四人会亲自破阵、追踪、研究与争夺发现，拥有不等玩家批准的目标；不自动引入四人队伍系统。

空白星片、会重演失踪剑士招式的石像、移动的地下星图、沉钟观测站与争夺古代力量的竞争远征贯穿四幕。地下仍活着的“阵亡者”揭示奇迹的代价，是主线的重要一支，而不是整篇只讲安置与轮班。普通人的生活让世界可亲，但不占核心阵容。

## 阅读顺序

1. [四幕与世界真相](story-bible.md)：第七远征、昼核、三方压力与公平伏笔。
2. [八位人物与可玩关系](characters.md)：核心探险者的能力、目标、秘密、主动行动与分歧。
3. [任务与探索网](quest-web.md)：八主场景、六支线与多解/失败继续。
4. [关键对白](scenes-dialogue.md)：探险者如何在发现、风险与利益之间争论。
5. [选择和四类结局](choices-endings.md)：自由迁行、有限共处、静眠封存、夺取控制的准备和后果。
6. [制作与旧合同](implementation-scope.md)：保留地图、装备、商人、原奖励，明确尚未实现。
7. [复核记录](review.md)：一致性修正与仍待验证项。

[假葬礼完整稿](scenes-funeral.md)保留为可选城镇生活插曲，不再计入六条重点冒险支线，不要求完成才进入深层遗迹或获得正面结局。
