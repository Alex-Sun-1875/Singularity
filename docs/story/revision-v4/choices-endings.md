# 剑与火 远征选择与四类结局

剧情v4探险者修订。玩家可为财富、力量、知识、同道或未知生命行动，不预设公开解放者身份。结局由探索准备、对昼核的实际接触、对人和伙伴的决定共同形成；没有善恶总分，也没有六支线全清门槛。

## 一 必须保存的事实

这些是纸面状态词，不是代码键。人物关系另存有限局部结果，不能把所有线索相加成“完美分”。

| 事实 | 状态范围 | 实际用途 |
| --- | --- | --- |
| 远征记录 | 未核实／两源互证／公开遮名／独立保管／军方独占 | 谁能主张发现，谁掌握责任证据；记录不是绝对读心 |
| 昼核接触 | 仅见光／观察到反应／重复自由接触／强迫取样 | 共处条件、伙伴协作、应激与可见反馈 |
| 自主拒绝 | 未测试／退开与中止均成功／被压制 | 是否真能拒绝；听见一句人声不等于同意 |
| 松环与散热 | 未试／失败读数／局部通过 | 是否可解除旧强束；失败可复试，不扣稀有材料 |
| 泄压与撤离 | 未核验／最低安全步骤通过／完整方案通过 | 最终行动能否开始；必须有实际安全路线与接应 |
| 迁行星路 | 未知／片段／核验到现有地图出口 | 自由迁行能否执行；支线可补观察但主线也给全线 |
| 静眠间 | 未知／退路已开放／可由昼核自行退出 | 是否可封存人类设施而不继续强制囚禁 |
| 束缚和兵器连接 | 原样／部分停用／全部解除／新主控接管 | 城盾/军械能力与昼核是否仍被当能源 |
| 人类扣押 | 未处理／已解除且撤令送达／改名继续 | 获释者真实去处；不可被释放昼核自动洗白 |
| 资料与私人路线 | 有限知情共享／自愿公开／未经同意暴露 | 同伴信任、接应方式、不可逆的安全屋变化 |
| 终局方案 | 未选／自由迁行／有限共处／封存遗库／夺取控制 | 只执行已有条件的方案，不能临时生成准备 |

经济与旧奖励各有原收据，不进入结局评分。古物护符/铜芯训练、装备流派与是否逛山羊/葬礼等生活插曲，都不判断道德立场。

## 二 六个会改变后面玩法的决定

### 发现是共同成果还是我的战利品

M1可以共享星图、只给一部分或暂不结盟。谨慎并非背叛，后果是同伴先行路线与信息不同；到Q3/M6明确承诺共同署名后再私占，才构成失信。艾妲可以争自己的份额而不必被写成反派；玩家同样可讨价还价。擅用塞维名义会让假交割失败转侧入，不让一句“骗术成功”跳全部危险。

### 更清晰的数据值不值得逼它再痛一次

M4强束取样能取得控制工况和军方接洽利益，也会造成可见应激与拒绝。选择不是“好人不研究、坏人搞科学”；可以通过更慢、可撤回的多次观察取得相关知识，不必放弃好奇。墨伦是否承认未知影响后面谁愿意署名，蕾萨是否协作由玩家对生命边界的行为决定，不凭隐藏好感。

### 保留旧誓还是承认旧誓被用错

Q1/M3里布兰主动承认加固过外围封门/倒钩，只知道当时被称作临时救灾，不能被推成全知设计者。玩家可帮助修正剑式并公开完整记录，停止危险试炼只留证据，或把阵纹交军方。布兰的成长不是必然自杀赎罪，而是选择以后拿盾替谁挡、允许谁离开。

### 真相公开多少由谁决定

M5可公布施令者与远征事实而遮住处，也可由独立见证保管正本；两者均可支持负责结局。完整公开每个地下人的姓名不是默认上位选项。将资料交征掘军能换个人撤榜/研究邀请，但独立证据与安全受损；日后反悔需到F06取回/复制、送达撤令或迁移被暴露接应，不能一句忏悔回档。

### 一个会说人话的未知存在等于同意了吗

昼核可以模仿“留下”，也会模仿“别走”。共处不能据此成立，必须让退路真实开放、停止所有强束与取能，反复看到它自主接近、停留、离开，再保持这一自由。若它退开，玩家可尊重转为自由迁行/封存路线，或重新控制；不把失败交流写成它欠玩家的服从。

### 击败洛德里克以后究竟是谁赢

玩家可以因为不同理由与他战斗：结束强束、争发现份额、救被扣同行、夺回控制权。战后维持同样拘束并换个人签令，是支配结局；不是因为打倒Boss就自动成为自由之友。反之，选择释放昼核但此前伤害证人，仍会在人物与城市回访承担后果。

## 三 四类结局

玩家可见短摘要：**A 让它远行；B 保持可以退出的相遇；C 人类退出遗库；D 夺取控制。** A改变昼核的去处，B选择继续接触但接受不可靠回报，C主动结束人类探索并放弃未解知识；三者的地理执行、知识结果和尾声不同，不只是同一个“放它自由”换名字。

### A 让太阳走自己的路

**已完成的准备**：M3局部松环与地表散热验证通过；M5完整泄压/撤离方案通过；迁行星路核验到已有地图的可说明出口；所有兵器连接可实际切断；人类危险区已撤离。路线可以来自主线古图加现场核验，不强制Q2/Q5。

**终局行动**：回U1切断永久拘束、依已核验顺序打开迁行口，玩家不是骑着它出征，而是让它选择是否离开。它先停在照了十八年的墙旁，随后沿既有洞道投出越来越远的光；延伸到不可玩深部只作尾声，不冒充新可玩地区。若观察显示它暂不愿走，可以保持开放退路，不能重锁并还叫自由。

**所得与代价**：不再用一个生命维持城盾与军械，冷白奇迹消退，高风险工坊关闭或迁移，部分城市防护需重建。玩家失去将昼核当永久武器/研究对象的机会，获得一项不能装进背包的发现。居民可感激、遗憾或怨恨；地下强制令是否真正撤销仍单独显示。

**冒险者尾声**：蕾萨可能继续追踪但不捕获；墨伦的书明确写下它离去之后不知道的部分；布兰决定不再守一座困住生命的门；艾妲与玩家谈的是普通战利品与成果，而非卖掉昼核。不存在必给新增神器补偿的承诺。

### B 不是主人的邻居

**已完成的准备**：A所需安全松环与泄压成立；至少两轮可撤回的自由接触；开放可用退路并亲见昼核离开、返回或拒绝；兵器连接全部切断，取能不再是留它的条件；人类岗位无强迫、可撤回。无需全部史料公开，但不能伪造认可。

**终局行动**：把拘束观测改为开放边界，先退开让昼核自己选择。它若持续退避，本结局不被强推，仅切至已经满足前置的A开放迁行或C封存；若相应准备不足，先沿已开路线补必要动作，不自动生成迁行星路；若在开放条件下自愿接近，建立有限观察期。没有一段神奇长谈让它签“永远为城供能”的契约。

**所得与代价**：保留相遇与研究的可能，不能获得可靠的永久能源或任意使用权；城盾仍失去强制供能，城中有人认为探队放弃了最有价值的东西。观察者须接受有时一无所获，愿留下的人有自己可结束的班次。不是兼得自由、全部产能、全部知识的金色大团圆。

**尾声闭环**：在一次明确的后续回访中，玩家看见昼核曾离开又自行回来或仍保持距离，观察者按期收工，旧索已拆；“可退出”由实际行动证实。长期会发生什么仍未知，不把未知冒称已解决。墨伦终于能写“我们获准看了一会儿”，而非“我们拥有”。

### C 把遗库留在地图之外

**已完成的准备**：M3局部松环与地表散热验证通过，最低泄压与撤离核验通过；U1-08古观测站静眠间已打开自主退路；兵器/取能联系断开；危险区的人实际撤出。无需完整长途迁行路或多轮接触，因此不是失败玩家被迫支配生命的兜底。

**终局行动**：恢复昼核可以自行退入的安静环境，撤掉倒钩；观察它退回后关闭的是人类研究/征掘入口，不堵其深部退路，不施强制沉睡。若它没有退回，不可把强行推入说成“自愿静眠”，必须继续完成A的迁行准备或另选D。

**所得与代价**：停止开采和不断进入它的生活，放弃大部分未读遗库与核心样本；人类定居区要接受部分设施停用。对知识型玩家是真实损失：一些谜永远不由这次远征解答。它不是一切皆好的“保密真结局”，封存也让公共监督更难，玩家需留下可验证边界与独立保管记录，不能独占秘密通行权。

**尾声**：地图上不是一片凭空抹掉的空白，而是注明危险与关闭的人类入口，普通道路保持地理一致；埃林不必终身守门，观察职责结束，布兰可带走的是被纠正的工记。伊洛可能保留未完成处而不画一个自信的假答案。

### D 带回一轮不会拒绝的太阳

**已完成的准备**：玩家知情接管永久拘束与军械连接，明确确认当昼核拒绝时仍强制控制；主控已夺下，最低泄压/撤离步骤仍须完成，不靠虐待跳过安全前置。以前公开过资料或救过人也可进入本结局，不能只有全坏行为才算支配。

**终局行动**：替换洛德里克的控制署名，重新压住昼核并继续取能。玩家可以谋求力量、名望或“绝对稳定”，也可以选择把控制交给自信更温和的人；只要没有被控制者的拒绝权，本质没有改变。力量体现为世界与叙事后果，不默认添加目录外神器或强迫其他结局少拿旧装备。

**所得与代价**：眼前城盾和军械维持，探队有了惊人名声，却延续对昼核的侵害与累积风险。解救过的旧工不自动被重新抓回，若人类扣押已解除，保留这项真实好事；若把新工也锁进工籍，另明确显示双重侵害。复杂后果不是将所有行为统统涂黑。

**冒险者尾声**：蕾萨拒绝替新主控追捕逃离者；墨伦若已成长会公开纠正“它认可我们”的宣传；艾妲可能只取自己合法份额后散伙，布兰拒绝打造新索。个别尚未成长者可能留下，但不会全员感恩。被留下的冷光再次模仿“请准我们下班”，玩家知道这不是自己的胜利口号。

## 四 没准备好时怎么办

开始M7前必须完成最低泄压与至少一处实际接应/安全出口核验；由主线提供，无支线、魅力骰、稀有材料门槛。执行A/B/C前分别列缺项，允许沿已开真实道路补做短必要动作；缺条件不能只按一个按钮生成星路、同意或静眠。相关机关失败可退回稳定工况再试。

若玩家不想负责后续，可以选择“停止继续远征”作为提前离场记录：结清已赚取报酬、保留已发生救援/失信，明确昼核问题未解决；不伪装成第五种完整通关结局。没有把拒绝牺牲自己/没清支线设成隐藏坏结局。

四类结局不是末尾四种颜色：A需要迁行探索，B需要理解并尊重独立回应，C需要静眠退路和放弃未解知识，D需要明确维持强制。准备可重叠，若玩家真的做足多种条件，最终仍有价值选择，这是前面劳动换来的自由而非抹掉劳动。

## 五 三条完整旅程例子

**逐利但有界的寻宝者**：留星图副本、和艾妲谈份额、做Q3/Q6取有价发现；不喜欢公共演说，资料独立保管。见到昼核拒绝后不再采样，完成静眠与撤离，选C。拿到原有装备和声名，不必成为市政英雄，也承认一些宝物不该带走。

**充满好奇的冒险者**：跟墨伦显影、被假认主反证、随蕾萨观察古兽、与伊洛核对星路。完成自由接触和开放退路，可选B；若昼核持续退避就按准备选A，不以“我付出很多”要求它留下。知识不等于占有。

**权力的竞争者**：向征掘军交资料换进入权，先救工匠以获得技术，最后因洛德里克独吞控制而击败他。明确接管强束得到D；获救者保留自由但伙伴反对其夺核，结局不会因救过人就判A，也不把先前救援删掉。
