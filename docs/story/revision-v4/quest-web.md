# 剑与火 远征任务与探索网

剧情v4探险者修订候选。八个主线场景、六条重点冒险支线；城镇假葬礼和停业拍卖退居生活插曲，不再主导阵容与任务比例。每条重点支线都有发现、行动、关系冲突和回访，不把“调查”写成连续读文件。全部是纸面设计，未实现。

## 一 八个主线场景

### M1 影子里的星图

S01→S04。夺回远征遗物匣：玩家可先从高地救信使、观察守军换封，或直接打入；原救车战和奖励前置保留，交涉只争取撤人窗口。艾妲在现场看出封蜡里藏着拉线针，能用刀背压住，但需要玩家先处理观察面的守兵；不是她一出场替玩家赢。

匣中星片只有背光才显路。玩家可自己试摆、根据车上暗色包布推断，或听艾妲提示；无固定职业钥匙。明面是夺宝，近年求援信与阵亡名单冲突，打开第一层秘密。潜入失败转同一战场，信使退向S03，车轴夹纸/军营副本兜底事实。玩家可共享星图、留副本只给同伴一部分或暂不结盟；这改变谁先行探路与之后质问，不自动扣报酬或生成第二件遗物。

### M2 失落探队还在吃晚饭

S07/E01、U1-01/04/05；E02/E05也可合法进入。伊洛不是等救的包裹：玩家初见时，他正沿高架支护标记一条炉卫看不见的观察线，并用自己的测绘证明公告的“死路”是谎话。可采纳他的侧入、以扣押令矛盾拆散看守、或战斗解除武装。安全出口打开后，哪些人先走由本人决定；埃林不代表所有人签字。

埃林用盾面接住一枚飞来的旧机关碎片，带玩家看见深处移动的星光，却不交出全部工记。她允许探险，不允许玩家再把人或未知生命打包“带回”。重要事实由活人、配给和新修工位交叉证明。谈崩仍能看现场，解除看押并保住原路；已离开的人在接应处出现，不回地牢重生。玩家继续可为遗库而非必须接受救济使命，但强行夺资料会损害埃林的协作意愿。

### M3 古门记得错误的一招

R2 H03/H08/H09、U1-06/07。布兰带玩家面对会重演第七远征剑式的石像，第三击与他记忆不同：拘束环加装后，旧阵的安全间隔被删掉。玩家可观察停顿、从可见侧廊打断警戒镜，或正面以掩体/推击破阵；布兰可在限定的一段抵住一侧，不成为永久跟班。若他不在，墙上留下相同的动作磨痕和旧工记。

墨伦需要玩家在安全间隔转动镜面，显出上一支探队开门的动作；显影只重放记录，不自动开现在的门。失败先退回安全侧并取得缺帧信息，换时机再试，不收稀有材料。门后第一次看见昼核避开拔出的兵器。

同时开放H03院内旧散热架的短实操：验证局部松环的地表后果，一人接管、一人亲手中止，确认备用泄放接上。不是另造新地图节点。原H08桥头战、放桥与A05/W03奖励独立保持，U1不能绕进H09/H10。

### M4 它借了你的声音

U1-07/08。接触昼核前，蕾萨从古兽留下的让路弧线看出可观察的退让区，拉住准备直冲光翼的玩家；若她不在，玩家可自己观察焦痕之外完整的苔藓。墨伦以三种短节奏试探，不把一次发光当答应；昼核先模仿人的问候，随后模仿一句“别过来”。

玩家可收起武器继续可撤回观察、保持距离记录、局部松环看反应，或压住它取更强烈的样本。后者得到较清晰的强束工况，却增加应激、失去蕾萨/埃林的该项协作；不附送独占超强装备。局部解环触发炉卫警戒，可提前扰乱巡检避战或正面打断，战斗目标是解除程序威胁，不杀受害者。

失败有可见预警，拉退位回稳定工况、保留观察；不把读错一次信号变成全城毁灭。揭示昼核有拒绝能力，玩家再决定研究、获利、放走或封存。幕末明确共享/有限透露/交军方三种资料路线，触发一次已告知的封存行动；日常休息不推进。

### M5 沉钟下面没有神

B08/E06、U2-03/06/07。沉钟观测站的共振会让墙面出现不同年代的虚影，其中有明显重复和被改写处。玩家可比对真实磨痕、按记录复原短序列、从侧廊避过巡检、或战斗解除警戒；必须同时辨别“记录了什么”与“当时实际发生什么”。E04深闸仍从U2-03内部开启，不以魔法调频穿墙。

三个可玩动作支撑结局：读取真实迁行星路并核验一段；在记录与原型上核验静眠条件，真正退路留在U1-08现场开启；在U2-03完成可中止泄放试验。泄放的最低安全步骤由主线提供，无支线/金币门槛，失败可重试，必须实际完成才可进入最终行动。共处路线另需重复自由接近/退开的观测和R2散热验证，不用一段长讲话判同意。

洛德里克会面提出研究署名、古物份额与撤榜，换独占主控。玩家可问图、谈钱、质问退出权或暂缓。三箱点验仍留B10同货台；码头水槽不是全城泄压，古物训练也不判立场。达成准备后列出哪条方案可执行，玩家确认最后远征。

### M6 竞争者留下的营地

R4 F04/F06/F07与F09/F10。F04新拘束件由被扣工匠制造，F06是征掘令与控制交接，F07藏装置运输痕迹与接应点。可先救人获现场知识、先潜档案取接洽证据、或攻据点夺回装置；至少核实一处基础接应与实际出口，不能只开门便字幕“全救”。

核心角色各在一处可选有限协作：艾妲假谈交割让玩家有观察陷阱的窗口，布兰在工坊破一个固定剑阵，蕾萨看清巡防侧入面，墨伦扰动已研究的警戒镜。每次都有进入/结束条件，不同时把四人做成自动队伍。无该角色仍有环境线索与玩家可执行手段。

撤销强制令要拿到正本、发往指定岗哨并看见撤岗；拒收命令的扣押组仍须解除，不是拿纸自动改变全城。完成何项改变在场人、局部通行和尾声责任，不要求全清才打Boss。两外台仍逐台停用，E08只到F16。

### M7 不再分给你的那一份

F13。洛德里克想独占昼核与发现声名；若玩家曾支持他，争执可以是分配与控制权，而不强制玩家忽然变圣人。若玩家已反对拘束，他会要求其对真实危险负责，却拒绝任何限制自己的控制。

保留原Boss战与内射口规则；新增主控镜作为可见叙事机关候选，未实现也未改变原数值。人物协作只改变已登记的战前接近或一处局部任务，不凭好感删掉原必败条件。战后原绞盘/主箱及时兑现装备，不能让长剧情吞奖励。

### M8 不是每样发现都该带回家

从已发现合法路线回U1执行，允许使用已解锁安全旅行而不强制长空跑，不新增第五张图。四个执行骨架分别是打开已核验迁行口、撤掉强束并开放可拒绝的共处边界、恢复静眠间自主退路并封存人类入口、或接管永久拘束。没有准备的选项明确不可用，先补其短必要动作，不能用尾声帮玩家完成未知机关。

操作后必须看见：昼核怎样行动，原看押是否解除，留下/离开的人有没有真实去处，同伴还愿不愿同行。对一个古代生命的态度和对人的态度分别结算；释放昼核不能自动洗掉出卖证人的事。尾声允许独自拿钱离开，也允许伙伴各走自己的路。

## 二 六条重点冒险支线

### Q1 没有倒下的剑士

**地点与人物**：S12废誓院→U1-06誓团军械长廊；布兰。第一幕可先探，第二幕继续。废院石像每晚向一个空位置敬礼，随后对看不见的敌人出剑；布兰说那是自己曾仰慕的誓卫队长，记录却把这位英雄最后一击停在同伴背后。

**三个场景**：观察剑式缺拍；从院落/侧室/地下长廊分别取得当前阵纹、旧记录与武器磨痕；进入有限试剑场复原那一击。玩家可以破镜让投影停止、诱导石像击中防护石柱读取背面刻纹，或接受一次有明确退路的战斗试炼。失败退出场地保留观察，不重刷奖励，不要求火属性。

**揭示与选择**：队长当年劈断的是同伴背上的强束索，不是背叛；后来的人把那一击从训练中删去。布兰想恢复完整剑式证明旧誓仍可被修正，也可能想封掉整套试炼免新手受害。玩家可保留并标明风险、停止战斗机关只留记录，或把阵纹交征掘军换接洽。资料不是新技能/新装备默认授权。

**后果**：布兰在M6可以按修复后的理解拆一段剑阵，而不是只会顶盾；若玩家交给军方，对方会在指定工坊加设可预见的阵纹，布兰拒绝替其背书，玩家仍可绕入/破阵。封停试炼保安全但失去一次仪式性传承，他会遗憾而不是自动翻脸。回访石像敬礼停止或改向门外，结局反映他是否还称自己誓卫。

### Q2 猎物在追猎人

**地点与人物**：S05猎场→S19伏击地→S17洞口外围；蕾萨。洞门仍须从U1内开，追踪不让玩家从S17强开E03。一只铁角古兽反复把人赶离某条猎径，征掘者悬赏称它吃人。

**三个场景**：勘查掉落武器与完整干粮，辨出攻击是驱离而非捕食；从崖上观察古兽在冷光出现时退开的路线；处理捕兽索与两名准备取角的猎手。蕾萨会先跃过一处可见机关把玩家拉离弩线，再要求玩家别把这当她愿意无条件带路。

**多解**：拆索、以现有响片把猎手引到空场谈判、潜入破坏其信号位，或打败猎手。古兽危险依然真实，玩家可保持距离绕过，也可在它明确冲撞预警后防御脱离；不需要完整驯兽系统、不以稀有饲料喂服。

**选择与代价**：保护它的迁行带会失去一处方便的取材猎位，但得到可重复观察的行为；逼走它能方便短期勘探，却让昼核迁行判断更依赖古图；杀伤它只作若未来实现的独立敌类分支，本轮不强行许诺可杀全生物。猎手败走不等于所有人承认蕾萨正确。

**后果**：M4出现古兽曾示范的安全弧线，帮助理解昼核不是任意攻击；没有本支线仍能看焦痕和苔藓。蕾萨愿提供观察协作，或只保留交易而拒绝替玩家捕捉未知生命。回访有留下的足迹和被解除的索，不把古兽变随从或免费战斗召唤。

### Q3 第四个脚印

**地点与人物**：S14湿林庄园→H11契约楼→U1-01货栈；艾妲。一份旧探队分赃契据列三人，废库的防陷标记却证明当时有第四个人。艾妲不是被发现偷偷绑人的经纪，她是在查自己曾信任的队伍为何把一个人从功劳里删掉。

**三个场景**：庄园中相互咬合的封箱线让玩家选择先断哪一处；契约楼对照进入顺序与借款；货栈见到第四位成员——当年替伤员撤离、主动退出争宝，如今靠修路标过活的塞维。塞维不是秘密大反派，也不想被艾妲再次拖回队伍。

**行动与失败**：艾妲可近身压住一组陷阱，玩家从另一侧解绳；也可观察磨痕从侧门绕开，或战斗解除征掘看守。触发陷阱改变局部接近、可退可重试，关键旧记录另有见证，不一烧永久断线。谈判可以承认原债仍在、只澄清名誉，不能用一张纸抹掉所有私人约定。

**选择**：把发现署为完整旧队、尊重塞维不愿公开姓名但保留其份额证明、或与艾妲共同利用缺名契据扩大自己的控制。艾妲会争取自己的收益，不被默认写成高尚让利；真正弧线是敢谈利益但不伪造他人的同意。

**后果**：M6的假交割可由塞维自愿提供真实印记，或由艾妲承担更高暴露风险；未经同意借他的名，会被当场识破，转为侧入/战斗。最终远征成果的署名与财富去向出现具体差异，但不新增玩家金币预算或唯一装备。旧奖励不是道德押金。

### Q4 会说谎的观测站

**地点与人物**：H13风蚀祠廊→U2-04/06；墨伦。祠廊每次显影都会把最先站进去的人显示为“发现者”，墨伦以为这是古代认主，几乎把自己写进新论文标题。

**三个场景**：第一次看到惊人幻象；换站位、换时间、遮住一块镜面，复做反证；到U2发现原观测者会把资助者图像套在所有记录前面。这不是全部史料无用，而是说明视觉权威也可以被编辑。玩家真的操作站位与镜面，不只是选一句“你错了”。

**危险**：停太久会激活只追逐影像源的巡检像。可留下反射让它追假目标、绕过、或正面战斗；墨伦愿冒险维持一次短显影，玩家负责给他安全退路。若他被迫撤退，残留影纹仍指向下一步，不要求NPC死亡换真相。

**选择**：公开更正连同方法，把失误写成匿名疑点以保当前研究接近，或明知造假仍把自己包装成认主者向军方交易。后者确实能换到局部邀请，但今后不能拿该幻象证明昼核认可玩家。

**后果**：墨伦在M5会主动标注“不知道”，或因玩家逼其撒谎拒绝署名；方法被公开后，可由伊洛/现有记录替代其一次显影提示，不形成必须招募学者的锁。回访观测站可以留下更正标记或继续误导新来者。代价是声望与获取知识的方式，不用惩罚性删掉商货。

### Q5 给地图画一颗不存在的星

**地点与人物**：U1-02/04与U1-09；伊洛、埃林。伊洛的地图多出一颗星，埃林说是镜面裂纹。他坚持沿旧绞盘井的观察位核对，想成为发现者，不再只是布兰的徒弟。

**三个场景**：根据晶点方向选合法观察路；在不同时段的遮光状态看同一片洞顶，避开/处理一处巡检；回到居所把结果画在一张人人能改的图上。E05仍需上方先开机械，伊洛不会从下面替玩家穿墙开梯。

**奇妙的答案**：那颗“星”是昼核光翼被一只古旧铜鸟反射的微光。铜鸟不是囚禁灵魂，只会重复抬翼；但误差标出了原图漏掉的安全观测角。玩家可把它作为自己的发现、与伊洛共同署名，或问他是否愿让地图无署名共享。

**人物冲突**：伊洛排满勘测班表，让别人以为拒绝就是拖累探队；埃林却又想亲自替下所有人。玩家可以逐人确认意愿、缩小勘测范围，或催大家跟上。成功不是必须画全每条线：只画可信的一段同样有用，失败读数标为未知。

**兑现与温暖**：完成后人们把晶点投在洞顶吃一顿晚饭，灯没调好也照样吃，不判任务失败。有人想立刻走，有人想留最后一张画，玩家不替他们决定。M4/M5可多一个观察角但不是唯一线索；尾声伊洛的课堂是能离开老师的地方，或仍需学会不把同伴变助手。生活感发生在探险之后，不取代探险。

### Q6 没有船的航海图

**地点与人物**：B04灯油作坊→B14搁浅船场→B09封签仓院；娜薇与自选一位核心伙伴。娜薇曾替旧航路鉴定古物，手里一张航海图画着不可能进河的船。她判断那不是骗局，而是船上镜组投到岸边的“影船”，请玩家替她核实失落货单，自己只在安全观察面协作，不假称她是第六位永久战斗队友。

**三个场景**：用灯片复原不完整船影；进入真实搁浅船体，按影像找隐蔽甲板而非穿过幻船；在仓院面对买家对古物解释权的争执。可从船腹侧孔潜入、用光影引开巡检、与已知货主谈合法取证，或战斗解除抢占者。水下部分不开放，不新增游泳/氧气系统。

**发现**：一份货单证明当年的远征本来带了归还观测装置的运费，不是天然计划永久占有。这是主线责任的旁证，不独占真相。另有一只只会重复最后句客套话的茶壶和缺鞋舞影灯，给场景以荒诞乐趣，不逐件变新装备。

**选择**：让货单作为公开历史保留、遮去无关私人航路后交独立保管、或交给买家独占叙述。娜薇可以同意卖自己的古物，却反对玩家替她承诺无限供人照护。取货受阻时可保住拓印继续，失去原件的保管权而不是重打整船。

**后果**：M5多一份可核验旁证，娜薇可提供接应时限/鉴定而非无限床位；结局她可终于出游或自愿留一段明确时间，买家与街坊有不同评语。拍卖和学舞作为短回访，不抢走核心冒险篇幅，不创造新金币来源或商店。
