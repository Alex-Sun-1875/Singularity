# 弓箭手技能与专精设计 v3

2026-11-10。建议采用**同一弓术体系、不同主动技能、后续按完整玩法再分专精**。重箭和清群箭可以一起装备，用现有四主动槽决定取舍。重箭数值和命中机制属于设计提案，尚未接入运行版；本轮实际修改仅为箭矢材质。

## 为什么先做技能

单体爆发与多目标清场是同一个弓箭手面对不同敌群时的战术选择。若仅因目标数量就拆职业，打首领与打小怪会变成换职业的问题。当前弓术已经具备穿透、连穿、连射和标记，可以自然补齐重箭，而不需要新建职业成长、重复装备和重复动画。

《博德之门3》的设计可以分三层理解：职业提供基础能力，子职业改变长期玩法，专长与技能提供战斗选项。其猎人子职业内部就有偏单体的巨像屠夫、对付相邻敌人的部落击破，以及后期的群体射击；这些能力没有各拆成一个职业。参见[猎人资料](https://bg3.wiki/wiki/Hunter)。

“神射手：孤注一掷”通过降低攻击检定、提高伤害形成风险收益，适合作为重箭的取舍参考；它本身并不提供本方案的额外暴击，那是本作拟定的差异。参见[神射手资料](https://bg3.wiki/wiki/Sharpshooter:_All_In)。真正适合分子职业的例子是魔射手：整套魔法箭能力改变作战方式，Larian 已在[官方介绍](https://baldursgate3.game/news/community-update-34-connecting-with-cross-play-hotfix-32_141)中把它列为战士子职业。

## 技能职责

| 技能 | 主要用途 | 代价与边界 | 状态 |
| --- | --- | --- | --- |
| 普通射击 | 稳定输出、移动与蓄弓的基础操作 | 按真实弹道接触，不额外加入全局随机未命中 | 已有 |
| 重箭狙击 | 单个精英或首领，高伤、高暴击、高破势 | 只伤一敌；需要瞄准；较长冷却；有可改善的命中风险 | 新提案，候选 BOW_06 |
| 穿云箭 BOW_01 | 穿透排成一列的敌人，破盾破阵 | 释放后锁定直线，后续穿透伤害衰减 | 已有，保留职责 |
| 连穿箭 BOW_02 | 清理聚集或相邻的多个敌人 | 同一敌人每次施放只受击一次；不能把剩余次数集中到首领 | 已有，保留当前连续转向实现 |
| 疾风连射 BOW_03 | 较快释放、多箭持续压制，适合短输出窗口 | 分多次接触，整组输出会受走位、遮挡或中断影响 | 已有 |
| 猎王印 BOW_04 | 指定优先击杀目标，为重箭创造准备收益 | 占一个主动槽；只给自己收益；不无限叠层 | 已有增伤；命中联动待实现 |
| 万箭齐发 BOW_05 | 一次处理多名已选敌人 | 保留终极充能和共享锁，未用完的目标预算不灌给单个敌人 | 已有 |

用户所称的“分裂箭”，在当前源码中已经是**连穿箭**：一支箭首击后依次转向最近的合法敌人，并非同时生成子箭。旧设计中的分裂箭仅保留为历史。重箭提案不要求恢复子箭机制；若以后确实希望“一次同时射向多敌”，可在连穿箭上设计互斥的分裂变体，再比较两者手感。

## 重箭的首轮试调值

以下均为本作候选值，不是《博德之门3》的数值，也不是已经验证的平衡结果。S 沿用当前运行时的基础技能威力。

| 参数 | 建议起点 |
| --- | --- |
| 成长 | 五阶，伤害从 3.0S 增至 4.4S；暂用 Lv4/12/20/28/36 门槛 |
| 目标与距离 | 一支直飞实体箭，只伤第一个敌人，射程 16m 起，最高 20m；遇墙结束 |
| 时序 | 约 0.65 秒瞄准、0.25 秒后摇、8 秒冷却；松弦前可取消，放箭后进入冷却 |
| 暴击 | 当前角色暴击率加 20 个百分点，上限 50%；仅重箭暴击倍率为 2 倍 |
| 破势 | 高于同阶普通射击，首轮从 18 点起调；不强制位移敌人 |
| 基准命中 | 80%；仅用于重箭，不推广到全部普通攻击或其他技能 |

命中可以通过准备改善：站稳瞄准至少 0.45 秒加 10 个百分点，猎王印加 10 个百分点；边移动边释放减 15 个百分点，目标快速横向移动减 10 个百分点，最终限制在 60%—95%。界面在瞄准时显示当前预计命中率和“站稳／标记”提示。动作游戏中应先试玩这个风险强度；若随机空箭的挫败感偏强，可改为更窄的真实弹道和更长前摇，而不把额外命中惩罚默默加到所有箭上。

命中率不能替代弹道：即使抽中命中，也必须真实接触敌人，不能穿墙或自动追踪；抽中失败则表现为擦过或被闪开，显示 MISS，不扣血、不破势、不触发命中装备，也不给命中蓄能。一次重箭只做一次命中与暴击采样，分开的箭身、接触特效不能重复抽取。数值快照、原因反馈和实体路线应保持一致，避免看起来打中了却无缘无故消失。

重箭的核心循环是**拉开距离 → 猎王印 → 站稳瞄准 → 重箭 → 用移动和普通射击渡过冷却**。遇到敌群则换用连穿箭，或先调整敌人排列再用穿云箭。可同时携带两种输出技，玩家不必为了不同敌人重建角色。

## 什么时候再拆专精

先让装备、现有被动与技能搭配形成“神射”和“猎群”两种倾向，允许在安全点调整。单次重箭更高伤或连穿多打一个目标，不足以支撑独立职业。

只有加入完整循环时才值得考虑子职业：例如伏击者具有潜行、首击、脱战再入场；兽伴游侠围绕宠物指令与协同；魔射手拥有独立魔法箭选择及资源循环。它们都需要多项技能、被动与敌人交互一起支撑，不只是换箭色或调整倍率。

## 接入顺序与现有系统复用

先补重箭主动技能，不替换 BOW_01 或 BOW_02，避免破坏既有装备对稳定技能 ID 的联动。候选 BOW_06 加入弓术技能池后仍只装备四主动，等级成长和存档迁移按既有数据流程扩展。新命中、暴击参数应进入技能定义，由纯规则层结算，运行时只呈现结果。

复用现有蓄弓动画、真实投射物、几何碰撞、暴击、标记、MISS 事件和技能面板。新增自定义部分仅为重箭的单目标参数、命中风险和预瞄说明；Cocos 的动画、网格和材质能力已足够，不需要新增战斗框架或第三方依赖。

首轮验收应比较单个首领、两名相邻敌人、四名散开敌人三种场景，分别观察总伤、击杀时间、失手反馈和站稳瞄准的可操作性。通过后再确定系数、等级门槛与是否引入专精。
