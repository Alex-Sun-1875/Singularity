# 命中击退与受击反馈 v1

2026-11-10，运行版本0.3.4。按用户要求，让命中怪物产生可见的受击与击退，适用于当前前两章以及已有敌人模板。

## 原因与改动

之前普通命中主要扣血并变色0.085秒，没有通用击退；敌人数据也沿用了历史的`hitReactionMovesEnemy:false`。现在在权威伤害结算后启动短促冲量，使用现有场景分步滑动、碰撞、地形高度与敌人招式执行器，不引入新的物理或动画库。玩家不会被这套规则反向推走。

| 命中或体型 | 实际位移 |
| --- | --- |
| 普通物理直接命中 | 0.32米 |
| 普通杖弹、火雷直接命中 | 0.24米 |
| 已标定的破盾/重击、重箭、陨击、重型终极、基础蓄力箭 | 0.52米 |
| 重甲、盾兵或机械 | 对应距离×0.48 |
| Boss | 对应距离×0.16 |
| 不可打断招式的蓄势/有效段 | 再×0.25，保持其招式，不改成长失衡 |
| 固定装置、具有实体阻挡的巨兽 | 不平移，保留变色与短促姿态反馈 |

位移在0.16秒内减速完成，普通可受击敌人有最多0.12秒的短受击停顿，不改写已有技能破防、Boss削韧或失衡时长。同一目标0.32秒内只接收一次完整冲量，伤害仍逐次结算。燃烧、持续环境伤害、额外伤害连锁不反复叠加普通击退；真实直击的影刃使用物理命中反馈。MISS、零伤害不会产生击退。

击退沿来击方向发生。范围技能、弧线子箭与雷电连接使用实际来击点计算方向；目标位于来击点中心时沿该次施放方向。敌人脚下的预警与攻击几何随身体同步，已落地的目标区域或场景区域保持原位。

移动逐步经过原有墙、柱、边界检测，额外拒绝超过0.6米的高差，不穿墙或推落台阶。死亡敌人也完成这次短冲量，原有死亡/掉落收据只结算一次。存档保留实际位置，重载和旅行清理未完成的瞬态冲量，不重新施加伤害或奖励。

原有受击帧可用时会播放，缺少对应帧时使用短促的身体压缩与方向倾斜，命中变色延长至0.16秒，致命命中的短消散延至0.30秒。没有把换色宣称为新绘制的动作素材，也没有改变玩家的命中范围、伤害、暴击率或技能解锁条件。

## 验证

- TypeScript检查与现有102项检查通过。
- 受控规则复核：普通0.32米、重击0.52米、Boss0.0512米、巨兽0米，燃烧不击退，墙边与高差停下，连续命中限叠加，致命击退和保存后的实际位置保留，预警几何同步。
- 八件成长装备的来源、唯一获取、成长与独有效果复核通过。
- 桌面键鼠和915×412手机横屏触屏长按完成真实杖弹命中；实际记录扣血、身体位移、姿态变化与变色。随后正常施放技能完成致命命中，再保存、重载核对击杀、经验和掉落没有复制。画面截帧时暂停Cocos引擎作视觉检查，没有改写怪物血量来制造命中结果。

截图与结果见`src/cocos/test-results/enemy-hit-response-v1/`。浏览器通过不代表TapTap真机通过；TapTap设备上的表现仍待平台验收。本次没有新增平台API、资源分包或运行依赖。
