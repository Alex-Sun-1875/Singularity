# 冒险日志与地图 v1

当前页面布局已由用户确认的[v6接入](adventure-journal-v6.md)覆盖：两页左侧返回、地图独立三栏、传送固定底部、任务深色阅读。下文保留v1历史布局与数据契约，不再以地图保留任务树或右上关闭作为现行要求。

2026-11-16。本方案替代上一轮窄幅“章节／主线／支线”三页签菜单；既有章节简介、任务、选择记录、地图与第三章宠物门槛继续复用。

## 同一个冒险工作区

顶层只有“日志／地图”，两种视图共享同一份章节、任务和地点选择。左侧按章节展开整条主线或支线，支持当前、已完成与地点筛选；地点目录列出已到访区域，地点详情显示该地见闻与已解锁符文传送的状态及操作，不另设传送点筛选。右侧日志展示故事、当前目标、行动时间线和实际选择；切到地图时，显示同一区域地图与选中目标卡。右上沿用公共关闭控件退出日志，原地图和任务入口都进入同一工作区。

选择任务只更新阅读内容与地图焦点，不开始寻路、切换追踪或推进剧情。地图任务标记带回所属日志条目和具体目标；同任务、同地点的多条目标也保留各自身份。目标卡的操作匹配选中目标及其真实事件，历史目标不显示指向另一当前目标的前往按钮。只有点击明确的前往或传送操作，才调用已有导航和传送控制器。选择状态仅属于当前界面会话，不进入`GameState`。

## 内容层级与真实进度

| 内容 | 日志组织与地图关联 |
| --- | --- |
| 章节 | 简介、五项主任务进度和独立关底结果；主线阶段与首领胜利分别读取真实记录。 |
| 主线 | 当前阶段的调查、清场、狩猎或多解法；已有结果回看不再调用当前任务导航。 |
| 支线 | 每条故事为一个条目，各行动组成时间线，实际选择保留；隐藏奇遇未发现时不显示条目与地图目标。 |
| 地点 | 只列实际到访的可玩区域，关联该地日志；传送点与可用状态继续读取现有规则。 |
| 已读故事 | 只读取`campaign:seen`对白记录；回看没有进度、奖励或自动导航副作用。 |

第一、二章目前共10项主任务、9条支线。任务地点可以跨地图，深城地图也同时承载两章内容，不能把区域图层直接等同章节。救援、交涉、断警和机关保留多个可知目标，不默认选择分支或给出机关操作顺序。已到访目标可带精确坐标，显式选择未到访目标时只显示区域概略环、问号及区域名称，不创建精确地点标记或揭开迷雾。现场玩家标记保持可见；室内地点沿用所属区域识别，不会通过日志写入迷雾、到访或交互发现记录。可玩章节保留“首胜战利品”和“装备来源”的现有详情入口。

第三章继续显示“敬请期待”，简介只说明故事与任务筹备、宠物计划随本章开放；第四至八章使用通用筹备文案。所有未开放章节的目标和操作均为空，地图视图使用只读预告，不创建规划区域、地图针、任务或奖励。宠物访问继续由`PetAccess`检查发布状态和真实进入凭证。

## 接入契约

`features/journey/common/AdventureJournal.ts`提供只读快照：

- `journalEntries(game)`：章节、主线、已知支线、到访地点与已读故事条目。
- `journalEntry(game,id)`：一个条目的简介、纯文本分节、时间线、地图目标与显式操作。
- `journalAreaPreview(game,areaId)`：兼容猎区等显式地图定位；未到访的已制作区域仅显示通用未探索说明与区域指向，不透露场景介绍、POI、精确坐标或传送操作，也不加入左侧地点目录。
- `defaultJournalEntry(game)`：当前章节的进行中主任务，没有时选择本章。
- `journalMarkers(game,entryId?,area?)`：选择条目的地图目标；未选择时仅提供当前可探索故事目标。目标保留所属`entryId`，使地图可选回日志。

稳定ID为`chapter:1`、`main:border-traces`、`side:<任务ID>`、`area:S01`与`replay:<场景ID>`。`JournalTarget.current`标记当前行动，已完成目标保持完成状态。文本随`AdventureJournalText.ts`维护；操作转发现有`journey-go`、`journey-field-go`、前置目标导航和`map-travel`，模型本身不调用它们，也不保存选择或写入游戏状态。“在地图定位”使用`journal:mode:map`保留当前任务选择，不将目标替换成孤立地点。

## 参考与验证

借鉴《博德之门3》的[日志层级](https://docs.baldursgate3.game/index.php?title=Journal_Structure_Overview)与[日志设计原则](https://docs.baldursgate3.game/index.php?title=Journal_Design_Guidelines)：将任务、目标与实际行动记录分层，以已知、相关的信息说明下一步；本项目继续使用自身世界、数据、暗金组件和手机触控规范。

完整记录见[本轮验收](../../src/cocos/release/adventure-journal-validation.json)。类型检查与正常test档Web构建通过；本轮已有规则套件记录155项通过，只读模型16项及地图嵌入19项focused检查通过。模型与地图focused检查使用真实`GameSession`展示夹具或引擎替身，不能代替Cocos、正常游戏流程与平台验收。

固定v4产物完成844×390、932×430两种DPR3浏览器触控验收：正文滚动，地图世界／区域／现场切换，当前玩家与已知区域标记，任务选择和缩放保留，多目标精确回选，未知区域迷雾，第三章只读，以及公共关闭按钮的清理和防穿透均通过；浏览操作前后存档快照不变，未见浏览器错误。第二章采坑使用独立展示夹具验证第二条救援目标的marker和事件匹配，没有执行该任务或推进剧情。自定点的明确前往按钮只验证现有导航回调，未将回调监测当成真实行走验收。

最终验收直接绑定固定产物的索引、脚本与相关源码哈希，包含当时并发更新的公共界面模块，不声称全项目只有两份文件变更。快照之后仍在进行的其他聊天音频源码工作单独记录，不计作本轮游戏运行验收。TapTap小游戏平台、实际手机安全区及未来第三章正式开放后的宠物自然解锁仍需另行验证。本轮没有打包或发布。
