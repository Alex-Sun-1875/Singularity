# 随机强化与养成面板接入 v2

2026-11-10后续视觉对齐见[原稿／上一轮／当前运行对照](../../source-art/ui/character-panels-bg3-v3/README.md)：复用原稿人物与大剑，校准分栏、字体、技能4＋3目录、装备详情及公共边框。下方保留规则与第一轮接入验证记录。

2026-11-10。用户确认按稀有度决定容量、最多三条随机强化属性。本版已接入 Cocos 主工程，并按已确认的暖金奇幻设计方向重做人物、装备、技能和强化面板。旧版先复用通用面板导致视觉偏离；现已替换材质、立绘、技能插画、字体和面板布局。最终游戏画面仍需用户美术验收。

## 已实现的规则

| 品质 | 强化属性容量 | 默认自身极限 |
| --- | --- | --- |
| 普通／精良 | 1条 | ＋3／＋5 |
| 稀有／史诗 | 2条 | ＋8／＋10 |
| 传奇／神器 | 3条 | ＋12／＋15 |

项目品质名称“传奇”对应用户所说的“传说”。沿用106件装备的逐件上限，A10为＋6、J03为＋4；当前章节阶段上限仍为＋3／＋6。容量按品质判定，强化阶数按装备配置和阶段共同限制。

＋1生成首条，＋3在容量允许时生成第二条，＋6在容量允许时生成第三条；其余阶数等概率增强已有一条。新增属性排除已存在的种类，同类数值累计，不出现第四条。每次成功提供正的数值成长。

词条池按部位、武器类型和装备定位确定，实际接入九种属性：伤害加成、暴击率、暴击伤害、力量、敏捷、智力、体质、生命上限、护甲。抗性和单条重铸没有加入本版。

| 部位 | 合法候选 |
| --- | --- |
| 近战剑类 | 伤害、暴击率、暴击伤害、力量、体质 |
| 弓／法杖 | 伤害、暴击率、暴击伤害、敏捷／智力 |
| 副手 | 伤害、暴击率、生命、护甲 |
| 防具 | 生命、护甲、体质，以及按套装定位选择的主属性 |
| 首饰 | 生命、暴击率、暴击伤害、体质、力量、敏捷、智力 |

当前每阶范围由品质系数和部位投入权重计算：伤害基准1.2～1.6个百分点、暴击率0.5～0.8个百分点、暴击伤害3～5个百分点、护甲0.4～0.7个百分点、生命4～6，之后按权重缩放和取整；四项属性普通至史诗为＋1，传奇／神器为＋1～2。单手武器权重0.8、副手0.2、双手1、防具及首饰0.65。范围和概率直接来自规则层，界面不另外写死。

预览显示实际候选、概率、幅度、费用和上限；确认后显示实际命中属性。设计稿的“伤害3.8%、暴击1.4%、新增力量2”是说明样例；实际存档按种子和历史产生结果，不强制抽中该组合。示例传奇单手剑升＋6费用保持130金币、3废铁。

九类收益已接入角色及战斗结算。体质每点增加4生命，不重复计入生命加成；提升生命上限不会免费回血。暴击率沿用30%全身有效上限，暴击倍率上限250%；装备护甲沿用40%有效上限。达到角色有效上限后，装备本身仍可以积累该属性的原始值，换装会重新汇总；当前没有单件词条数值封顶。

## 存档与旧版兼容

- 强化状态升级为v2。先按旧规则校验v1存档，再保留已投入金币、废铁、培养经验及旧事务凭证，免费生成对应阶数的随机历史；旧固定强化收益随后停用，避免双重叠加。
- 随机历史和扣费事务持久化，重复确认、读档或保存重试不会重新收费或抽取。历史校验核对种子、装备、阶数和数值，拒绝篡改与不完整账本。
- 传承按原规则转移培养经验和手续费，来源清除生效进度，历史仍保留；转回同件装备不会刷新已生成结果。
- 余火锻印的一次性骰面、领取收益和奖励历史保留，独立于本次最多三条的付费强化属性。传奇装备随人物等级成长的基础数值继续生效。
- 人物加点和技能升阶采用预览后统一应用，检查可用点数和状态令牌，离开页面丢弃未应用草稿。

## 界面与资源

原生 Cocos `Node / Sprite / Label / Button / ScrollView` 组织交互，复用已有资源加载、技能装配、颜色反馈和平台存储层，无新增UI依赖。项目已有 FairyGUI 继续保留；本次以原生组件适配现有 Hud 和菜单路由，无需新增另一套运行时。

人物页使用按设计稿整理的完整拉斐尔立绘；外观页仍可查看实时3D角色。装备页使用九槽、物品格与详情三栏；已有物品专属图继续优先使用，缺图时使用同风格的部位插画。技能页及战斗HUD共用30个按技能ID配置的独立插画，四个主动槽、终极和两个被动槽分别装配。强化页使用独立空工坊背景和大剑插画，全部动态数值为原生文字。

材质、细铜框、按钮、静态标志和图标从项目自己的设计稿确定性提取；人物、空工坊、大剑和补充技能图由云端 OpenAI image_gen 生成并单独归档。字体复用本机安装的 Noto Serif SC，按 OFL 1.1 子集化、改名并随包附带许可证；无字体或模型下载。

本轮运行资源源文件共59件、9,847,002字节（约9.39MiB，包含字体及许可；不含.meta），清单见[源资源校验](../../source-art/ui/character-panels-bg3-v2/runtime-asset-manifest.json)。`release/taptap.json`为界面材质与技能图分别增加 `panel-art`、`skill-icons` 分包配置，沿用现有构建时路由生成和 `GameResources` 加载层。此处是源文件与配置检查，未重新测量TapTap完整上传包、首包或可玩前下载量；后续平台构建必须分别登记。官方依据：[Cocos适配](https://developer.taptap.cn/minigameapidoc/dev/engine/Cocos-Laya-Egret/)、[分包规范](https://developer.taptap.cn/minigameapidoc/dev/tutorial/basic/subpackage/)。

原稿、提示词、来源、许可证及生成／美术验收状态见[资源记录](../../source-art/ui/character-panels-bg3-v2/README.md)。手机布局保留至少48逻辑像素触控尺寸与8像素间距，按844×390、932×430检查；概念图中紧凑的视觉按钮与实际触控区分开处理。
