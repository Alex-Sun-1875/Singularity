# 剧情、支线首领与装备来源 v1

2026-11-15。接续[第二章冒险与任务面板](chapter-two-adventure-v1.md)，把剧情与实际战斗穿插起来。正常test／release采用用户确认的规则：主线首领给固定装备，支线与野外首领共享同章随机奖池。任务面板仍只分主线、支线。

## 主线首领固定装备

主线固定装备只由真实击败章节首领结算，和是否先做完主任务无关。普通任务、交谈、调查、和平停机不发这些装备。

| 首领 | 地点 | 首胜固定装备 |
| --- | --- | --- |
| 灰披队长 | S10 | 守夜者之约史诗武器＋石桥誓戒传奇戒指 |
| 守桥铠卫 | H08 | 熔镜护手史诗护手＋断岳之誓传奇武器 |

武器从既有四流派对应款中按击杀时的掉落偏好确定，款式与基础属性固定，后续沿用既有装备骰子、强化与宝石规则。装备落在首领现场，任务面板能查看未结算、地上待拾或已拥有状态；不是在普通任务完成后再领取一套。首通固定装备每组只结算一次，主线首领正常复战只给常规材料和经验，不进行随机装备抽取、不推进随机保底。

主任务的经验与材料继续按实际任务步骤结算，第二章完整主线的53,430固定经验不变。dev已有额外传奇／神器工具覆盖保留于隔离档位，不改变正常模式的规则。

## 支线与野外首领随机装备

支线首领从世界初始化时就存在，接任务、推进对话和交付都不生成或重置首领。自由探索先遇到并击杀，照样获得同一份随机结算；之后接任务直接承认已有真实胜利，无需再杀一次。

| 品质 | 基础概率 | 保底 |
| --- | ---: | --- |
| 神器 | 1% | 无指定神器保底 |
| 传奇 | 3.6% | 连续49次未获传奇及以上，第50次传奇及以上 |
| 史诗 | 10% | 连续9次未获史诗及以上，第10次史诗及以上 |

这是每个有效首领生命的一次品质抽取，不是三次独立抽取。支线和野外首领共用计数，主线固定装备不消耗或重置这些计数。再战沿用10分钟间隔、真实再战入口、死亡轮次与保存凭证，不能通过重载尸体重抽。

史诗和传奇使用同章共享候选，武器按既有掉落偏好筛选；原六条支线的SQ史诗、传奇物品并入对应章节和品质，不再由交任务固定发放。已有首领成长传奇按章节合并。五件神器继续共享，包含四流派成长武器和原有神器护符，不受武器偏好限制。金币、经验仍可因首领不同而不同，共享的是装备规则。

## 三个新增世界首领

| 支线 | 世界首领 | 地点／等级 | 任务中的战斗位置 |
| --- | --- | --- | --- |
| 让工坊重新开门 | 夺料机首 | H05／12级 | 了解工匠需求 → H04调查支架与制动器 → H05击败机首、取回支架 → 选择修复顺序 |
| 炉卫留下的最后一道命令 | 井链号令卫 | U1-09／15级 | 听取疑问 → 检查只读号令 → 到绞盘井击败守卫并取中继证据 → 选择记录处置 |
| 桥前的两条路 | 截路督军 | H07／17级 | 核对近侧道路 → 查看勒索痕迹 → 击败督军取回原件 → 决定居民与货运安排 |

三条均为四步，任务交付的金币、材料和经验保持不变，合计360金币、22废铁、3符纹、2,800经验；首领本身另结算真实战斗收益。取证必须到现场确认，不重复发首领装备。三条可以在第二章途中进行，没有守桥铠卫通关前置。

原“失窃的军械”明确以H17裂岳獠王为战斗目标，替代含糊的整图清场。它本来就在世界中，未接军械支线击杀也按随机首领规则结算。其余既有支线保留各自的调查、战斗和选择，移除任务末步固定装备／神器自选，交付只结算剧情、材料与经验。

新首领复用已有巨像、三刃守卫和盾战首领的模型、动画、预警及招式执行器，使用独立身份、等级、首胜和再战记录。没有制作三套新角色美术或独立新动画。地图容量、既有主线交涉点和NPC安全位置分开核对，新增可选首领不成为旧任务的整图清场前置。

## 实现边界

- 世界安装不读支线收据，新首领不用普通游荡怪刷新字段，统一走真实Boss死亡管线。
- 旧和平停机／交涉只处理其明确的原有对象，不生成Boss击杀、固定装备或随机抽取；主线和新增首领不能被整区操作顺带结算。
- 提前击杀、战斗中保存、地上装备未拾取、再次进入地图和再战均按现有持久化与来源凭证校验。
- 任务面板显示真实首领要求，自动前往把角色带到战斗接近位置，遇敌停下交还操作；不会替玩家击杀。
- 只维护当前规则，不新增旧档迁移、旧奖池兼容或历史装备补发。

独立场景宝物、商店、锻造和逆钟隐藏探索的专属来源保留。本轮调整任务面板中的九条支线、主线保底与Boss装备管线，没有把所有非Boss探索宝物一并移入随机池。
