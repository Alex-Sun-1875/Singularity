# 独立技能靶场 v1

2026-11-12。独立Web试玩：[打开](http://127.0.0.1:7471/?view=2d&player=3d&progression=natural)，输出为 `src/cocos/build/concept-2d-training-range/`；本地服务使用既有 `tools/serve-web.py`，端口7471。当前 Cocos 主工程的独立练习入口，复用现有 GameSession、PureCombat、技能特效、角色与手机触控，不新增依赖或生成美术。

## 使用

- 主菜单第四项「技能靶场」进入；设置 → 旅途、暂停菜单也提供入口。操作帮助保留在设置中。
- 顶部「靶场设置」可打开靶位、距离、资源及统计；C / F8 打开技能选择。手机使用原摇杆、技能按钮、拖动瞄准和取消区。
- 选择流派、技能、1—5级后自动装入对应武器与技能。普通技能下方提供「移至1槽」至「移至4槽」，点击可指定位置；已占用时交换两槽，不重复上栏。切换技能、等级和流派保留本轮各流派的配置。普通技能使用 Q/E/R/T 或 1—4，终极 G；终极保持固定专用槽，被动自动放入被动槽，闪避仍用独立按钮。2026-11-12对调普通槽3与终极的固定HUD位置，图案和触控随对应按钮移动，快捷键含义不变。
- 靶场内使用临时 Lv40 角色，基础三种武器，全部技能开放。属性分配采用固定合法预算，切换等级不改变人物属性。
- 「群怪实战」提供5、10、20只近战、盾兵和远程混编，默认10只。怪物使用普通40级生命、追击、攻击、闪避与防御规则，可被真正击杀；不会在每帧补血。首排间距1.6米、后排间距1.8米，起始距离沿用靶距设置。
- 群怪模式中点击「再来一波」重新生成整群，并恢复角色、资源、冷却与统计。击杀仍触发正常战斗中的击杀效果，但不产生经验或战利品；统计增加存活与击杀数量。静止靶阵和反击演练继续保留。
- 单靶、五靶密集阵、五靶直线阵；起始第一靶距依次为 1.5、4、8、12 米，直线后续靶间隔 2 米。地格间距 2 米，重置回到固定起点。
- 默认靶标不主动攻击。开启「反击演练」后使用原怪物 AI，会追击和攻击，可测试护盾、减伤与闪避；倒下可在靶场菜单重置。
- 「生命减半」用于治疗测试；不触发一次虚构的战斗命中。需要实际受击条件的技能使用反击演练。
- 默认无限职业资源，每帧补满，保留技能真实冷却；可切回正常消耗与恢复。

## 比较与统计

所有命中、伤害、弹道、范围、灼烧、减速、控制和位移都走原有战斗规则。靶标复用现有敌人呈现并标为「训练靶」，保持普通人形目标的碰撞与命中属性；不代表首领、机械目标或所有敌人类型。普通训练靶生命不会降到零；群怪实战中的怪物可死亡，两者均不结算经验或战利品。

统计读取实际 `hit.hpLost`，包含多段、持续和附加伤害；命中次数是伤害事件数，MISS 读取实际未命中事件，暴击读取实际标记。DPS 从首次命中计时，包含停手时间，最少按一秒计算；打开菜单暂停计时。防御和治疗效果另看生命、护盾与原战斗反馈，不计为输出伤害。

变更靶阵、距离、资源模式、反击模式、技能等级或装配，以及「重置本轮」，会清除上轮动作、弹体、异常、增益、冷却与统计，恢复生命和资源，并把靶标与人物放回起始位置。默认静止靶仍接受受击位移，位移后需重置才能继续比较固定距离。

## 存档及平台

靶场区域不加入剧情地图、传送路线或存档区域列表。进入前保存普通旅程，然后切换到独立 GameSession；退出恢复同一个原旅程对象及地图。靶场的自动保存、前后台保存和销毁保存均不写入 SaveStore；刷新/宿主重建后继续原旅程。

入口是 Cocos 游戏内按钮，TapTap 不依赖 URL、DOM/BOM 或网页注入。保留原 localhost `test=max` 技能调试入口，仅供开发对照。没有新增平台 API 或资源下载路径。

场地复用 SceneBuilder 的平地、碰撞与资源销毁；网格合并为一份网格，场景原有容器回收网格和材质。界面复用 Hud、RpgPanel、MenuPanel 与公共反馈颜色。现有引擎和战斗实现已足够，无需引入另一个靶场/战斗库。

依据：[Cocos 3.8 原生图元](https://docs.cocos.com/creator/3.8/api/en/class/Primitive)、[TapTap Cocos 适配说明](https://developer.taptap.cn/minigameapidoc/dev/engine/Cocos-Laya-Egret/)。
