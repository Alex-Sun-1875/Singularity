# 装备与经验生命周期 v3 接入记录

2026-11-11。主工程 `src/cocos/`，保持 Cocos Creator 3.8.8、现有 TapTap 平台适配和存档格式。按[设计](equipment-lifecycle-v3.md)落实前两章；第三至八章为目录准备，没有开放新地区和任务。没有新增依赖、测试框架或生成美术资源。

## 已接入规则

每日重复战斗经验按当天首次开始游玩时的等级锁定：Lv1—5 为1000、Lv6—10 为1500、Lv11—15 为3000、Lv16—20 为6000。手动刷怪、自动战斗、挂机和Boss复战共享；挂机另有1000子额度及100%／75%／50%／25%衰减。任务、固定守军首胜、Boss首通经验不占额度。北京时间00:00重置，升级、模式切换、切图、读档不补满；经验封顶仍可掉装备、获得材料和计数。Lv21—39暂沿用6000，满级不再获取重复经验，后续章节须另行配平。

保留现有升级曲线和40级上限，Lv11累计10600、Lv20累计64030。按已审阅的每日一次性预算和战斗额度执行十次会话，累计65849经验到20级；这是账本核对，不是十天真人游玩测量，也没有强制日历门槛。前两章旅程任务经验分别2380、13200，发放时仍逐任务结算，不额外每天刷新。

任务实际保障2件史诗、2件传奇；另4类战斗目标仅配置在奖池中，不保证掉出、指定部位或收齐。第二章任务传奇在关底前领取。普通装备固定数值，后章装备可以替换；只有明确标注成长的DG物品随等级计算。八章合计56类、122个定义；第三章起每章任务预留2史诗＋2传奇（含一把传奇武器），战斗另配2史诗＋2传奇，目前不会从开放章节掉出未来物品。

全部已开放Boss的首杀与有效复战均使用一次互斥品质抽取：神器1%、传奇3.6%、史诗10%、其余85.4%。神器命中后武器／项链初始权重70%／30%，已持有目标优先换为同档未持有目标；没有神器硬保底。武器按持久化偏好匹配破军／弓术／火术／雷术。连续未出史诗及以上，第10抽保证史诗及以上；连续未出传奇及以上，第50抽保证传奇及以上。高品质同时重置较低档计数，任务奖励不影响计数。保底提高长期实际高品质占比，3.6%和1%是基础抽率。

普通怪沿用20%基础装备触发与原区域6次未触发后的下一次保底，触发后基础品质65%精良／34%稀有／1%史诗；区域低品质池缺项时从本地精良／稀有候选回退。普通怪不直接抽传奇或神器，史诗只取当前章节战斗池。高级重复物品转金币／废铁，不生成重复唯一装备。

Boss死亡后按真实日历等待600秒，由玩家在当地入口主动复战；离线时间计入等待，没有离线积攒多只Boss或自动复活。首通保留剧情数值，复战按当前开放阶段调整至最高Lv10／20、对应一／二章掉落池。每次普通Boss战利品12／16金币＋2铁；两章任务和共同关底首通固定金币合计1350（含原562），首次基础Boss金币已扣回，不重复计入保障预算。额外掉落、精英、探索和复战收入另计。

原三条随机词条、强化和100%经验传承继续复用。前两章阶段上限＋3／＋6。任务传奇武器加4%直接伤害，战斗传奇武器在恢复／失衡窗口加8%，戒指减少2%直接伤害，猎坠击杀恢复3%已损生命（5秒间隔）；两件套使用既有套装通道。新增弓／火杖／雷杖成长神器复用已接入的神器机制和现有批准图标／武器模型，没有将概念图当作新资产接入。

## 兼容与保存

旧CJ物品、培养和已解锁未领取资格保留；第一章旧任务史诗映射新任务史诗额度，已领取或待领取都不能再重复领一份。未解锁的旧40击杀／关底必送史诗不再新增。原8件DG保持身份，补3种神器武器形态；旧8%／0.5%数值仅用于历史来源验证，不参与新Boss抽取。

复用既有掉落、拾取、存档双槽与平台服务。每个Boss只保留当前轮记录，实际物品来源另行归档；轮次、池版本、流派、保底和结果一并保存，读档不能重抽。保留旧挂机已用额度并计入共享额度，不回收旧经验。新来源和畸形元数据／保底记录纳入存档验证。

计时使用现有可注入客户端日历，保护已记录时间回拨；没有接入服务器权威时钟，外部改未来时间或回滚存档仍属于后续服务端工作。未新增或猜测TapTap接口。
