# 施法范围指示器 v1

2026-11-12，用户选定淡金窄雾边最远射程圈与香槟金刻纹落点圈，要求接入当前 Cocos 主工程。已确认的交互参考保存于 [reference.html](../../source-art/ui/skill-aim-indicators-v1/reference.html)。该文件仅供设计参考，不进入小游戏运行包。

## 显示与数值

- 按住键盘技能键或触控技能按钮时显示，手动拖动与现有自动瞄准共用同一套提示。释放、取消、菜单、后台、死亡与切换场景时清理。
- 最大射程读取当前等级的 `castRangeMetres`，圆心跟随角色。淡金雾边以真实半径为透明度峰值，向内、外渐隐；窄雾边以参考图 174∶6 的比例为基准，按镜头限制可见厚度。雾边不是额外射程。
- 圆形落点读取已有技能几何半径：陷阱、弹体冲击圆、落点爆炸圆、连锁接续范围和脉冲选敌范围。选敌／连锁技能的圈表示对应规则的搜寻边界，不表示圈内所有敌人必定受伤。火油沿用现有 4.5 米射程、1.1 米燃烧半径。
- 作用范围采用香槟白主边、向内淡出的金色透明带、六段内线与十二处短刻纹；中心保留小菱形。半径很小时省略无法辨认的刻纹，保留真实边界与渐变。
- 按用户要求只接入圆形提示，不额外绘制直线、扇形、自身范围，也不把矩形／走廊／扇形伤害区伪装成圆形。上述技能原有施法与判定不变。
- 地形阻挡、超距时，落点作用圈沿用公共失败色，并提供断线和叉号；最远射程圈仍保留淡金色。距离、落点限制、碰撞、伤害与消耗全部沿用现有规则。

## 实现与复用

`features/combat/runtime/SkillAimIndicators.ts` 复用 Cocos 3.8.8 内置透明 unlit 材质、顶点色和动态网格，以原生透明度渐变近似设计中的柔化，不使用屏幕模糊、DOM、位图下载或新依赖。角色射程与落点各用一个网格，最多两个 MeshRenderer；缓冲区复用，位置、半径和镜头比例未变化时不重新上传网格。所有顶点采样当前地面／桥面高度，使用深度测试且不写深度；HUD保持现有层级。

颜色集中于 `FeedbackPalette` 的 `aim.*` 语义，并通过 `FeedbackView` 读取。`Effects` 负责瞄准期间的更新、池化和销毁；`ChapterGame.clearInput` 清理输入时同时清理瞄准提示。现有粒子、弹道、人物动作和帧率设置不变。

官方接口依据：[Cocos 动态网格](https://docs.cocos.com/creator/3.8/manual/en/asset/model/scripting-mesh.html)、[Mesh.updateSubMesh](https://docs.cocos.com/creator/3.8/api/en/class/Mesh)。原有项目中的 `ThunderArcField` 已使用相同动态网格更新流程。
