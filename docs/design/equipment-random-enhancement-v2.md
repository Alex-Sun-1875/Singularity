# 装备随机强化方案 v2

2026-11-10。**用户已确认：装备稀有度决定随机强化词条容量，最多三条；属性种类、增强落点与提升幅度可以随机。** 此处的“装备等级”指品质，不是人物等级、穿戴等级或装备数值等级。项目名称“传奇”对应用户所说的“传说”。

本页记录已确认的新设计，替代后续强化设计中的固定伤害／生命收益。现已接入Cocos规则、战斗、存档迁移及人物／装备／技能／强化界面，见[接入记录与验证](equipment-random-enhancement-integration-v2.md)。原始[设计稿](../../source-art/ui/character-panels-bg3-v1/README.md)保留用于视觉对照，最终运行画面等待用户美术验收。

## 品质与培养上限

| 品质 | 随机强化词条最多 | 现有默认强化上限 |
| --- | --- | --- |
| 普通 | 1条 | ＋3 |
| 精良 | 1条 | ＋5 |
| 稀有 | 2条 | ＋8 |
| 史诗 | 2条 | ＋10 |
| 传奇 | 3条 | ＋12 |
| 神器 | 3条 | ＋15 |

强化上限仍允许逐件配置，不能只按品质统一写死。同品质装备可通过自身极限、基础属性、词条倾向和独有效果形成差异。传奇、神器都以三条为上限，神器主要通过更高的数值潜力、更高强化上限和独特效果体现区别。

当前阶段上限继续取装备自身极限与阶段开放上限的较低值；第一、第二章仍为＋3、＋6。人物等级和章节进度可以开放阶段，但不改变由品质确定的词条容量。传奇／神器原有基础数值随人物等级自动成长的规则继续保留。

三条指本方案生成的随机强化属性。基础属性、固定流派词条和传奇独有机制单独列示，不作为可反复随机追加的强化词条。

## 强化时怎样随机

| 到达的强化等级 | 行为 |
| --- | --- |
| ＋1 | 随机生成第一条强化属性及初始数值 |
| ＋3 | 容量至少两条时，随机生成第二条；否则增强已有属性 |
| ＋6 | 容量为三条时，随机生成第三条；否则增强已有属性 |
| 其他等级 | 随机选中一条已有强化属性，再随机增加其数值 |

因此普通／精良只会培养一条，稀有／史诗在＋3形成两条，传奇／神器在＋6形成三条。达到三条后继续强化只提高已有属性，不产生第四条。

新增时从合法词条池排除已经拥有的强化属性；增强时同类数值累计到原行。每次强化确定成功并产生正收益，既有词条保留。初版可让合法候选等概率、已存在的可增强词条等概率；数值只在较窄区间内浮动。实际权重和范围属于后续调参项，提交前必须能查看。

若后续增加单件词条数值上限，候选须排除无法继续成长的词条；全部候选不能成长时应停止扣费。当前实现只限制词条数量和强化阶数，没有单件词条数值封顶。全身暴击率30%、暴击倍率250%、装备护甲40%的有效结算上限继续生效；装备原始词条可以继续累积，换装后重新汇总。

## 按部位和流派配置词条池

| 装备 | 候选示例 |
| --- | --- |
| 剑、斧、锤 | 伤害加成、暴击率、暴击伤害、力量、体质 |
| 弓 | 伤害加成、暴击率、暴击伤害、敏捷 |
| 法杖 | 法术伤害、暴击率、暴击伤害、智力 |
| 防具、盾牌 | 生命上限、护甲、体质、适用抗性 |
| 戒指、项链 | 与定位相符的主属性、暴击、生命或流派加成 |

这是词条池方向，具体装备使用经过配置的子集。抗性、暴击伤害等尚未接入的独立装备属性需在落地时补齐实际结算，不能只做展示。独有机制的触发次数、目标数、掉落机会等不自动进入普通数值池。

不同属性以相近战斗收益折算每阶培养预算，不能把“伤害＋1%”“暴击率＋1个百分点”“力量＋1”视为等价。双手武器与单手加副手按接近的总收益和成本配平；多个装备来源的同类加成汇总后只结算一次。

## 强化示例与界面表达

以传奇单手剑“最后一班岗”为例。以下数值用于UI说明，尚未作为正式平衡参数。

| 强化过程 | 本次随机结果 | 累计结果 |
| --- | --- | --- |
| ＋1 | 新增伤害加成＋1.5% | 伤害＋1.5% |
| ＋2 | 命中伤害，增加1.2个百分点 | 伤害＋2.7% |
| ＋3 | 新增暴击率＋0.8个百分点 | 伤害＋2.7%，暴击率＋0.8个百分点 |
| ＋4 | 命中伤害，增加1.1个百分点 | 伤害＋3.8%，暴击率＋0.8个百分点 |
| ＋5 | 命中暴击率，增加0.6个百分点 | 伤害＋3.8%，暴击率＋1.4个百分点 |
| ＋6 | 新增力量＋2 | 伤害＋3.8%，暴击率＋1.4个百分点，力量＋2 |

＋5预览页展示“传奇品质 · 词条2／3”，第三行写“＋6解锁随机属性”。已存在伤害、暴击率后，此示例的第三条剩余候选是力量、体质、暴击伤害，各1／3；示意数值范围分别为＋1～2、＋1～2、＋4～6%。预览只显示候选、概率、范围和费用，实际结果在确认后揭晓。

按现有第一版费用，传奇单手剑升到＋6消耗130金币、3废铁。示例强化前持有868金币、96废铁，完成后为738金币、93废铁。阶段上限＋6、自身极限＋12保持可见。

完成页显示三条实际属性，高亮“新增：力量＋2”，同时显示已扣费用与阶段状态。已经达到本阶段＋6后，继续强化按钮标明阶段限制。未揭晓前不能把候选结果画成已确定的增长箭头。

面板使用“强化属性”作为分区名，逐条写伤害加成、暴击率、力量等实际属性，不再使用含义不明的“强化威力”。

## 与现有培养记录的衔接

- 当前固定强化收益需要由新规则替代，不能保留旧固定增益后再重复叠加新词条。强化经验、已投入金币与材料应有明确迁移；具体旧档数值转换在接入前单独核对。
- [余火锻印](equipment-dice-v1.md)的一次性领取历史、原始骰面、已得收益及额外升格奖励记录保留。骰印不提供可重复培养的第四条强化词条，来源与强化分别标明；两者如何在新界面合并展示、是否调整新装备的免费锻印，属于后续接入细化，不视为本次已确认的机制变更。
- 传承继续转移培养进度并清除来源对应的生效进度，目标按自身部位、合法词条池与上限结算，不能复制原装备的传奇机制。既有随机结果及生成历史必须持久保存，不能靠来回传承刷新随机结果。
- 确认强化时，随机结果、扣费、进度与事务凭证一并持久化；重复点击、读档或恢复不重新抽取、不重复收费。预览与揭晓共用同一份规则数据。
- 单条重铸可作为后续服务：选中一条、其余保留、新旧二选一，并按同等培养投入换算；价格、锁定和具体转换不在本次确认范围。
