# 第二章冒险节奏与多解法遭遇 v1

2026-11-15后续调整见[剧情、支线首领与装备来源](story-boss-rewards-v1.md)：新增三场支线Boss，三条新支线从三步扩为四步；主线固定装备改为主线Boss真实首胜掉落，支线和野外Boss随机掉落，原支线固定装备／神器自选已移入对应随机池。本文其余探索、选择、任务两分类与经验规则保留。

2026-11-15。针对“第二章后段不停刷怪”的反馈，本轮先调整当前可玩的第二章，再以同一原则约束后续章节。本记录覆盖本轮实现、设计依据和验收边界；八章完整故事仍见[剧情 v8](campaign-v8.md)。

## 问题与目标

原第二章五段主任务是一次观察、一次累计击败9只游荡怪、三次固定清场。三誓阵等地图已有停机交互，但没有完整成为主任务的可选解法。完成任务后不足20级时，默认引导又把玩家送往猎区，导致后段体验集中在重复击杀。

按当前升级曲线，11级到20级需要53,430经验，原五段主任务只给13,200。旧十日模型还依赖每天约450次重复击杀。因此只增加装备、材料或怪物种类不足以解决这次反馈。

本轮目标：完整完成第二章主任务即可准备挑战关底；调查、人物选择、现场操作和战斗交替出现；前面的选择改变后续可用解法；主线不要求累计刷怪。自由狩猎、现有重复战斗日额度、Boss再战与随机掉落继续适用。原“约十天、每天大量重复击杀”的成长目标由本轮冒险体验目标覆盖，不把旧模型作为本轮验收依据。

## 参考的设计原则

《博德之门3》的官方介绍强调探索、实验、环境互动和选择带来的世界反馈。本项目借鉴的是让同一问题容纳多种解决方式、让信息有用途、让人物在后面回应前面的行动。[官方游戏介绍](https://baldursgate3.game/about/)

Larian还专门为通过对话、探索和环境解谜避开战斗增加经验奖励。对本项目的直接启发是：玩家解决了遭遇就应获得任务成长，不能为了补经验再要求击败已经离开或停机的守军。[官方更新：Inspiration, Freedom & Pacifism](https://baldursgate3.game/news/community-update-11-inspiration-freedom-pacifism_17)

当前实现复用Cocos、现有战役事件、对话、地图交互、公共菜单和持久收据。新增内容是本作的矿区、征用令与古代炉卫故事，不引入第三方剧情、角色或美术。现有框架已能承担这些规则，无需增加运行依赖。

## 本轮第二章内容

| 地点 | 新的主要体验 | 可选解法与后果 |
| --- | --- | --- |
| H01 山驿 | 了解战局，确定工位和矿区方向 | 保留简短观察，避免入章即长篇说明 |
| H03 工匠院 | 保卫撤离通道 | 保留本章一次集中的工位防守战 |
| H04 矿区 | 调查故障，处理井下救援 | 先检查制动器，再选择护送证人或保全货签；两条路线都完成救援。证人帮助前哨交涉，货签提供警报线索。实际击败守军只解除威胁，不能自动替玩家作救援决定 |
| H07 石梁前哨 | 根据已有信息选择突破方式 | 带证人交涉；根据货签切断警报后减少守军再战；或直接战斗。主任务只结算一次 |
| U1-06 三誓军械廊 | 读线索、判断顺序、操作机关 | 现场读取三剑线索，分步操作三处控制台；顺序错误有反馈并允许重试。可中途改为完成固定战斗与增援 |
| H08 断岳前堡 | 本章关底 | 仍需实际战胜守桥铠卫，保留20级准备门槛 |

同一遭遇使用独立的解决结果。交涉和停机不会写入虚假的击杀或Boss首胜，也不会触发击杀抽奖；对应守军撤离或停止工作，对应增援停止。战斗路线仍按真实击败结算战斗收益。双方获得同一份主任务经验、金币、材料及任务装备资格，改变解法或读档不能重领主任务奖励。

## 交互与持久化

沿用原“旅程”入口，整理为“任务面板”，只区分主线与支线，原章节目录与装备奖励另保留入口。面板展示真实当前阶段、完成条件、地点、奖励、已完成及尚未开放状态；隐藏支线只在发现后透露内容。第二章支线明确显示11级章节通行要求，未达到时保留详情并显示原因。

任务详情展示当前遭遇的解法、已知线索、前置条件和已选结果，可从“自动前往”导航到实际现场事件。日常HUD沿用现有紧凑引导；玩家主动打开详情时再查看完整内容。角色必须到现场执行行动，查看面板和导航本身不能完成遭遇。自动任务或自动前往到达新的决策点后停止，交还明确确认；玩家自己选择救援分支、交涉或机关输入。

各阶段、分支、机关顺序和解决结果随现有主存档保存。读取中途存档能继续操作，错误顺序可重新尝试，解决后离开再返回也不能再生成对应固定守军或增援。新规则只维护当前格式，不新增旧版迁移、补发或重算逻辑。

## 第二章支线

本轮新增三条普通支线，进入第二章后即可按各自线索进行，中途可做，不要求击败第二章Boss。未完成的支线在通关后仍可继续；任务面板把它们与原有支线统一呈现。默认主线指引保留当前主任务与关底目标，主线与关底完成后可推荐尚未完成的支线，全部完成后结束引导；玩家主动选狩猎时仍按其选择前往猎区。

| 支线 | 三段现场路线 | 最后决定 |
| --- | --- | --- |
| 让工坊重新开门 | H01工匠伊妲 → H04调查支护与工具箱 → H01回访 | 优先修公共工具台，或优先修采坑退路 |
| 炉卫留下的最后一道命令 | U1-07接触留守者 → U1-08检查残留记录 → U1-07核对 | 封存供能核心，或保留隔离的只读记录 |
| 桥前的两条路 | H07接触哨兵 → H07检查近侧道路 → H07处置 | 优先修居民撤离坡道，或安排限载货运接近线 |

每条均有明确的现场信息与两个说明已知后果的选择，前两步只记录调查，末步结算一次。两分支获得相同报酬；合计360金币、22废铁、3符纹、2,800经验。桥前支线只处理前哨近侧道路，不打开或绕过守桥铠卫所在的大桥。矿区证人／货签、前哨交涉／战斗、三誓停机／战斗会在相应支线详情中得到不同回应；尚未解决对应主线遭遇时使用当前可核对的信息，不因主线解法或完成顺序永久失去支线。

NPC和事件随第二章开放，过时步骤隐藏，完成后仍能回访已选结果。当前后果通过处置记录和人物回应表达；没有新增完整城镇经营、动态建筑、水位或生产模拟。这些是有限的作者内容，不作为重复日常，也不代表第三章已经开放。

## 后续章节的内容约束（规划，尚未接入）

后续章节应围绕一个新的处境组织内容，避免把本轮三种任务机械复制到每张地图。每个主要遭遇先写清人物诉求、可观察信息、两种以上行动和可见后果，再配置敌人、经验和材料。

- 第三章“沉钟回响”：以声音、旧影像和当前证词之间的矛盾组织调查，给玩家验证真假和安排接应的空间。
- 第四章“沉没王座”：围绕通路与水位变化组织探索，开路、保存证据、援助人物产生不同局部结果。
- 第五、六章：把战争压力落在救援、拆除、潜入和阵地选择上，部分准备行动改变决战条件。
- 第七、八章：回收前面的人物与证据，让关键选择影响最终方案和战场，不以大量同质清场拖长终局。

以上为制作原则，不代表新增潜行系统、队友AI、完整声学模拟、水体模拟或后六章已经完成。人物关系优先通过具体事件和回访表达，暂不增加需要日常刷满的好感度条。
