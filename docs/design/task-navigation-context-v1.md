## 操作流程

| 玩家所处状态 | 任务区 | 场景操作 |
| --- | --- | --- |
| 正常探索 | 当前任务、方向和距离；下方“自动寻路” | 不显示独立交互图标或空操作按钮 |
| 已开启寻路 | 显示“停止寻路”，继续沿实际道路跨图行走 | 行进中收起情境操作，避免误点沿途物件 |
| 遇敌、打开菜单或手动接管 | 保存当前目标，显示“继续寻路” | 先由玩家处理战斗或菜单，不擅自恢复移动 |
| 抵达任务目标 | 显示“已抵达目标” | 在目标旁显示“调查／交谈／开启／进入”等文字按钮 |
| 操作完成 | 更新下一阶段，可再次开启寻路 | 关闭已不适用的情境操作；清场与狩猎继续自动结算 |

任务栏保留点击进入本章详情的入口。“自动寻路”直接位于任务栏下方；原通用自动操作入口收为同一行的“更多”，保留已有自动战斗、挂机和场景目标选择。两枚按钮保持至少48逻辑像素触控高度和8逻辑像素间距，不额外抬高战斗控件。

每个当前可进行的任务详情都提供“开启自动寻路／继续寻路”。任务选择使用实际任务ID，查看第二章任务时不会误走向第一章当前任务。未完成前置的阶段只展示详情；等级或道路未开放时不启动移动。重载后不自动恢复寻路。

## 寻路边界

寻路复用已有 Navigation、Automation 和真实出口，继续遵守道路、碰撞、等级和章节制作范围。手动移动会接管，进入敌人可见威胁范围时暂停，保留任务目标供玩家点击继续。主动点击“停止寻路”会清除待继续的路线。

寻路负责走到目标和跨图，不代替战斗、对话选择或现场操作。调查任务到达后仍需点场景目标旁的“调查”；固定守军和狩猎达成后使用原有自动结算。任务完成会更新追踪目标，不在未确认的情况下自动启动下一段移动。

## 情境操作

操作采用跟随世界目标位置的文字按钮，显示目标名称和具体动作。NPC显示交谈或交易，任务线索显示调查，宝箱显示开启，检查点显示休整，出口显示进入目的地。长名称在按钮内收敛，完整任务说明仍可在详情查看。

只选择一个近距离、可见且位于同一可行走层的目标。当前调查目标优先，其次人物与现场物件；无需交付的清场／狩猎任务不再弹交任务按钮。操作距离沿用规则层的实际交互半径，离开范围立即收起，隐藏后不拦截触摸。

弹出位置跟随目标上方，避开已有HUD，不能把离屏目标的操作钉在屏幕角落。导航中、菜单、演出、对话、骰盘、倒下、施放和近身危险期间收起。出口的原名称牌只保留说明，情境操作出现时隐藏重复名牌。

按钮按下时绑定目标ID，松手时重新核对当前目标与规则；按住期间目标变化不会触发另一个人物或物件。出口等级不足时显示原因并禁用。实际交互、旅行和奖励仍由 GameSession 验证，界面不直接改动剧情或发奖。
