# 装备网格四行修订 v2

2026-11-11。沿用已确认的浮层弹窗、圆角双层金属框和缩小后的字号。

- 按用户要求移除四个主面板共用外壳的右上角 ×。保留底部“返回旅途”、点击窗外与 Esc 关闭。
- 中间装备网格采用四列、四个完整可见行。图标从 54×48 缩至 46×42 个参考布局单位；四行按实际视口高度分配，手机点击区域保留至少约 48×48 个逻辑像素。
- 品质/部位提示略向上移，列表可用高度从 220 增至 226 个参考单位。四列居中对齐，最后一行留在列表裁切范围内。
- 16 格以内不再显示列表滚动条，也不能拖出空白；超过 16 件时使用相同网格继续纵向滚动。小屏辅助兼容仍优先保留触控尺寸，不用缩小点击区域强塞四行。
- 装备标记、强化数值和分类名称采用单行适配。正文说明继续使用原有滚动区域，物品与属性内容不变。

验证复用 TypeScript 检查、隔离 Web 构建和实际画布操作；分别检查初始三件装备、16 件完整四行、17 件原生滚动及空分类。样例装备在独立浏览器上下文中注入，并在注入前禁用保存。覆盖默认横屏、刘海安全区、Pro、Plus、Max、1280×720 与 1920×1080 桌面；额外检查第四行点击、四个页签、底部返回和窗外/Esc 关闭。
