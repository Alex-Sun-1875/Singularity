# 脱战与随处换装 v1

2026-11-12，已接入 Cocos 主工程；TapTap 真机体验待验收。

## 换装与休整点

脱战后在任何可行走位置更换已拥有、满足等级与槽位要求的装备，包括跨类型武器和配套职业。普通穿戴与职业切换共用脱战条件，不要求返回检查点。换装保留生命、技能冷却、终极蓄能与终极共享锁，双手占副手和左右戒指规则继续有效。

检查点就是旅途中的休整／死亡返回位置。现有实现会记录返回坐标，主动休整补满生命、生命药、火油与旧专注药携带量；它不负责解锁换装，也不是普通进度保存的唯一位置。保留它是为了失败后的重试距离和途中补给。属性／技能点重配与锻造沿用现有现场限制，本次不扩大到这些系统；洛恩工坊仍可锻造。

原来的间接限制是：跨类型武器在界面先引导职业选择，而职业选择复用了检查点整备校验。现在职业切换改用换装校验，人物页和职业页的提示同步使用真实状态。

## 状态与时间

| 状态 | 判定与行为 |
|---|---|
| 探索／已脱战 | 无当前威胁，也无待完成的安全倒计时；动作结束后可以换装 |
| 战斗 | 被发现并在有效警戒／追击范围内、被追赶或正在遭受攻击；造成伤害、受击及护盾承伤也记录参战 |
| 清群后的脱战等待 | 本轮记录的参战敌人全部倒下，威胁消失后连续安全 **1秒** |
| 撤离后的脱战等待 | 仍有参战敌人存活，或离开了交战地图；追击与威胁结束后连续安全 **5秒** |
| 再次交战 | 新威胁或伤害立即取消安全计时，处理完威胁后重新开始 |

1秒和5秒是首轮体验参数，统一维护在 `core/GameSession.ts` 导出的 `DISENGAGEMENT_SECONDS` 常量。连续时间使用模拟时钟；暂停菜单、交谈、骰盘、后台和离线不推进。存档保存参战对象和已累计安全时间，恢复后继续，跨地图不会直接清除战斗锁。死亡重试明确结束上一轮战斗。

“清群”仅看本轮参与的敌人，不要求清空整张地图。远处未参战的怪物、死亡残留、孤立的过期攻击状态不延长等待。首领同样需要真正结束追击或被击败；闪避一次、进入后摇、拉开近战攻击距离都不代表脱战。

## 威胁边界

- 警戒和追击距离复用已有敌人配置及受伤仇恨距离；正在出招时也检查该招的有效距离。保持视线或实际追击的敌人持续锁定换装；墙后未发现玩家、没有追击的静止敌人不只因距离近而锁定。
- 仍可能到达玩家的敌方弹体、贴身敌方弹体、玩家身上的燃烧、脚下火焰和当前危险区域会阻止脱战；远处与玩家轨迹无关的敌方弹体不会锁住整张地图。
- 还有存活敌人时，未结束的己方弹体、伤害技能和施加给敌人的燃烧必须结算完；不能先发射再换装。普通增益、护盾和冷却本身不构成战斗。
- 安全空场景中的未完成自身动作和己方弹体沿用背包清理逻辑，避免菜单暂停后永远等不到动作结束；不借此删除真实威胁或跳过安全计时。

复用现有 AI、弹体、伤害结算、模拟时钟和存档校验实现；这是项目自己的玩法规则，无需增加引擎插件或第三方依赖。

## 玩家反馈与验证

威胁解除和脱战完成时复用现有轻提示，不新增常驻HUD。装备／职业页显示战斗阻止原因或剩余秒数；菜单暂停时提示“返回旅途继续”，已脱战则显示可换装。人物页不再用“请到检查点整备”概括穿戴状态。

复用现有规则检查并补充必要边界：远离检查点切职业与资源保留；清当前怪群但保留远处怪物；撤离5秒、重新追击、暂停查询、跨地图和存档恢复；无关远程攻击状态／弹体与真实来袭弹体／持续伤害。未把规则检查或Web构建视为TapTap平台与真机验收。
