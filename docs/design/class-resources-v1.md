# 职业资源、药水与属性成长 v1

2026-11-12。按用户确认接入 Cocos 主工程：战士使用体力，弓箭手使用专注，火／雷法师共用法力；取消独立终极蓄能。本文取代旧资料中“普通技免费、终极100蓄能”的资源规则，战术冷却继续沿用；技能目录已按[全部技能恢复与七按钮布局](restored-skill-library-v1.md)扩展，恢复技能的资源消耗见该文。

同日后续确认：[命中与闪避](accuracy-evasion-v1.md)已接入；弓术专注上限每增加2点提供0.5命中值，当前专注消耗不降低命中率；敏捷每点同时提供0.2闪避值。

## 消耗与恢复

普攻、走路、弓普攻按住蓄力和独立闪避不耗职业资源。瞬发技能在实际成功出手时一次扣除；预瞄、取消或出手前打断免费，实际释放后落空不返还。接收输入和释放时都检查余额，资源不足不会启动技能冷却。技能升级不增加本轮资源消耗，避免加点后反而更难使用。

基础上限100；战斗中每秒恢复8，脱战后每秒恢复20，移动与受伤不会中断恢复。普攻命中和普通技能命中不再产生大招能量。护盾、陷阱、持续区域和装备次级伤害不额外扣费。后台、暂停、对话和离线不推进战斗时间，不补算资源；回到安全检查点主动休整和死亡重试补满资源。

主要输出保持无冷却，战术与防守冷却、闪避2.5秒和终极1.5秒释放间隔保留。原本“额外＋2蓄能”的装备改为满足同一条件时回复2点当前职业资源，每次施放所有这类返还合计最多2点，不能递归触发。资源参数集中在 `ClassResource.ts`，技能费用与生成规则源在 `tools/design/class-resources-v1.json`；导出时保留冻结的旧技能定义和原阶级快照，避免破坏旧档校验。

首轮目标：满资源能完成三个常规技能加一个终极，长时间最快连发才会需要穿插普攻或补给。此为可运行的初始平衡，不能当作最终实战结论。

## 药水

| 药水 | 携带上限 | 恢复 | 表现 |
| --- | --- | --- | --- |
| 生命药水 | 3 | 最大生命40%，至少40点 | 沿用红色生命药 |
| 体力药水 | 2 | 当前体力上限45% | 琥珀色瓶，闪电符号 |
| 专注药水 | 2 | 当前专注上限45% | 绿色瓶，沿用专注符号 |
| 法力药水 | 2 | 当前法力上限45% | 蓝色瓶，水滴符号 |

三种资源药水独立计数，只能用于对应职业；不会临时增加攻击、暴击或资源上限。全部药水共用5秒冷却，与火油冷却分开。状态已满、库存不足、职业不匹配或当前无法饮用时不扣库存、不启动新冷却；恢复超出上限的部分截断。

初始、检查点休整及重试补足上述携带量。沿用既有补给掉落与拾取：资源补给概率不额外增加，在原专注补给份额中确定性分配三种资源药水。新版掉落记录标记 `supplyVersion:2`，历史地面专注药仍按原版本校验并保留原物品，不重新抽奖。满库存不拾取、可部分拾取、掉落保存和过期规则继续复用。

HUD只显示生命药、当前职业药水和火油三个入口；换职业只切换中间入口的图标、名称和库存，不把所有药水铺开。键盘5用红药、6用当前职业药水、K投掷火油。自动战斗优先按原条件补血，在可见战斗目标前、生命高于45%且资源低于20%时使用对应资源药；资源不足时仍继续普攻和闪避，不为等药中止战斗。

## 属性、切换与存档

力量每高于10一点增加2点体力上限，敏捷对应专注，智力对应法力；体质继续增加生命。计算包含已接入的装备属性，不另加“耐力／精神”等属性。只增加储备，不同时按百分比增加自然恢复速度，以免主属性把消耗完全抵消；药水按上限比例恢复，因此上限成长也会提高药水收益。

切换职业、装备、加点或重配时保留当前资源比例；火法和雷法共用同一份法力，不能靠轮流切换回满。新增加点预览展示当前职业上限的前后变化；人物面板、技能详情和HUD显示相同规则。

内部沿用 `player.focus/maxFocus` 存储当前职业的可恢复资源，不再将它解释成所有职业的专注；新增 `resourceVersion:1` 与体力／法力药水库存。`combat.charge` 仅为旧格式兼容保留为0，不参与战斗或界面。

旧档先按旧上限100、旧库存与完整游戏记录校验，再在副本上迁移，保留生命、资源比例、经验、装备、剧情、原专注药水和地面物品，新增体力／法力药水初始各2瓶；旧蓄能不兑换其他奖励。重复读档不会再次发药或回满资源。新档上限必须精确匹配属性与装备计算，拒绝伪造上限、库存和未知版本。

两项类型检查和现有120项测试通过；仅调整受新规则影响的原测试断言及旧格式样本，不新增测试依赖或正式测试用例。

临时实际规则审计覆盖四系16个职业技能的出手费用、完整轮转、空资源普攻与闪避、出手前取消、释放时重新检查、四系加点与重配、药水冷却及满状态拒用。满资源整套释放后分别剩余约40.5／41.7／27.3／40.9；最低基础上限的战士最快连续释放断空斩47次、约23.5秒后才首次不足6点。此为固定目标、持续最快输入的受控数据，不等于自然战斗或挂机时长。
