# 战斗节奏与技巧 v1

2026-11-16 后续修正：按用户补充，全部敌人（普通怪、精英与Boss）均移除技能地面范围轮廓、方向箭头、远程预瞄线与持续区域边界；保留蓄势动作、刀光、火焰、弹体、受击与音效，战斗判定及技巧收益不变。下方首版红黄范围说明及其验收截图属于移除前记录，不再代表当前地面提示。

本轮针对普通 test 的秒怪、预警不可读与反击缺少反馈进行实装，复用现有 Cocos 招式执行器、碰撞、动画、音效和公共反馈组件。没有新增付费门槛，不改主线固定装备与支线随机掉落规则。

## 耐久与成长

- 内容等级、怪物身份决定生命，绝不读取玩家等级、装备或充值状态动态补血。
- 有 Boss 身份的目标使用固定耐久系数 5；第二章主线 Boss 的异常基础生命从 150 修正为 450。第一章主线实际 4068 HP，第二章 7605 HP。
- 普通猎群保留易清理的杂兵，前期生命系数 1.25，之后 0.8，猎群精英另用 2.5。战役增援按每只怪物的正常生命和角色权重分配，不再把原两只怪物的血量拆给五只或八只；原两名奖励来源、经验预算与额外杂兵不发装备的规则保留。
- 三支线 Boss 当前生命：夺料机首 Lv12 为 5080，井链号令卫 Lv15 为 4884，截路督军 Lv17 为 5832。等级不同导致其与借用外观的原精英生命不同。
- 按用户要求不做旧版存档兼容或怪物生命迁移；新旅程及新生成遭遇使用新数值，旧测试档中已经保存的活体数据不作为新平衡验证依据。

## 玩家操作

| 操作 | 实际规则 |
| --- | --- |
| 精准闪避 | 原 0.06–0.20 秒直接攻击无敌窗保留；实际攻击接触被此窗口避开后才触发，每次闪避动作至多一次。地面持续伤害仍须走出。 |
| 闪后反击 | 恢复 6 点职业资源，2.5 秒内首次直接攻击接触获得 20% 伤害加成；同一攻击动作的多段、多目标共用，最长保留 4 秒，不叠层、不延续到另一动作。燃烧和附加伤害不消耗或享受此奖励。 |
| 普攻连段 | 三段伤害系数 0.85／0.95／1.20，总伤害预算与原三次普攻相同，第三段额外削韧 15。无盾普通怪可被打断 0.5 秒，盾目标可破盾最多 0.8 秒；同目标破阵间隔 5 秒。 |
| 破阵与失衡 | 普通怪黄色蓄力可被破阵打断；首领须累计 100 削韧且处于可打断状态才失衡 0.8 秒，之后有 8 秒保护。红色承诺招式不会被普通连打取消。 |
| 绕盾与抓空当 | 正面物理盾保留原减伤，火雷直击正面也至少受 30% 盾减伤；侧面、破盾和收招时可以充分输出。主线两 Boss 和新三 Boss 收招受伤提高 25%，失衡时提高 35%。 |

普攻命中的短暂反冲有保护间隔；已锁向的攻击与正在释放的攻击不会被普攻反冲持续拖延，技能的真实破阵判定仍独立执行。

## 打击反馈与预警

预警读取实际结算几何，以黄色／红色边界、最终锁向方向钩和真实环波缺口表达，不铺满地实心色块。最多显示 4 名近敌、12 个招式几何以及附近 3 个地面区域，保留人物、弹道与退路。

命中有短暂接触特效、重甲反馈和分级音效；原生敌人补充受击短闪，重击和第三段反馈更明确。精准闪避、打断、破防、失衡、反击均从真实事件显示贴身短词，最多同时 4 条；生命扣除与护盾吸收分开表达。没有增加常驻 HUD 面板，没有暂停模拟或输入，也没有降低帧率。减少动态设置关闭短闪、形变与镜头震动，预警仍保留。
