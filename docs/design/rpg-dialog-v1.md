# 人物与装备浮层弹窗 v1

2026-11-11。按用户要求，将人物、装备、技能和锻造的公共外壳改为浮层弹窗，保留原有内容、图片、页签和业务操作。后续去除右上角 ×、完整四行装备网格的调整见[网格修订 v2](rpg-dialog-grid-v2.md)。

## 呈现与交互

- 默认 844×390 横屏下，窗口约 740×342，居中后左右各留约 52、上下各留 24 个逻辑像素。桌面窗口宽度上限为 1120 个逻辑像素；刘海安全区内适当收窄外边距。
- 四周为半透明暗遮罩，仍能辨认场景。打开期间沿用既有菜单暂停逻辑，场景输入不会穿透。
- 最新版按用户要求去掉右上角 ×，使用底部返回按钮、点击窗外与 Esc 关闭。手机页签、穿戴和返回等主要操作保留原有触控尺寸。
- 复用左侧任务卡正在使用的 `DoubleGoldFrame` 和 `UiSkin.panel`，采用同一双层金属边框资源及皮肤比例，不另建一套框。内侧细卷叶纹复用 `UiChrome.frame`；内部内容采用圆角裁切，避免图片和旧装饰越过金属边缘。
- 根据用户后续反馈，文字整体缩小约 8%，手机辅助文字下限为 11 个逻辑像素。长装备名称、等级说明和技能等级保持单行适配，说明文字继续由原有滚动区域承载。文字调整不缩小点击区域。

## 验证与边界

复用 TypeScript 检查和本地 Web 构建。运行检查覆盖默认横屏、刘海安全区、Pro、Plus、Max、1280×720 和 1920×1080 桌面；使用真实画布触摸或鼠标操作验证穿戴、四个页签、窗内空白、关闭按钮、窗外关闭和 Esc。长名称样例在隔离上下文中验证，添加样例前禁用保存，不改写玩家的旅程。

原工作目录的 Cocos 直接构建遇到写入 `settings/v2/packages/engine.json` 的 UNKNOWN 错误。本轮从相同源文件的独立临时工程完成构建，再将完整产物复制回本地预览目录；不修改编译后的业务代码，也不更改引擎配置内容。该工作目录的直接构建问题单独保留记录。
