# 第一版金币锻造与装备强化接入

2026-11-10。Cocos主工程已接入[已确认方案](equipment-forging-and-gold-v1.md)的第一版：逐件强化上限、前两章阶段限制、锻造工费、强化、传承和旧档迁移。精炼、宝石及其他商人的新服务仍按后续阶段安排。

## 使用入口

在行囊选择装备，点击「养成」查看强化收益与费用；在安全检查点或已发现的洛恩工坊现场，可以确认强化与传承。洛恩交易页也提供「锻造与强化」入口。工坊资格按实际距离、视线和危险状态检查，站在工坊附近重载后可继续整备，离开后不能远程提交。

「锻造配方」列出已学图纸，先查看成品和材料，再确认锻造。当前没有图纸时显示获取说明。第一件锻造装备免金币工费，材料照常消耗；旧档已经锻造过装备的，不重新发教学优惠。图纸不会因锻造消失，已拥有的唯一成品不能重复制作。

## 上限与收益

当前106件装备均有有效的独立强化上限。普通／精良／稀有／史诗／传奇／神器默认分别为＋3／5／8／10／12／15；第一版的独立例外为银弦手套A10＋6、探险家的印戒J03＋4，同为稀有的洛恩旧盾W15仍为＋8。

第一章阶段开放＋3，第二章阶段开放＋6；实际可强化到装备上限与阶段上限中的较低值。第二章沿用现有角色成长阶段，Lv11开放或实际进入第二章后永久记录，返回第一章不降阶。后六章尚未开放，当前不会提前开放＋7至＋15。

| 部位 | 每阶收益 |
| --- | --- |
| 双手主武器 | 普攻与兼容技能威力＋2% |
| 单手主武器 | 普攻与兼容技能威力＋1.6% |
| 副手 | 普攻与兼容技能威力＋0.4% |
| 防具 | 最大生命＋3 |
| 首饰 | 最大生命＋2 |

这些强化收益与免费骰印分别结算。传奇、神器原有随人物等级自动成长继续免费生效；强化不改变品质、穿戴条件或独特触发机制。生命上限增加不直接补血，转出已装备物的经验后，生命与护盾按新的上限约束。暂存经验在下一阶段开放时立即重算属性。

## 第一版费用

稀有双手主武器的＋1至＋6金币基准为15／25／40／60／90／130，累计360。品质费用倍率为普通80%、精良90%、稀有100%、史诗110%、传奇125%、神器150%；部位倍率为双手100%、单手80%、副手20%、防具及首饰65%。金币使用整数比例计算后向上取整，避免浮点误差多收1币。

例如普通单手佣兵长剑W01的前三阶分别为10／16／26金币，累计52。相同品质、相同阶数的单手与副手材料合计等于双手，金币合计最多相差取整的1币；因此部分低阶副手强化不收废铁。升级前显示本次实际扣款。

锻造基础工费为武器30、其他部位20金币，再按品质倍率取整；首件教学免工费。原有配方材料不变。传承费为转出经验的4%向上取整，最低5金币。

## 强化经验与保存

强化记录独立的经验进度，目标曲线决定当前强化等级；同部位传承可跨武器流派，目标已有经验时合并。转出后来源经验清零，原装备、原生效果与骰印记录保留；目标上限较低时，超额经验仍保存并可再次转出。部分经验已经覆盖下一阶时，只收补齐该阶所需的金币及比例材料。

第一版沿用现有主存档版本3，新增版本1的强化记录。缺少该字段的合法旧档迁移为空进度，保留金币、库存、来源、商货及其他进度。已有强化请求收据却删除强化字段、伪造经验、重复或改写事务的快照会被拒绝。

每次确认附带当前报价状态，重复按钮事件不会再次扣款。金币、材料、经验与唯一请求收据作为完整快照，继续交给现有双槽SaveStore与PlatformServices保存；失败时重试当前完整结果。未添加浏览器专用存档路径、平台接口或第三方依赖。

强化事务首轮最多2048笔，达到后拒绝新事务并保留原进度，避免账本持续挤占小游戏本地存储。后续若调整费用、装备上限或经验曲线，需要扩展规则版本和显式迁移，不能直接用新规则否定旧账本。
