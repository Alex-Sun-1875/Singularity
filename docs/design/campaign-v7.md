# 剑与火：破晓之战 剧情重构方案 v7

**四章结构已被[完整八章剧情v8](campaign-v8.md)替代。当前制作范围仅第一、第二章；下方四章表与对应终局安排保留为上一版设计记录，不再作为章节数量和制作范围依据。刷怪与任务并重的原则继续有效。**

2026-11-10。**新主线提案。** 保留拉斐尔等现有人物、四个地表地区、两个地下区域，以刷怪和任务并重的两条路线推进一场由边境兽潮发展到大陆存亡的战争。两条路线都能独立完成成长与战役，在每章共同的关底Boss汇合，玩家可随时混合游玩。当前运行剧情仍以v6及既有任务数据为准；本轮完成故事与进度设计，尚未迁移对白、任务状态、Boss、双路线配平或地图演出。

玩家要亲历的故事是：**兽潮冲出群山，沉没的古老王城重新亮起灯火。一个本应死去的君王正借人类争夺天火的战争重返世间。你从边境冒险者成长为战场上的关键力量，攻破黑冠，阻止大陆被长夜吞没。**

## 当前剧情与需要解决的问题

[现行v6](campaign-v6.md)的故事从弥菈展示遗库样片、委托拉斐尔夺回遗物匣开始。匣中求援信署名者十八年前已经被宣布阵亡。玩家进入地下，发现远征队幸存者仍被留在工坊中，继而发现天火是一种遭到拘束的古老生命。阿德里安希望借它维持城防和扩大控制；玩家最后攻破黑冠，决定释放、合作、封炉或继续控制天火。

四幕现名是血路破关、断岳夺火、沉钟惊雷、黑冠陨落。更早的阵亡者的晚饭、救命的人关上了门等标题仍见于历史稿。当前运行版还保留找回原信、核验抄本、带工匠离场、校光复秤、回深炉执行决定等动作。自由狩猎和等级通行已解除这些任务对跨区的限制，但旧故事的关注点仍集中在一支远征队及一套设施的归属上。

新主线需要让玩家在行动中看见更大的局势：怪物为什么聚集，城市为什么开战，古代遗迹正在发生什么，打倒各章敌人之后世界发生了什么变化。取信、搬运与核验适合承载局部线索；主线的关键转折由战场、敌人和重大事件呈现。

## 世界危机与古代敌人

### 长夜与兽潮

大陆最近出现异常的暮色：白昼里突然失去日光，野兽离开原来的巢穴，矿井深处传来并不存在的军队脚步。人们把裂隙中涌出的黑暗和生物称为蚀潮。它会侵蚀生命、唤醒古代战争设施，并将相距很远的灾区逐渐连接起来。

第一章的兽群中既有受到侵蚀的凶兽，也有被更深处威胁驱赶的普通野兽。玩家能从迁徙、巢穴与敌人行为判断差别。各地军队、盗匪和狩猎团仍有自己的利益，人类敌人不统一改成失去意识的傀儡。

长夜按剧情事件推进，不按玩家在线时间倒计时。长时间刷怪、休整或探索不会让城镇在后台毁灭，也不会导致主线自动失败。

### 天火与旧帝国

数百年前，古帝国试图利用天火和巨大的王冠装置打开另一片天地，取得不会枯竭的力量。灾难吞没了王城。幸存者摧毁了大部分装置，天火协助压住残存的裂口，随后消失在地下。

十八年前，破晓第七远征军重新发现天火。它逸散的光热曾救下陷入灾区的人，后来被当作持续供能的工具，留守变成拘禁。近年的征掘不断扰动封闭的地层，各方又将古代装置接入军械与城防，终于使沉没王城重新与地表相连。

天火保留古老非人生命的身份。它有趋近、退避与拒绝，不是被杀死就能掉落神器的资源怪，也不承担为玩家解释全部历史的职责。本体仍在誓火深城；跨区域传导的是光热与共振，不能随手装进背包带走。

### 永夜君主 维萨里昂

**维萨里昂，称号永夜君主，是本作新增的核心敌人：古帝国最后的君主，也是开启王冠装置的人。** 他在灾难中与装置结合，肉身和军队被困在沉没王城。如今他利用苏醒的战争设施、被侵蚀的军团和人类接通的供能通路，把自己的王座重新接到大陆上。

剧情与对白使用维萨里昂，Boss名牌使用永夜君主·维萨里昂。

他的目标是恢复帝国的疆域与统治，活人与城市在他眼中都是可以征用的力量。他记得人类如何因争夺天火而互相攻击，因此相信人只能被统一支配。他会主动夺取阵地、切断退路、唤醒旧军团，构成一个玩家能够反击和最终打倒的敌人。

维萨里昂从第一章就留下可见痕迹：兽群朝同一方向逃离，遗卫在无人命令时转向地下；第二章通过远古战像直接干涉战场；第三章在沉城展现真实意图。终章不再临时揭晓一个此前毫无存在感的幕后主使。

### 阿德里安的战争

阿德里安仍是黑冠统帅，不改成国王或古代血统继承人。他相信集中军队、工匠和天火才能守住城市，愿意牺牲外围聚落的自主权换取中心要塞的安全。他知道扩大抽取会恶化裂隙，却决定以眼前防务为由继续。

他与维萨里昂有各自的目标。维萨里昂会利用他接通的网络，但阿德里安仍须对征用、拘禁和牺牲边境负责。终章击败他之后，战役继续进入与维萨里昂的决战；两场冲突各有自己的战利品与结算。

### 第一章 兽潮之夜

**开场就让玩家亲历异常。** 拉斐尔抵达石桥镇时，猎场的兽群正在冲击镇外道路。一次短暂的日蚀使远处旧哨塔自行亮起，黑暗退去后，路上留下不属于任何现役军队的长矛。玩家可以立即出镇狩猎，也可以参加边境任务，调查兽潮、夺回哨塔，并在任务中的战斗获得经验与装备。

石桥镇是逐渐显出温度的据点：铁匠接收猎获的矿骨，旅店安置伤者，行会悬赏危险兽首。镇内保持安全，开场战场设在镇外；教学可以跳过，不把保卫城镇变成随时可能失败的守家任务。

弥菈知道一支失联远征队可能与异常有关，提出共同深入。玩家可以合作，也可以沿兽群迁徙和古代兵器自行追查。求援信成为一条可选人物线索，地下路线可以凭等级、探索与战斗进入。

中段进入下城浅部，看见被宣布阵亡的人仍在生活。阵亡者的晚饭保留为这一幕的关键场景：伊芙琳把最后一份面包留给即将换岗的人，而门外的遗卫已经开始自行集结。幸存者知道，十八年间从未有这么多旧兵同时醒来。

第一章让**灰披队长**与**裂岳獠王**承担两种不同的威胁。队长控制军事据点，是两条路线共同挑战的章节关底；獠王统领被蚀潮侵入的兽群，保留为可选强敌，两者有独立战场和奖励。章节高潮是边境防线上的大战，玩家击败共同关底后，在远方山体中看见巨大的古代冠形轮廓亮起。任务玩家由战役安排接近战场，刷怪玩家达到战斗能力后可直接挑战。

章节结束时，石桥镇保住了道路，幸存者有了地表落脚点，玩家则第一次知道兽潮只是前兆。Lv11直接开放断岳高地，不要求领完救援报酬、读信或看过晚饭场景。

### 第二章 群山战火

高地的矿藏和古代熔炉能制造抵抗蚀潮的武器，也能为重型军械供能。黑冠军、地方守军和遗迹掠夺者围绕矿镇、山桥和炉厅交战。玩家从外围战场一路深入，看到同一批军械既救下工位，又被用于扣押获救的工匠。

阿德里安在此正式登场。他亲自抵住一次失控的熔炉爆发，随后征用全院工匠与天火读数。玩家理解他为何获得支持，也能看见他把受保护者变成了不得离场的劳力。

本章的主场景是**山桥破阵、熔炉激战、天火初见**。守桥铠卫保留为军事强敌，三誓守卫与震炉巨像保留不同的古代防卫身份。把原本连续的稳镜、试读、交接压缩为战场中可以直接理解的行动：打断过载攻击、击破供能护卫、抢占不会被火线覆盖的炉厅。

见到天火时，玩家亲眼看见它主动避开拘束器，并在安全时接近人。伊芙琳留下，是因为她知道被抽走的光正在把什么东西引上来。与此同时，维萨里昂通过一具远古战像向战场发出第一道命令：所有遗卫同时转身，对准仍然活着的人。

高潮战役终止一次足以毁掉矿镇的过载，玩家夺下战场武备与通向深层的道路。熔炉最后一次震动唤起河湾深处的钟声，将第三章危机带到地表。到Lv21即可赴河湾，未做工匠支线也能继续狩猎和挑战。

### 第三章 沉没王座

风暴河湾发生退潮，水下露出连续的街道、王像和军团方阵。旧码头上的战斗变成争夺登陆点：掠夺者抢走遗物，古代守军向岸上推进，蚀潮生物沿水道进入湿地。

玩家深入沉钟禁域，在**沉城街战、古王陵墓、钟楼围攻**中接近王座。瑟维恩的旧拓本可以帮助理解细节，但玩家在战场中已经看到关键事实：王冠装置会把被接入的灯塔与城盾变成维萨里昂可以占据的阵地。

历史揭露发生在可参与的战斗中。旧战阵重演当年王城覆没的片段，维萨里昂从破碎战像后走过，直接命令自己的军团向地表进发。重播、残存意志和真实敌人需要有清楚的视觉区别，不把每段回声都当成活人复生。

灰烬掠夺者保留为本章的人类战场强敌，**新增一场能体现沉城势力的非人首领战**，阻断古代军团登陆。胜利让河湾获得喘息，也暴露更坏的事实：阿德里安已经把黑冠接到同一网络上，最大的裂口将在城域张开。

章节末，玩家看见来自边境、矿镇与河湾的旗帜在通往黑冠的道路上出现。此前帮助过的人可以带来具名援军；没有完成个人支线时，地区守军和基本防线仍然存在。Lv31开放城域，不要求集齐证词、拓本或阵营声望。

### 第四章 破晓之战

黑冠城域成为两场战争重叠的战场：统帅试图用更强的城盾维持征用秩序，城外的蚀潮军团则沿供能通路逼近。玩家从外围据点、城墙突破口打到内堡，亲眼看见前几章的军事、工坊与居民力量分别承担防线。

阿德里安是终章前段的主要Boss。击败他会结束永久征用和对主控的武力独占，直接结算现有统帅奖包；他的缴械、受审、离开或参与守城属于后果选择。玩家不会因为拒绝原谅他而失去挑战维萨里昂的机会。

**维萨里昂是完整战役的最终Boss，需要新增独立身份、招式和场景。** 黑冠后方张开的裂口把人带到沉城王座与城防设施交叠的终战空间。战斗分为王座护卫、维萨里昂本体和王冠崩解三个阶段，提供清群与单体输出的交替节奏。剑、弓、火、雷都能完成有效攻击，不要求装备某件传奇、消耗任务道具或在战前点满机关清单。

天火可以通过玩家已经争取到的合作提供援助，但击败维萨里昂的基本路径始终成立。破坏王冠的关键攻击是玩家与战场同盟实际完成的行动。天火的去留和被拘束状态改变援助、政治选择与尾声，不把一段隐藏支线变成唯一获胜钥匙。

维萨里昂倒下后，持续扩张的主裂口关闭，正常的晨光重新照到城墙上。胜利在此成立，之后才决定军队、天火与旧设施的归属。终局在战场附近完成，不要求带着胜利再跑一遍跨区交接。

| 瑟维恩 | 解释沉城与装置的来历，把可验证的知识交给前线 | 承认自己曾把猜测写成古代命令，不能由一次揭密洗去责任 |

| 伊芙琳 | 带领幸存远征者决定何时、为何再次参战 | 她有权离开地下生活，其他幸存者也各自决定，不统一献身 |
| 艾莉丝 | 以港口关系、鉴定能力和旧航路组织补给与接应 | 她为过去失败接应承担自己那一部分，不成为无条件供给的商店 |
| 阿德里安与黑冠军 | 真实抵抗蚀潮，同时征用人口并垄断天火 | 防务能力与当前责任同时成立，不能用被古敌利用消除责任 |
| 维萨里昂与旧帝国军团 | 从地下扩张，争夺地表供能阵地，试图恢复统治 | 目标与行为清楚，提供贯穿四章且可被击败的主要威胁 |

地区守军、地下幸存者、自由探险者各有自己的诉求，不另增一套需要重复刷声望才能看懂的阵营系统。宏大战争通过可见战线、具名人物的行动和玩家能参与的战斗体现。

## 怪物和装备如何承载故事

| 章节 | 刷怪与副本的方向 | 内容规模要求 |
| --- | --- | --- |
| 兽潮之夜 | 猎兽、喷囊兽、铁鬃兽、变异群首、遗迹中的初醒卫兵 | 先复用当前已接入生态，补充迁徙与侵蚀差异；獠王保留可选挑战价值 |
| 群山战火 | 裂岩巨兽、熔炉寄生物、采掘机、炉卫与军事精英 | 新巨兽、寄生物需要独立轮廓和招式设计，不能只把旧杂兵改名 |
| 沉没王座 | 水道异兽、古代甲士、沉城施法者、王墓守卫 | 至少补一场真正不同于人类军官和机械守卫的章节强敌 |
| 破晓之战 | 蚀潮军团、攻城巨兽、古帝国近卫、维萨里昂 | 最终Boss及攻城表现按新增内容排期，不能用现有统帅贴新名字代替 |

刷怪与任务是并列的完整成长路线。玩家可以进兽巢、挑战精英、刷来源Boss，也可以沿任务参与调查、清剿与战役，成长后挑战同一个章节关底。世界背景解释持续出现的兽群、遗迹守军和裂隙残部，战役首胜只记录一次；重复挑战不把同一个人物再次死亡写成新的主线事件。

每章战斗路线和固定任务路线分别提供高级武器的既有设计继续保留，普通阶段武器有自己的穿戴等级。八件已接入的成长传奇和神器不改ID、成长曲线、当前概率或本旅程唯一凭证。

最后一班岗属于边境守军，逐月之弦属于猎场，长夜圣烛见证矿镇与工坊，雨前的静默关联古代雷卫。王庭的黄昏可以承载旧帝国遗产，第二次黎明保留墓志和深闸镇守两条独立来源。具体人物支线可以在战争中有更深意义，传奇和神器仍按既有规则获取，不能改成八件必收集的主线钥匙。

## 刷怪与任务并重的推进规则

**两条路线具有相同地位，都能提供完整升级、足够的装备强度和完整通关路径。** 玩家自由分配时间，可以一直刷怪、一直沿任务游玩，或随时混合。任务路线本身包含清剿、据点战、精英挑战和关底Boss战；任务爱好者也在实际战斗中成长。

| 环节 | 刷怪路线 | 任务路线 | 共同规则 |
| --- | --- | --- | --- |
| 升级 | 狩猎、精英与副本持续提供经验 | 沿途必要战斗与任务结算共同提供经验 | 两边都能独立达到后续地区与终战所需等级 |
| 装备 | 掉落、累计保底与战斗材料兑换 | 任务固定奖励与沿途战斗掉落 | 同阶段主要装备强度和构筑可用性相当，各流派都能成型 |
| 章末准备 | 自选猎区与装备，直接接近Boss | 调查战况、攻克据点，随任务接近Boss | Boss入口不独占任务钥匙、指定装备或阵营声望 |
| 本章通关 | 实际击败本章指定关底Boss | 任务推进到同一Boss，并实际击败 | 以同一份Boss首胜记录判定通关 |
| 最终通关 | 击败各章共同关底及维萨里昂 | 沿任务完成同样的关底与最终战 | 通关与基础结局资格相同 |

### 历史四章任务战役安排

| 章节 | 任务路线的主要行动 | 刷怪路线如何汇合 |
| --- | --- | --- |
| 兽潮之夜 | 调查兽潮、清剿威胁、夺回哨塔、参与裂隘关攻坚 | 在边境狩猎、挑战精英并取得装备后，直接挑战灰披队长 |
| 群山战火 | 解放工位、争夺矿区、抵挡熔炉失控、突破守桥军阵 | 在高地与地下升级、刷取战利品后，进入同样的战役Boss战 |
| 沉没王座 | 阻止军团登陆、夺取钟楼、深入王墓、攻入沉城核心 | 在河湾与禁域狩猎成长，再挑战同样的登陆战与沉城关底 |
| 破晓之战 | 攻克城防据点、切断敌方供能、击败阿德里安、迎战维萨里昂 | 通过城域战斗达到能力要求，直接挑战相同的统帅与最终Boss |

任务的调查、选择与人物关系构成完整叙事；送信、护送与寻物保留为少量地方事件。重复战斗悬赏展示清楚目标、奖励与地点，不要求每轮重新往返接单。

### 开放地区与完成关卡

- **Lv11、21、31继续决定后续地区的探索开放。** 保留现有安全条件，不追加任务清单、指定职业、传奇装备或声望门槛。
- **每个设有关底Boss的战斗关，实际击败该Boss才算通关；每章的指定关底两条路线相同。** 达到地区等级不自动写入Boss胜利，读完对白或领完任务也不代替Boss战。
- 玩家可以先进入已到级的地区探索，尚未击败的前章Boss仍显示未通关。完整战役需要完成共同的章节关底与最终Boss，任务完成率不进入通关判定。
- Boss首次击败不要求先接任务。先刷怪打过Boss、后来转做任务时，任务承认真实首胜，不强迫再杀一次，也不重复发放同一份首胜奖励。
- 支线可以提供援助、额外装备和人物回响；最低战场准备由关底场景提供，两条路线都具备战胜Boss的基础条件。NPC不会用一次交涉或过场替玩家直接结算关底胜利。
- 混合路线共用经验、装备、任务和Boss记录。不同来源的合法奖励可分别领取，同一奖励、同一唯一装备与同一首胜不能因切换路线重领。
- 任务菜单提供连续的战役目标，狩猎指引提供猎区、经验、掉落与Boss入口。两者并列呈现，玩家随时可以切换。

### 成长与奖励配平

每章任务的经验预算要包含任务必经击杀、精英、共同Boss首胜和任务结算。沿任务正常完成即可达到下一地区门槛；进入最终Boss前，任务路线必须已经能达到所需等级，不能借用战后经验补战前门槛。刷怪路线使用同一人物成长曲线，以狩猎和精英持续获得对应经验。

首轮配平目标为：在相近角色构筑与熟练度下，两条路线达到同一阶段的有效游玩时间差控制在约10%以内。任务计入赶路、对话、战斗与交付；刷怪计入赶路、清怪和补给。这个数值是待验证的设计目标，当前版本没有完成相应实测。

两边均应有稳定的高级武器供给。任务路线有固定奖励，刷怪路线通过掉落与累计保底取得同档装备；共同关底奖包两边都直接领取。任务途中击杀掉落照常保留，配平时将其计入路线总收益，避免任务奖励与必要战斗奖励被遗漏或重复计算。

传奇和神器可以保留不同来源与独有玩法，普通通关强度与主要流派构筑在两边都应成立。八件已接入成长装备的现有来源、概率与本旅程唯一凭证继续保留，本次规则修正不直接重发或改掉它们。

后续验收分别走完整刷怪路线、完整任务路线和混合路线，确认升级、装备、全部共同关底、结局与存档均能成立。已有任务经验预算、和平处理关底、旧终局前置与HUD优先级需要按本节迁移；本节是设计修正，尚未作为双路线通关规则接入运行版。

## 胜利与结局

完成各章共同关底、打倒维萨里昂并关闭主裂口是两条路线共同的战役胜利。结局决定胜利之后怎样生活，不把某个对白选项写成世界得救的唯一答案。

**诸城共守**：拆除对天火的永久强束，由地区共同承担防线、工坊与补给。天火是否停留取决于它的真实回应；人类必须接受有限能源和更分散的责任，重建较慢，没有一座要塞能承诺替所有人挡住危险。

**铁冠秩序**：拉斐尔接管主控和集中军队，继续用拘束抽取维持强大的城防。城市获得眼前稳定，边境要承担征用，天火的应激和同伴的反对也继续存在。这条路线明确记录继续控制的选择，不包装成无代价的最强结局。

**熄炉远行**：关闭人类的抽取设施，留下天火可以自行迁离的通路，各地重建常规工坊与防务。人类失去旧装置带来的便利和统一护盾，冒险者的下一段旅程从仍然危险的大陆开始。

三条路线的基本可执行条件由终战提供，个人支线改变具体人物和地区的处境。主裂口已经关闭，任何路线都不因核心拒绝合作而临时要求重新打一次主线。余下兽群、局部裂隙和失控设施构成通关后的狩猎、副本与后续扩展，不推翻已经取得的胜利。

## 从现有内容迁移

本轮保留地图与人物作为基础，新增世界危机与维萨里昂，重写章节事件的目标和因果。四章剧情不能仅靠替换标题或把押运者改称军团完成。

| 内容 | 迁移安排 |
| --- | --- |
| 四个地表地区、两个地下区域与既有地点ID | 保留连接关系；在现有空间内安排战线和事件，新增终战空间另行登记 |
| 灰披队长、守桥铠卫、灰烬掠夺者、阿德里安 | 保留独立身份与已有掉落，再按新剧情调整出场；新增Boss使用新ID |
| 老人物的关系和阵亡者的晚饭 | 保留能成立的经历，置于大战中的具体处境，不清空人物重起 |
| 读信、校光、复秤、搬运等旧前置 | 从主线推进中移出或压缩，保留需要的个人支线与可选探索 |
| 当前八件成长装备与已完成收据 | 保持取得和唯一性，不因改名或换任务结构重发一件 |
| 已有存档 | 等级、装备、金钱与真实完成事件保留；新旧剧情标志建立明确映射，不把旧交信标志直接当成新大战胜利 |

制作顺序应先完成四章事件与旧任务映射，再接入开场兽潮和章节战场，随后生产沉城强敌、维萨里昂与终战空间，最后完成对白、结局和存档迁移。每一步分别核验剧情表达、实际玩法和美术；本方案不宣称新增敌人、战场演出或结局已进入运行版。
