# 每件装备五孔宝石系统接入

本页保留首次接入记录。后续用户要求按装备品质分孔，当前规则与兼容处理以[品质孔位与宝石等级 v2](equipment-gems-quality-v2.md)为准，已覆盖下文“一律五孔”和仅开放Ⅰ／Ⅱ阶的旧规则。

2026-11-15。当前 Cocos 主工程接入免费宝石培养：每件装备五孔、材料获取、定向兑换、开孔、镶嵌、合成、无损拆卸、培养迁移和回收。月卡与经验加速不在本次范围。付费材料和外观只提供代码契约，真实支付、服务端账号与商业账本未接入。

## 使用入口

行囊选中装备后点击“镶嵌”，或从洛恩工坊的“镶嵌”页签进入。每件装备固定显示五孔，第一孔免费开放，其余孔依次消耗材料开启；不按品质或充值身份改变孔数。当前沿用既有按物品 ID 保存的培养方式，没有新增同名装备独立实例；现有穿戴和存档规则禁止同一物品 ID 同时占两个戒指槽。

页面提供免费来源、定向兑换、宝石合成和迁移培养。开孔、镶嵌、合成、迁移及回收须在正常脱战后，于安全检查点或洛恩工坊操作；有交谈、攻击动作、施法或弹体时拒绝提交。返回沿进入来源回到装备或工坊，不新增战斗 HUD。

单手五孔＋副手五孔的标准投入、收益，均等于双手五孔。全身最多45个实际孔，双手配置为40个实际生效孔，两种持武方式均为40个标准孔的收益预算。宝石只提供数值，不按宝石颗数额外触发套装。

## 属性与战斗

首轮五种宝石方向为伤害加成、生命上限、护甲、暴击率和暴击伤害。标准Ⅰ阶分别为0.2%、2、0.1%、0.05个百分点、0.5个百分点；Ⅱ阶乘1.5，主副手按4／5和1／5缩放。数值是初版配置，后续需自然游玩配平，不代表礼包价格或长期毕业节奏已经确认。

全身宝石统一汇总，生命最后取整，其他属性保留足够精度；副手Ⅱ阶暴击0.015个百分点不会提前被抹去。伤害与暴击沿现有装备结算，护甲沿真实受伤路径，生命同步人物上限与存档核对；现有全身属性有效上限继续生效。增加生命上限不直接治疗，拆卸不重置职业资源、技能冷却或随机强化历史。

## 保存与接入边界

`features/gems/data/Gems.ts` 集中五孔、阶段、规格、属性和费用；`common/GemWorkshop.ts` 管理报价、事务、免费来源与校验；`runtime/GemPanel.ts` 与 `locales/` 管理真实界面和中英文词条。宝石库存独立于旧装备库存。五孔、主副手等价和既有掉落来源重放属于本作规则，沿用锻造事务方式实现；界面复用 Cocos 与项目公共组件。目录与脚本均有 Cocos 元数据，没有新增第三方依赖。

报价绑定材料、金币、进度、操作与修订状态；旧报价或重复点击不重扣。整个操作先作用于副本，再一起提交材料、孔、晶质、金币与事务。存档按来源和事务重放校验，保留现有双槽、写后核对与失败重试。合法旧档缺少 `gems` 时迁移为空材料、空培养，保留金币、装备和任务；无法通过删掉宝石字段来抹去已有交易回执。

普通狩猎按出生槽累计计数，不逐杀扩张日志；任务／Boss奖励记录与操作记录分别最多4096条，达到容量后拒绝继续新增对应记录并保留当前进度，后续需实现安全归档。这是本地账本容量边界，不是付费次数上限或平台限制。所有本地校验用于拒绝损坏和非法快照，不替代服务端付费安全。

外观在 `features/appearance/common/AppearanceContracts.ts` 预留定义、授权、穿戴及恢复契约，不注册空服务。材料购买在 `features/commerce/common/PurchaseContracts.ts` 预留商品、账号归属、订单、环境与服务接口，未配置商品价格、未开放购买按钮、未调用支付 API。未来必须补齐稳定账号、服务端余额／消费、旅程防回滚、平台资质与真实支付验收，不能把本次客户端养成当作内购上线。

UI 复用项目暗金管理面板和原有滚动列表；没有增加 UI 库或生成美术资源。依据项目[UI规范](../../.agents/skills/singularity-ui-design/references/ui-layout-guidelines.md)和[Cocos ScrollView说明](https://docs.cocos.com/creator/3.8/manual/en/ui-system/components/editor/scrollview.html)。
