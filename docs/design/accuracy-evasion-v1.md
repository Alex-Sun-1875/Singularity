# 命中、闪避与专注上限 v1

2026-11-12。用户明确确认新增命中与闪避属性：弓箭手的专注上限提高命中，当前专注消耗不影响命中率。本方案已接入 Cocos 主工程，沿用现有四项加点，不增加独立加点货币或战斗按钮。

## 属性与首轮数值

| 项目 | 规则 |
| --- | --- |
| 玩家基础命中值 | 100 |
| 弓术专注收益 | 专注上限每高于100一点，命中值增加0.25；即敏捷带来的每2点专注上限增加0.5命中值 |
| 玩家基础闪避值 | 5 |
| 敏捷闪避收益 | 含装备的敏捷每高于10一点，闪避值增加0.2；闪避值上限25 |
| 最终接触命中率 | `(攻击者命中值－目标闪避值)÷100`，限制在60%—100% |
| 敌人基础闪避值 | 普通近战3、盾兵1、弓手8、队长5；每高于Lv1一级增加0.05，首领另加2 |
| 敌人命中值 | 100；每高于Lv1一级增加0.1，首领另加2 |

人物界面使用“命中值／闪避值”，它们是对抗数值，不能把命中值100误读成对任何敌人都100%命中。例如基础弓手对Lv1普通近战为97%，对Lv1弓手为92%；专注上限140时命中值110，对这两类目标的接触命中率均为100%。这些是首轮可运行参数，后续按自然战斗中的空箭感和敌我生存节奏微调。

专注上限按敏捷和装备真实属性推导，出手时冻结命中值；没有读取当前 `player.focus`。消耗、自然恢复或饮用专注药水不会改变命中属性。只有弓术使用专注上限的命中加成；其他流派仍有基础命中值和敏捷带来的闪避收益。

## 判定顺序与边界

1. 原有射程、墙体、弹道与实际接触判定先执行。数值命中不能让箭穿墙、转弯、追踪或凭空击中远处目标。
2. 实际触碰后进行命中／闪避对抗；成功后才结算伤害、破势和命中联动。未命中显示MISS，技能已成功释放的资源不返还。
3. 同一玩家技能、同一目标只生成一个命中结果。多段、贯穿接触、次爆和雷电装饰连线不重复掷骰；对不同目标分别判断。成功接触记录与失败记录分开，未命中不会被当成命中人数或连击完成数。
4. 命中抽样复用已有的确定性随机函数，与暴击使用不同键；结果取决于种子、攻击ID与目标ID，不受帧率、回调次数或当前资源影响。基础攻击与玩家技能保留出手时的命中快照。
5. 已附着燃烧、装备次级伤害不额外抽样。火墙的各伤害拍共享该次施放对目标的结果；站在火墙里的减速仍按区域规则独立生效。陷阱伤害被闪避时不施加其命中后的定身／减速，雷弧未命中首目标时不施加打断。
6. 敌人直接近战与弹体也接入对抗。近战使用招式段的身份，独立投射物各判一次；地面危险、燃烧和环境伤害不因被动闪避免疫。
7. 主动疾影步的原动作无敌与冷却保留，仍不耗资源。主动闪避优先检查；被动闪避成功不会扣护盾、消耗一次减伤、造成受伤硬直或打断施法，也不凭空触发原本要求主动精准闪避的装备奖励。

统计判定失败后会记录实际MISS事件并唤起敌人的战斗响应，不伪装成暴击或零伤害。玩家被动闪避在角色头顶显示绿色“闪避”；敌人未中继续使用既有MISS反馈。HUD不增加常驻面板。

## 界面与存档

人物概览新增命中值与闪避值；属性加点预览同时显示生命、主属性伤害、职业资源上限、命中值和闪避值。弓手敏捷每加1点，预览应同时体现专注上限＋2、命中＋0.5、闪避＋0.2。

命中和闪避为派生战斗属性，不在存档中另存可任意加点的字段。新增的动作、弹体和技能命中快照为可选字段，旧档不需要清库或重发奖励；恢复仍按原规则清除在途输入和弹体，不重放伤害。新快照校验实际属性允许的命中上界，并验证多段技能缓存结果与确定性抽样一致，拒绝伪造命中值或把MISS缓存改成命中。

复用位置：`features/combat/common/CombatAccuracy.ts`集中规则和抽样，`PureCombat`与`GameSession`接入实际伤害，`EnemyCombat`传递攻击身份，`CombatPersistence`校验新增快照。复用现有属性／装备、随机函数和MISS表现，不增加依赖。

## 验证记录

两项类型检查和120项现有测试通过；只为原A02远近伤害比较选定可重复命中的固定种子，没有新增测试依赖。临时实际规则审计验证：相同种子与施放ID下上限成长让未命中变为命中、飞行中清零当前专注不改变命中、实体墙仍阻挡、五阶连斩仅提示一次MISS、未命中无破势／燃烧／控制／连击奖励、被动闪避先于护盾／一次减伤／硬直、主动闪避及地面伤害边界、旧快照恢复、伪造值与结果拒绝。

50,000个确定性攻击样本中，理论92%的命中率得到92.048%；相同攻击／目标重复取样结果一致。此为规则抽样核对，不代替自然战斗平衡测试。结果见 `test-results/accuracy-evasion-v1/core-audit.json`。

编译版覆盖844×390、915×412、568×320及1280×720四种视口，每种检查四流派的人物数值与面板边界，运行错误为0。iPhone横屏通过实际触屏验证敏捷加点预览100→102专注、100→100.5命中、5→5.2闪避，以及应用、保存和重新进入后的保留；实体箭矢的真实MISS与玩家被动闪避均已在原场景观察，玩家闪避样本未损失生命，画面截图与事件记录位于同目录。
