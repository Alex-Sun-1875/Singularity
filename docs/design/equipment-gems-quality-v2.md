# 装备品质孔位与宝石等级

2026-11-15。按用户修正，装备品质决定孔位上限，宝石等级决定每孔效果。本规则覆盖[首次五孔接入](equipment-gems-integration-v1.md)中“所有装备五孔”和仅开放Ⅰ／Ⅱ阶的旧规则。仍采用免费积累材料的养成方式，实际支付未接入。

## 装备孔位

| 装备品质 | 颜色 | 最多孔数 | 开孔资格 |
| --- | --- | ---: | --- |
| 普通 | 白色 | 0 | 不支持 |
| 精良 | 绿色 | 0 | 不支持 |
| 稀有 | 蓝色 | 2 | 支持 |
| 史诗 | 紫色 | 3 | 支持 |
| 传奇 | 橙色 | 4 | 支持 |
| 神器 | 橙色及神器标识 | 5 | 支持 |

规则适用于武器、防具和饰品。稀有及以上装备第一孔免费，其余孔按实际容量依次开启；普通与精良没有可用第一孔，材料、金币或购买资格不能绕过品质门槛。随机强化的1／2／3条词条容量继续使用自身规则。

界面按品质展示真实孔数，不给低品质装备画五个可操作假孔；列表、详情和迁移预览显示实际分母。无孔装备仍可查看材料、兑换、合成及领取历史返还。

## 宝石等级

| 宝石等级 | 正常开放等级 | 相对Ⅰ级效果 |
| --- | ---: | ---: |
| Ⅰ级 | Lv1 | 1.0倍 |
| Ⅱ级 | Lv10 | 1.5倍 |
| Ⅲ级 | Lv20 | 2.25倍 |
| Ⅳ级 | Lv30 | 3.375倍 |
| Ⅴ级 | Lv40 | 5.0625倍 |

第二章成长阶段的当前角色至少可用Ⅱ级。宝石等级与装备品质分别判断：蓝色装备有两个孔，角色满足条件后可以镶Ⅴ级宝石；神器有五孔，也可以使用低级宝石。购买不能提前开放角色尚未达到的宝石等级。

三个同属性、同等级的标准宝石等价量合成高一级，成功率100%；按晶质计为15份当前级变5份下一级，最高Ⅴ级。合成费用沿用 `5×3^(当前级−1)` 金币，确认前显示全部消耗。已镶嵌宝石先无损拆下再参与合成，拆卸返原属性、原等级和原份数。

## 费用与迁移

主副手继续采用4／1／5份晶质规格：单手主手4、副手1、双手及其他标准部位5；同品质主副手的总收益与成本等价于相应双手武器。不同品质按实际孔数计算，不因副手孔少而补出额外孔。

各合法孔沿用原标准开孔费用：第2／3／4／5孔消耗5／10／20／40开孔料及同量金币，再按规格缩放；没有该孔的品质不能支付这笔费用。镶嵌、拆卸、定向兑换、材料免费来源及全部属性有效上限沿用已接入规则。

从高容量装备迁移到低容量装备时，只生效目标合法孔位，多余宝石按原级别和份数退回，剩余开孔投入保留为可领取返还，不复制来源培养。目标品质不支持开孔时拒绝新的培养迁移；既有旧培养通过版本迁移回收，不继续提供战斗属性。

## 当前版本存档与返还

用户已明确本次不做旧版本兼容：只维护当前品质孔位规则和v2宝石状态，不实现旧版五孔转换、旧交易前缀重放或历史补偿，也不自动清理已有存档。

当前版本正常回收或不同容量迁移产生的返还，按当前金币与材料容量分次领取，剩余量继续保存；满余额不截断、不销毁。这里的“培养返还”属于当前操作，不是旧档补偿。报价预览不修改余额，重复领取或旧报价不能重复退款。

当前版本保存完整材料、孔位、宝石、来源与事务，并按同一套规则重放校验；正常读取、写入、失败重试和刷新恢复仍需验证。

## 实现位置与验收范围

品质容量与宝石等级在 `features/gems/data/Gems.ts` 集中配置；`common/GemWorkshop.ts` 处理操作门槛、培养转移、待领余额及当前规则重放。`runtime/GemPanel.ts` 和词库提供实际孔数、等级说明、培养转移和领取界面，`GameSession` 接入实际属性与持久化。

复用现有类型检查、150项回归和临时规则／浏览器探针。验证需覆盖六种品质、Ⅰ—Ⅴ级门槛、当前高低品质培养转移、金币满时分次退款、预览无副作用、重复领取拒绝、当前档保存恢复及手机横屏真实操作。受控存档和浏览器验证不替代自然成长配平或TapTap真机验收；证据归档于 `src/cocos/test-results/gems-quality-v2/`。
