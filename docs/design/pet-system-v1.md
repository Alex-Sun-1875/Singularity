# 宠物系统 v1：实现后暂不开放

**历史记录：本版已被[宠物系统v2](pet-system-v2.md)取代。** 下文的道限、角色等级约束和借用术语仅描述早期实现，不再作为当前开发或开放依据；原验收结果也只适用于当时规则。

2026-11-15。适用于当前 Cocos / TapTap 小游戏。用户已明确：系统先做好，所有章节暂不开放；这取代最初对“第三章开放”的推测。

## 开放状态

统一由 `features/pets/data/Pets.ts` 的 `PET_POLICY.enabled` 控制，当前为 `false`。不按章节、角色等级、dev / test / release、URL 或存档字段自动开启。暂停菜单隐藏宠物入口，直接菜单路由和业务操作也必须检查同一开关。关闭期间不获得宠物、灵蕴或宠物经验，不消耗培养材料，也不提供战斗效果。

以后开放属于新的内容投放决定；启用开关前须完成下方开放验收。现有存档仅增加空宠物状态，不自动领取初始宠物或补发过去的击杀收益。

## 参考方向与取舍

主要参照《斗战神》灵兽的**本源技、附身技、进化技三层能力，以及道阶、道限与感应的成长关系**，并参考《梦幻西游》的参战伙伴选择与培养定位。这里采用适合当前即时动作战斗的自动协战、护盾和治疗，不照搬回合制指令、原作人物、美术、概率或经济数值。

对应到本项目：本源技由物种决定；附身技由玩家定向学习，集中修饰灵宠的本源能力；进化技在满足等级和感应条件后确定解锁，体现各物种的成长分支。道阶是宠物等级，道限是品阶提供的成长上限，仍受角色等级限制；感应作为能力加成通过照料提高，不随在线时间或战斗下降。保留养成与搭配的主干，首版不增加饥饿惩罚、随机悟性或随机顶掉技能。

参考来源与核验范围：

- [《斗战神》官方宠物介绍](https://dzs.qq.com/webplat/info/news_version3/394/3871/4846/4847/m3352/201211/179094.shtml)：2012-11-03历史资料，2026-11-15从官网游戏资料导航找到并读取。其描述本源、附身、进化技能，以及出战、休息和随战成长，仅参考结构，不视作当前版本完整数值依据。
- [《梦幻西游》官方宠物与召唤兽说明](https://xyq.163.com/introduce/zhs001.html)及[资质、技能、成长资料](https://xyq.163.com/introduce/zhs006.html)：2026-11-15从官网资料导航找到并通过直接HTTP读取，参考携带、培养和技能组合的结构。其宠物／召唤兽分工与本项目的统一“宠物”称呼不同；本项目不复刻其数值、炼妖或随机覆盖规则。

项目已有 Cocos 3.8.8、公共暗金菜单与平台存档层可承载本功能。宠物成长和击杀凭证属于本项目玩法规则，采用无引擎 TypeScript 模块实现；不引入新的 UI 框架、宠物插件或网络服务。

## 首批伙伴

| ID | 名称 | 本源定位 | 战斗职责 |
| --- | --- | --- | --- |
| `ember_fox` | 烬尾狐 | 攻击 | 自动攻击主人已经交战的有效目标 |
| `stone_turtle` | 磐甲龟 | 守护 | 战斗中为主人补充有上限的护盾 |
| `dew_sprite` | 露芽灵 | 恢复 | 战斗中为受伤主人恢复生命 |

每种最多结契一只，共携带三只，同时只可出战一只，其余休息。首次结契免费，后续每只花费80金币与20灵蕴；不通过自动赠送、付费购买或随机抽取取得。

v1采用协战能力模型，宠物不单独受击、死亡或损失忠诚度。攻击宠只辅助已参战目标，不越墙攻击或主动招惹新的闲置敌人；宠物伤害不复制玩家装备触发链。暂停、对话、过场、后台和死亡沿用主会话的暂停／恢复规则。协战冷却由真实游戏时钟推进并保存，不能借存读档或反复切宠跳过等待。

## 品阶与晋升

按用户最终确认，宠物使用独立的三级品阶：**普通、珍兽、神兽**。品阶与宠物等级分别保存和展示；同一物种可逐步升至更高品阶，不因晋升重置经验、感应、进化或技能。首次结契均为普通，晋阶由明确操作完成。

| 品阶 | 道限 | 对应能力系数 |
| --- | --- | --- |
| 普通 | 20级 | ×1 |
| 珍兽 | 30级 | ×1.25 |
| 神兽 | 40级 | ×1.5 |

| 目标品阶 | 宠物等级 | 感应 | 金币 | 灵蕴 |
| --- | --- | --- | --- | --- |
| 珍兽 | 10 | 20 | 100 | 20 |
| 神兽 | 30 | 60 | 350 | 70 |

必须逐级晋升，确定成功，不跳级或随机降阶。品阶序号从普通0到神兽2，协战能力乘以 `1＋品阶序号×0.25`。界面普通使用中性色、珍兽紫色、神兽橙色，并始终展示实际宠物品阶名称。

## 成长与培养

| 操作或规则 | v1数值 |
| --- | --- |
| 等级上限 | 取角色等级与当前品阶道限的较小值，最高40级 |
| 累计升级经验 | 到达等级 `L` 所需累计经验为 `30 × (L−1) × L` |
| 普通敌人有效击杀 | 1灵蕴；出战宠物4经验 |
| 首领有效击杀 | 5灵蕴；出战宠物12经验 |
| 训练 | 15金币＋3灵蕴，获得25宠物经验；受等级上限限制 |
| 提高感应 | 10金币＋2灵蕴，感应＋10，上限100 |
| 第一次进化 | 10级、感应20；100金币＋20灵蕴 |
| 第二次进化 | 25级、感应60；300金币＋60灵蕴 |

所有消耗操作在现有安全检查点的准备条件下进行，出战和休息也沿用相同限制。操作前展示真实成本、当前余额和不满足的条件，提交时复核报价凭证，过期报价不得扣费。

击杀收益只接受已经结算的真实敌人生命回执，训练靶、训练敌人和低于角色等级超过3级的敌人不计入；尚未结契任何伙伴时不积累灵蕴。同一敌人同一轮生命不能重复结算。达到角色等级或品阶道限后不继续囤积足以跨入下一等级的宠物经验，训练在已达当前上限时不可执行。不同宠物不共享自身等级和感应。

灵蕴上限999999，培养操作记录最多4096条，敌人收益来源最多2048个；达到上限时拒绝超额操作／收益，保留现有状态，不截断或覆盖旧凭证。

## 本源、附身与进化技

本源技保持物种身份：烬尾狐“烬火追击”、磐甲龟“磐甲守护”、露芽灵“露芽回春”。本源技能随等级、感应、品阶以及已获得的附身、进化技共同成长。

附身技有两个位置，分别于宠物5级、15级开放。每次学习花费50金币＋10灵蕴，选择明确技能，不能重复学习或随机覆盖既有技能。

| 技能 | 效果 |
| --- | --- |
| 威势 `ferocity` | 协战能力数值＋15% |
| 迅捷 `haste` | 协战间隔缩短15% |
| 共鸣 `devotion` | 协战能力数值随感应增加，每点感应＋0.2% |

进化技按物种与阶段确定解锁，不占附身槽；第一次进化加强对应职责，第二次进化改善发动节奏。两阶段有独立技能名称和效果，界面显示已解锁状态以及真实条件。

| 物种 | 第一进化技 | 第二进化技 |
| --- | --- | --- |
| 烬尾狐 | 余烬凝锋：本源伤害＋15% | 双焰疾行：本源发动间隔缩短10% |
| 磐甲龟 | 玄岩护心：本源护盾＋20% | 磐甲轮转：本源发动间隔缩短10% |
| 露芽灵 | 甘露蕴生：本源治疗＋20% | 新芽循环：本源发动间隔缩短10% |

协战能力基础值分别为攻击5、守护7、恢复5，每级增加0.8；每点感应提供0.2%的感应系数，再乘品阶系数和物种进化技的效果。威势与共鸣再分别乘以自身系数，最终保留两位小数。攻击默认间隔3秒，守护与恢复8秒；迅捷将对应间隔乘以0.85，第二进化技的节奏效果继续乘于实际间隔。效果读取同一份规则，界面不另写一套示意数值。

v1不包含融合炼妖、随机洗资质、改名、放生、宠物交易和宠物装备，这些不计为已经交付的功能。

## 接入边界

- `features/pets/common/`：状态、报价与提交、收益去重、存档校验及协战规则。
- `features/pets/data/`：开放开关、物种、技能及成长参数。
- `features/pets/locales/`：功能文案。
- `features/pets/runtime/`：复用公共暗金面板的宠物列表、详情、培养与确认页。
- `core/GameSession.ts`：组合宠物状态、敌人结算与战斗推进；存档继续通过既有 `SaveStore` / `PlatformStorage`，不新增独立浏览器存储。
- `app/`：暂停菜单中的按需入口与操作路由；不增加战斗HUD常驻按钮，不改变七按钮布局。

旧档缺少宠物字段时补为空状态；已有宠物状态须经过边界、物种、技能、唯一出战、成长和收益记录校验，不能用“未开放”跳过存档校验。感应沿用宠物状态的 `bond` 字段，进化技由物种和已完成进化阶段派生，不新增可独立伪造的技能解锁存档。临时战斗特效不应改变平台选择或资源加载方式。
