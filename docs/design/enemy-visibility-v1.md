# 敌人血条常显与攻击轮廓清理 v1

2026-11-10，版本0.3.5。按用户要求清理怪物攻击示意线，让敌对单位通过常驻红血条和名称与NPC区分。

- 原生招式与旧执行器均取消射击瞄准线、扇形/圆环/矩形范围轮廓、冲锋箭头及范围边框。只移除表现，不改攻击时机、判定、距离、伤害或碰撞。
- 保留攻击动作、实际弹体与短尾迹、命中/受击粒子、可破坏的技能物件。实际持续危险区域保留火焰、尘雾或能量效果；远处区域也保留一个低成本效果，不因去掉边框而完全隐形。玩家自己的攻击与技能预瞄未修改。
- 当前画面范围内的存活敌人持续显示红血条、名称与等级，不再依赖接战、受伤、10米距离或3.2秒倒计时，也不以玩家的视线遮挡决定是否隐去血条。
- 只为`state.enemies`中的敌人显示血条；友方工匠、NPC与演出人员不混入。死亡目标完成短促扣血展示后收起，离开画面则释放显示槽；返回画面重新显示。
- 只为画面内单位分配血条，池上限与现有遭遇的200单位上限一致，避免旧24条限制让人群中的部分敌人没有血条；没有增加实际怪物数量。边缘血条留在可视区域，菜单、演出与竖屏提示期间仍按HUD规则隐藏。

复用现有Cocos Camera、Graphics、Label、UIOpacity、粒子和弹体表现，无新增依赖或平台API。血条根节点按严格有效性重建，避免旋屏时使用等待销毁的节点。

验证：类型检查、既有102项检查通过。桌面1280×720和手机915×412实测，13米外未接战的3只怪物在4.6秒以上仍常显满血血条；受控人群场景的32个目标全部有血条（画面总计35条），死亡和离开画面后正确收起。实际喷吐攻击仍释放弹体并扣除玩家生命，记录中只存在短弹体尾迹，没有长攻击轮廓；3名友方工匠均无敌人血条。手机旋屏恢复通过，浏览器无错误。压力场景属于显示复核，未作为新增游戏遭遇发布。

结果与截图：`src/cocos/test-results/enemy-display-v1/`。TapTap平台与真机表现仍待验收，浏览器复核不代替设备结论。
