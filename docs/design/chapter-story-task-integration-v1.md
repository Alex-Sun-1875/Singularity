# 章节故事与任务合并 v1

日期：2026-11-16。当前正式可玩内容仍为第一、第二章。

本记录保留章节数据与简介契约；界面组织以后续的[冒险日志与地图 v1](adventure-journal-map-v1.md)为准，原窄幅三页签不再作为最终方案。

## 展示与内容边界

章节简介与该章真实任务放在同一任务入口内，便于先了解故事，再查看目标、首领进度与已完成任务。章节展示统一读取 `journeyChapterDisplay(chapter)`，不直接把后续章节的内部规划名用作已制作内容。

| 章节 | 对玩家显示 | 当前故事与任务 |
| --- | --- | --- |
| 第一章 | 兽潮之夜 | 石桥镇兽潮、渡口遗物、磨坊、灰披营地与采掘廊；最终挑战灰披队长。 |
| 第二章 | 群山战火 | 工位保卫、采坑证人或货签、前哨多解法、三誓阵；最终挑战守桥铠卫。 |
| 第三章 | 敬请期待 | 说明故事和任务正在筹备、宠物计划随本章正式开放，不添加未设计剧情。 |
| 第四至八章 | 敬请期待 | 仅说明新的旅程正在筹备，不展示计划稿中的剧情、任务或奖励。 |

第3—8章继续 `available:false`；本轮没有添加这些章节的地图、任务、奖励或通关路径。八章规划文档仍是规划资料，不能据此将未制作内容标为可玩。宠物计划从第三章开放也不代表当前开放第三章；宠物开放由独立规则检查真实已开放章节，不能用角色等级或第二章通关代替。

## 数据契约与兼容

- `features/journey/data/ChapterJourney.ts` 保留章节 ID、首领、战场、等级、任务目标、奖励和真实首领击败判定。
- `journeyChapterDisplay(chapter)` 提供 `id`、`name`、`title`、`story`、`available`；第三章标题为“第3章 · 敬请期待”。未来章节的内部规划名保留供内容维护，不参与当前展示。
- 中英文简介随 `features/journey/locales/ChapterStoryText.ts` 维护；游戏界面沿用当前中文展示规则。
- 已有任务完成凭证、导航、奖励与回看记录无需迁移；不存在未来章节的伪任务或提前领取入口。

## 验证范围

数据与词库接入后 `npm --prefix src/cocos run check:core` 通过。章节页与任务页合并的实际画面、触控及平台验证随本轮整体界面验收记录，类型检查不替代运行验收。
