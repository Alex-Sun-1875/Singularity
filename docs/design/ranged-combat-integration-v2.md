## 当前实现

- `ChapterGame`读取选中技能的真实等级、射程、选点方式与几何，不再把所有目标夹到1.2—4.5m。超距/遮挡显示无效预瞄，松手不合法时不自动走近。
- 键盘Q/E/R/T（或1—4）对应四主动，G终极，空格固定闪避；C战斗技能、V属性、B装备。手机按住技能拖动、松开释放，拖入取消区/失焦取消；左右手移动和瞄准各有指针所有权。
- 手指开始拖拽时保存世界目标、相机平面基向量和输入比例。镜头拉远或角色移动不会重新投影旧目标；新手指位移才更新目标。
- `RangedCamera`只决定呈现，判伤不读取相机。它采样本人、远处走廊/交叉条/矩形/扇区/圆盘的边界，沿固定观察角平滑取景。常规战斗正交半高至少6.8m；最大作用区连续扩大可用画幅，优先保留人物可读尺寸，场景略向左构图避开右侧操作区。没有改变人物世界比例。
- 原生投射物从起点真实飞行，障碍/不同层先截断；预瞄、权威事件和最终渲染分开。BOW02首击后才出现子箭，THU02/04/05只渲染权威选中边和当拍接点。火系覆盖所有合法范围目标，没有隐藏5人上限。
- 受击敌人察觉范围扩到30m，近战沿现有导航接近；弩手14m起手、18m弹程，释放时复核遮挡/同层。18m瞄准线沿锁定方向逐段截断，不穿墙画假射线。F13固定弩台的专属36m射线独立复核各自遮挡，不修改普通弩手射程。
- 每次升级自动加5最大生命、1.5基础技能威力、3属性点；到门槛自动解锁/进阶。安全检查点分配/重配属性与配置四主动、一终极、两被动。COM02治疗必须占一个主动槽。
- 技能本身不耗专注或符纸。用户后续界面要求恢复的生命药、火油、检查点补给独立保留；它们不变成额外技能槽，也不改变终极蓄能与45秒共享锁。
