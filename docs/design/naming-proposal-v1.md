# 《剑与火》命名提案 v1

2026-11-02 · **仅供挑选的候选，不是已采用设定。** 本轮只建立此提案；人物稿、主线、地图标签、商人账户及运行数据均未替换。

## 方向

问题不在于名字不够长，而在于旧名多数像临时标签：石桥、灰石、沉桥；再不断用“誓”给人物和遗迹加气氛，整个世界就缺少自己的称呼。

这一版采用**自然的人名＋有专名的大地名＋少量有画面的俗称**。人物名字能在争吵、招呼和战斗中直接叫出口；城镇听起来有人生活，不是每个地方都叫“某某遗迹”。不靠给每个名字塞满“欧、斯、尔、亚”制造西幻感。《剑与火》不改名。

## 二、世界：专名和地貌各占一半

| 对应位置 | 旧名 | 候选名 | 日常称呼／命名作用 |
| --- | --- | --- | --- |
| R1 地表大区 | 石桥边地 | **维兰边境** | 维兰。先有地方的名字，再说明它是边境；不是把一个桥名放大成全区。 |
| R2 地表大区 | 沉桥高地 | **鸦脊高地** | 鸦脊。用山脊轮廓建立画面，保留矿区、岩林和跨谷道路的地理感。 |
| R3 地表大区 | 沉钟河湾 | **洛汀河湾** | 洛汀。地表是有日常生活的河湾，古钟的秘密留给地下，而不是全区都背着主线谜底。 |
| R4 地表大区 | 灰石城域 | **卡德林城域** | 卡德林。城市有自己的专名，不以石材颜色命名。 |
| U1 独立地下网络 | 旧誓下城 | **诺温下城** | 诺温。先让这里像一座曾有人生活的地下城，再由玩家发现它的历史。 |
| U2 独立地下网络 | 沉钟地宫与旧水道 | **钟渊** | 地图说明仍写“地宫与旧水道”；主标签简短，给共振古钟和深层遗迹留下辨识度。 |
| S01 核心镇 | 石桥镇 | **榆冠镇** | 榆冠。保留朴实、能住人的小镇气质，但不再是工程设施标签。 |
| R4 城市本体 | 灰石城 | **卡德林** | 与大区使用同一专名，不另造一个近似名称。 |
| R4 内堡 | 灰石堡 | **卡德林内堡** | 保持城市与内堡的归属关系；不暗示内堡是另一座城市。 |

“诺温”“榆冠”等目前只作为名称候选，不据此追加古王朝、标志建筑或资产需求。其他矿井、工坊、岗哨暂不逐一花式改名：**大地方需要记忆点，普通设施需要看得懂。** 地理连接、地图编号、入口条件与空间规模完全不变。

## 三、组织与主线称呼

| 旧称 | 候选称呼 | 处理理由与边界 |
| --- | --- | --- |
| 散旗探队 | **无旗探队** | 是临时结伴者的叫法，不意味着玩家已宣誓入会，也不自动变成固定四人队。 |
| 灰石征掘军 | **卡德林守军** | 使用现实世界内能成立的公开名称；征掘、征用与夺取遗迹仍是其行动，不必全塞进组织名。 |
| 白枝余誓者 | **守灯人** | 对地下这批人的俗称，不是新宗教或必须终身承担的职责；他们仍各有立场，也能离开。 |
| 白枝第七远征 | **鸢尾第七远征** | “鸢尾”提供远征组织的辨识；首次可写“鸢尾远征团的第七次远征”，其后简称“第七远征”。不新增另一支失踪探队。 |
| 昼核 | **白昼** | 人类给那种古老非人生命的称呼，不是它已确认的自称。少一点能源核心的物件感，多一点“地下竟有白昼”的奇异。它仍不是神，也不新增说人话或许愿能力。 |

白枝金属先保留为材料名，不因远征改名而全局替换“白枝”。沉钟也可以继续是古代共振器的描述；只移除它在地表大区、地下网络、建筑名上层层重复的用法。名称中的“灯”不增加守灯人必须守下去的剧情义务。

## 四、放在一句话里听

> 莉赛特在榆冠镇等你。加雷特已经去了鸦脊，奈芙留下的足迹却一直通向诺温。

> 温德尔想先听钟渊的回声。康拉德只问了一句：谁能把“白昼”带回卡德林？

这些只是称呼试读，不增加人物位置、任务前置或已发生的剧情。重点是玩家能自然说出“去鸦脊找加雷特”，而不是背一串同音长名或“灰烬断誓某某”的称号。

## 采用边界

- 本案是一套推荐，不再堆多套近似备选让用户替我们做筛选。先判断整套听感，再决定哪些保留或调整。
- 自然人名可能与现实人物、常见译名或其他作品重合；这里不声称独创、商标可注册或已做名称清查。没有以照搬特定游戏角色、地点为设计方法。
- 若获认可，再按本表同步人物、主线、地图、界面显示名和交叉引用；历史稿须明确保留版本，不做无差别全库字符串替换。
- 本轮停止于命名提案。未修改正稿，未改剧情、数值、商货、代码、图像或地图拓扑。
