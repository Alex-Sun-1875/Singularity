## 经验日限与材料补偿

普通 test/release 按当天首次推进时的等级锁定共享刷怪经验额度，北京时间零点刷新。手动、自动与在线挂机共享；挂机保留 1,000 子限及原分段经验衰减。

| 日初等级 | 共享战斗经验额度 |
| --- | ---: |
| 1–5 | 1,000 |
| 6–10 | 1,500 |
| 11–15 | 3,000 |
| 16–20 | 6,000 |
| 21–79 | 沿用每 10 级增加 1,500 的现有规则 |

达到共享额度后，后续真实击杀改为强化材料加成；挂机达到其子限时，挂机击杀也有该补偿。普通档满 80 级同样获得材料加成。宝石保持基础掉落节奏，任务奖励不乘倍，不新增离线结算。

| 敌人 | 基础强化石收益 | 经验满额后的强化石收益 |
| --- | --- | --- |
| 普通怪 | 约 3 次真实击杀 1 枚 | 每次 1 枚 |
| 精英 | 每次 1 枚 | 每次 2 枚 |
| Boss | 每次 3 枚 | 每次 6 枚 |

dev 仍使用独立存档、正常技能冷却、怪物经验 ×5、每日经验不限及既有 Boss 高阶装备规则。dev 不享受普通档的满额材料补偿。

## 强化材料与宝石

| 强化石阶级 | 适用目标强化等级 |
| --- | --- |
| Ⅰ | ＋1–3 |
| Ⅱ | ＋4–6 |
| Ⅲ | ＋7–9 |
| Ⅳ | ＋10–12 |
| Ⅴ | ＋13–15 |

每次强化消耗 1 枚对应阶强化石，并保留原金币、铁、符纹和锻造芯费用。3 枚低阶石可付少量金币合成 1 枚高阶石，Ⅱ／Ⅲ／Ⅳ／Ⅴ阶合成分别在角色 12／25／40／64 级开放，工坊提供库存、合成与费用预览。

宝石沿用Ⅰ–Ⅴ阶、属性、镶嵌和 3 合 1 规则，新增直接获得完整宝石的真实击杀来源：普通怪约 8 杀 1 颗、精英约 3 杀 1 颗、Boss 每杀 1 颗。掉落按实际怪物等级及当前开放章节限定，第一、二章主要为Ⅰ／Ⅱ阶；dev 80 级不会把低阶怪变成顶阶材料来源。

任务现场步骤与主线阶段分别沿真实来源给予对应阶强化石和完整宝石，界面展示培养奖励。材料和宝石直接自动收集到各自材料包；这不是装备地面实体。重复尸体、读档和重复交付均不能再领；宝石库存满时进入现有待领流程。

## 连续任务

一次启动后持续赶路、战斗、拾取、调查和交付。多分支、骰子与机关等待玩家操作，完成后继续原队列；选“稍后”会暂缓该项，避免重复弹出。机关下一控制台由玩家从日志指定，自动任务不读取答案。

公开支线按任务目录纳入，隐藏支线仍需真实发现；未访问地点的独立探索不自动泄露。证据任务能先导向真实首领，和平退役、休眠敌人及已核验线索不会变成永远无法完成的待办。满级或普通档经验封顶不停止任务，已知任务全部完成后明确结束，不转成无限刷怪。
