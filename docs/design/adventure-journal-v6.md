# 地图与任务面板 v6

2026-11-16。按用户确认的 [v6 设计稿](../../source-art/ui/adventure-journal-v6/README.md)接入当前 Cocos 工程。此版覆盖 v1 的页面布局；只读任务模型、剧情、奖励、迷雾与导航规则继续复用。

两页共用 766×354 逻辑基准浮窗、64 高页头、左侧公共返回箭头和“地图／任务”文字页签。任务页使用 228／494 分栏、深色正文、独立滚动、隐藏已完成及章节内的主线／支线／回看；详情保留真实故事、行动、选择与奖励入口。地图页独立使用图例96／地图526／传送点100三栏，间隔8，不保留任务树或另占80高的底卡。世界、区域与现场切换放在“地图模式”菜单中，具体任务与自定标记的明确操作留在地图底部。

传送点按本次确认的28逻辑像素连续行命中，选中框高22；只有该列表使用此紧凑例外，不叠加重合的48热区。列表独立滚动，传送保留48触区并固定右栏底部；正常列表高192，受限／错误提示出现时列表减高32，按钮位置不变。其余独立操作保留至少48触区。大横屏按浮窗比例扩展，实际安全区继续参与布局；28行的浏览器触控检查与TapTap真机验收分开记录。

第三章及后续仍显示“敬请期待”，没有新增剧情、地图、任务或奖励开放；宠物仍由既有发布与真实进入条件统一关闭。

实现入口为 `AdventureJournalPanel.ts`、`MapPanel.ts` 与共用 `GoldPanelHeader.ts` 的可选左返参数；没有新增运行依赖、测试框架或平台接口。正常test网页导出不升版，也未制作或发布小游戏包。
