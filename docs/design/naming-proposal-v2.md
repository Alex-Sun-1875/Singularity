# 《剑与火》命名提案 v2：让名字在世界里有来历

2026-11-02 · **新一轮候选，未采用，未迁移。** 只新增本页；《剑与火》、现有角色身份、剧情正稿、地图标签和运行数据均不改。v1 的一批名字不再作为本轮推荐。

参考《博德之门》的不是几个音节，而是名字的层次：有人用普通本名，有人被职业圈用姓称呼；城镇可能记住一个普通人的名字，居民俗称也可能与官方说法相反。**人物不必名字即命运，地名也不必一听就泄露真相。** 以下只推荐这一套，不列同音近义备选。

## 一、八个人：先能叫出口，再让名字背得起经历

“既有依据”来自 [v4 人物稿](../story/revision-v4/characters.md)；“新增用法”是本轮提案，不冒充已有情节。姓氏用于契据、旧名录、书信等正式场合，不要求玩家背全名；不据姓氏新增贵族血统或家族支线。

| 旧名 | 新名候选／日常叫法 | 与已有背景的一句话联系 | 新增用法，尚未采用 |
| --- | --- | --- | --- |
| 艾妲 | **维蕾塔·奎因**／维蕾塔 | 寻宝佣兵兼远征经纪，失败后失去信用，却仍要找回共同分赃契据。 | 她给探队起过许多响亮名字，但旧败约、新契据都签同一个“维蕾塔·奎因”：这次不换招牌躲债，也不把别人应得的份额抹掉。签名不成为机关钥匙。 |
| 布兰 | **奥斯温·赫尔**／奥斯温 | 退役誓卫兼铸匠，曾守过封门，如今必须承认旧规矩也保护过错误。 | 旧军籍写“赫尔”，镇上叫“奥斯温师傅”；菲恩后来第一次直呼“奥斯温”，让称谓体现师徒变成平等同伴。另一个可选伏笔是阵亡名录上还有同姓者，而他暂不愿解释是谁；这只是新增悬念，尚未决定是否亲属，也不应取代他对封门责任的坦白。 |
| 蕾萨 | **苔丝**／苔丝 | 古兽追踪者，给兽起绰号、给危险地标起笨名字，却反对把生命据为己有。 | 保留一个没有长姓和神秘称号的普通名字；她可以自我介绍“苔丝。别叫我猎兽大师。”不设待揭晓的真名、被删去的家族或强制身份反转。 |
| 墨伦 | **西里安·佩尔**／西里安 | 回声学者曾因不成熟的发现被嘲笑，仍渴望让一种发现以自己命名。 | 学术争论里叫“佩尔”，同行叫“西里安”；遗迹可能证实他那篇被嘲笑的论文的一部分，也可能迫使他更正另一部分。旧论文和更正稿保留同一署名，不把一次发现写成他终于全对了；文书不增加必读前置。 |
| 娜薇 | **奥黛·莫兰**／奥黛 | 古物商熟悉旧航路，做过避开封锁运送藏品与人的生意，最后想离店去学舞。 | 客人称“莫兰女士”，旧航路上的熟人叫“奥黛”；她可能认得某些旧航图上被抹去的记号，未必愿在柜台前解释。熟悉旧航路是已有背景，具体哪张图、哪次运送仍是待定提案；结尾可以不再把她和店名捆成一个称呼。 |
| 伊洛 | **菲恩**／菲恩 | 年轻测绘师急于摆脱“布兰的徒弟”，喜欢把北向箭头画成鸟。 | 同行打趣叫他“倒鸟”，来自他自己会拿反的鸟形北标；他在地图上坚持署“菲恩”，外号不代替本名，也不凭空赋予鸟类魔法。 |
| 埃林 | **塞蕾娜·维斯**／塞蕾娜 | 第七远征幸存者被宣布阵亡，却还在地下带同伴承受真实危险。 | 地表阵亡记录与地下新绳签出现同一个全名：玩家先核对名字，再认出活人；她不以“第七守望者”取代姓名，也不因带队而失去离开的权利。绳签姓名是新增载体，幸存与封口是真正已有背景。 |
| 洛德里克 | **埃德蒙·瓦洛**／埃德蒙；公务中称瓦洛守备长 | 守备长亲自倒酒、欣赏探险者胆识，却要求独占昼核与所有人的退出权。 | 城内人说“瓦洛守备长”时可以是真心信赖；礼貌的本名不预告反派，直到玩家比较他署名的防务许诺与扣押命令，才判断这个名字意味着什么。无额外世袭头衔。 |

“倒鸟”只是熟人间偶尔出现的外号，不是所有 UI 都要显示的职业称号。其余人不硬凑一套“断誓者／逐影者／守灯者”；有些名字只是父母给的名字，也应有位置。

## 二、七个地方：不同年代的人，留下不同称呼

地理依据为 [v3 地理合同](../maps/world-geography-v3.md)；主线依据为 [v4 设定](../story/revision-v4/story-bible.md)。**下表所有新名称的具体词源、地方掌故及其发现载体都是新增提案。** 它们借用已有场景安放细节，不新增区域、通道、谜题前置、家族或需要击败的历史人物。

| 对应位置／旧名 | 新名候选／口头叫法 | 已有依据 | 名字的来历与玩家能发现的细节（新增提案） |
| --- | --- | --- | --- |
| R1 石桥边地 | **阿维恩边地**／阿维恩 | 西部边地有驿路、旧军需站、石塔、镇村与采石地。 | 阿维恩原是一位测路人，后来被旅店故事讲成开疆骑士；旧驿站留存的路线抄本与碑像手中刻尺能让玩家看出，他著名的“长剑”其实是量杆。名字承载被民间讲错的小历史，不另立一个王朝。 |
| R2 沉桥高地 | **长阶高地**／长阶 | 矿业聚落、露天采面、山脊哨路、矿桥及高差道路已经存在。 | 最早指沿采面修出的搬矿阶路，后来泛指整片高地；新商路已有车道，矿工仍说“上长阶”。现有采面可留下旧踏步与近代车辙并置的痕迹：名比道路更长寿，不把整张地图改成楼梯。 |
| R3 沉钟河湾 | **归帆湾**／归帆 | 河埠镇、农庄、湿地、码头、灯油作坊与搁浅船场已经存在。 | 老码头有为归航者留灯的习惯，河湾因此得名；码头也留着未归船只的纪念牌。白灯普及后，小作坊还在卖带船名的旧式油灯：既有温暖的归来，也容得下没等到的人，不是每一盏灯都关联昼核或隐藏任务。 |
| R4 灰石城域 | **维庸城域**／维庸 | 有城墙、外城聚落、工坊、文书院、军营与内堡，不只是一座堡。 | 维庸是早年主持修墙的匠师之名；现今庆典把他塑成持剑的城主，石匠留下的旧工记却只认得一个会算工钱的同行。城的历史不必只属于掌权者；不据此断言现任守备长与他有血缘。 |
| U1 旧誓下城 | **无暮下城**／无暮 | 地下有居所、工坊与深层炉厅；有人被宣布阵亡、扣押劳动，冷白灯长期不灭。 | “无暮”是地下人自己的叫法：不熄灯曾像祝福，后来意味着迟迟等不到下工。居所门边被反复补画的日落，是玩家能看见的反差。名字不意味着时间停止，也不提前给出昼核的全部真相。 |
| U2 沉钟地宫与旧水道 | **聆听之庭**／听庭 | 旧水道、档案廊与古代共振器并存；共振器曾用于与非人生命交流，而非召魂。 | “聆听之庭”是研究者对一段残缺古称的暂译，不是已破解的原文；最初大家以为是受命倾听神谕的地方，记录与现场对照后才发现，设施也在等待另一方回应；玩家需要分清听见的是旧回声，还是当下真正的回答。原名是否准确仍可保留争论，不新增神祇。 |
| S01 石桥镇 | **贝拉渡**／贝拉渡 | 镇内已有旅店、行会、铁匠街、渡口街与仓院；桥梁与渡运可以并存。 | 名字来自一位叫贝拉的摆渡人；桥修好以后，人们仍说“去贝拉渡”。旅店喜欢把她讲成贵妇，渡口旧价牌却显示她只是个认真收船钱、会把绳索借给陌生人的船主。故事到这里就够，不必再给她隐藏王族身份。 |

R4 城市本体相应候选为“维庸”，内堡为“维庸内堡”，不另外制造第二座近名城市。U2 首次标注可写“聆听之庭｜地宫与旧水道”，使地理功能仍清楚；“听庭”只作熟人间简称。七地之外的矿井、仓库、岗哨先保留能读懂的设施名。

这组有普通地貌名“长阶”、生活愿望“归帆”、小人物遗名“贝拉渡”、被改写的城市记忆“维庸”、地下俗称“无暮”及不确定译名“聆听之庭”。不让每处都有一位死去的神，也不让所有名称都解释主线秘密。

## 四、本轮边界与核对

- 既有依据只取 v4 人物／主线及 v3 地理；新词源、签名、俗称和可发现载体已逐列标明为提案。它们并未写回世界正稿。
- 不新增第九位主要人物；阿维恩、维庸、贝拉仅是地方掌故候选，不自动需要模型、支线或资产。本轮不制作任何图像、代码或地图。
- 五个商人账户仍对应原艾妲、布兰、蕾萨、墨伦、娜薇；新名字不成为稳定身份键，不改库存、数量、报酬与唯一货源。
- 不调整主线、地图编号、入口条件和人物权利边界。特别是无暮没有时间魔法，听庭没有神谕能力，贝拉渡没有新增渡船捷径。
- 本轮没有迁移 v1 的组织名、远征名或昼核称呼；这些仍按各正稿现状保留。若用户认可这套名字，再单独同步正稿和地图显示名，不无差别替换历史文档。
