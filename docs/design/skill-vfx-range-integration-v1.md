# 技能范围与连击特效接入 v1

2026-11-10。按用户确认的亮芯、橙色焰体、快速退亮方向接入火系效果，同时增强近战三段连击。视觉层读取实际施放事件保存的等级与范围，表现、判伤和预瞄使用同一份几何。

## 接入内容

- 普通剑三段为顺斩、反斩、收尾重斩，动作时长0.38／0.38／0.56秒，释放时刻0.12／0.12／0.22秒。每刀仍为原24基础伤害，三刀总时长1.32秒，与原三次0.44秒预算一致；每刀同目标最多命中一次。长按连续出刀，后摇末0.12秒允许一次输入缓冲，停顿超过0.45秒或打断后回到首刀。
- 新增两段原生骨骼动作，复用已有Quaternius UAL2 CC0资源，与前刀末姿态进行0.08秒入段衔接。已有主角模型、碰撞位移和存档不包含临时连击状态。动作来源、映射、哈希见[来源记录](../../source-art/characters/player-melee-combo-v1/provenance.json)，[可复现导出脚本](../../tools/model-pipeline/build-player-melee-combo.py)。
- `MeleeSkillEffects`作为普攻和破军战技的共同刃面／命中闪实现。银白亮锋、透明银金刃面、微弱前刀残影和收尾地尘增强节奏，厚度向范围内部增长。刃面锚点对齐1.08米的挥剑高度，避免低位刃光被近身目标遮没，亮锋向内加厚而不扩范围。普通剑仍为1.45米、110度；破军扇面、十字并集和圆盘分别服从真实几何。十字每一段都显示两臂，不把多段误画为交替单臂。
- 火爆沿真实圆盘显示错深卷焰和局部火冠；落焰二次爆发降低亮度但保持同一判定范围。炎墙沿真实宽、深显示双排交错火舌，火浪前缘按矩形推进，低位余焰在真实场范围保留至结束。前缘尚未到达的地面不提前铺满火海；卡片根部与端点服从地形和视线遮挡。
- 火焰新增4张512×512透明生产材质，PNG合计509,392字节；来源为云端内置OpenAI image_gen，Pillow仅执行等格裁切、底部透明衰减、等比缩放和脚锚对齐。保留[原图、提示词与生成记录](../../source-art/skills/fire-runtime-v3/provenance.json)和[确定性处理记录](../../source-art/skills/fire-runtime-v3/processing.json)。生成成功、内部原画检查、运行检查与用户美术验收分别登记。
- 雷系沿真实连接绘制，移除暗示额外伤害的大面积落地云。直线雷击即使未命中也显示本次实际走廊，遇墙截短；走廊抖动、分枝限制在宽度之内。弓箭继续复用实际弹体及已飞轨迹。
- `SkillVfxGeometry`集中解析事件几何，保留显式零值及十字角度数组，旧调用仅回退当前技能目录。`FeedbackPalette`继续统一命中颜色；减少动态效果开关同步关闭残影、精简接点并降低火焰亮度。

## 引擎与资源约束

复用项目已有Cocos内置透明Unlit材质、Mesh、Line、资源加载层及原生预烘焙骨骼动画，没有新增运行库、后处理或粒子引擎。参考[Cocos 3.8骨骼动画文档](https://docs.cocos.com/creator/3.8/manual/en/animation/skeletal-animation.html)及已安装引擎接口。资源池上限仍为24刃面、64火焰卡片，网格／材质缓存有界；切区、取消、调试改级和销毁清理临时表现。
