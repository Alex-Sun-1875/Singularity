# 怪物行为复核与三刃守誓阵优化

2026-11-12，当前 Cocos / TapTap 小游戏工程。用户反馈三刃守誓阵像木桩，本轮复核全部56个运行身份，修正追击、距离选择、冷却站位及碰撞寻路；不提高生命、等级或奖励，不改手机帧率设置。

## 查明的问题与修正

| 问题 | 原因 | 当前行为 |
| --- | --- | --- |
| 三刃阵无法走动或转身 | `ELITE_06`速度/转速为0，`stationary:true`，朝向固定出口；30米第三剑沿同一轴线空放 | 共享底座以2米/秒移阵，正常寻路追击；每段出招追踪至末段锁向，锁向后可横移躲避 |
| 部分锁道精英在远处反复空放 | 起手距离绕过了持续区域的实际长度，6米锁道被当成12米有效攻击 | 施法者原点的地面区域也按实际几何距离起手；没有够得着的技能时走近 |
| 等技能或攻击名额时发呆 | 所有招式冷却时直接idle；等待名额时仅部分怪群近战允许移动 | 冷却及等待阶段按自身理想距离调整，保留完整后摇；远程可拉开，近战逼近 |
| 技能距离空档时选错招式 | 默认选择循环第一招，即使另一招需要更少位移即可生效 | 优先当前够得着的技能，否则选离合法攻击距离最近的招式；半血队列保留 |
| 看得到玩家但卡柱 | 仅在视线被挡时寻路，没有处理身体半径与点射线的差异 | 实际移动不足期望的25%时请求既有导航，下一帧绕行；路径/失败结果缓存0.5秒，目标移动超过2米失效 |
| 某些直接命中没有拉到单体仇恨 | 持续仇恨仅覆盖部分法术来源，普通箭/近战靠初始警戒范围 | 实际扣血统一给予该目标20秒受伤警戒；已有怪群协助和有界追击继续生效 |

## 三刃阵的节奏与呈现

近身仍是第一剑扇形→第二剑直刺→第三剑地斩，各段保留0.90/0.85/1.10秒起手、原锁向/伤害和1.80秒最终收势。第一段起手距离2.8米，第三剑由历史30米固定轴适配还原为5米；半血仅第三剑带既有缺口扇形，同段图形共用一次命中账本。

4—12米使用“守誓追斩”：1.25秒起手，最后0.40秒锁向，12×0.9米地斩，基础伤害20，收势1.80秒，冷却7秒。冷却时接近玩家并切回近身三段，远处不能永久站定无伤射击。每群最多2只同时出招、全场攻击费用上限3继续生效，出手/收势期间不随意取消动作追人。

复用已绘制的四向及三次剑击，追斩明确映射第三剑姿态。底座整体滑移，未伪造行走帧或新骨骼；仍是一份生命与掉落凭证，未拆成三个独立敌人。按此前[攻击轮廓清理](enemy-visibility-v1.md)，保持取消范围线：起手增加局部刀身蓄光，释放时显示实际剑痕，不恢复长瞄准线或范围边框。独立雕像锚点、更多过渡姿态与用户美术认可仍是素材边界。

复用项目已有`EnemyCombat`阶段执行器、`Navigation`、碰撞查询、原生粒子/Line和角色图集。已核对[Cocos 3.8动画能力](https://docs.cocos.com/creator/3.8/manual/en/animation/index.html)及[动画状态](https://docs.cocos.com/creator/3.8/manual/en/animation/animation-state.html)；当前图集与权威战斗阶段已有完整接线，引入新的AI/动画库不会补齐缺少的绘制姿态，因此以现有执行器的接入与规则修正实现，没有新增依赖或平台API。生成器和导出资料同步，重新生成不会恢复固定木桩配置。
