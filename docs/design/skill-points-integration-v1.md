# 技能点成长接入记录

2026-11-10。按[第二章全技能开放方案](skill-points-progression-v1.md)接入Cocos主工程。角色达到第二章阶段（通常Lv11）时，30个技能全部免费开放为1级；角色升级不再自动提升技能等级。每次角色升级获得1技能点，第二章阶段额外2点，40级共41点。2—5级分别消耗1/2/3/4点，与每级3属性点独立计算。

## 实际行为

技能页提供当前等级、下一级变化、点数成本、升级和降级预览、本系重置、全部重置、撤销、应用。预览不修改角色或存档，关闭即丢弃；应用时校验安全检查点、脱战状态、完整预算及预览版本，再一次性保存。重配免费，不恢复生命、不复制点数；跨流派投入共用预算，通用技能不被“重置本系”影响。

HUD、键盘和触控继续使用实际四槽配置，技能图案随槽位移动；未开放和空槽中央仍为空。技能入口仅增加小圆点提示有可分配点数。瞄准距离、施放、被动、特效和存档校验统一读取玩家实际投入的等级，取消原按人物等级自动选技能阶级的接口。满级试玩提供应得点数，不把30个技能全部升满。

现有五阶几何、目标数与伤害组织继续使用；新增断空末刀普攻强化、突袭接斩、护盾破裂保护与反击、战技交替、标记首击削韧、火焰燃烧联动与刷新、移动普攻、雷印第三击与贯雷联动、精准闪避奖励、治疗前置与低血末跳等条件效果。附雷原本没有基础削韧，第三击采用明确额外4点削韧，避免百分比乘零。治疗持续时不能重开首跳；护盾奖励、击杀传播和附加效果按明确次数与内部触发间隔结算。

新增规则在 `core/SkillUpgrades.ts`，复用 `PureCombat.ts` 的实际接触、命中、护盾、治疗和被动路径。`tools/design/skill-points-revision-v1.json` 保存30技能/150阶的参数与文案，经既有导出器生成 `PureSkills.ts`，无需新增依赖。

## 清空测试存档

用户于本轮明确取消旧档迁移，并要求直接清库。本轮只接受新格式成长存档，不导入或迁移旧阶级、点数或进度。

新版本首次启动，在读取存档前删除当前游戏的旧存档槽、旧备份、旧探索图以及此前试验的新格式槽；清理成功后写入一次性标记 `sword-fire.skills-v1-reset`。新存档使用独立前缀 `sword-fire.skills-v1`，下一次启动保留新旅程，不再次清理。删除或标记校验失败时报告错误并允许重试，不伪报已清空。界面偏好与其他应用键不在此次游戏进度库的清理范围。

`PlatformServices.ts` 集中处理平台差异：TapTap使用官方的[读取存储键列表](https://developer.taptap.cn/minigameapidoc/dev/api/storage/tap.getStorageInfoSync/)与[删除指定键](https://developer.taptap.cn/minigameapidoc/dev/api/storage/tap.removeStorageSync/)，并核对已安装官方插件 `tap-minigame.d.ts` 的声明。浏览器预览使用Cocos的 `sys.localStorage`。规则层不依赖浏览器DOM或本机数据库文件。
