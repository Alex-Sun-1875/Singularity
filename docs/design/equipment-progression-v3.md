# 装备五阶造型与后续成长设计 v3

日期：2026-11-06。引擎：Cocos Creator 3.8.8。本文区分**当前真实装备**和**设计图谱**；美术数量不代表可领取物品数量。

本轮按用户确认的“高级装备更华丽，宝石和魔法结构更明显”执行。目标是从普通钢木皮到完整魔法构造的可读变化，长剑恢复可信长刃比例。已有装备 ID、名字、品级、属性、掉落、商人、配方及存档规则不改。没有人物等级门槛；`grade` 只表示品级，不覆盖现有 `ItemDef.level`。

## 当前边界与交付

## 技术与资源选择

检查了项目现有 Cocos 3.8.8、FairyGUI 1.2.2 依赖。目录展示可直接复用 Cocos 的 Texture2D/SpriteFrame 裁切能力；不为装备图鉴引入图集生成器、图片处理依赖或另一套 UI 库。本轮只是原画与切片元数据，不重写装备规则。

通用开源图标和素材包适合功能图标，却不具备本作从普通长剑到雷翼传奇、三条服装路线的连续造型与现有身份匹配；因此核心装备原画用内置 `image_gen` 原生透明生成，以接入和适配为主。无第三方图包或字体许可证引入，未宣称生成物具备额外排他版权。

所有 PNG 从工具输出原字节复制到 `source-art/equipment/v3/` 和 `src/cocos/assets/resources/equipment/v3/`。没有用 Python 绘制、换色、拼接、重采样或抠图。Pillow 仅只读 alpha 测量并写 JSON。首次输出中部分背景雾与边缘过近的问题使用同一内置 imagegen 定向修正；最终选择、提示词、SHA256 在 `generation-prompts.json` 与 `provenance.json` 中保留。

## 首饰与词条预算

首饰五档为行旅旧物→探路与归乡→银叶翠晶→紫月环仪→归星天冠。每档独立戒指与完整项链，普通铁/木/皮绳，精良银与木嵌片，稀有单主宝石，史诗开环紫晶，传奇星钻与完整轨道托架。J03 使用精良戒指，J08 使用精良木嵌银项链；原名与原描述不改。

以下是**未来新增物的设计预算**，不追改当前 A/J 的固定效果，不是已平衡结论。属性使用同一加算池、现有效果去重与历史设计上限；无随机洗词条、耐久、无限强化或通用攻速叠加。

| 品阶 | 单件词条预算 | 条件/机制预算 |
|---|---|---|
| 普通 | 一个基础防护或武器族基础能力 | 无独立触发 |
| 精良 | 基础值＋一个小型确定属性；小槽约胸甲半预算 | 不超过一个易读的常驻/探索效果 |
| 稀有 | 基础值＋一个条件词条，可带一个小辅助属性 | 一个有明确触发窗口与内置冷却的主题效果 |
| 史诗 | 不超过三个有效属性入口 | 一个主机制＋一个辅助条件，不增加连锁层数 |
| 传奇 | 与史诗相近的总属性预算，力量体现在独特玩法 | 一个专属行为转化；不靠五个被动叠数值 |

同类伤害加成总和仍封顶+40%，移动+20%，冷却缩减20%，总护盾30，物理减伤40%，元素抗性50%，额外最大生命+40。一次直接动作最多两个次级伤害事件，次级事件不得递归触发；换装不重置内置冷却。头/手/靴/戒指的直接属性预算建议为胸甲的0.4–0.6，项链0.6–0.8，副手0.7–1.0；未来数值须结合主手占用核定，不把美术品阶当自动数值乘数。

外观路线和历史2/4件套分开：当前 oath/wind/seeker 真实套装成员及效果不变；本设计的“观星”在美术元数据中沿用 `seeker` 分类键仅为图库兼容，不代表把历史寻宝客套改成法师套。后续若引入法师真实套装，必须另起真实套装ID与规则审核。

## 切片与复核

`manifest.json`：`images[imageId].resource` 为 Cocos resources 路径（无扩展名）；`items[artId]` 包含 `image/rect/family/grade/name/materials/features/existingIds`。

- `rect`、`slotRects` 都是**整图左上原点的像素坐标** `[x,y,w,h]`，不先按列等分，已按实际输出和物件位置测量。`slotRects` 的键使用真实槽名：head/chest/hands/feet/offhand/ringLeft/ringRight/necklace。
- `grip` 为相对于该物件 `rect` 的像素握持点；另有 `normalizedGrip`。长剑均以皮柄中央握持，不以图像中心或护手当手握点。
- 透明边缘含细抗锯齿和受控魔法光；`materialBoundsAlpha128` 表示主体测量，不能据此重写alpha。原图无需离线裁切，可由SpriteFrame复用完整PNG。
- 剑板 1620×971，其余六板 1774×887。每款主体高约630–953像素，首饰环与项链分别约230–440像素高，满足小图之外的细节查看。
- 已核对7张 RGBA alpha含0与255，四角透明（杖板左上角仅1/255抗锯齿残值），所有主体alpha≥128不接触上下边缘；来源与运行PNG SHA256逐项一致。35记录、16真实永久装备映射，3消耗符未改。本轮没有新测试依赖或测试脚手架。

原生接入已复用现有构建/检查和手动查看：35记录与7族放大图无串列或拉伸，品阶和旧物件映射正确，设计款只读且不进入库存。7件真实武器已接新版成年身体的四向站/走/跑/攻击与原行囊预览；原库存、掉落、交易和战斗规则保留。验收范围见`src/cocos/test-results/natural-v4-final-audit.json`，不把夹具摆姿当作合法通关。
