# 金币锻造与装备强化方案 v1

2026-11-10 后续设计已改为用户确认的[按品质最多三条随机强化属性](equipment-random-enhancement-v2.md)。本页保留第一版固定收益、金币工费、逐件上限与传承的实现背景；当前Cocos已切换随机强化，见[随机强化接入v2](equipment-random-enhancement-integration-v2.md)。

2026-11-10。**用户已确认设计方向：金币主要用于锻造与装备养成，不同装备具有不同强化上限。第一版已接入Cocos，具体参数和验证见[接入记录](equipment-forging-integration-v1.md)。** 当前只开放第一、第二章；精炼、宝石及后六章扩展仍为后续设计。

装备取得与成长继续遵循[武器与装备成长系统](weapon-system-v2.md)、[八件成长装备](growing-equipment-catalog-v1.md)和[前两章双路线](chapter-journey-integration-v1.md)。本方案替代旧稿中“普通至史诗统一最多＋3”和“换装约返还70%强化材料”的规则。

## 当前金币与锻造

当前运行版已有5名商人、6件限购装备，总价300金币；前两章可到达商人的5件商品合计220金币。购买、强化、传承及锻造工费已接入，出售与买回仍未接入。现有10种锻造配方增加金币工费，首件教学免费，原有材料要求保留。

金币由任务、固定事件、据点、敌人掉落、重复装备兑换及可重复狩猎产出。第一章旅程任务152金币、关底首胜80金币；第二章任务210金币、关底首胜120金币，两章合计562金币。该数值仅统计旅程任务和两章关底首胜，不含其他剧情、战斗或探索收入，不能与旧稿“540金币全程预算”混用。

运行依据：[装备与商货](../../src/cocos/assets/scripts/features/equipment/data/Equipment.ts)、[旅程任务](../../src/cocos/assets/scripts/features/journey/data/ChapterJourney.ts)、[旅程结算](../../src/cocos/assets/scripts/features/journey/common/ChapterJourney.ts)、[掉落结算](../../src/cocos/assets/scripts/features/campaign/common/CampaignLoot.ts)、[购买与制作](../../src/cocos/assets/scripts/core/GameSession.ts)。

## 装备强化上限

品质提供默认上限，每件装备可以按定位配置独立上限；不能把品质上限写死在按钮或界面里。同品质的差异需要连同基础数值、独有效果和满强化收益一起配平。

| 品质 | 默认强化上限 | 培养定位 |
| --- | --- | --- |
| 普通 白色 | ＋3 | 开局过渡，低投入 |
| 精良 绿色 | ＋5 | 前期适当培养 |
| 稀有 蓝色 | ＋8 | 阶段主力 |
| 史诗 紫色 | ＋10 | 持续培养的高级装备 |
| 传奇 橙色 | ＋12 | 长期成长与构筑核心 |
| 神器 | ＋15 | 高投入的长期目标 |

第一版为106件装备配置了有效上限，稀有的银弦手套A10为＋6，同为稀有的洛恩旧盾W15为＋8；精良的探险家印戒J03为＋4。任务、狩猎和Boss的同档奖励保持相近的综合培养价值，不统一压低某条路线的上限。

**当前可强化上限＝min（装备自身上限，当前阶段开放上限）。**

| 阶段 | 阶段开放上限 | 范围 |
| --- | --- | --- |
| 第一章阶段 | ＋3 | 白装到神器均检查各自上限 |
| 第二章阶段 | ＋6 | 白装最高＋3、绿装最高＋5；其他默认装备可到＋6 |
| 后续章节 | 逐步开放，最终支持＋15 | 随后六章内容配置；当前运行范围不预先开放 |

阶段跟随已达到的角色成长阶段永久开放。第二章按现有Lv11开放条件处理，任务与狩猎路线一致；不额外要求接约、完成任务链或击败关底。返回第一章不会降低已开放阶段和既有强化效果。

装备详情同时区分当前强化等级、当前可强化上限和装备自身极限。例如第二章的一件传奇显示“当前＋6，阶段可到＋6，装备极限＋12”。达到阶段上限后保留装备，后续阶段开放再继续培养。

## 锻造与强化

**锻造制造指定装备，强化改善已有装备。** 锻造消耗已学图纸所需材料与金币工费，成品、独有效果及总费用在提交前可见；教学首造免费。图纸属于永久知识，锻造不再次消耗图纸。

强化消耗金币与废铁，确定成功。费用同时随强化等级和装备品阶递增；首轮优先复用现有废铁、符纹与锻造芯，新增材料需有独立玩法价值和可靠来源。各阶收益明确，不改变穿戴等级或装备品质。

- 武器提升基础武器强度，使普攻与兼容主动技能读取同一份强化结果。
- 防具提升配置的基础生命或防御。百分比减伤等属性继续遵守现有对应上限，不因强化等级高而突破。
- 首饰提升指定的数值属性。缺少合适基础属性的物品需逐件定义强化收益，不能出现付费后无实际收益。
- 传奇、神器继续按人物等级自动成长，强化是独立的额外培养，不收取自动成长费用。
- 独特触发机制、命中次数、目标上限、触发间隔与额外掉落机会不随强化自动放大。
- 双手武器与单手加副手按相近总收益和培养成本配平，不能因多一个可强化槽位就多出整份输出预算。

每阶收益按装备总预算调参，不继续沿用旧稿“每阶固定增加2装等”。原第一章阶段装强化后仍属于第一章阶段；高强化也不会自动生成传奇、神器或新的唯一装备。

## 换装传承

换装备时通过少量金币转移强化经验，保留玩家的强化投入。经验是持久培养进度，与已支付金币、材料和手续费分开记录，不按换装时的物价或折扣重新生成经验。

1. 选择同装备部位的来源和目标；目标必须已拥有，支持在安全状态更换流派武器。
2. 预览来源转出、目标按自身曲线结算后的强化等级、保留经验及金币费用；目标已有经验时展示合并结果。
3. 确认后转移经验并清除来源对应经验。目标按自身上限及阶段上限生效，超额经验保留，后续开放可继续使用。
4. 原装备本体、来源、原生特效和免费骰印记录保持归属；目标不会获得来源装备的传奇机制或额外掉落奖励。

强化进度只能转移一次持有，不能在两件装备之间复制。转出后的来源仍是原来那件装备，不重新生成免费锻印机会。传承经验不兑换金币或原材料；若以后增加强化材料返还，必须与同笔经验转移互斥，不能同时传承和返料。

把高上限装备传给低上限装备时，超额进度仍保存，允许日后转出；不能静默删除。反向传承也按目标曲线换算，不能将便宜装备的“＋6”直接复制为高成本装备的“＋6”。

## 精炼与镶嵌

强化提供稳定基础成长；精炼调整一条附加属性，后续开放金币与符纹消耗、新旧结果二选一以及连续不满意的进度保障。具体属性池和保底次数在该阶段配平，首轮不与强化同时增加多套随机词条。

现有[每件一次的免费骰印](equipment-dice-v1.md)保留。后续整合时保留原始骰面、来源、是否已领取及额外升格装备的唯一收据；付费精炼只改变允许调整的附属性，不重发升格装备、不清除免费领取历史，也不能与同一条骰印收益重复叠加。

宝石镶嵌作为后续阶段的定向培养：少量孔位、明确属性方向，消耗宝石与金币，宝石可拆下复用。宝石详细合成、供给与拆卸费用另行配置，第一版先完成锻造、强化和传承。

## 接入顺序与验收

第一版完成逐件强化上限、前两章阶段限制、锻造工费、强化、传承与完整存档迁移。复用现有装备目录、配方、属性重算、交易、存档和行囊能力，纯规则仍放在Cocos core，内容配置放在data，界面和平台持久化复用runtime适配层。

第二阶段整合精炼与免费骰印，再扩展宝石、商货和后续章节。首轮不需要增加第三方经济库，也不因设计文档增加测试依赖；实施前再按仓库约定检查现成能力。

验收复用现有检查和代表手动流程：

- 白、绿、蓝、紫、橙、神器以及同品质不同配置的物品，均使用正确的自身与阶段上限；到上限、材料不足或金币不足时不扣费。
- 第二章开放和返回第一章不重复发阶段收益；任务、狩猎均可正常开放强化阶段。
- 升级、换装、成长装备自动成长、传承和读档后使用同一份实际属性，低阶装备不能借强化改变品质。
- 高低上限装备双向传承不丢经验、不复制、不重发骰印或额外装备；目标已有强化时合并结果可预览且一致。
- 金币、材料、强化经验、来源和请求收据一并保存。重复点击、保存失败重试及前后台中断不重复扣费；旧档未有强化记录时按零进度迁移，不重置金币和商人库存。
- 当前金币上限为9999；未来增加出售等入账时，超过容量不得静默丢失，也不得产生买卖、拆解与传承之间的返还循环。

界面沿用[布局规范](ui-layout-guidelines.md)，完整养成界面按需打开，关闭后恢复紧凑探索HUD。TapTap持久化、前后台恢复和目标真机需要单独验收，文档与Web验证不作为平台接入完成的证据。
