# 剑与火 三款参考游戏的设计转化

核对日期：2026-11-02。用户明确希望任务参考《博德之门3》，玩法参考《火炬之光》和《斗战神》，重点是探宝、打Boss、获得不同等级与品质的装备，并允许材料合成。本文区分**来源确实支持的特点**与**为单人小项目提出的原创方案**，不是复制清单，也不代表已实现。

本作分工：**BG3提供发现与任务组织方法，火炬提供探索和战利品回报思路，斗战神提供走位与动作空间的参考方向。** 既有原创四章片段由近战、弓、法杖、符咒四条装备路线，加推击、火油与少量机关构成；角色、宝物名、剧情、Boss招式、数值和美术独立设计。

## 可以借鉴但暂不制作

- 程序化宝箱候选与随机普通战利品只在不破坏固定主线、不会使唯一装备丢失的前提下后续评估；当前章节按固定首通保底写清。
- 不做多人经济、拍卖行、耐久惩罚、概率合成失败、付费强化、无限职业树或大队伍叙事。
- 合成与武器等级品质以[装备与合成规格](interactions/equipment-and-crafting.md)为新权威；不是由“参考某作品”一句话推出完整系统。
- 正式美术先验证单角色质量，再按武器动作族扩近战、弓、杖、符咒与副手；同族共享动作，不把独立图标当作已完成攻击动画。旧剑系预算不覆盖新动作。

| [官方伤害类型文档](https://docs.baldursgate3.game/index.php?title=ApplyDamage) | 系统明确区分斩/刺/钝及多种元素伤害类型 | 本作先用7类，并把伤害类型和燃烧/冰缓状态分字段；没有照搬全部13类 |
| [官方Patch 3修复记录](https://baldursgate3.game/news/patch-3-mac-support-magic-mirror-more_93) | 记录了装备授予法术、卸装能力以及重复装备/触发循环相关修复 | 在实时版事先限定次级触发预算、同effectId去重、卸装不刷新冷却和资源，不把回合/短休逻辑直接搬进秒级战斗 |

这些资料支持“类型专属动作、条件能力、跨部位协作”的借鉴方向；本作6套2/4件计数、数值、专注自然恢复、无限普通箭及一次性符咒的确定制作/消耗规则均为原创适配，不归因于BG3已有相同实现。符咒也不是照抄原作卷轴清单：按用户要求每次耗一张，耗尽回免费武器，不能假称纯符零资源无限循环。单人即时动作没有队友替代资源，因此每种配装都保留零耗基础武器；是否好玩仍需实测。

## 商人与地图探索的新增借鉴

[官方GenerateItems](https://docs.baldursgate3.game/index.php?title=GenerateItems)与[SetCustomTradeTreasure](https://docs.baldursgate3.game/index.php?title=SetCustomTradeTreasure)说明商人可有各自的贸易货表；[ClearTradeGeneratedItems](https://docs.baldursgate3.game/index.php?title=ClearTradeGeneratedItems)区分普通生成货和独特物品。由此借鉴不同商人不同货、普通补给与独特库存分账，而不是给同一全局商城换头像。本作5商人、6专售物、固定价格与章节补货属于原创简化，不声称BG3采用相同金币数或补货周期。

探索沿[官方介绍](https://baldursgate3.game/about)的探索、选择、互动方向，将原创四区域设计成相互连接的道路/高道/侧室网络。区域发现、商人路条、可先处理支路、由另一侧打开近路、任务后重访构成空间逻辑；不是把原三条路重新命名后仍只许走一条。具体[探索地图逻辑](story/exploration-map-logic.md)区分官方理念与本作网图/安全检查点/固定主线保底。没有复制原作地图、随机传奇商店或把长休补货直接等同本作免费休整。

## 被否决区域v2的原创边界留档

用户否决小场景充当完整区域后，本作扩为四章各12子区、4宏路径，并加入可进入内部、聚落与野外行程。空间因果继续沿上节官方探索原则；520—600m级包围盒、20—40分钟主线/35—60分钟探索、32名可选敌与铁40增量都是本作未测设计候选，不是BG3官方尺度或其经济数据。原三条route与主线收据不被宏路径数替代，地图变大也不借参考作品之名复制剧情、地图或加入未经定义的自由攀爬。
