## 一 实际看过参考地图后得到什么

这次参考的是游戏地图的实际组织，不是只看一张营地图的画风。研究查看了荒野、幽暗地域、古代熔炉和修道院小径的地图/截图，并交叉核对地点资料。以下图片由社区Wiki托管，并非拉瑞安官方策划图；不据截图像素换算真实米数，也不声称测出了BG3全幕时长。

| 实际观察与核对 | 对本作的影响 |
| --- | --- |
| 荒野主图包含聚落、中央村落、西侧营地、北路、南部湿地、海岸和遗迹；染疫村落自身有建筑/环路，却只是大区的一部分。[荒野地形图](https://bg3.wiki/w/images/6/61/Map_Wilderness_A_Terrain_Tex.webp) [地点资料](https://bg3.wiki/wiki/Wilderness) | 本作一座村落、一片营垒或一个Boss据点不能再充当整章。大地区里须有多个可独立进入和停留的地点。 |

**本作借鉴的是地点之间的依赖、任务交叠和世界状态，不复制BG3的地名、轮廓、人物或任务。** 不机械要求每个地点都塞齐剧情/战斗/宝箱；有的地点适合相识与对质，有的主打危险探索，有的承接大战，它们共同形成冒险。

## 二 先纠正世界 章节 地区和单次游玩之间的关系

| 层级 | 本作含义 | 不再怎样理解 |
| --- | --- | --- |
| 完整世界愿景 | 灰石边地这一段战役的地理、人际关系和历史变化 | 不是一张图把所有内容画完，更不是四个小竞技场 |
| 叙事章或幕 | 一个核心矛盾的阶段：发现问题、深入调查、各方摊牌、最后解决；会跨区和回访 | 不等于一张地图，不必20—40分钟完结；章/幕是否再细分待故事排期 |
| 大地区 | 一张地表主图或独立地下网络，容纳多个聚落/遗迹/荒野片区 | 不等于一个镇、一座桥或一间地牢 |
| 地点或片区 | 村镇街区、森林营垒、矿坑、山隘、地下据点等有自身内容的空间 | 不按一个箱子/一座塔的图标数量凑“区域数” |
| 室内与层级 | 旅店、宅邸、监区、地下工坊、地宫楼层等真实可进入空间 | 不是所有房子都只画外墙，也不是每扇门都需新加载 |
| 一次游玩段 | 可在20—40分钟目标内推进一个现场问题、获得变化，再保存/整备 | 不要求玩家这次就通整章；完成单次段落不重置当地世界 |

20—40分钟是对原“区域游玩时长”的**新解释建议，待认可后采用**。完整章、完整地下区及全世界的总时长暂不承诺；先看剧情与可玩内容是否成立，再测真实游玩时间。熟练绕路或少看对白更快，不用强制等待填时。

## 三 原创主冲突 归来的人听见了旧矿炉

### 玩家为什么留下

自由剑士起初仍为报酬接艾妲的追回契约。回到石桥镇后，布兰拿出一枚只有他和失踪学徒才用的铆钉：它出现在数十年前封闭的旧誓矿炉附近。几个从矿里逃回的人，能准确复述未曾经历过的旧战场片段；矿炉已经没有燃料，夜里却仍透出冷白炉光。

洛德里克一边封锁矿区，一边秘密抓回会修誓团军械的工匠。艾妲所属行会想取得进入旧库的权利，却没有告诉玩家原委托中还有另一份“带回活口”的附约。蕾萨发现自己交给行会的隐蔽猎径已经被佣兵用于抓人，她不确定泄密者是谁。

**封路只是压力背景，不是修路和运货主线。** 玩家实际做的是调查、寻找失踪者、进入遗迹、潜入/交涉或战斗救人、面对人说谎的证据，以及决定如何处理危险但有价值的旧炉。既可为利益深入，也可在与人物相处后选择帮忙；不强迫神选、救世或城市治理。

### 奇幻核心

拟设“回声矿炉”能把曾在此锻铸的誓言与记忆留在金属里。矿炉正在重复一段未完成的旧命令，仍活动的炉卫分不清新工匠和旧主人。它不是无限装备机器，也不把所有人物变成受附身的无责任者：洛德里克利用异常是真实选择，行会隐瞒风险也是真实选择。

玩家先看到冷炉光、听到不合年代的敲击节奏，再从活人证言、工坊痕迹和誓团旧记录拼出缘由；不用找到三枚发光石才允许剧情继续。关闭一段共鸣、绕过炉卫控制区或在安全机关后作战，是拟议局部解法，不等于已经新增了一整套魔法物理系统。

“回声矿炉”、学徒和炉卫均为**新原创剧情/资产候选**。需要新美术、音效、行为和状态预算，不能说旧佣兵换色即可实现全部奇幻内容。

### 四个叙事阶段的候选关系

1. **封路之约**：追回契约把玩家带入石桥边地，同时认识失踪案和相互矛盾的委托。原灰披队长/钢剑事件可成为这一阶段的一次高潮，而非整幕唯一内容。
2. **矿炉旧声**：从沉桥高地进入地下旧誓网络，找到活人、旧命令与各方抢夺的原因。矿桥战是进入矿业地区的关键事件之一，不是整区的全部。
3. **沉钟之证**：河湾的人和誓团旧记录改变玩家对矿炉的理解；各方提出不同处置方案，人物线与主冲突交叉，不能只点验三箱就结束全部剧情。
4. **灰石之争**：对洛德里克、囚禁工匠和旧炉控制权作最终行动。外城/内堡/地下入口提供不同接近和准备；已建立的人物关系改变援助和遭遇，不只是结尾一句评价。

这四个名称只是工作标题。可沿用原四章的内容身份，也可在评审后拆章；旧18目标不是新全篇总目标数。

## 五 三条真正跨地点的人物线

### 艾妲 两份契约

**她想要什么：**拿回行会委托成果并保住经纪资格；她知道附约要求带回一个能辨认炉纹的活人，却先只向主角谈宝箱和钢剑。不是因为她无所不知，而是她也不知道“带回”意味着将人交给谁。

**玩家会做什么：**从行会办事处的副本、军营缴获的名单、地下证人的口述发现两份契约不一致；回镇直接质问她，或带着副本去河湾见真正付款方。任务跨镇内房间、敌方据点和地下，不是阅读一页字就领材料。

**可见后果候选：**让她公开翻脸，她会亲自撤回一份用于认人的文件，改变一个岗哨的接洽人；要求她私下帮忙，她可安排一次受限身份接近，但进入深处后仍须调查/战斗；不再信任她，玩家沿地下证据链继续，艾妲不能扣押已经属于玩家的装备或删除商店库存。不同做法改变关系、入口和现场对白，不默认给打折或多一件唯一武器。

**她不是任务牌：**在得知活口会被送入炉厅后，她必须决定是否违约，并实际到一个后续地点承担代价。角色行动按玩家已确认的阶段推进，不靠隐形现实倒计时。

### 布兰 失踪的学徒

**他想要什么：**把学徒带回来，同时不愿承认自己早年曾修复过封炉部件。学徒暂称“伊洛”，是拟新增可交谈人物，不是藏在箱里的任务道具。

**玩家会做什么：**在矿业聚落找到相互矛盾的目击记录；从工作服修补和墙上新锤痕判断人还活着；进入监区，选择正面战斗、与看守谈条件或从废工坊绕入。伊洛不肯立刻走，因为另一名工匠仍被迫在炉厅工作，救援需要面对真实处境，不是打开铁门就瞬移完结。

**可见后果候选：**先打开安全撤离路，再救人，可以让人物在离开危险区后以短过渡回镇，免长距离护送AI；先触动炉厅会改变局部防御，但不会因走错顺序秒杀重要NPC。带回的人能亲口说明布兰的旧事，并在后续地点作出自己的决定；只取到记录也能继续主冲突，但少一名能说出具体现场知识的人。

**奇幻与战斗在同一条线上：**布兰熟悉的锤击节奏既是辨认活人的线索，也是发现矿炉在重复旧命令的证据。炉卫战场中的金属共鸣与石柱遮挡，应由玩家亲眼观察理解，而不是一句“此处需要火属性”硬锁职业。

### 蕾萨 被出卖的猎径

**她想要什么：**找出是谁把她提供的隐路交给佣兵，保护沿路藏匿的人；也隐瞒自己当初收钱卖过一份路线记录。她仍是猎商，但不只替玩家指一个宝囊。

**玩家会做什么：**勘查一次伏击的位置，从被反用的猎记判断袭击者事先知道岔道；跟踪消息到地下货栈，再到河湾旅店与转运者交涉。可以设法让双方见面、夺取来往信物，或者在交易现场开战。调查、场景摆位和人物判断共同决定接近方式。

**可见后果候选：**公开泄密链会让一条猎路由藏身处转为戒备区，但另一方愿意提供出口；私下解决则保留隐路，后续某次战斗不会获得公开援助。状态在明确的阶段确认后变化，原地不凭空刷新一队敌人，不改蕾萨已售装备和保管物。

这三条线各有不同主职：契约与信任、救人与旧秘密、调查与背叛。它们可以交叠，但不要求玩家全做才打最终Boss，不把所有支线合并成“集齐三份证据”的硬钥匙。

## 六 一个可玩的剧情探索网示例

**以下仅是跨区任务网的一段示例，不是完整第一章或全世界。** 这些纸面标签不是运行时ID。本例演示为什么同一地点值得进入、为什么会打、怎么回访产生变化。

```text
镇内工坊T ──学徒铆钉──→ 林间伏击地A ──佣兵名单──→ 矿业监区P
   │                        │                         ↑
   │                        └─旧猎记→ 废磨坊M → 地下货栈E
   └→ 行会副本室C ──双契约线索─────────────────────┤
                                                     ├→ 回声工坊F
                                                     └→ 地下撤离口X ⇢ 地表旧哨S
回程：救出的证人/已有记录 → 镇内T与C对质 → 军营岗哨G或河湾接洽点
```

- **T与C是聚落内可进入的不同地方。** 布兰会听实际调查结果；艾妲会被质问，不把所有信息合并成旅店门口一段长独白。
- **A是战斗与调查交汇。** 玩家可看见箭位、倒伏车轮和一段可绕的高地。战前绕侧能够先找幸存目击者；正面战斗后仍能由现场痕迹继续，重要线索不被油火烧毁。此处不是必须打完才亮起任务物。
- **M/E提供环境解与人物接触。** 废磨坊的底层侧门由可见机械插销控制，不耗钥匙。地下货栈有可交涉看守与两条接近路线；成功交涉只改变这一处通行，不能一句话把整图所有敌人消除。
- **P提供真正的救援。** 监区前有公共工作带、守卫观察位、侧后检修廊。玩家可打败当值组、用已经知道的雇佣矛盾要求交人，或沿检修廊打开出口。谈判条件是已经确认的事实，不是隐藏魅力骰，也不要求付清一大笔钱。
- **F是独立危险现场。** 能先观察炉卫的巡行/启动范围和石柱遮挡，再选择绕过其控制区拿到记录，或进入战斗解决当前威胁。若选择战斗，地形与敌人动作必须有完整规则和预警；“剧情敌人”不能只有血量加大。
- **X是有方向性的近路。** 拟从地下安全侧操作后开向S；未开时仍可沿E→M返回。第一次离开不是空中传送，之后回访不要求重复解谜。
- **G承接而非抹掉旧Boss。** 已有证言/契约会改变岗哨接洽与战前处境，灰披队长的战斗仍可作为阶段高潮。是否给整场Boss新增交涉解，须在原目标映射评审中单独决定；本例不擅自跳过原抬杆/领奖收据，也不提前发W02。

### 同一段内容的不同实际玩法

| 玩家做法 | 当下玩法 | 后续变化 |
| --- | --- | --- |
| 先入军营，后查地下 | 先打/交涉守卫获得名单，再从监区找下行入口 | 知道人名但不懂矿炉；回声工坊会补上原因，不强迫回头再读同一页 |
| 先跟猎记下地下 | 通过废磨坊进入货栈，看见囚工与异常，再去地表求证 | 地表人物的说法可被直接质问；无需先接完三条任务才允许进入 |
| 先找契约副本再救人 | 镇内调查→有限通行交涉→监区/炉厅操作 | 减少一处正面战斗，但仍需处理危险与救援，不是纯对白跳过所有玩法 |
| 只推进自己的契约 | 可从主要路段打到阶段Boss、保留原固定报酬 | 不判坏结局；人物线仍可回访，进入明确的剧情推进节点前提示会改变哪些现场 |

### 事件状态与失败后的继续方式

| 事实 | 候选状态 | 不能发生的事 |
| --- | --- | --- |
| 契约真相 | 未听说／发现矛盾／已对质；证据来源分别记录 | 把未读过长对白当作永久失败，或自动销毁玩家已经获得的装备 |
| 监区处置 | 当值组敌对／局部放行／已解除看押；路线分别开通 | 一次谈判失败永久封主线；失败后仍可绕入或战斗，不倒扣未知费用 |
| 学徒处境 | 尚未找到／已接触／等待安全撤离／已回镇 | 玩家多逛两分钟便无提示死亡；把人当可卖库存物；必须实时护送穿整张地图 |
| 炉厅认识 | 只见异常／看过现场／获得某种解释 | 需要同一组固定三页纸才准过门；缺一个支线就无法理解主冲突 |
| 近路 | 未开／从正确侧打开后保持 | 读档后落回半开门、穿墙、重复发发现奖励 |
| 世界推进 | 玩家明确确认某次关键行动后进入下一阶段 | 普通进店、存档或休整暗自推进抓人/处决/封路 |

零金币、零消耗符、零油仍有基础武器、步行通道和可重试的必要操作。可选救援不是数值收集清单；战斗失败重试按安全点恢复，已完成的发现/释放事实不被回滚成再抓一次人。若未来增加真正的限时危险，须单独明确提示和授权设计，不能从BG3参考中顺手引入隐藏倒计时。

## 七 战斗不是填路人数

新世界需要先定义遭遇在故事中的职责，再定敌人总数。暂不沿用v2“每区固定新增8人”的均摊法。

- **野外遭遇**让玩家判断是否介入、从哪边接近，例如伏击地有明确目标与退路；不是任何路口都突然刷三名佣兵。
- **可谈判据点**保留强攻、局部交涉和空间绕行的区别。绕过战斗应有路线/信息成本，不自动在另一端补一场同样的怪。
- **遗迹危险**拟引入炉卫这一新敌人候选，能表现奇幻异常；其动作、反馈与制作另计，不用文字声明已复用成功。
- **人物线冲突战**的胜负改变看押/接近面/在场人物等真实事实。重要NPC的安全、撤退、同时死亡恢复必须定义，不能只奖励铁后人物消失。
- **地区首领和主线Boss**有更完整场地与前因后果，旧四位可保留/重写；是否增加独立支线首领应由地点内容论证，不为“看着大”规定每区一个。

原实时单主角战斗、预警、零资源基础攻击、明确安全退路等底线继续有效。扩大世界不自动授权完整队伍回合制、自由飞行、犯罪模拟或任意物理破坏。

原目标ID保留为历史与迁移索引，不因重写显示名强行迁移旧玩家选择。新的救人、违约或炉厅处置均是新选择，旧“放行队长/拆铜芯”不能被解释成玩家已经同意。

## 九 完整愿景与首个可制作片区必须分开

### 完整愿景现在确定什么

确定需要大地区内的多地点、独立地下网络、可进入聚落、跨区人物线、条件回路和状态变化。尚未确定地图总尺寸、总时长、NPC总数、敌类/首领总数、所有支线数量和最终生产总量。需要先通过叙事地图与玩法灰盒验证，不能声称“画得更大就达到BG3规模”。

下次全域图只负责看大地区之间关系；第一张地区详图须看得出一个大地区里多座真正的地点及其内部规模；聚落/地牢再分别有可进入的详图。不能用一张俯视图把整个世界压成七个挨着的景观模型。

### 首个制作片区验证什么

先取本例中一段：**石桥镇工坊/契约室 → 林间伏击地 → 废磨坊与地下货栈/监区支口 → 带着人物或证据回镇。** 它是一块竖切片，不是完整石桥边地，更不是完整第一章。

必须在这块切片里看见：

1. 一个NPC除了卖货还会因事实改变态度并行动；另一人物有不同目标。
2. 一处能实际改变接近方式的调查结果，以及一处不靠阅读也可发现的入口。
3. 至少一场可绕/可谈的遭遇和一场有完整动作/地形反馈的战斗样板；选择的结果不是重复发材料。
4. 一次地表到地下再回地表的有条件连接；保存/退出/回城保留进度。
5. 回镇后人物/现场状态有可见变化，而不是所有人重念接任务台词。

20—40分钟仅作为这一类完整片区会话的初步目标，待实玩后调整。制作切片规模小是验证顺序，不是拿它反过来裁掉整段世界愿景。也不能用第一切片的角色/场景数量宣称全世界只需要这些资源。

### 生产负担须重新估计

新的负担不只有地图面积：聚落内外景、地下洞窟与工坊、可交谈新人物、炉卫敌类、不同世界状态、人物行进/安全转移表现、跨区任务/存档、相应音效与测试都要重新登记。旧204是原设计基线；被否决v2的212不是本版报价。没有经过分解的工时和内存估算，当前不报总数。

可按地点和内部楼层分区加载，但这只是后续工程方案。跨区事实必须一致，活动遭遇不能因切块重置、NPC不能在新旧地点同时出现、已开路线/已领装备不重生。设计提案不等于已实现流式世界。

## 十 这版评审真正要决定的事

- 是否认可“异常矿炉与失踪工匠”为奇幻主冲突，而不是继续只用宝物清单串四场Boss。
- 是否认可艾妲、布兰、蕾萨有跨地点的人物行动和可见后果，而不是只能报价/提示/阻拦。
- 是否接受“一章跨多个大地区与地下网络”，20—40分钟用于一次片区游玩段的重新定义。
- 哪条人物线先作为竖切片验证；完整世界的地图、任务与资源总量在通过方向后再展开。

在这些方向得到认可前，不全仓库再次改写成“已采用v3”，不批量生产四张新图，不修改玩法JSON、不发布游戏，也不把新设定冒称已经可玩。
