## 统一画面语言

### 视角与尺度

参考图以地面为主，墙体只有适量立面厚度。正式素材应按当前正交镜头适配，树木、门洞、桌椅、石板保持同一人物尺度。当前运行镜头带有斜俯视角，不能把方向板直接铺到XZ平面后当作完成；已经带透视的建筑与桌子也需要防止二次投影变形。

地图分成地面、低矮细节、墙体与高物、遮挡前景、可交互物五层。地面承担材质与静态光照；高墙、树冠和前景拆开，以便保留人物遮挡和必要的淡出。开关门、绞盘、可开箱与机关状态使用独立素材。

### 配色与光照

| 材质 | 建议色彩锚点 | 明暗与使用方式 |
| --- | --- | --- |
| 旧石板 | 灰褐 `#878780`、冷灰 `#666D70` | 同一石块有轻微色差；接缝与缺角清楚，整片地面保持安静 |
| 老木材 | 灰棕 `#776B58`、深褐 `#4F4940` | 木纹随板向变化，扶手/桌沿有磨损，避免全屋蜜黄 |
| 泥土与碎石 | 灰褐 `#786D59`、灰砾 `#99958A` | 主路踩实，两侧碎石与草根逐渐增加 |
| 草与苔 | 鼠尾草 `#777D54`、暗苔 `#4E5D43` | 物种、湿度与日照带来变化，保留植物本色 |
| 水面 | 灰青 `#4D696B`、深青 `#354D53` | 浅水见岸石，水纹顺流，边缘有湿泥与水线 |
| 局部火光 | 琥珀 `#D9A35C`、火芯 `#FFE1A1` | 光源附近暖，离开灯位恢复环境色，空间边角仍可读 |

以上色值是制作起点，不是逐像素硬性替色。白天可以明亮，植被可以鲜活；通过控制大面积地表的饱和度与纹理对比，为人物、交互物和技能预警留出辨识空间。地下居所保留暖生活气氛，工坊保留冷白工艺光，不能仅按地层给全图套同一滤镜。

### 材质与细节

先绘大形，再绘磨损，最后补细纹。石材的磨圆边、凿痕与泥缝应属于同一表面；木头沿纹理开裂；青苔集中在潮湿接缝和背光边缘。小裂纹、碎叶和零碎石子服务于结构，避免整屏均匀铺满细节。

道路随真实使用产生主次：车道有宽磨损和车辙，步径较窄，门口与桥头有踩踏。路面进入草地、泥岸、石阶时有过渡；石块与树根的接触阴影柔和，并与环境光方向一致。

参考中的枝状石刻属于遗迹语汇。城镇、农地和矿场依靠各自的工艺与使用痕迹建立身份，地区特色通过结构、材料、植被和生活痕迹表达。

## 九类地形的制作要求

| 地形家族与目录键 | 主材质和构图 | 需要补的衔接与变体 |
| --- | --- | --- |
| 城镇铺石 town-stone | 不规则旧铺石，建筑沿街组织，排水沟与门口磨损带出街巷 | 石路接草土、墙脚、门槛、转角、河岸、石桥桥头 |
| 草甸农庄 meadow-earth | 灰褐踩实土、橄榄草块、田埂、旧矮墙，路旁留种植和营地痕迹 | 草土斑块、车辙、田埂、栅栏脚、营火周围踩踏 |
| 白桦林地 birch-forest | 白桦与其他树种按地点搭配，树根、落叶、蕨类成组，路径穿行其中 | 林缘到空地、树根到岩脚、枯湿落叶、疏密变化；birch为家族键，不强制所有森林只画白桦 |
| 芦苇湿岸 reed-marsh | 灰青水、湿泥、暗苔、芦苇与干燥砾岸，营屋落在干地平台 | 水陆湿边、浅深水、码头接岸、渠壁水线、干路与栈桥 |
| 山口采场 mountain-quarry | 灰褐层状岩面、大块岩脊、碎石坡与连续可走岩坡，采掘处有凿面 | 岩层转折、坡顶/坡脚、采面断口、护边；自然岩地与砌石路区别清楚 |
| 旧誓遗迹 oath-ruin | 与参考最接近的旧石板、浅雕、残拱与零星苔缝，院落中心留白 | 完整/破损/缺失铺石、残柱柱脚、断墙、门洞、埋土边；铭纹克制 |
| 生活室内 warm-interior | 灰棕老木、石砌墙脚、工作台或起居陈设沿墙，局部灯与炉火 | 木石交界、门槛、家具接地、炉边烟灰/工具痕迹；灯位与功能对应 |
| 地下居所 inhabited-undercity | 自然岩壁与人工支护共同围合，分别表现居所、矿廊、监区、工坊 | 凿痕、支架脚、干湿岩边、住宅门口、矿轨/机关接口；居所与工坊有不同光色 |
| 沉钟水道 drowned-crypt | 冷灰切石、潮痕、旧渠、拱廊与干燥高台，档案和居所保留使用痕迹 | 水线、渠壁转角、排水口、干阶、钟纹浅雕；封潮前厅、档案廊与旧居分别处理 |

每个家族的首批生产单元包括基础地面、色形变体、相邻材质过渡、地脚细节和一段可拼接边界。变体数量由正常镜头下的重复程度决定。方向板本身不具有无缝平铺、透明分层或碰撞配准能力。

## 复用资源与接入方式

继续使用Cocos Creator 3.8.8现有地面网格、SpriteFrame裁切与builtin-unlit材质。官方Unlit适合将静态光照画入纹理；本次以美术素材和接入适配为主，无需另换引擎。[Cocos Unlit](https://docs.cocos.com/creator/3.8/manual/en/shader/effect-builtin-unlit.html)

现有natural-v3建筑、家具与树木可保留构形，按新地面统一边缘、饱和度、接触阴影与尺度。仓库hall.png与本次参考具有同一石厅构图，可作内部对照；本轮以实际附件副本为权威，不假定两文件逐字节相同。

已有Poly Haven和ambientCG材质可作为石木结构与颗粒尺度参考，其素材使用CC0许可；保留现有来源清单。最终手绘地表需单独审阅，直接换成照片albedo仍会延续质感割裂。[Poly Haven许可](https://polyhaven.com/license) · [ambientCG许可](https://docs.ambientcg.com/license/)

裁切、缩放、遮罩合成、透明通道与图集排版继续用已有Pillow工具。生成新像素使用云端image_gen，先做代表样张；生成记录与美术验收分开保存，选中的正式资产保存到项目后再接入。

## 正式地图验收

1. 在正常手机横屏与桌面镜头下，先看清人物、敌人、道路和危险预警；地面细纹不压过动作轮廓。
2. 同一物体的比例、接地与受光一致，平铺接缝和重复轮廓在连续移动中不明显。
3. 路面、坡面、桥面、干岸的视觉范围与真实碰撞/导航对应；入口、门缝与退路不被新增装饰堵住。
4. 区域有自己的结构和使用痕迹；树、岩、灯、箱桶的摆放能解释空间用途。
5. 按[远距适配要求](../design/ranged-combat-integration-v2.md)复核12至18米射线、掩体和取景；97区材质与地形覆盖不能替代实际镜头和合法射线证据。
6. 单独记录静态画质结论、运行资源加载、遮挡、状态切换与性能结果。首批代表场景通过后再扩展批量。
