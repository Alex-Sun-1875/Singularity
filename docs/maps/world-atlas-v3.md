## 两种图，各负其责

- **无字PNG美术图**：原创生成的地貌、聚落与空间气氛草案；用于判断世界感、地貌差异、聚落内部是否像可展开的地方。道路和建筑不逐像素对应合同，不能直接充当导航图。
- **带中文SVG规划图**：原生可编辑的地理关系示意。标号、连接、首次开门条件和人物覆盖以这些图及绘制合同为准。其地形边界、道路宽度、楼层与桥位仍是制图示意，并非已测可走面/灰盒/导航网格。
- **人物覆盖PNG**：由同名SVG直接渲染，便于直接查看。场景徽标与引线只表示故事锚点，不是瞬移边；全图是设计者全知，不是玩家开局已知信息。

主图采用高俯视制图，不再把一个大地区缩成一条通Boss的等距悬浮沙盘。没有公里尺、测定面积、已测游玩时长或性能承诺。石桥镇是20处地点中的一处，包含镇内街区与多个可展开内景；地下单独成图，而非角落地窖。

## 图例与读法

- **R1—R4**：地表大地区；**U1、U2**：两套独立地下网络。
- **S01—S20**：首区地点；**H01—H17**：沉桥高地；**B01—B18**：沉钟河湾；**F01—F17**：灰石城域。**T1—T6**：石桥镇内部功能处，不是额外6个大地区或新检查点。
- **E01—E08**：上下层端口，两端必须对应。地图上下投影相邻不表示可穿墙。
- 浅色道路为候选双向实体边；首次开通条件写在端口旁或侧栏。U2前厅深闸为虚线与门栏，不是开放道路。
- 绿色：聚落/交谈；褐色：调查或可改变接近方式的据点；红色：有前因后果的战斗；紫色：遗迹/异常；灰蓝：观察/交通；深红：阶段Boss。
- 02中M1—M8为主场景、Q1—Q6为重点冒险支线。艾妲褐、布兰蓝、蕾萨绿、墨伦紫；彩色引线是地点指示，不是路。一个地点可承担多线剧情，不重复发奖。调查顺序不强制先接任务才看见现场。
- 路线无节点交叉不自动相连；桥的小横板只标示地理跨越候选，未替代高差和导航审核。

## 三类内容怎样共存

**剧情**：以寻找白枝第七远征遗库为主动冒险；背光星片、旧剑阵、活着的探队、失真显影与会拒绝的昼核贯穿地表/地下。四核心进入危险现场而非只守商店；M8回U1-08实际执行结局，不在终堡点选后假称完成。

**战斗**：劫车隘口、伏击地、陷井谷有观察面和退路；军营、废村、庄园、监区允许调查、交涉、侧入或战斗等接近方式。北岭哨关是重要阶段Boss，不封死整个地区所有出口。

**探索**：遗迹、谷地、洞窟、塔和地下居所不只是通主奖的走廊；从不同入口进入能改变先看到人、记录还是异常设施的次序。秘密和奖励保留，但不吞掉故事与冲突。

## 必须保持的边界

- R1↔R2、R1↔R3、R2↔R3、R3↔R4为候选地理旅行边；普通旅行不自动推进剧情、封旧地图或发章节奖励。
- U1与U2没有直接无条件地下连接：U1经E07到R3地表，再经E06进U2。
- E03、E07、E08首次由地下内侧开启；E02梯首次由地表放下；E05从地表安全操作；E01普通插销可返。
- E04可从R1到U2前厅；01—02深闸须从U2-03内侧开启。先到前厅可原路返，不穿过深闸直达后期区域。
- E08只到R4:F16堡外检修位置，不进终Boss或宝库，不自动拆外弩台、不领取W06/T08。
- R2条件只在H08—H09矿桥：清桥组、原手柄接好、放桥；H09/H10无另一个渡口后门。
- R3条件只在B11—B10：B12水槽开、B11放吊臂；原战斗与三次点验留在同一B10货台，不拆成长跑。
- R4 F11—F12是普通道路；两台解除锁F12—F13；战胜洛德里克并开绞盘锁F13—F14军械库。领主档案楼不是主箱前置。
- 48类物品、5商人账户不因画了更多建筑而增加。没有新增CP、掉落、免费装备、材料预算或重复人物实例。商人驻点/迁移仍需与最终世界状态映射核对。
