## 两种图的分工

- **PNG**确定场景材质、轮廓、光照、视线组织、地标和主要空间块面。全部使用内置图像生成工具独立生成并人工看过像素；首章和矿桥各经过一次针对性连通修图。不是现成引擎截图、切片地图、注册精灵或可直接走的碰撞网格。
- **SVG**是准确的设计拓扑，负责路线与状态条件；它不是压在 PNG 上的像素级配准层，也不是按比例施工图。线在没有节点处交叉不表示接通。任何装饰道路、栏杆开口或投影视觉，均不得覆盖 SVG 与原玩法文档的连接条件。
- PNG 是完整场景设计展示，不承诺所有机关都处于统一的“第一次进入”状态；例如河湾展示可见平台和栈道，不能把画面上一段相邻木面直接实现成绕过水槽/吊臂的通道。**首次可达性和相对层级只按 SVG/地图逻辑实现**，制作灰盒时必须重画对应机关态、检查遮挡和宽度。终章 Boss 地坪与其后宝龛同层，不能按插画墙体透视误建第二层库房。
- 全套为**设计者全知图**。玩家地图仍按“未知—听闻/远望—亲历”揭示，不把秘密、商人和宝箱预先全亮。不能把这一套全知 SVG 原样当开场玩家地图。

## 风格与参考

采用用户所给参考的写实手绘 2.5D / 高位等距观察感：暖灰石、旧木、旧铜、亚麻帐篷、青绿安全营地、锈红敌区、左上暖主光与偏冷补光。避免低模几何面、俯拍照片和夸张大城堡。四章各有地标：首章木门与车棚、二章轨道与干槽、三章断钟与水槽、终章两外弩台与小宝龛。

用户参考 Library ID：用户提供的私人参考附件（不随公开项目重复发布）。实见内容是左下营地、中段跨谷石路、左上山坡、右上木栅石塔与右下矿口的无字环境图；仅作质感与镜头参考，不当玩法文本或复制布局。PNG 无生成文字，避免把错误标签算成正确标注；所有中文与ID由矢量标注层确定。
