# 剑与火 第三版地理与剧情地图绘制合同

2026-11-02 · v3地理草案0.1。**可逆设计稿，未获用户认可、未成为已采用设定、未实现。** 本页把[世界结构与剧情探索提案](world-structure-v3-proposal.md)转成能绘制、能检查的空间关系，不重写人物剧情，不继承已被否决v2的尺寸/12子区/212母项/铁40。按完整静态地图与自主推进的要求继续制作可评审草案；这不表示方向已获确认，正式设定与工程实施仍另行评审。

本轮输出应是**地理区域图册**，不是再次画等距悬浮沙盘。全世界关系、首个大地表地区、独立地下网络和人物线覆盖各用适合的层级表示。地图中的纸面标签用于审图，**不是新增游戏JSON、任务ID、CP或奖励授权**。

## 一 这一轮画什么

1. **世界关系图**：四个地表大地区和两个独立地下网络的空间关系，聚落/内景作为其组成，不把世界画成六个挨着的建筑模型。
2. **石桥边地地表详图**：第一大地表地区完整候选，包含20处有内部内容的独立地点；石桥镇只是其中一处，不是地图边缘一个帐篷。它不是完整世界，也不代表整个第一章只能在这一图活动。
3. **剧情与战斗覆盖图**：复用同一地理底图，单独显示艾妲、布兰、蕾萨的跨地点线，区分调查/交涉/救援/可选战斗/阶段Boss，避免全部内容都用宝箱标记。
4. **两个地下网络图**：有自己的尺度、据点与回路，入口通过E01—E08端口号与地表对应；可在世界图以副图先表达，不能把完整地下网络缩成一个地窖剖面。

此处“20地点”是本稿的可核对清单，不是用数量宣称达到BG3体量，也不限制未来完整内容。尺度感来自镇与村的内部街路、地区间的山谷/河道/森林分隔和跨区探索，不来自增加空白画布或标签。

## 二 画法和地理表达

主图近正俯视或很高视角的地理制图；可用写实地形材质，但建筑应按街区和聚落簇表现，不用高耸建筑占满半张图。地图边缘山林/河流继续伸出画幅，不露悬浮岛底座。保留足够地表连续性，看得出路是在山脊、谷底还是沿河岸。

- 用清晰的路网、河道、岩壁和林地变化表达距离。没有节点的线交叉不自动连通；桥、隘口、楼层出入口明确画符号。
- 全世界图不承载所有小房间；地区图显示地点边界与内部骨架；聚落/监区/炉厅可以进一步展开，不能把一座有旅店、铁匠街、行会和渡口的镇只画一间房。
- 石桥镇、废磨坊村、灰披军营至少应肉眼辨出街/巷/院落和多入口；塔、单个宝箱、战斗圆圈不能与整个镇画成同样面积的圆形节点。
- 地下按独立页/层表达；垂直投影相邻不代表能穿墙到达，入口号必须双端对应。
- 主地图可显示内容类型的小符号，但不把三条人物任务箭头、战斗范围、全量秘密同时压成一团。剧情覆盖图与地理图使用同一坐标。
- 图头写“设计者全知草案”；玩家实际地图仍按发现揭示。没有测定比例尺，不画虚假“1公里”尺，不报已测时长、面积或引擎性能。

### 石桥镇内部不是六个额外大区域

镇内细图使用T1旅店公共厅/客房、T2行会办事处/副本室、T3铁匠街/布兰工坊、T4渡口街/仓院、T5拘留所/值房、T6广场/回返接洽点。它们构成可步行的街区：T1↔T2↔T6↔T3↔T4↔T1，T5分别接T2/T6。民居可作不可进入背景，不假称每扇门都有任务。

艾妲通常在T2、布兰在T3；证人安全回镇后出现在T6或对应工坊的明确位置。迁移只产生一个人物实例；图上同时画“初见”和“回返”要用状态图层，不能让人物复制。T1/T2/T3等是制图内部号，不新增六个CP。

地理骨架建议：北部石脊与断层隔开军营/石塔/废誓院，河谷从北向南穿过中部，经劫车隘口向南渡弯折；东南另有旧人工渠接泵院，不能把两条水线随便画成同一条会逆坡的河。桥口集中在可读的隘口、村边与南渡范围，深水/崖谷不能被路网直接跨越。林地围合道路但不遮掉所有地标。

这张图不再“三路全部在同一个平台汇合再打Boss”。例如南部民居/猎场/庄园形成回环，北部镇—军营—石塔—峡谷另成回环，废村把地表与地下连接；玩家可跨圈调查。S10哨关是一个重要事件，不截断S15/S16的全部出境道路。
