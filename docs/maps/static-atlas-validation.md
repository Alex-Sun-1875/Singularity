## 使用边界与下一阶段

本批原为全图尝试，现降为**未通过区域尺度的局部场景参考**，不是已配准地图贴图。PNG的场景块面与SVG的逻辑图分层交付，二者未做像素级坐标对应；精确地面轮廓、可走净宽、3D层级、遮挡拆层、初始/开启/破坏等机关状态、雾区切片、碰撞导航和运行内存还需灰盒与正式美术生产。不能将本报告中的“纸面路径可达”改写成“实机已通关”。

实现时若画面装饰产生可疑旁路，以探索逻辑与SVG条件为约束修场景，而非删玩法条件；三章不能因木栈道画得相邻就跳过水槽/吊臂，终章不能因墙体透视把主箱抬到新楼层。主通路净宽1.2m、回转1.8m、安全边0.35m和各相对高差均仍为原灰盒目标，未以像素量算伪称达标。

实际运行验收继续使用地图规范MAP01—MAP12、商人MT01—MT10；本文件不创造另一套“已全部通过”的游戏用例。未修改代码、数据JSON、网站、Git状态或运行端。源提示词与原始最终图保存于`source-art/maps/static-atlas/`，交付索引为[静态图册](static-atlas.md)。
