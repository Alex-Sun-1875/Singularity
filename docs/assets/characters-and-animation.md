## 角色定义与复用

区域扩张前已登记的角色基线为**11个定义=原6基础设计+2灰披佣兵变体+3商人**，不是区域v2的人物/敌人总数上限。艾妲和布兰同时承担交易身份，仍是既有两人，不重复计数。本轮显示名改变但内部ID不变：行路人→自由剑士、阿禾→艾妲、老周→布兰、罗铎→洛德里克、围路兵→灰披佣兵、路障头目→灰披队长。原图与基模仍按旧文件名保存，不能把更名当成新造型已生产。现有六个静态基模仅占位；两变体尚未制作。守桥铠卫是强化盾兵的小Boss，灰烬掠夺者是投油头领的小Boss；两者复用敌人身体和动作，只用更完整的护肩/腰带材质、固定站位和短头目条识别，不新建角色或独立动作。终章侧路铁棘监守替换原盾兵实例，复用同一身体、盾兵招式与短姓名条，不为该精英额外新增战斗角色定义。故事里搬运队、普通路人、守备传令等优先以画外声、字幕、静态远景剪影或既有角色表达，后续可交互新人物或新敌人原型须由获确认的世界/剧情/战斗规划明确，再分别登记设计与动作预算；这里不擅自添加，也不再把旧11项当全局禁增条款。

## 动作 ID 与方向

动作用 `<角色资源ID>__<动作名>__<方向>` 唯一命名。方向为 `front_right`、`back_right`、`back_left`、`front_left`；8 向仅为后续有预算才加的选项，不是首版承诺。所有下表帧数为**每方向的不同绘制/渲染帧**，不是播放次数、敌人实例数或唯一源动作数。可复用骨架模板，但换装备后要逐角色检查穿插和重新渲染。

## 时序与动作含义

逐帧元数据必须有 `durationMs`、循环标记、脚底锚点、攻击/交互事件标记。**旧动作时间以[战斗交互](../interactions/combat.md)和[敌人招式](../interactions/enemy-encounters.md)为来源，新增武器/符咒时序另对齐[完整装备](../interactions/equipment-and-crafting.md)**；下表仅列旧动作事件，不冒称新动作已有完整采样表。帧数表示图像采样量，可变时长、持帧、播放重定时，不以“10帧÷12fps”擅自拉长攻击，也不让动画末帧控制实际冷却。

| 动作类 | 必须对齐的事件 | 不允许的表现 |
| --- | --- | --- |
| idle／walk | 无玩法时间锁；起点12fps循环，走路触地帧标脚步声，根位移由游戏控制 | 固定站立根点跳动；镜像改变持剑手 |
| 玩家 sword | 0–0.12s前摇；0.12–0.22s有效；收招至0.44s；0.30s后可被指定动作取消 | 将总时长另定为0.6s；有效窗后继续画大伤害弧 |
| 玩家 push | 0–0.10s蓄肩；0.10–0.16s有效；收招至0.50s | 一个动作重复推多次；把推击画成法术爆炸 |
| 玩家 dodge | 0–0.04s启动；0.04–0.22s位移；收势至0.34s | 视觉位移超出安全边界；残影暗示免疫持续火 |
| 玩家 cast | 预瞄独立可取消；确认后0–0.18s抬壶、0.18s释放、回收到0.48s；飞行0.30s另用道具 | 把投油画成魔法；动作取消后手里又发射第二壶 |
| hit／stagger／down | 玩家普通命中视觉0.12s，重击硬直0.30s；敌人失衡按敌种/事件读时长；倒地可约0.7s演出，碰撞退出由规则决定 | 统一6帧强制所有敌人同样硬直；倒地堵主线 |
| 灰披佣兵 attack | 0.65s举棍；0.10s有效；0.65s后摇 | 圆盾普通兵表现成完整架盾能力 |
| 头目 sweep／followup | 横扫0.80s预警、0.16s有效、1.00s后摇；半血短击独立0.60s前摇、0.10s有效、1.20s后摇 | 一次预警直接打两次；无收招 |
| 头目 charge | 1.00s预警、0.55s冲锋；撞石失衡1.50s，否则后摇1.10s | 冲锋中滑向未提示方向 |
| shield guard／bash | 抬盾0.75s、直推0.28s、后摇0.85s；被推失衡0.25s等按规则重定时 | 复用普通小圆盾姿态冒充宽方盾 |
| archer aim／shoot／reload | 1.10s瞄准，末0.30s锁方向；单次释放弩矢；装填1.80s | 无装填连射；弩矢穿硬掩体 |
| 灰披佣兵 cast | 搬油头领举壶1.20s、投出回收1.00s；与玩家相同动作意图、不同预警时间 | 因共享模板继承玩家的快速投掷节奏 |
| 洛德里克 charge／slash | 盾冲1.05s预警、0.65s冲、撞石1.40s失衡；重斩0.85s前摇、第一段0.16s有效，两段间0.65s再预警、第二段0.12s有效、最后1.35s后摇 | 美术自行延长有效窗；两段只提示一次 |
| command／surrender | 号令举手1.40s；内弩位另有1.00s瞄准；投降是非敌对演出，末帧保持；头目复用四向 down 末帧为缴械保持态：卸盾、锤放脚边、清醒坐地，直到选择/交车结束，不执行普通敌人的淡出 | 投降后仍挥剑；用尸体姿态代替头目选择与洛德里克结局 |
| talk／interact／repair | 演出起点0.5—0.8s，不覆盖交互规则时钟；短对白可跳；机关结果另存 | 动画中断导致奖励重复；对话锁住整个任务 |

宝箱开启与装备查看复用玩家 interact，艾妲查看藏宝记录复用 interact，布兰松开库门普通棘爪复用 repair。守桥铠卫（150HP加两名弩手）复用盾兵guard/bash，灰烬掠夺者（132HP加三名手下）复用灰披佣兵cast；准确招式时序与数值以交互稿为准。装备目录本身仍共用主角身体；区域扩张新增的敌人实例、人物或原型另核预算，不能据此把新角色都当同一旧身体。武器家族与一次性消耗符咒仍有追加动作依赖。制作/分解走静态UI，工作台可复用布兰repair；复演使用当前构筑的同一套动作，不复制动作定义。**57条/1720帧仅保留作旧剑系基线，新系统全量尚未估算。** 近景卡、图标、静态掉落既不是身体动作，也不能证明弓的拉放、杖的施放或符咒手势和消耗帧已具备。

旧“剑路重击/火路省油”仅说明旧剑击与投油的复用来源，不再限制当前构筑。新法杖与符咒施放按下表追加；不新增召唤、跳跃、游泳、攀爬或骑乘动作。短梯是开放通道的状态道具，不引入攀梯角色动作；通过短切换/既定坡道表达。

## 全装备动作与换装增量

以下是必须关闭的制作依赖，均为设计计划、未制作、帧数与工时未验证。准确动作时序、资源费用、输入与取消窗以[装备与合成](../interactions/equipment-and-crafting.md)和[战斗交互](../interactions/combat.md)为准；旧表的`sword`、`cast`不擅自兼任弓、法杖或符咒施放。

| 家族或接口 | 必须制作与核对 | 单独记录的输出成本 |
| --- | --- | --- |
| 近战6件 | 逐件确认握持点、武器家族轮廓、挥击轨迹；不是6张剑卡自动覆盖6种武器 | 可共享动作的清单、不可共享的动作/方向、附件遮挡与最终渲染数 |
| 弓4件 | 双手持弓待机/移动、拉弦蓄势、释放与回收；箭从正确握持侧发出，弦线不穿手 | 弓臂/弦的状态、四向手部与披布穿插、箭体和轨迹 |
| 法杖4件 | 杖持握待机/移动、前摇、法术释放与回收；杖头和法术实际出口一致 | 不同杖长/杖头附件、法术出口、地面与远程法术遮挡 |
| 副手2件 | W15盾限单手近战且R覆盖主手技；W16法器限短杖、+20专注不回满；左右握点和阻挡/施法姿态按玩法表；不镜像改持物侧 | 合法配对的接触/遮挡验证，不为非法组合渲染 |
| 一次性符咒8类 | 取符/发动/耗去，Q/E引用背包数量；仅真正释放扣1张并提交CD，取消/前摇被打断不扣；不消耗专注 | 空堆叠、冷却、取消与释放耗张分别可读；纸符/符石共享消耗语法，不新增一套身体，不画成无限施放装备 |
| 护甲16件 | 头、身、手、足的层级、接缝与材质；至少四构筑的整套轮廓和混搭样板 | 同一身体的附件/覆盖层，不按每种组合新增角色；不能把组合数当成已完成帧 |
| 首饰8件与套装 | 首饰以物品页清楚辨识；套装以成员/2件/4件状态表达，细小首饰不强制制作一套身体动画 | 可见挂件若需要再列附件，静态卡不等于已绑定佩戴表现 |

追加预算必须在统一样板中测得：动作与方向数、母帧和裁后尺寸、握点/遮挡修正量、图集页与常驻内存、重渲染时间、通过证据。先验近战、弓、杖、符咒各一条完整攻击链与一种四件套，再推导四构筑和48类覆盖；不以`48×1720`粗乘，也不以“同骨架”报零增量。完整预算与四构筑覆盖未闭合前，不声称首章920帧或全篇1720帧已经覆盖本轮设计。

## 商人动作与头像增量

5位商人中艾妲/布兰复用已登记身体，蕾萨/墨伦/娜薇各新增1个角色定义。3新角色需要站姿、短对白/交易与必要方向的同人一致性；位置迁移可用安全锚点状态切换，若出现入离镜头则复用walk并另列输出，不默认扩成完整NPC演出库；可复用安全NPC动作模板，但每个新外形仍须绑定、手部/衣装遮挡校正和重新渲染。布兰的修理模板与艾妲交接动作可作为交易演出来源，不代表新增交易已接入。**新增商人的动作数、帧数、工时与内存均未估算，不在旧57条/1720帧里**。

5张商人头像从各自通过的静帧裁切，不独立增加5个插画设计。正背识别、表情缩小后的可读性、交易焦点与静音提示逐项核对；当前没有新商人模型、肖像或动作成品。其出现区域/商品与会面条件见[商人合同](../interactions/merchants-and-trade.md)，不以美术外观擅自加可跟随NPC或新战斗者。

## 既有角色与被否决v2遭遇的边界

被否决v2曾提出每章4组×2旧模板实例、共32个可选敌人，仍复用原灰披近战/盾兵/弩手/投油模板，不因此新增32个角色定义；原Boss模板不作为新敌反复刷奖。但新增摆位、数量、巡逻、导航、射线和存档实例均需单列实施与性能预算；重复实例不增加角色设计数，也不等于没有工作量。真正不同身体、动作或识别轮廓的新角色/敌人，只按后续获确认规划的提案登记，不能为了填大地图自行宣布新增怪物或额外装备奖励。

[被否决区域尺度第二版](../maps/regional-scale-v2.md)曾只列32个可选实例、无新增身体原型，这不是v3人物/敌人或剧情关系的上限；旧57动作/1720帧与原11角色表均不覆盖全部新增动作/实施成本。单屏8至12敌是并发目标，不是区域实例总数。荒野/聚落/室内的常驻与非活跃实例、遭遇并发、门洞/层级导航、远处人物表现、全方向动作与分包峰值均未估算；20—40/35—60分钟只是被否决v2的未测目标，不能成为v3时长约束或动画完成证据。

## 帧注册与交付验收

1. 工作母帧内脚底原点锁为 `(256, 432)` 的 512×512 坐标起点；较宽画布保持相同世界比例并以世界根点重算坐标，不能居中后失去原点。原点可在首次样板统一修正一次，随后全库锁定。
2. 每帧写明未裁尺寸、裁剪矩形、脚底原点在裁图内的坐标、武器握点、视觉高度；运行排序使用地面根点，不使用头顶或包围盒。
3. 透明 RGBA，边缘无白边/黑边。直通 Alpha 或预乘 Alpha 必须整条管线一致；在浅灰、深灰、暖土地面三底检查，不仅在透明棋盘格看图。
4. 动作安全边距不少于母帧 8 px；剑尖、披布、盾边任何帧不能裁切。图集裁边允许锚点在裁矩形外，不能强行移动角色以把锚点塞回图内。
5. 四向同人、同装备、同光照；连续方向切换身体高度差目标 ≤2 px，固定站立根点漂移 ≤1 px（运行输出尺寸）。走路接地由触地时刻检查，不要求脚尖全程不动。
6. 以 100% 母图、运行输出尺寸和半速动画三种检查。清楚看到成人肩肘膝、短披布不遮腿、剑/锤/弩分别可辨；钢、皮、布不融成同一种塑料。
7. 每角色需前后左右静帧、动作联系表、四向同屏对照、循环视频/预览以及导出元数据。只有通过后的资源可标“正式”；现有静态四向图不能补上动作标签就通过。

性能计算与图集预算见 [美术方向](art-direction.md)，具体排期见 [制作顺序](production-roadmap.md)。
