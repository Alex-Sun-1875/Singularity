# 战士全身动作恢复 v4

后续用户反馈脚仍歪，已进一步修复连斩载体的绑定与坐标转换差异，见[脚部绑定修复 v5](warrior-foot-bind-v5.md)。本文只记录关闭额外脚步层的过程，不能作为最终修复结论。

2026-11-12。用户反馈战士施放技能时脚步和身体不同步、姿势扭曲，并表示战士原动作无需改动。本次为近战武器和 WAR 技能恢复原有全身动作。

原因是挥砍本身已有配套的髋部发力、转腰、腿部支撑和回势；独立走跑腿部采样或原地踏步 IK 又覆盖了这些骨骼。`Actors.update` 现在将持近战武器或正在使用 WAR 技能的角色交回完整原动作，并立即清除脚步与重心叠加，避免进入近战时留下此前职业的退出混合。原有连斩采样和动作间衔接继续使用现有实现。

类型检查、现有 120 项测试及 Cocos Web mobile 构建通过。844×390、DPR3 原生场景检查了静止／移动普攻和四个 WAR 技能，共十组。各动作期间独立走跑层、原地踏步、持杖支撑层均为零，恢复原生挂点，角色骨骼未被后处理覆盖；实际绘制关节与当前全身骨骼矩阵误差低于 0.0001。普攻与连斩仍使用原来的三段动作，突进和防守动作正常完成。从法师踏步直接切入第一刀时无姿态残留；法师与弓的踏步仍正常。
