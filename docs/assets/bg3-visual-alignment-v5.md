# BG3方向的整体配色与界面质感

后续用户用新参考明确要求“总体偏暖的金色”。最新运行配色与实装记录见[暖金校准v6](warm-gold-alignment-v6.md)，本页保留上一阶段记录。

2026-11-05。本轮根据用户两张新参考及此前7张界面参考，对正式Cocos3.8.8手机横屏版本做整体视觉统一。用户明确要求去掉大面积土黄，并纠正按钮/面板须参考BG3；最终采用烟黑内凹、细金属包边和古典角饰，保留清亮的场景本色与技能色。

## 已实施

- **整套界面**：17张原创可编辑SVG皮肤重做烟黑渐变、金属明暗棱、暗槽与卷叶角线；HUD、对话、标题/暂停、人物、9装备槽、行囊、技能、掷骰和FairyGUI地图共用。源像素/逻辑像素为2:1，尺寸、24px九切和UUID保留。没有复制BG3截图像素或增加框架。
- **大底与文字**：烟黑面板`#16191F`、按钮`#1C2128`、冷白正文`#F1F5F5`、淡香槟金`#E4CFA7`与少量青蓝选中；面板贴图从几乎不透明的棕面降为3.5%中性覆层，父节点危险/状态颜色可正确透出。金色集中在细边与重点，不铺黄褐底。
- **层次与语义色**：红莓生命、蓝青专注、青蓝奥术/路线、亮紫封印、青绿盟友、粉红敌人、暖金祷文；D20为酒红切面、细金属棱与白色结果。浮在场景上的交互/提示/武器文字加原生深色描边。
- **人物与地图**：人物预览改中性主光/冷色补光，空装备槽银灰减淡；品质和符咒色统一语义。地图原插画与实时顶视捕获均用白乘色，去掉灰黄叠染；探索遮罩、公开地点信息、缩放/定位等原逻辑保留。
- **场景**：中性日光与灰蓝半球/地反色提高人物竖面可读性，森林地表复用已加载草地PBR而路径保留暖土；绿植、灰石、木、织物和水相互区分。地下保留低于户外的照度与冷暖关系，局部灯收敛通量/范围；灯数与粒子容量不增，PBR贴图通道/因子、角色身份、几何及碰撞不改。
- **加载背景**：以现有原创图用内置image_gen做1次编辑，保留河谷/桥/石镇/树木构图，改为清朗白日、春绿树叶、青蓝河水与灰石。下方保留承载文字的暗部。旧源图留存；新图、prompt和前后哈希见`source-art/ui/loading-clear-v2/`。
