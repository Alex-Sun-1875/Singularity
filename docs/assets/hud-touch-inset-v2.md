# 高频战斗按钮的触控余量

2026-11-10。用户指出上一版普攻与技能过于靠近屏幕边缘；以触控舒适度为优先，保持当前紧凑圆弧，只将战斗按钮组整体向内调整。

信息栏继续使用6逻辑像素外边距；普攻、四个主槽、闪避与终极使用16逻辑像素的右侧/底部触控边界余量。iPhone 14默认844×390画面中，普攻可见边框距右边及底边均约18.33逻辑像素，较上一版约8.33各增加10。更大的硬件安全区直接优先，不在其上再次叠加16。配置集中在`UiTheme.ts`的`UI_HUD_INSETS`，避免信息贴边与高频触控共用同一边距。

按钮尺寸、圆弧、组内间距及四槽位置关系保持不变，头像栏不随战斗组内收。工程类型检查、web-mobile构建、六组iPhone尺寸、两组安全区夹具与既有移动/攻击/取消/闪避触控流程通过，无浏览器运行错误；默认7469已更新。复用现有检查与构建副本，没有新增依赖或测试套件，真实设备验收仍单独进行。
