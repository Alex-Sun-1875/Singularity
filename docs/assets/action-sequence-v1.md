# 战斗动作衔接 v1

2026-11-08。按“技能抬手、挥砍与施法动作都要衔接”的要求，将现有2D关键姿势接成准备、抬手/举剑、实际释放、连段回势、最终收势与持武器待机。复用当前已验收人物、原生图集与Cocos渲染，不重绘脸、衣装、裁切或脚锚，也没有增加动画库。

## 同一动作时钟

`core/CombatActionTiming.ts`集中角色执行的拍数、间隔和完整动作时长；`runtime/PlayerActionPresentation.ts`以同一`ActionState`、实际`CombatCast.nextSegment`及释放标记采样已有姿势。普通剑在0.12s有效点进入出剑帧，普通杖在0.20s弹体产生时进入前推帧，弓快射和蓄力松手延续已有拉弦姿势后放箭。

剑/杖/弓的四帧按准备、抬起、释放、收回使用；通用施法三帧按胸前聚能、伸掌、收手使用。连斩与连箭中间只回到举剑/拉弦，不在每拍之间站回idle；多拍雷法保持引导姿势，最后一拍后才进入完整后摇。突袭前段使用自身持武器跑姿，接近实际停止点转举剑，再在真实落点出剑。

| 动作 | 角色执行的拍数/间隔 |
|---|---|
| WAR_01 / WAR_02 | 按接受阶级的2/3刀或1/2刀；0.16s |
| WAR_05 | 三刀；0.18s |
| BOW_03 | 3—5箭；0.10s |
| BOW_05 | 三拍箭列；0.16s |
| THU_04 / THU_05 | 按实际声明拍数；0.25s |

动作总长覆盖最后一次角色释放及完整后摇，修正五连箭末两箭、雷法末拍从待机姿势出现的问题。已离手的火墙、火海、次爆、地裂余震和治疗持续效果继续由世界时钟执行，不要求人物对每次持续伤害重新挥手。

动作期间朝向与实际攻击/发射方向一致；拉弓瞄准阶段仍可转向。0.45s受伤保护窗保留，短受击表现只占最初约0.12s，轻伤不覆盖仍在执行的动作。闪避或重击取消角色连段后，未释放拍停止；已发箭、已落地场和已提交冷却不回滚。

## 手部与发射衔接

`PlayerHandAnchors.ts`按实际图集裁切、UPP、帧缩放与脚锚校准相机平面的手/杖端位置，注明约0.03—0.06m视觉误差。`FlatActors.playerPresentation()`提供当前姿势、拍数和世界坐标；`Effects`在人物采样之后更新持续聚能与每次释放的手部闪光。长前摇不再仅有一次很快消失的胸前粒子。持杖施法使用本身的抬杖、前推和收杖图，法杖不因切到通用施法图消失。

新生箭矢、杖弹和火弹在最初0.14s使用冻结的手/杖端呈现偏置并退回原逻辑轨迹，尾迹记录实际呈现点；火弹额外考虑透明图的底锚。即时雷弧的施法者端取第一次实际显示时的手部锚点，敌方接点不变。该桥接只作用于表现，未增加命中范围、改写碰撞或追踪目标。

BOW_05单箭碰撞宽恢复普通箭0.3m，选敌矩形宽不再误作单箭宽，避免远处目标在箭出生时就受伤。移动连发的新箭跟随当次角色位置出生，初次冻结方向/目标及已出箭路径保持；移动或敌人走离仍允许落空。

## 资产与验收边界

现有脚锚抽查224样本，脚底误差不超过0.026m；举剑后顶部变化包含剑尖，未用整图高度重新缩放人物。W08/L02现有通用施法仍共享既有背弓姿势，不把它标成新增独立施法美术；本轮完成的是已有动作与实际结果的时间、朝向和发射衔接。

类型检查、已有95项规则检查及真实GameSession边界探针通过。角色执行拍、取消、移动发射与实际飞抵后判伤的探针记录在`temp/action-sequence-*.json`。实机连续录制使用新隔离浏览器，真实`ChapterGame.update`及Cocos原生粒子随渲染帧推进；CDP只观察画面，Pillow按原始时间戳编码GIF，没有生成中间帧、慢放或额外停顿。

最终构建、连续动作、关键姿势图和验收结果见[动作运行目录](../../src/cocos/test-results/action-sequence-v3/actual-sequences.json)，入口仍为默认7469试玩版。手机尺寸来自844×390浏览器视口，不作为硬件性能结论。

最终默认包实载`index.21d5e.js`。7场自然渲染循环记录了264次姿势状态及210张实际画面，未出现运行异常或失败请求；动作链、逐拍手部聚能、普通剑击、移动连发与杖端出生衔接分别见[最终汇总](../../src/cocos/test-results/action-sequence-v3/summary.json)和[原速动画目录](../../src/cocos/test-results/action-sequence-v3/animation-artifacts.json)。
