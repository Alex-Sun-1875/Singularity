# 火系普攻与技能表现 v7

2026-11-11。用户否定 v4 后，明确选择“厚重写实：亮火核、翻卷爆燃、暗红外焰”，随后明确要求**不要黑烟**。当前保留炽亮火核、橙红翻卷和火星，移除所有新火体与卷焰相中的中性炭烟和暗灰余烟；火系爆燃也不再附加烟尘 burst。v4／v5／v6 的试验素材保留在 source-art 和 temp，不作为通过依据。

## v8 颜色密度修订

针对“颜色很淡”的反馈，火海持续层不透明度由 0.25 调整至 0.60，余焰段由 0.48 调整至 0.74，后排卷焰保留更多颜色。贴图切相改为先保持上一相火体、待下一相密实后再退去，避免两张都变透明时草地冲淡橙红色。烟雾选择器只负责去烟；已确认的火焰恢复密实 alpha，不再额外乘成薄雾。

保持无黑烟、原有几何、伤害与时序、64 卡片池和既有帧率设置，没有新增贴图、粒子、光源或材质引擎。原始参考和关键相不重新生成；派生记录与哈希随当前素材更新。

## v7/v8 接入记录

普攻方向形、陨石实体及四系范围辅助显示随后按用户反馈修订，最新接入见[普攻与陨石修订记录](combat-design-v9.md)。下述三张 atlas 资源量只对应 v7/v8。

- 普攻与赤焰枪使用独立炽亮火核，橙红外壳、原生世界空间短尾焰和真实接点爆燃。赤焰枪的火核、尾焰强度高于普攻。
- 焚星坠落表现加速下坠、短促亮核和翻卷爆燃；主火体、低位前景卷焰按真实地面位置错深排列。二次内燃仍读取原有实际段数与范围。
- 火墙与火海使用同源低位翻卷材质，长、短两轴同时约束卡片，前锋与已经扫过的区域分开推进；前景裁片使用独立透明衰减，避免矩形切口。
- 护盾沿用贴身焰纹和受击事件，增加小型动态火体。普攻元素反馈从错误的 THU 改为已有职业解析器返回的 FIR／THU。

判定范围、伤害数值、冷却与段数没有提高。保持原帧率设置、64 张卡片上限、原生粒子与 Line；没有新运行依赖、光源、后处理或自定义 GPU 体积材质。

运行仅预加载三张 atlas。[尺寸、PNG 大小、纹理原始字节与 SHA256](../../source-art/skills/fire-runtime-v7/processing.json)单独记录；这些数值不等于完整上传包、首包或可玩前资源量。原有 v2／v3 素材保持不变，弃用的本轮试验不放入 resources。
