# iPhone 14及以上的默认设计基准

2026-11-10。长期规则见[界面布局设计规范](../design/ui-layout-guidelines.md#默认设备分辨率与单位)。用户指定iPhone 14及以上屏幕规格为默认设计依据，TapTap小游戏仍是当前主要运行平台。

iPhone 14横屏参考为2532×1170物理像素，默认布局和全屏移动检查使用844×390逻辑视口、3倍设备像素密度。物理屏幕规格按[Apple资料](https://support.apple.com/en-us/111850)核对，逻辑视口与已安装Playwright的iPhone 14屏幕参数核对；没有直接使用带Safari工具栏的750×340浏览器预设作为小游戏全屏基准。

运行HUD与Cocos项目设置统一采用约1558×720设计单位，保留固定高度、宽度随屏幕适配。启动画布及项目初始化脚本同步；文字和触控仍按现有设计尺度布局，不随物理像素数变小。默认移动触控与发布检查脚本改为iPhone 14全屏视口和设备密度。项目及Cocos的AGENTS.md均记录这一长期约束。

工程类型检查、脚本语法检查及web-mobile构建通过，完整成功输出已更新默认7469。构建复用此前已建立的C盘副本，完整同步资源和脚本并检查脚本哈希，再同步完整输出回默认试玩。

浏览器验证覆盖844×390、852×393、926×428、932×430、874×402、956×440六组全屏逻辑尺寸，均设置浏览器设备密度3。检查四个主技能槽、48逻辑像素触控尺寸、地图圆边28逻辑像素图标、控件间距及行囊/技能/设置入口，全部通过，无运行错误。另在基准和最大视口验证左右各64、底部24逻辑像素的安全区压力夹具；这些是人工压力值，不是对Apple设备真实安全边距的测量结论。实际边距继续由既有Cocos安全区接口提供，不硬编码为机型常量。

默认手机触控流程通过双指移动与攻击、可见边缘取消、火油取消、拉弓取消不发箭和取消后闪避。安全区部分依据已安装Cocos接口实现及Apple布局规范；本地技能库相关检索未得到适用条目，未采用其无关结果。

**渲染与真机边界：**本机已安装Cocos 3.8.8的Web屏幕适配器将引擎设备密度上限设为2，因此基准夹具记录浏览器设备密度3、引擎密度2、Canvas缓冲1688×780。此次统一设计与检查基准，没有修改引擎或强制3倍渲染；截图按逻辑尺寸导出，不冒充2532×1170原生渲染。浏览器尺寸、用户代理与安全区夹具不能替代实际iPhone、TapTap平台和目标Android设备验收。
