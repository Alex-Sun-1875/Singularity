# 近战剑气覆盖与动作衔接 v13

用户随后明确要求增加剑气前向长度，长度与宽度的最新修订见[剑气前向长度 v14](melee-reach-v14.md)。本页保留 v13 的动作衔接与历史画面记录。

2026-11-11。按用户要求扩大近战剑气的视觉覆盖，并改善普攻连段和多段战技的衔接。继续使用原有角色、CC0 动作、透明钢刃材质及 Cocos 3.8.8 组件，没有生成新图或修改角色身份。

`MeleeBladeSurfaces` 将弧面展开比例由 0.64 调至 0.82，增加向内的细碎刃面宽度，并将亮刃推近真实命中边缘。基础扇形内的可见弧面由约 70° 变为约 90°；半径、伤害和判定角度仍由原有权威几何提供，新增的宽度向内展开，不把装饰画到不可命中的远处。剑气平滑退亮，消除原先主刃切换到残影时的亮度骤降。

主角持近战武器时使用 Cocos 原生实时骨骼混合；烘焙模式本身不支持交叉过渡。切换播放模式时停止旧状态并通过公开 `createState` 接口重新初始化导入动作，确保实时曲线可用。只为这一个近战主角启用实时混合，远程武器和其他角色保留烘焙播放。沿用已有帧率设置，没有增加或降低帧率上限。

普攻保留跟随下一刀的余势，略过重复的入场停留；多段战技在真实命中拍点前 0.06 秒衔接下一刀的起手。普攻和战技的伤害拍点、段数与总时长沿用规则时钟，减少的是角色表现的命中停顿。普通斩最多 0.012 秒，终结普攻最多 0.022 秒；受击、音效及实际伤害反馈仍依据原事件。

默认试玩已更新为 `concept-2d-melee-flow-v13c`，主包 `index.a01f0.js`，普通和 `test=max` 入口均验证加载新版。类型检查与 Cocos 本地构建通过。手机 844×390 DPR3、桌面 1280×720 的连续两轮三连击、断空斩和破晓裁决均无运行报错；近处实际命中，远处和背后目标未被装饰波及。30,870 个几何采样点没有越过实际半径。

实际记录中可见 16 个原生混合帧和 16 个下一刀提前准备帧，主角骨骼持续运动。火系普攻的短尾、离手间隔和陨火检查通过，剑／弓／雷法真实普攻均命中，切换模式后的导入动作状态正常。保持既有 60 帧配置；本记录不是目标设备帧率或持续负载测量。
