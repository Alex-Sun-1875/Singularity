# 法师受击动作与持杖限制 v3

2026-11-12。按用户要求补充施法中的受击表现，并禁止未装备法杖时施放火、雷技能。

`playerHurtProgress` 统一原生与 2D 呈现：受击后约 0.04 秒进入已有 `hit` 动作的主要后仰阶段，完整回势在 0.22 秒内播放。原生主角按实际 `hurtTime` 采样，2D 分支取消“有动作就不受击”的覆盖。受击期间脚步层让位；普通伤害后按当前动作时间接回施法，重击在前摇内的打断继续由既有规则处理。没有新增玩法硬直或改写伤害时钟。

法杖受击使用实时骨骼，在胸部和身体受击动作上复用 `idle_staff` 的右臂持杖姿势。右臂从独立、无渲染器的节点骨架采样，避免与走跑采样互相平均；回到施法时用约 0.06 秒退出持杖支撑。武器挂点从最终骨骼重新绑定，使法杖与手掌同步，避免通用受击动作把法杖垂进地面。暂停保留受击姿势，死亡仍使用倒地动作。

Cocos 3.8.8 的自动挂点会在晚更新修正前填入当帧骨骼矩阵缓存。程序化姿态生效期间暂由统一角色层更新已注册挂点目标，确保实际蒙皮矩阵使用修正后的骨骼。恢复烘焙前先还原挂点注册列表，保留挂点目标的变换更新；暂停换装也同步最终挂点。没有修改引擎或访问生产运行时的私有缓存字段。

设计修订保存在 `tools/design/mage-staff-requirement-v1.json`，经 `export-combat-runtime.py --skills-only` 导出，八个火／雷主动及终极技能声明 `compatibleWeapons: staff`。`SkillWeapons` 统一规则与界面的武器判断、文案；开始施法和实际出手时均检查装备，未满足时不生成法术、不扣资源、不进入冷却。技能按钮禁用并提示“需要装备法杖”。已合法发出的法术继续独立运行；通用闪避使用原有武器兼容规则。

验证：当前源码类型检查与现有 120 项测试通过；八个法师技能对剑、弓、空槽、未知武器均拒绝，对全部 66 个注册法杖变体均成功释放。出手前移除法杖会取消且不扣资源，合法发出的投射物在换武器后仍能命中。

844×390、DPR3 浏览器实际场景覆盖前摇中普通受击、持续施法中受击、重击打断、移动受击后恢复、暂停和暂停换装。实际绘制模型的手、髋、脚与头部共至少 11 个有效关节参与核对；矩阵与最终骨骼误差低于 0.0001，挂点位置误差低于 0.0001。每组受击第 8 帧另检查可见法杖的几何范围，未垂入地面。六组移动攻击回归通过；浏览器没有脚本或控制台错误。按钮置灰、禁用、提示法杖以及装备法杖后成功施法均已检查。
