# 普攻、陨石落体与玩家范围辅助显示修订

落体外观随后按用户反馈改为连续彗星火体，最新接入见[彗星轮廓 v10](fire-comet-v10.md)。本页的实体岩块与构建信息保留为 v9 历史记录。

2026-11-11，按用户反馈修订：普攻需要明确方向与火焰实体；焚星坠落需要可见的陨石落体；战士、射手、火法和雷法去掉技能范围、弹道方框等辅助显示。继续沿用无黑烟、浓橙深红与紧凑亮芯的要求。

`Effects` 不再绘制玩家普攻范围圈，`NativeSkillVfx` 的玩家技能预览绘制已移除；油瓶原有非技能抛物线保留。火海的矩形地面描边同步移除。输入瞄准、有效距离、命中几何、伤害、段数、冷却及敌方反馈读取原有规则，没有用删显示的方式修改判定。

普攻与赤焰枪改为沿飞行方向展开的火头和短焰尾，火头仍锚定实际弹体位置；不再把圆形核当作完整火弹。焰尾贴图从项目现有云端生成的 `fire-tongues-v1` 确定性旋转、缩放和透明边缘处理得到，本轮未调用生成模型。沿用原始[火焰来源](../../source-art/skills/pure-skills-v2/fire-particle-v1/provenance.json)和已有 CC0 点火芯。

`SkillMeteorBody` 复用项目已有 Poly Haven CC0 苔岩网格，单独提取一个岩块，不加载整套场景模型。陨石沿真实世界 Y 加速斜落；实体岩石、向后拖曳的火尾与触地爆燃分开表现。落体读取原有施法准备时长，释放时退场并接原有真实爆燃事件；中断和清场不会留下落体。标准材质在场景渲染管线就绪后创建，最多复用四个陨石节点。原始网格、纹理和许可见[场景来源记录](environment-fidelity-v2.md)，派生文件哈希见[本轮来源](../../source-art/skills/combat-design-v9/provenance.json)。

继续复用 Cocos 3.8.8 的 MeshRenderer、内置材质、透明卡片和原有池，没有新增运行依赖、自定义 shader、黑烟、灯光或后处理。火焰卡片仍上限 64，保持原帧率设置。新增资源合计约 350 KB（源 PNG 与网格 JSON）；此数值不等于首包、完整上传包或可玩前所需资源。

默认试玩已更新为 `concept-2d-combat-design-v9b`，主包 `index.11197.js`，入口 `http://127.0.0.1:7469/?view=2d&player=3d&test=max`；普通入口与测试入口均验证加载新版。旧默认包移到项目 temp 保留。

类型检查及 Cocos 3.8.8 Web 构建通过。844×390 DPR3、1280×720 代表施放和 15 组火系等级施放均无运行报错；四系共 60 个预览状态没有产生辅助 Line。火弹八方向头部锚点与方向检查通过，火体 1192 个几何角点没有越过实际地面范围；峰值 60/64 张卡片，清场后卡片与陨石均为零。战士、射手、雷法的真实普攻亦各记录一次命中。既有 60 帧设置不变，此记录不作为真机帧率测量。
