# 火系普攻与技能表现 v4

**状态：用户已否定本版观感，保留为试验记录，不作为美术通过或默认试玩更新依据。** 后续重做火体与流动材质，技术检查通过不能代替美术验收。

2026-11-11，针对火系普攻、技能辨识度与打击感的修订。运行工程为 Cocos Creator 3.8.8 / TypeScript，发布目标仍为 TapTap 小游戏。

## 本次变化

- 火系法杖普攻从中性小光点改为独立火球序列：短白热核、橙红焰体、短尾焰，释放端沿用角色手部锚点；命中后在实际接点短促爆燃。火系普攻原先错误使用 `THU` 元素反馈，现由已有 `weaponCombatFamily` 解析，火／雷职业保持各自的反馈。
- 赤焰枪复用同一火弹材质，尺寸与尾焰强度高于普攻；停止使用缩小的爆炸云充当飞行弹体。爆燃仅响应真实 impact 事件。
- 焚星坠落使用向下的火核和加速下坠，落地由紧凑火核发展为火焰爆燃、低位卷焰和余烬。主火体保持紧凑比例并限制体积，避免高等级变成遮住敌人的巨大火幕；原有二次内燃仍服从原段数和范围。
- 焰心护盾在原有肩臂焰纹上增加小型动态火舌，受击反馈继续来自真实护盾事件。
- 炎墙与火海改用四相滚动火舌，按真实矩形错位摆放；每张面向镜头的火舌同时裁在矩形的长、短两轴之内，避免斜视变成薄片。低亮贴地火床连接底部，火海前锋与已扫过区域继续分开推进。
- 爆燃从重复烟云叠层改为一个主火体与两个低位卷焰，普攻接点仅使用主火体。共用 quad，池上限维持 64，不新增光源、后处理、运行依赖或帧率限制。

本轮修改的是呈现和普攻元素反馈，没有调高伤害、扩大判定范围、增加伤害段数或改变技能冷却。范围仍读取 `SkillVfxGeometry` 与权威战斗事件。

## 资源与来源

使用云端内置 OpenAI image_gen 生成一张透明生产序列，包含火弹、爆燃、持续火舌各四相。[原始输出与来源](../../source-art/skills/fire-runtime-v4/provenance.json)、[完整提示词](../../source-art/skills/fire-runtime-v4/prompt.txt)、[确定性派生脚本](../../source-art/skills/fire-runtime-v4/derive.py)、[尺寸、锚点与哈希](../../source-art/skills/fire-runtime-v4/processing.json)分别保存。

Pillow / Numpy 只执行格子裁切、亮核锚点对齐、底部透明衰减与 Lanczos 缩放，保留生成的 alpha。12 张运行 PNG 共 863,835 字节，火弹与火舌 256×256，爆燃 384×384。旧素材保留，本轮运行预加载从旧 28 张改为新 12 张；PNG 总量不代表完整上传包、首包或可玩前资源量。

继续使用项目现有资源加载器与内置透明 Unlit 材质；火星、焦痕和短尾迹复用原生粒子／Line。引擎依据为本机 3.8.8 接口及 [Cocos 粒子渲染模块](https://docs.cocos.com/creator/3.8/manual/zh/particle-system/renderer.html)，未引入新的特效框架。
