# 剑气前向长度 v14

2026-11-11，用户明确需要增加向前延伸的长度。撤回 v13 对弧面展开和刃面宽度的加宽，恢复较窄的轮廓；保留已经接入的近战原生动画混合、转刀衔接与平滑退亮。

普攻的真实近战距离从 1.45m 延长到 1.85m。断空斩和破晓裁决的扇形半径增加 25%，判定与实际刃面共用该半径；原有角度、伤害、段数与动作时序保持原值。突进、自保和落地圆盘不随本次前向剑气调整扩大。

| 技能 | 五级前向距离／半径 |
| --- | --- |
| 断空斩 | 3.0 / 3.0 / 3.175 / 3.3 / 3.45 m |
| 破晓裁决 | 4.375 / 4.375 / 4.6375 / 4.8125 / 5.025 m |

沿用已有设计导出器，新增 `tools/design/melee-reach-revision-v2.json` 显式修订，然后仅重新生成 `PureSkills.ts`；冻结的原始设计目录保持历史原貌。普攻范围继续由 `BASIC_ATTACK` 同时供命中与显示读取。

旧存档只接受此前精确的半径、投送距离和范围组合，其他技能字段仍须与当前声明完全一致。旧在途斩击经原有恢复流程清理，持久生命和进度继续保留；伪造伤害、混杂范围的快照仍拒绝。没有新增正式测试依赖或修改帧率设置。

默认试玩已更新为 `concept-2d-melee-reach-v14`，主包 `index.43ef7.js`，普通及测试入口均确认加载新距离。类型检查、Cocos 本地构建和现有 116 项检查通过；没有新增正式测试用例。

手机和桌面的实际卡片半径为普攻 1.85m、五级断空斩 3.45m、五级破晓裁决 5.025m。原范围外、现范围内的目标实际受到攻击，远处和身后目标未受伤。30,870 个几何采样点没有越过实际半径；近战原生动作混合继续生效。导出差异检查只发现两项技能的 30 个距离字段变化，未改变其他技能数值。
