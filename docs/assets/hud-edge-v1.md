# HUD贴边间距修正

后续已按触控反馈将战斗按钮组内收，最新默认边距与效果见[高频战斗按钮的触控余量](hud-touch-inset-v2.md)。下文是v1阶段记录。

2026-11-10。用户指出此前截图中头像和技能离屏幕边框过远。

此前展示中混入了安全区压力夹具截图，左右人为各预留64逻辑像素，底部预留24；这些是压力值，不是默认布局，也不是实测机型边距。后续默认效果图只展示正常布局，压力夹具另行明确标注，不再混排为默认效果。

运行布局也收紧了额外留白：手机默认外边距改为6逻辑像素，硬件安全区与默认外边距取较大者，不在安全区上再次累加边距。头像/状态栏及任务栏沿这一边界排列。四主槽继续同圆心、同半径、等角距，圆弧改为围绕左上方向对称的102°扇段，按四槽与普攻实际触控边界计算右下锚点，移除旧的额外右移/抬高留白。底部常驻武器名称收起，武器详情仍可从行囊和攻击提示查看。

基准844×390的普通布局测量：

| 对象 | 之前 | 本次 |
| --- | --- | --- |
| 头像/状态栏距左边、上边 | 约12逻辑像素 | 6逻辑像素 |
| 普攻距右边 | 16.25逻辑像素 | 约8.33逻辑像素 |
| 普攻距底边 | 约32.24逻辑像素 | 约8.33逻辑像素 |

不增加技能、不修改槽位配置或规则，48逻辑像素触控尺寸及8逻辑像素间距保留。六组iPhone横屏尺寸、两组安全区压力夹具、实际菜单点击与既有双指移动攻击/取消/闪避检查通过，浏览器运行错误为0；工程类型检查和web-mobile构建通过，默认7469已更新。构建复用已建立的C盘副本，同步资源与脚本并检查哈希后，完整同步输出回默认试玩。TapTap平台与真机验收仍单独进行。
