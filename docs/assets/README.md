## 当前范围与事实

- 48类物品=40件永久装备+8类一次性符咒。永久装备为16武器（6近战/4弓/4杖/2副手）、16护甲（头/身/手/足各4）、8首饰（戒指/项链各4）；符咒成功释放扣1张，取消/前摇打断不扣，休整不免费补符。六套正式套装每套5件候选、2/4件门槛，成员均来自40件永久装备，符咒快捷栏和背包张数不计套装，不额外制造30件；四构筑共用一个主角身体。
- 特色商人5人：复用艾妲/布兰，新增猎商蕾萨、符印商墨伦、灯油古物商娜薇；买卖与金币以[商人合同](../interactions/merchants-and-trade.md)为准，地图探索以[地图逻辑](../story/exploration-map-logic.md)为准。只有6件可选装备转专售，原Boss/隐匣/配方收据不改。

## 状态用语

| 状态 | 可以证明 | 不能证明 |
| --- | --- | --- |
| 参考 | 有可查看的方向图 | 非模型、绑定或动作帧 |
| 占位 | 文件存在，可检查接口/比例 | 非获批最终外观 |
| 结构/技术研究 | 某项几何、绑定或渲染可复现 | 面数/骨架/渲染成功不保证美术合格 |
| 失败并停止 | 有失败证据和停止原因 | 不能计作新角色交付或正式进展 |
| 计划 | 规则或制作任务已定义 | 非已制作、接入或测试通过 |
| 样板通过 | 单项外观/技术有验收证据 | 不外推整章、全构筑或48类通过 |
| 正式通过 | 外观、动作、状态、实机均有记录 | 当前正式角色没有这一状态 |
