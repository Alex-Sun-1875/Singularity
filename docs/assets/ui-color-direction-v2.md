# 界面暖色方案清单

历史阶段记录。2026-11-05后续用户要求去土黄并整体对齐BG3，当前运行色与皮肤见[最新视觉统一](bg3-visual-alignment-v5.md)；本页旧暖色表不再是当前配色。

状态（2026-11-05）：参考研究、独立资源制作与手机横屏 Cocos 接入已完成一版。17 张原创古铜界面图已用于 HUD、行囊、对话、地图及掷骰。最终发布构建的真实触控、滚动及 844×390 / 915×412 字号已复核；不能据此宣称最终美术或手机硬件性能验收完成。

已查看本地 BG3 官方设定集人物、聚落与地下场景，以及地图 banner/侧栏/图例。第一版8张原创材质候选与组合板位于 [第一章材质设计目录](../../assets/materials/chapter-one-v3/README.md)；组合板仍为设计图。实际接入的是独立 UI 切图与六组配套 PBR 资源，运行时记录见 [PBR 接入说明](pbr-runtime-v3.md)。没有分发 BG3 原资源。

最终 `UiTheme.ts` 使用褐黑 `#191715`、烟褐面板 `#211E1A`、古铜线 `#79684F`、米白正文 `#E1DFCE`、柔金 `#C4B89B` 与灰橄榄选中态 `#30392B`。下表保留最初暖色提案的历史值；当前已用更克制的色值替代，不能将其当作运行时精确配色。

参照本地 BG3 地图侧栏、图例和美术设定的皮革、旧黄铜及纸张质感；以下是本项目建议色值，不是原游戏精确取色。参考来源见 [BG3 参考记录](../maps/map-ui-bg3-reference.md)。

| 对象 | 质感与用途 | 建议色 |
| --- | --- | --- |
| 整屏背景、地图外框 | 极深褐黑，轻微皮革纹理 | `#17120E` |
| 探索手记、行囊、对话面板 | 烟熏棕，边缘压暗 | `#261D16` |
| 普通按钮 | 深皮革棕 | `#3B2C20` |
| 选中标签、选中按钮 | 古铜棕 | `#62482C` |
| 悬停与按下 | 暖铜色提亮 | `#795C35` |
| 边框与分隔 | 低亮度旧黄铜 | `#9E7C46` |
| 标题与关键操作 | 柔和旧金色 | `#D0B477` |
| 正文 | 羊皮纸米白 | `#E4D5B7` |
| 次要文字与未探索地点 | 暖灰褐 | `#9B8D75` |
| 队伍、路线、危险提示 | 灰橄榄绿、暖金、暗赭红 | `#94A078` / `#D6B46C` / `#8B4334` |

替换范围：地图背景、探索手记、切层、筛选、缩放与标记控件；HUD 生命、任务、快捷栏和交互提示；行囊、装备、对话、掷骰、暂停菜单。地图地形插画保留其自然地貌色彩。优先复用 Kenney 边框和现成皮革、纸张纹理，以着色、九宫格拉伸和轻微明暗层次完成适配。
