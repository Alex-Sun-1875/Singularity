## 已知边界

这是可操作的本地2D版本，使用低帧方向/姿态图。单帧受击、两帧施法/交互与站立NPC按真实帧数记录；并非完整逐帧长动画。侧背面的小扣件可能有差异，装备外观按剑/弓/杖类别共享，未逐件绘制数值装备或各武器翻滚/死亡变体。

建筑/植被/岩石家族复用，尚无每个世界朝向的独立建筑立面；地表为原授权albedo的unlit表现。场景构图、步态过渡和美术一致性仍可精修；部分餐具与桌面尚未逐像素贴合，四方向画姿与360度实际飞行方向也有小幅手部对位余量。原3D对比资源和隐藏物理场景仍在包内。浏览器手机尺寸/UA检查不代表实体手机帧率、发热或内存验收；TapTap真机包与公开发布不在本次本地交付中。
