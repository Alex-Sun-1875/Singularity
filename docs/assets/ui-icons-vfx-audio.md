# 剑与火界面图标特效与声音

> **版本状态 2026-11-02 09:42 UTC：用户再次否决区域v2的尺度与过度寻宝定位。** 本文保留的12子区/4宏路、包围盒、20—40/35—60分钟、8新增母项和212计数均是该被否决候选的记录，不是v3获认可愿景、预算或交付。v3须重新以真实地图参考及剧情、战斗、探索共同作用研究；本次不另造尺寸、支线或奖励。单人演示只限制生产批次，不限制世界规模；40永久装备+8消耗符类型保持。

## 表达目标

探索、地形与局部选择可以借鉴写实奇幻 RPG 的可读性；拾取、有限装备提升和打开宝库的反馈可借鉴《传奇》的爽快感。这里仍是实时单人动作游戏，被否决v2曾尝试扩大空间，v3需重新研究剧情、战斗与探索的组织，不增加队伍头像栏、完整职业三套技能树、随机词缀大词典、多人攻城界面或海量稀有度皮肤。

`ui_dialogue`复用为`story_choice_ch03_treasure`，不新增选择界面。并列呈现完整守誓护符与拆出余烬铜芯的真实物件近景、训练效果与代价；明确二者是剧情古物选择，解锁训练，不是48类物品里的项链/符咒。默认高亮保留整件但必须明确确认；关闭或返回不提交。选择后另一项标“本次未获得”，不能用切换装备取得未选物。两训练仍互斥，9训练目录单档最多8种、启用1种；这个限制只属于训练栏，与9槽永久装备的固有效果和套装共同生效，快捷栏本身不加属性/套数。具体原效果见[成长目录](../interactions/progression-loot.md)，实体目录见[装备与合成](../interactions/equipment-and-crafting.md)。

### 属性比较与六套四件套

所有48类卡显示名称、类别（永久装备/一次性符咒）、装备槽或快捷用途、L阶级、品质文字/1—5缺口、基础属性、固定词条、套装键（T类无套装）、取得途径与拥有/发现状态；符咒另显示剩余张数、批次产量和成功使用耗1张。属性总览显示基础值、装备加值、词条/套装来源、封顶前后结果，不能只用绿色箭头把移动代价或冷却惩罚藏掉。近战/弓/杖的伤害、射程、前摇、专注关系不同，不把三者都标“剑伤”。

6套正式套装逐套显示5件候选成员，穿其中4件可激活最高门槛，拥有数量与已装备数量分开；只按已装备的不同成员统计2件/4件门槛。重复戒指、旧ID别名、背包拥有物、消耗符咒、快捷栏引用和已用符发现记录不凑件数；拆一件前预览会停用的加成；副手不兼容时不以红字警告后仍计算属性。套装和固定词条可协同，叠加/封顶按权威规则，不再全局限制成一个生效效果。

4种试玩构筑“反击守桥者、风径猎人、沉钟织法者、双印巡秘者”采用同一装备页面与比较组件，明确近战、弓、法杖和有限符咒爆发+免费主武器的轮转、优势、张数代价及合法装备。试玩配发与主线奖励必须标识不同来源；若用隔离试用物，结束不写入真实拥有集合，不偷偷补齐未探索的物品。

键鼠提示固定区分：R武器技/盾格挡、Q/E双符咒、F交互、L推、K投油、Space闪避；符咒只在真正释放时同次扣1张并提交冷却；取消/前摇打断不扣张，空库存与R专注不足是不同状态；零符保持免费主武器可用。W15必须显示“覆盖主手R技”，W16只提高专注上限20不回满。

### 品质制作与分解

品质用文字、颜色、缺口三线索；L阶级与品质分别显示，品质不自动暗加伤害倍率。数值、配方、受保护物、分解返还以及可重复制造范围只读[装备权威表](../interactions/equipment-and-crafting.md)，17张永久图纸分为10张永久装备配方与7张符咒批量配方，不保留12剑/5配方时期限制。

`ui_crafting_workbench`仍为1个界面设计，配方卡复用纸张底稿、真实产出物缩图、材料图和文字；不按配方数重复计插图。确认前分开列永久装备产出与符咒批量产量，列材料、当前堆叠、产后数量/容量、是否会替换装备或破坏套装。取消不扣料；事务提交中禁重复；会话成功但尚未保存写“已制作，尚未保存”，保存成功才写“已保存”。只有10种配方永久装备可按权威规则分解，消耗符咒不可分解；受保护或当前装备物、返还超上限、来源不明等情况显示具体原因；不能先毁物再弹失败。

物品近景和静态掉落由[40件装备与8类符咒外观登记](environment-and-props.md)同源导出，不把图标、卡片、模型和动作混称一件已完成资产。品质覆盖、合成确认与分解反馈复用`fx_loot`、`sfx_interact_confirm`、`sfx_hit_metal`，不额外制造5档全屏光柱。新材料地面复用掉落袋，不各造世界矿石。

### 探宝奖励与复演

`design_ui_replay_panel`始终标“复演”。`standard`与`no_flask`是投油条件，不得写成“全程无法术/无火”；弓、杖、符和专注在复演中的隔离快照按[探索规格](../interactions/exploration-and-replay.md)。真实装备、符咒数量/CD与材料不在副本中制作、分解或改写；复演使用有限虚拟符配给，不回写真实背包。结算只发明确的普通材料，不伪装主世界Boss复活或第二次通关；待领余量、无奖练习与保存重试都有明确状态。回访列表、装备预览、HUD目标与结算都复用现有13面板，不新增排行榜、小地图或新配音。
