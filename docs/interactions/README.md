## 当前决定

做一款单人、2.5D、可保存的连续剧情探索动作游戏。世界愿景需以剧情冲突、人物任务、战斗和探索共同支撑大型地上/地下区域网络，不能以“小项目”把整幕压成短地图。原v2的整章主线20—40分钟/探索35—60分钟已被否决，不再是世界上限；20—40分钟仅可作为后续某局部游玩时段的待评估候选，不预先规定整幕总时长。首章《灰披宝匣》先闭环；第二至四章是内容规划，不能以入口占位冒充可玩。

核心循环方向修正：**遇见人物或冲突 → 了解地点、选择目标和路径 → 通过对话、探索或战斗产生进展 → 得到故事后果、关系回应与适当战利品 → 整备后继续区域旅程。** 这不是新增任务已写完的声明；具体人物任务和多层世界结构由下一版规划定义。 玩家每次操作都应知道打了谁、为什么没打中、装备怎样改变打法、失误后怎么继续。

- 自由剑士从艾妲的追回宝匣契约出发，布兰辨认遗物工艺、给实际藏宝线索；原四章片段各有明确头目战和装备回报；它们可保留为世界中的内容节点，不再规定整个区域只能围绕一件宝物收束。洛德里克囤积截走的遗址兵器，最终玩家击败他并打开门台旁的堡库凹室，不把故事重心放在治理城门或分配物资。详见 [故事总纲](../story/world-and-main-plot.md)、[第一章](../story/chapters/ch01-broken-road.md)。
- 原三条局部路线与稳定route ID保留，嵌入较大区域的宏路线网络，不再充当整章地图边界；2个有界决定分别是队长缴械誓保/看管，以及守誓护符/余烬铜芯的互斥装备选择。两个装饰发现不影响通关。剧情通过宝物用途、短人物冲突、环境证据回应探索，不把旧两项选择和寻宝事件当作人物/剧情任务总量上限；更完整剧情范围待下一版规划，不在本页擅自补新任务或自动授权新玩法。
- 美术为原创、成人比例、细致的皮革/钢铁/布料表现。受认可风格启发不等于复制已有角色或资产；明显分面的低模只可做内部占位，不能作为终版验收。
- 默认先按 **Android 横屏触屏**设计；这只是待确认的目标设备假设。桌面键鼠是并行的预览/辅助输入。未承诺 Tap 平台兼容、上传包、设备性能或现有原型接入。
- 所有距离、时长、伤害、敌人数量均是**首轮调优估值**，不表示已通过试玩。世界距离用米表达；1 m 是关卡设计单位，不绑定当前像素数。

## 权威边界与 ID 规则

1. `data/story/chapters.json`、`characters.json` 的既有章节、人物、任务、交互、奖励、检查点 ID 不重命名；显示名与叙事含义以本轮 Markdown 为准。旧 `grain`、`roadside_supply`、`city_supply` 等 ID 是待适配的历史键，不表示当前任务仍为运粮；JSON 未同步，不声称已包含新规则。
2. 既有 `interact_*` 是一组内容的稳定设计 ID，不强行冒充所有场景实例。新增动作、细分条件、实例和改装使用 `design_` 前缀；它们是**拟新增 ID**，未接入任何存档。
3. 任务顺序是已有 prerequisite 链。提前可做的场景动作允许记事实，只有前置任务完成才结算后续目标；不给奖励两次，不用刷新场景惩罚探索者。
4. 世界对象状态与存档的歧义以 [存档与任务契约](save-and-quest-state.md) 为准，动作窗口以 [战斗](combat.md) 为准；改数字时须同步相关验收项。
5. 现有 `src/core.js`/README 中的金币升级、即时命中火油、重复普通敌人布局等属于早期原型观察，不是本规格的完成证据。没有用代码测试通过来替代本稿的设计验收。

## 不可破坏的通关约束

- 从任何检查点、任何改装、**零火油、零废铁、零包扎布、零符纹、零锻芯，未合成且只用旅人铁剑**均可继续主线；剑/推/移动可解决全部必需战斗。
- 主线圣匣车、三处封签遗物、手柄、清单、账页、绞盘和桥不可被烧毁、出售、丢弃或推入坑。
- 不要求将可移动箱子一直搬到未来章节；不会把不可再生物体当唯一开门钥匙。
- 不要求玩家掉坑、跳跃、盲冲火区或一击解谜；重要地面操作都有安全站位、撤离通道和可重试反馈。
- 已击败敌人、已领唯一奖励、完成的主线、打开的近路永久保存。死亡不重置整章；未击败头目恢复全血，未击败普通敌人重置位置/生命。
- 确认“已保存”必须有持久化成功证据；写失败只说“本次仍可玩，尚未保存”。不静默覆盖损坏存档或清空旧进度。

## 制作前验收闸门

**本次已做：**只读对照 JSON 的 ID/角色/章节；撰写与交叉引用静态检查。**本次未做：**开发、数值试玩、动画制作、设备测试、性能测量、Tap 开发工具验证。

下一步先评审文字与关卡纸面走查，再决定是否授权实现。首章演示的设计目标是让近战、弓箭、法杖、符咒四种构筑均可实际试用，不把剑模板改名当作远程或法术交付。技术样板可以按武器族分批验证，但未齐全时必须标为局部样板，不称四流派演示完成。48类型为四章全目录候选，不等于首章全发；首章来源与后章扩展由装备表逐项约束。不加入背包格子、全物理堆叠、无限火传播、随机词缀或额外技能树。

## 玩法参考如何转成自己的游戏

这是对用户“玩法参考《博德之门3》和《传奇》”的**原创设计转译**，不是对两作全部机制的考据或复制清单。

| 灵感方向 | 本作可执行落点 | 明确不搬入 |
|---|---|---|
| BG3式地形思考 | 坡道绕背、推离盾阵、矿车挡弩、油桶/水槽局部元素、原三条局部路线及区域级多入口回路 | 回合制、掷骰、巨大职业技能树、任意全物理、队友管理/恋爱 |
| BG3式有回应的探索/选择 | 发现旧契约、遗物铭文和捷径；队长的誓保会撤去侧仓小组；拆护符取铜芯会永久放弃完整护符 | 大型故事树、隐藏道德分、错选锁主线、强迫长对白 |
| 直接打击与装备获得感 | 每章头目战后有固定装备或改装组；支路能提前拿到会改变打法的装备；短亮边、专属图标、马上试用 | 无限刷数值、随机词条海、收费强化、玩家间交易/拍卖、自动挂机 |
| 单人动作构筑 | 9永久槽与2快捷栏、近战/弓/杖/符咒四条可混搭路线、装备固有效果、6套装的2/4件奖励，另保留1项传承训练 | 照搬职业/法术/装备名、九训练全开、召唤物AI、无限触发链、用稀有度代替实际机制 |
| 终章高潮 | 解除外弩台→洛德里克→亲手绞盘开军械库栅门→门台旁宝库凹室→守门者誓剑 | 城市治理、百人攻城、靠新必做地下城延迟战后主奖 |

鹿角圣印的剧情功能仍是辨认旧制铭文、证明宝物来历并指向堡库，不是必需背包钥匙或头目无敌机制。玩家法杖、符咒的战斗法术由装备系统独立定义；不能把圣印短亮误写成所有法术的来源。短魔光不替代形状和日志线索。参考作品只用于原创机制转译，不复制人物、装备名、剧情或标志。

## 装备与可重玩内容的规格优先级

固定奖励时点/主线状态由本目录存档表负责；商人价格/库存/金币以[商人与交易](merchants-and-trade.md)为准，区域发现/地图以[地图探索逻辑](../story/exploration-map-logic.md)为准；48类型目录、等级品质、四流派、套装、配方、制造补给/金币台账、叠加预算与旧奖励映射以[装备与合成](equipment-and-crafting.md)为准；支线/显式复演场景及虚拟状态以[探索与复演](exploration-and-replay.md)为准。原9改装现在作为**传承训练目录**保留，只有训练自身限选1项，能够与装备固有效果、合法套装奖励并存；同effectId仍去重，不恢复旧版全系统单效果限制。

永久装备共9槽：主手、副手、头、身、手、靴、戒指×2、项链；另有2个符咒快捷栏引用背包同一堆叠数量，不是两个穿戴位。双手武器占主副手；盾仅配单手近战、法器仅配单手杖；同物品ID不能重复装备，换装限安全检查点。目录为40件永久装备（16武器、16防具、8首饰）+8种消耗符咒，共48类型。6套各有5件永久候选，任意2/4件生效、可混2+2；消耗符不计套数，缄印套改为W16/J04/A11/A15/J07。

符咒成功发出扣1张，同useId、该T冷却原子提交；取消/放出前打断不扣，放出后落空或免疫仍扣。T01—T07各上限12、T08上限1，全部符咒总容量48；0张不能施放。符流靠库存与确定性合成补充，耗尽回免费杖弹，不是无限符循环。普通箭/杖基础弹不收费；特殊箭式用20专注/8s，杖技按表耗专注；基础上限100、W16为120。17永久图纸包括10永久装备配方及7符咒批次配方，符不可分解；休整不补符。所有数值均为待测试候选。

复演绝不重置主世界敌人、机关或主线掉落，用户必须明确进入隔离副本；它不是“继续探索”按钮暗中复活整章。两专题尚未实现，文档整合不等于可以开始刷装备、已支持法术或已支持合成。

5名商人是场景里的独立账户，不是检查点全目录商店。J03/A13/W15/A10/J06/A07六件专卖首次总价300金币；主线固定540，另4个可选钱袋各15。金币为独立第六资源 `design_res_gold`、cap9999，0金币仍可通关。商人常符按有限章节批次补货，不随休整/死亡/复演刷新；玩家不能卖符/制作物或材料换金币，非保护永久探索物仅按白名单出售并保同实例赎回。
