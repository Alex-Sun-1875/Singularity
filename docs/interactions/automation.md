# 自动寻路、自动战斗与挂机

## 当前规则：共享战斗经验额度（2026-11-11 v3）

前两章按每天30—60分钟、约10天预算。当天首次游玩时按等级锁定共享战斗经验上限：Lv1—5为1000、6—10为1500、11—15为3000、16—20为6000。手动重复刷怪、自动任务中的重复击杀、挂机及Boss复战共同消耗；任务、固定敌人首胜、Boss首通不占。当天升级和模式切换不补额度，北京时间00:00刷新。挂机仍另限1000，并保留下方四档衰减；经验封顶后仍可获得掉落、材料和击杀计数。

原144×26顶栏在手动／自动／挂机状态均显示“自动／挂机 · 战斗已获/共享上限”，尺寸、展开操作及48像素触控保持原样，挂机子额度在旅程奖池页显示。Boss死亡后10分钟由玩家主动复战，冷却和保底同存档保存。见[完整接入记录](../design/equipment-lifecycle-v3-integration.md)及[手机构建验证](../../src/cocos/test-results/lifecycle-v3/browser-review.json)。下方仅挂机占额度、自动顶栏不显示经验的描述为历史记录，已由本节替代。

## 2026-11-12：靠近NPC与任务时先对话

手动靠近可交互人物、当前调查任务和已满足前置的剧情任务时，进入原有交互距离即自动打开对话。商人先询问是否查看货物，选择“看看货物”后才打开原货架；弥菈和伊芙琳沿用原剧情对话，凯尔显示通路图对话。调查和现场剧情先展示原情境并询问是否继续，确认后仍由GameSession执行交互和结算。明确寻路与自动任务的目标同样使用此流程。

同次靠近只自动弹出一次，关闭对话／货架后不会立即重弹；离开交互距离外至少0.75米再返回才重新启用，手动点击或按F可随时重新交谈。同处的其他目标一并抑制，避免关闭后轮番弹窗。未满足前置、已经完成的调查和剧情不会自动触发；战斗、危险区域、攻击动作、菜单、演出和其他对话期间等待，无遮挡且同层安全时再打开。普通掉落、箱子、出口和旅程公告板保留原操作；赶路或挂机沿途不会被无关人物打断。

下方“商人抵达后直接打开商店”的行为由本节替代。

本轮验证：完整和严格核心类型检查、130项现有测试、Cocos Web-mobile编译与渲染策略检查通过。844×390和932×430／DPR3均通过真实手动移动靠近、商人招呼／拒绝／手动重开／触屏进入货架、库存未被自动购买、离开再靠近、剧情NPC对话、调查确认、剧情行动确认后才发经验、前置不足不弹、战斗挂起至脱战后再弹；原自动寻路与自动任务抵达流程复核通过，页面无脚本异常。画面验收通过，194个源码脚本与构建副本SHA-256一致。使用已确认过场和已结束战斗波次的新会话夹具，详细记录见[`proximity-dialogue-20261112`](../../src/cocos/test-results/proximity-dialogue-20261112/)，不替代自然完整流程或TapTap真机验收。本地7469更新，上一版保留在`src/cocos/temp/concept-2d-before-proximity-20261112`；未生成TapTap包。

## 2026-11-12：抵达后自动打开交互

- 普通寻路和自动任务抵达指定可交互目标后，使用目标ID打开交互，附近掉落与其他人物不会抢占目的地。人物对话、商店与检定复用原界面；调查和其他现场操作使用公共面板展示目标说明，确认后执行原有交互规则。
- 自动任务等待调查确认后继续下一阶段；选择“稍后”保留手动暂停，避免关闭后反复弹出。菜单、对话、检定、战斗危险、距离、遮挡和高度校验继续生效。位置导航和清场／狩猎目标不弹无关交互，出口仍按原规则跨图。
- 战利品页保留装备来源、掉落偏好与Boss再战冷却，移除明确掉率、奖池权重和保底进度。掉落结算与存档数据保持原规则。

## 2026-11-11：连续自动任务与每日狩猎经验

本节覆盖下方2026-11-10的三个互斥入口设计。左侧任务栏恢复“出发”文案，功能保持单纯赶路；完整自动操作从顶部开启。

- **左侧寻路**：沿真实道路跨图，到达后停下；遇敌暂停并保留路线。不会自动攻击、调查、领取奖励、拾取装备或消耗药剂。地图和任务详情里的寻路使用同一规则。
- **顶部自动任务**：合并原顶部寻路与战斗。持续保留任务及章节目标，赶路遇敌后战斗、拾取，再重新判断目标；观察任务自动靠近并通过原交互规则调查，清场包含固定守军与增援，狩猎任务按真实击杀计数。结算后继续下一阶段，任务与关底结束后选择可达猎区；等级通行未开放时先去已开放猎区成长，并定时重查原任务路线。任务回执及奖励不重置。
- **顶部挂机**：锁定开启时的场景，找怪、战斗、拾取、离开出生点等待原时间／距离刷新条件，循环执行；没有循环猎物时提示，不自动换图。恢复路线也不得离开该场景。
- 战斗优先处理近身威胁，任务清场继续寻找固定目标；保留目标并限制赶路追击距离，使用现有普攻、蓄力释放、已装备攻击／护盾／恢复技能。危险判断复用敌人的真实预警／招式／区域几何和原闪避输入，不修改伤害、碰撞、冷却或帧率。
- 自动任务与挂机按原药剂条件恢复；无药且低生命时尝试可达检查点并休整，再继续原目标。无安全恢复路线、道路持续受阻时保留目标；展开后点击当前暂停模式可继续。死亡停止，复活仍由玩家操作。
- 过场正常播放后续接；菜单、对话与检定挂起，处理完后重查状态并继续。手动移动／攻击／技能接管后等待玩家展开顶部并点击当前模式继续；主动停止清除意图。后台、登录中断、竖屏和资源故障保留暂停，回到允许状态仍须明确继续。读档不会自行启动自动操作。
- 分支剧情、检定掷骰／重掷、奖励自选和配装由玩家操作；自动模式继续延后新装备免费摇骰，避免拾取后每次打断。

### 紧凑顶部控件（已确认设计）

自动与挂机的顶栏固定等宽144×26逻辑像素，自动二字按整个顶栏居中；挂机显示“挂机 · 经验400/1000”，展开箭头固定在最右侧。点击顶栏向下展开144×56的双列面板，原暗金双框、上图标下文字，两个选项为“自动／挂机”；不再显示任务二字、额外停止按钮、经验底行、进度条或百分比。触控仍为48像素，横向与纵向操作间隔至少8像素。

点击另一项切换模式并收起；再次点击当前运行项停止，暂停时点击当前项继续。选中仅用蓝色文字表达，去掉顶栏模式名前的运行点和选项勾号，保留挂机与经验之间的间隔点；暂停仍用暂停标记；顶栏不随任务名或战斗状态变长。展开与收起本身不改变运行状态，点外部或Esc收起。左侧“出发／停止／继续／抵达”仍是独立的单纯寻路入口。

运行点／勾号精简后的实际效果与三视口交互复核见[最新验证](../../src/cocos/test-results/automation-no-marks-validation.json)。

### 每日狩猎经验

2026-11-11按[前两章五天成长节奏](../design/early-chapter-five-day-growth-v1.md)调整，参数集中在 `features/progression/data/HuntingExperience.ts`：**每日实际获得循环野怪经验最多1000**，每天北京时间00:00刷新。仅处于运行中的挂机模式时，循环野怪经验进入这份额度；自动任务和手动战斗正常发放经验、不占额度。切出再切回挂机、暂停和读档均保留已用额度。

| 当日已获经验 | 后续循环野怪经验倍率 |
| --- | --- |
| 0—249 | 100% |
| 250—499 | 75% |
| 500—749 | 50% |
| 750—999 | 25% |
| 1000 | 0% |

每次击杀按结算前所在档位计算，最终奖励裁到剩余额度；整数余量累计，避免小额奖励每次向上取整。只累计实际获得经验，不把角色满级后未获得的经验消耗到额度。任务、固定守军和首领首胜奖励不占额度；达到上限后仍可战斗、拾取、计数和完成任务。挂机顶栏显示“挂机 · 经验已获/1000”，去掉倍率与进度条；满额数字使用既有提示色。自动顶栏仅居中显示“自动”，不展示挂机额度。

记录写入既有完整存档回执，沿用验证和双槽提交；旧V3无此记录时视为尚未使用新规则额度。畸形计数拒绝加载，日期回拨不补满已记录额度。本轮使用**客户端日历**，不冒充服务器时间或账号级防作弊；人工改未来时间、回滚外部存档等仍需要后续服务器权威结算解决。

## 操作

- 画面上方提供「自动寻路」「自动战斗」「挂机」三个入口，桌面快捷键分别为 P、Y、H，再点当前运行模式可关闭。
- 自动寻路：选择本区域人物或出口，或在区域/世界地图选择地点后点击「前往此处」。沿真实道路步行，支持跨区域出口；门锁、等级、开放章节与战斗中的出口限制继续生效。到人物旁停下，交互、检定与剧情选择由玩家操作。
- 自动战斗：以开启位置附近为索敌范围，接近可见敌人，使用当前武器普攻、已装配且兼容的攻击技能及可用终极；目标离开范围后停止追赶。弓按原蓄力/松手规则连续射击。
- 挂机：在当前区域寻找可达的循环狩猎怪物，击败后继续索敌。清怪后远离出生点等待原有的时间/20米距离刷新条件；不主动跨区域，也不代选剧情或自动挑战固定关底。安全区没有循环猎物时提示前往猎区。
- 两种自动战斗方式在生命不高于45%且动作允许时，按原数量与间隔使用生命药；生命不高于20%且无药时停止。倒下后停止，返回检查点由玩家决定。

三个入口互斥，开启新模式会停止旧模式。移动/摇杆、手动攻击、技能、交互和取消操作立即接管；对话、检定、演出、菜单、竖屏、后台或登录中断停止自动操作，恢复前台后须手动重新开启。自动状态仅保留于本次运行，不随存档重新启动。挂机只在游戏前台运行，不产生离线收益。

自动战斗与挂机会自动拾取身边装备；附近12米内没有可见敌人时，沿现有道路前往可达掉落处。拾取仍校验1.35米范围、无遮挡、同层和当前动作，不隔墙收取。手动模式靠近后点击「拾取」或按F，普通自动寻路仍用于赶路。未拾取装备随存档保留。

自动操作期间，新掉落装备的免费摇骰保留在原队列中，结束自动操作后再处理，避免每次捡到新装备都中断狩猎；已经打开的检定仍须玩家完成。
