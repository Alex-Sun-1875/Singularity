## 1. 状态最小模型

主目标只有 `未开放 → 进行中 → 已完成`，没有不可逆失败。普通子事实可提前发生；前置链未完成时先存事实，前置完成后按章节顺序重新求值。奖励仅在目标从未完成转已完成的一次事务里授予。主线不要求持有可丢弃物。

沿用字段含义：`chapterId`、`checkpointId`、`completedObjectiveIds`、`defeatedEnemyIds`、`openedContainerIds`、`acquiredUniqueRewardIds`、`openedShortcutIds`、`inventory`。`selectedBuildModifierId`保留但当前只表示所选传承训练，不是全系统唯一效果。**拟新增/修订**：

### 装备与材料分别去重

- `design_container_ch02_storage_cache` / `design_container_ch03_loading_cache` 的早得卡分别用 `design_reward_ch02_storage_gear` / `design_reward_ch03_loading_gear` 收据；ch04破阵扣用 `design_reward_ch04_service_gear`。`unlockedModifierIds` 与收据同事务更新；材料余量另外保留，满材料不拒收卡。
- 主线卡组只做解锁集合并集，已有卡不再发、不折成额外铁。若先打Boss再开对应支箱，两卡都已会，则只领原材料并写“已掌握”收据，不出现空白奖励卡。
- 装备/训练/套装改变上限时不加当前生命，卸下只夹上限；再次穿戴不还被夹掉的血。新护具A05是实体，不再另写永久+15；旧永久加成只迁移一次，不与实体重复。恢复满血按既有检查点规则，不通过换装发治疗。
- 主攻击由当前合法主手的类别、等级与招式表推导，不再从已领奖励永久累计+3。`reward_ch04_clear`保留最终剑领取与通关收据；玩家可选择收下不装，重进不强制换最高剑。

### 旧送货和保管方案的未来迁移

这是尚未实现的内容修订契约。当前JSON/原型并没有本轮取宝机制；不能声称迁移已经可用。未来须用可识别内容版本区分，并保留原快照再写候选快照。

1. 新 `storyChoices` 只接受首章队长键与 `story_choice_ch03_treasure`。旧 `story_choice_ch03_first_delivery` 的 `roadside_first/city_first` 和上轮设计 `story_choice_ch03_relic_custody` 的 `chapel_trust/guild_seal` 都只作历史审计，**绝不映射成拆解授权**。旧版哪怕已选行会封存，也不代表愿意毁掉护符。

## 5. 原子提交与自动保存

这是技术实现的行为契约，不指定存储API已可用：

1. 验证动作实体、前置、范围和事件收据；已结算则返回当前结果，不再加物品。
2. 在本次会话内一次更新“机关/敌状态 + 目标 + 奖励/库存 + 去重ID”；先扣后加或先发奖后标记都不能暴露为两个可反复利用的中间状态。
3. 生成完整新快照，保留上一有效快照；写候选、结构/完整性验证、提交后才显示“已保存”。具体平台是否支持原子替换、容量与备份策略必须未来实测，不能凭设计假定。
4. 保存失败保留会话已结算状态，重试写**当前完整快照**，不重放奖励事件。旧成功档保留，UI持续“尚未保存”；不静默清缓存释放空间。
5. 触发：进入检查点、目标完成、唯一奖励、资源实际拾取/兑换/用布、装备/快捷栏切换、符数量/使用提交、交易/章节补货/金币、地图发现、关键世界状态/选择确认、暂停/后台前。短时间多个事件可合并一次写，但不得合并到让用户误认“早就已保存”。

伤害与消耗：投火在投出时优先消耗当前省油效果免费次，否则从会话库存扣1油并记录消耗；取消预瞄/抬壶不消耗两者。离开/重载不保存弹体，未产生的命中不补发；已击败/已爆桶各自状态保存。玩家可能失去一发未落地火油，但不会丢主线，检查点可补油；不能通过后台取消拿回油且保留伤害。普通受伤/头目剩余HP不作为永久战果；恢复按第6节重置。

连爆：同一爆炸批所有已爆桶、敌人击败、掉落集合按唯一事件一次结算；任何队列被后台中断时，保存的是结算前或完整结算后的稳定状态，不保存半条奖励链。对复杂链条实现若不能保证，先限制桶摆放数量，不放任不一致。

## 6. 死亡、退出、损坏与版本

| 情况 | 保留 | 重置/提示 |
|---|---|---|
| 死亡/返回检查点 | 已完成目标、已败敌、开门/桥/近路、唯一/普通领取、材料余额、选择/回响、已爆桶 | 玩家满生命，保留已提交符消耗不返还；未败普通敌满血回原可达点、未败头目满血；火/弹体/输入清；当前油/布余额保留，玩家可在检查点明确点休整补满三者 |
| 暂停→继续 | 会话世界包括尚未结束动作；不推进冷却/预警 | 清实际按键/触点；已投出弹体继续但不重复发射；未确认预瞄取消 |
| 后台→回前台（进程仍在） | 同暂停；先尝试保存当前稳定结果 | 暂停遮罩等待继续；不补跑离开的时间 |
| 进程被回收/刷新/正常重新打开 | 最近**成功**持久化快照的稳定事实 | 从记录检查点安全点恢复；敌生命/瞬态按死亡规则。未成功保存的会话进度可能丢失，先前警告必须真实 |
| 配额满/存储禁用 | 继续内存会话和旧有效档 | 显示未保存；可重试/返回；不要求清浏览器全部数据，不声称跨设备同步 |
| 当前快照损坏但备份有效 | 不覆盖原损坏字节，呈现上次有效时间/章节 | 用户选择恢复备份后才替换；说明可能回退，不能冒充无损修复 |
| 当前与备份均坏/未知版本 | 保留原档供将来处理 | 恢复页，可明确确认另开新旅程；禁止自动新开并覆写 |
| 版本迁移 | 原快照保留、ID映射表显式且单向可验证 | 未知ID或越界库存不能默默给奖励；无法证明迁移就返回恢复页。无平台准备验证前不承诺迁移已支持 |
| 新旅程 | 旧记录在确认页显示章节/检查点/进度 | 二次确认后成功写新档才切新游戏；取消/写失败继续旧档，重复确认不可清两次 |

若玩家与头目同帧倒下，只提交头目/敌人已败等战斗事实，玩家回检查点；每个任务/奖励仍单独检查自己的完整条件，不存在通用“头目死就发唯一奖”规则。矿桥护具仍等放桥，首章钢剑仍等抬杆，终章奖励仍等交接。首章门仍需抬杆、终章绞盘仍需本人转动；不把死亡演出变为跳过主线互动的方法。

## 9. 装备事务与来源优先级

## 10. 回访与复演不共用战斗状态

普通回访只去真实解锁的安全点，不自动休整、不复活敌人、不重发已取资源。新增两条隐匣线索、`design_ch01_oath_cache_panel`与唯一短剑按[探索规格](exploration-and-replay.md)保存；线索不是开匣钥匙，没读也可直接发现。

复演由玩家从安全检查点显式进入独立临时副本，**不写主世界目标、剧情choice、敌人、机关、箱或效果计数**。快照含真实9槽永久装备、1项训练、2个已发现类型快捷引用与派生套装/效果来源，验证规则与主世界完全一致；虚拟计数从0起。standard为虚拟满血/油3，专注按快照上限100或120满值；no_flask为虚拟油0并禁用投火和免费次，剑点原场景桶仍允许。真实生命/油布/符数量/材料/专注/CD/计数冻结，不能在副本合成、兑换或搬出虚拟物。

持久化仅新增`replayState.nextRunNo/lastSettledRunNo/activeReplay/pendingReward`和`replayCompletedModeIds`；完整定义与事务以探索第5节为准。每场有奖胜利铁2，使用递增runNo/结算高水位去重，最多1份待领0—2铁；未领尽只能领余量或无奖练习，不覆盖旧奖。无奖练习无runNo、不改变pending，胜利只可记模式完成。复演不出剑、配方、符纹或锻芯，主线66/18/2仅保证10永久首造56/15/1及有限余量10/3/1，重复铁2可确定补符而不保证全符无限。

复演Boss与玩家同帧倒下且Boss胜利已提交时结铁2一次，绝不调用主线抬杆发剑。正常失败/退出回入场前真实生命、油、符数量、专注、CD与计数，不额外补满；冷启动未完场结束无奖，按既有主世界冷启动恢复，已结算pending保留。写失败、非法场号、非法槽位/重复同名/双手冲突或虚拟物混入真实档进入原恢复流程，不静默补一盒。

旧材料补给收据的版本差额只按装备规范逐资源正差补入一次迁移待领，负差不追扣；不能保留旧收据又发完整新包。迁移计划/差额收据/配方替代同事务保存，未知原发放量不猜补。

## 11. 消耗符使用与旧永久符迁移

`成功释放`指弹体实际发出或即时/地面效果实际产生，不以命中为条件；落空、被挡、敌免疫仍扣1。接收动作与释放点均验证同一T数量>0及冷却，释放点同事务扣1、写唯一useId、本T冷却、lastCommittedUseNo及发射事实；主动通道串行分配单调nextUseNo，旧号≤高水位只读结果，不再扣或再发；仅保有限在途事务而非无限战斗log。取消/放出前打断不扣，死亡不返已提交消耗。保存失败仅重试当前完整快照，冷重启不重发瞬态弹体/补命中；不能既保留伤害又退符。

旧v3若确证有实际永久T实例，按每类型一次迁移收据转换有限包：T01=6，T02—T07各3，T08=1；旧装备槽只转换快捷引用，不再额外加一包。保留该T原CD，超单类/总容量留分项待领，不吞数量、不假称免费扩容；未知类型/重复或无法证明的来源进入恢复页。仅提案、未实际存在的永久符不发迁移物。旧T08来源/已消费事实矛盾先恢复审查，不重新补传奇。
