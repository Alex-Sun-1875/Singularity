## 1. 共通契约

交互只在 1.35m 内、同一可达地面、身体到接触点无实体墙、相应状态允许时显示“手形+动词+对象”。仅显示一个主提示，近旁其他可交互仅有小手形轮廓。玩家可点对象选中，但不会自动穿越战场走过去；走近后 F/互动确认。可隔看见的栏杆读铭牌，但不能隔栏转绞盘。

`不可用（理由可读）→ 可用 → 执行中 → 已完成`；0.3s以下操作用单击，长操作按一次开始，允许移动/取消退出，**不要求一直按住**。完成效果在最后一个提交点发生一次；中断前不扣资源、不改变持久状态。除水槽外，工具操作只对附近3m无敌且无飞来弹体威胁的对象开放；不让玩家打开菜单时被打死。水槽是明确的战斗例外：不弹菜单，点击后0.25s拉阀，达阈值提交一次；阈值前移动/受击/取消则取消，之后清火结果不回滚，不要求一直按住。

可重试操作失败不进入永久失败态：给具体原因“挡住了，换一侧”“先解除桥边守兵”“火还没退，试试水槽”；不只显示“无法交互”。同一失败提示1s内去重，不把连续点击变成弹窗墙。完成对象显示“已完成”，不能重复播放长动画、给资源或回锁。

## 3. 非战斗人物与证据

- 艾妲/布兰及新商人蕾萨/墨伦/娜薇均为安全NPC，不可攻击，不占战斗锁定优先级。选中会显示姓名牌+“交谈”；人在另一高台时提示“沿坡道靠近”，不隔空传送剧情。
- 开场/收尾世界对白各至多两句、每句可点击前进、始终显示“跳过”；世界字幕不暂停、允许移动并在战斗时让位，模态选择卡/文书详情只在安全状态打开并暂停；重要任务与选择与对白分开提交。跳过对白不能默认代替玩家选择。
- `design_ch01_cargo_handover`、`design_ch02_ledger_pickup`、`design_ch04_handover`：用“查转运单/记录藏品拓印/打开主宝箱验货”明确动词；证据进入日志而非普通可丢弃背包。关闭日志后仍在交互前安全位置。
- 检查点可主动休整补满有效生命/油3/布3、比较9槽永久装备、配置2个消耗符快捷引用、选1项传承训练、合成/分解，不复活敌人或主线道具。保存失败仍可玩，但提示状态不消失；没有假装已存的绿色勾。
- 有限叙事选择的具体 flags 以 [首章头目选择](../story/chapters/ch01-broken-road.md)、[第三章古物取舍](../story/chapters/ch03-riverside-granary.md) 及 [存档第4节](save-and-quest-state.md) 为准；选择改变队长的拘押安排或得到护符/铜芯中的哪件装备，并以撤兵、装备效果与一次补给兑现；不改变遗物不可毁与主线安全约束。

## 4. 世界复位与异常恢复

箱/矿车复位不回滚击败敌人、已开门、奖励或任务。复位前若目标安全位有人，延迟并提示“让出起点”，或用第二安全位；绝不把人瞬移进墙。触发复位时的动作只结算一次，点20次也不重复搬运/发奖。

玩家越界/被模型夹住：暂停菜单“返回最近检查点”须说明“保留已完成目标和已获物品，未击败头目恢复”；确认后清瞬态、回安全锚点，不惩罚资源。此为容错，不替代关卡碰撞验收。

关卡出入口必须预留 1.2m 连通带、1.8m 可回转面，交互接触点不放在坑边0.8m内。每个关键机关至少有一个不会被火/可推物占满的可达接触点；资源为0、箱已爆/烧尽、所有可选路线未走仍能证明可达。

## 5. 探宝交互而非搬运差事

- 契约板复用告示纸与蜡封，点击“接下宝匣追回契约”完成 `design_ch01_accept_job`。初始目标只追回宝匣；发现空托座后才追加转运线索，不提前知道下一章答案。车轴动作只是取宝途中一次短机关，不发展成材料修车任务。
- `design_ch02_ledger_pickup` 在矿桥宝台自动记录旧藏品拓印与下一处秘藏位置。此时只查看拓印上的同源枝角符号；圣印尚在第三章，取得实物后才与旧刻纹短金色共鸣，证明同源/提示藏宝图；没有符文密码、油照明门槛、门誓授权或新法术。
- `interact_ch03_grain` 三子实例分别显示圣印匣、誓约原卷、礼拜器物，动作叫“辨认藏品”。它们在同一安全货台，第三次短点验完成即呈现沉钟宝匣开盖并授奖；不要求护送、搬三趟、交还三个居民或防守计时。可选全文只增色，不影响宝匣解锁。
- 第三章古物以完整护符和内部铜芯共用托架表现；只在安全、暂停的卡片中确认取完整件/拆构件，确认后显示所选物与另一件失去的空槽。没有拆解小游戏或额外锻造台。具体效果见 [成长](progression-loot.md)。
- 三处支箱真实发装备：ch02/ch03提前解锁一张下一组基础卡，ch04固定破阵扣；沿用箱开盖、近景卡与领取动作。永久装备每种最多1件且无格子上限；符咒另按单类/总容量管理，材料满仍可拿未有永久装备、训练或学图纸；符满仅保留符待领余量。箱已开但卡未选时保留“挑选装备”提示；返回不默认选择。
- 终章 `interact_ch04_winch` 开启**堡门下层军械库栅门**，并非恢复居民城门权。库房只占既有门台后2—3m宝龛；普通棘爪不需圣印作为钥匙。`design_ch04_handover` 是玩家打开库内主宝箱、艾妲验货，授予守门者誓剑；开门后未取箱就退出，箱仍待领取且不会重打Boss。

## 6. 安全整备与新藏宝点

任一已解锁安全检查点可打开暂停的装备/制作页，不要求布兰真实走到每处，也不新增远端锻炉差事。制造前验证图纸、永久唯一拥有权或符批次容量、所需资源与请求收据；分解前验证属于合成可拆白名单、未装备在任一槽且不是唯一探宝物、全部返还可容纳，失败不先扣料或毁剑。没有概率失败、制造倒计时或真实货币。配装确认同时验证9永久槽、双手占位、永久同名去重、训练与套装，2快捷栏只校验不同且已发现T引用，不计套数；不战中换装，不回血/回专注/刷新技能CD。
