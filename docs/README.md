# 剑与火 前期设计文档

本目录以Markdown记录当前剧情、交互与资源设计。最新方向为**西式奇幻剧情、人物任务、战斗与探索共同驱动大型区域旅程**，装备和合成是其中一条成长线，不是全部内容；不再以运粮修路驱动任务。既有四章片段为灰披宝匣、沉桥宝库、沉钟秘藏、灰石堡宝库；它们保留供后续整合，不再作为v3世界的规模或任务总量上限。

本次装备重设计只做前期设计与文档核对；没有修改玩法代码、同步JSON、安装引擎、生产正式素材或进行GitHub上传；另行角色研究未过视觉验收，不属于已实现游戏。设计明确不代表游戏已经实现。

完整愿景含40永久装备（16武器、16护甲、8首饰）和8种一次性符咒；6套装仅由永久物组成。符咒成功释放扣一张，耗尽改用零消耗主武器；5名商人卖不同货，四区域用互连探索地图而非互斥路线。现有原型与旧119/148资源快照不覆盖这些新增需求；装备/商人版独立设计基线为204；212是被否决v2的候选账，不作为v3完整预算。v3世界规模、剧情量、资产与工时待参考研究后重新核算。

## 版本与资产关系

- 本目录当前Markdown是详细设计主记录，旧文件名与稳定ID不因显示名调整而随意改名。
- `design/jian-yu-huo-design-v1.docx`为历史快照；`../data/story/`JSON保留原结构和旧文案，尚未迁移，不冒称与本稿完全一致。
- `../src/`是早期玩法原型；新故事、品质合成与可选探索不是该原型已有功能。
- `../assets/concepts/`是历史造型参考，只有已明确批准部分可作为风格依据；角色更名和新增遗物不自动使旧图符合新设定。
- `../assets/maps/static-atlas/`为另行授权的静态地图设计图册，源稿在`../source-art/maps/static-atlas/`；不增加204独立游戏母资产的已完成数。
- `../assets/blockout/`、`../assets/studies/`为占位或结构研究，不是正式角色或可用动画。新资源设计数不等于已生产文件数。
- 唯一奖励、选择迁移和合成事务的权威分别在交互/装备存档规格；所有旧选择不得自动代表新取宝授权。
