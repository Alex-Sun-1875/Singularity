# TapTap device_91 内存与发热优化

日期：2026-11-12。优化游客测试包：0.3.20。真实设备复测尚未完成，未上传、提审或发布。

## 日志能确认的情况

用户提供的目录对应荣耀 X60i / LYN-AN00、Android 14、MT6833、TapTap 基础库 3.4.7。后台截图显示平均内存 948.21 MB、10 分钟内峰值 1153.79 MB、平均 FPS 53.790478、卡顿率 2.4%。这些是平台进程指标，不能与 Cocos 的纹理或缓冲计数直接等同。

截图里的内存多次明显回落，不能仅凭锯齿曲线判定持续泄漏。留存的自动测试画面主要停在酒馆入口，说明常驻资源和静止时的持续开销同样需要优化。JS 日志未提供堆、纹理、缓冲的定期拆分，也没有可靠的游戏版本标识；无法证明这份平台日志对应工作区的哪次构建。

`logcat` 中一次 `GC freed` 属于 Android 宿主的托管堆，并非游戏 JS 堆。系统热管理服务还存在传感器读取失败；这份日志不能量化用户实际手机的外壳温度、GPU 温度或降频幅度。

## 已落实的改动

1. **减少渲染管线的临时分配。** 本地分配采样集中指向 Cocos CRP 的 `_updateGlobal` / 全局 UBO 绑定路径。项目使用原生内置材质、没有 CRP 自定义后处理，改用 Cocos 3.8.8 官方仍支持的 Legacy Forward 管线。同步工程的两个模块配置与实际启用配置，没有修改安装目录中的引擎文件。
2. **补齐遮罩缓冲优化。** 原有 `CompactGraphics` 已用于普通 UI，但 `Mask` 自建的 Graphics 仍预留 65535 个顶点。新增 `CompactMask`，通过引擎提供的继承入口预置 `CompactGraphics`，保留原生 stencil、点击判断、裁剪和尺寸更新。8 个使用遮罩的脚本统一接入。
3. **停止绘制空遮罩。** 按钮内只包含禁用蒙层的遮罩，跟随蒙层一起启停。可用状态不再提交空 stencil 的清除、进入和退出绘制，禁用状态仍保持原有裁剪。

帧率配置保持原样。没有新增手机限帧、运行时强制 GC、玩法降频、角色减面、纹理降分辨率或新的依赖。

## 相同资源路径的本地 A/B

Windows Chromium，Android UA，844×390 逻辑视口，请求 DPR3，Cocos 3.8.8 Release 导出。两边均保持 60 帧设置。CDP 按分配采样记录 12 秒，包括期间已经回收的临时对象；仅诊断边界调用 GC，没有将其接入游戏。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 12 秒采样临时分配 | 420.00 MiB | 78.40 MiB |
| Cocos 图形缓冲 | 63.17 MiB | 15.93 MiB |
| Graphics / 遮罩 GPU 缓冲 | 48.34 MiB | 1.17 MiB |
| Cocos 纹理分配 | 230.72 MiB | 234.72 MiB |
| 酒馆绘制调用 / 帧 | 214 | 190 |

临时分配减少 **81.3%**，图形缓冲减少 **47.24 MiB**。新管线额外占用约 4 MiB 纹理，缓冲加纹理合计仍减少约 **43.24 MiB**。这些数据不包含完整宿主、驱动、解码图像和进程内存，不能据此声称平台的 1.15 GB 峰值已经降到某个数值。

另行验证的 TapTap 资源分包预览，酒馆纹理约 199.38 MiB、图形缓冲约 15.94 MiB。它复用了工程既有的原生贴图去重，不能把它与上述普通 Web 基线的纹理差额全部算作本轮优化。

## 验证与边界

- 完整类型、核心类型、116 项既有规则检查、TapTap 配置检查通过。
- 酒馆、城镇、野外 S03、石场 S13 及反复返回通过；物理碰撞体与角色数量一致。四个场景画面对比，平均每通道差异低于 0.043 / 255；变化集中在动态姿态与发光，另行目视复核裁剪和菜单。
- TapTap 分包路径下，两分钟 S13 受控战斗：角色通过正常经验接口准备到 Lv40，一次放置在现有敌人附近，之后使用现有挂机流程；27 次技能释放、49 次击败、32 次敌人重生。无脚本或资源请求错误，存档重载坐标一致。不是自然 Lv1 试玩或手机热测试。
- 火焰与雷电各补充 12 秒真实技能流程，分别完成 11 次、9 次技能释放，特效、伤害与存档恢复没有运行错误。
- 真实双指移动加攻击、原生菜单点击、四种发型选择、横屏尺寸变化、前后台暂停与恢复通过。WebGL 1 回退单独验证；强制拒绝 WebGL 2 产生的两条引擎 16405 能力探测日志单独记录，不作为玩法错误。首次并发检查的本地 HTTP 队列拒绝请求已排除，并用 128 连接队列重测。
- 反复切图仍可观察到约几十 KiB 的引擎缓冲缓存变化，不宣称所有计数绝对不增长。两分钟战斗期间新建特效池和掉落图像也会提高预热后的基线。

Legacy 管线在 Cocos 3.8.8 中受支持，但官方计划在后续大版本移除；引擎升级时必须重新评估，不能直接沿用本次选择。仍然常驻的多发型模型和纹理，以及 GPU 压缩纹理，是后续可继续测量的资源热点；本轮没有未经画面验收直接修改美术资产。

## 真机复测

使用本轮 0.3.20 游客测试包，以荣耀 X60i 原测试路线复跑，再覆盖用户实际发热设备。分别记录冷启动、酒馆静止、持续移动施法、反复切图、前后台恢复及 15–20 分钟持续游玩。保持相同亮度、充电状态和帧率，观察平台 10 分钟峰值、稳定内存、CPU/GPU 负载、卡顿率与温度变化。后台该机型的实际达标线以平台报告为准。

完整上传 ZIP 为 218,712,120 字节；本地首包审计 ZIP 为 1,284,291 字节，仅表示声明分包以外的离线文件集合。实际平台首包和可玩前下载量没有测量。游客包只使用本机存档；正式登录服务仍待部署，不代表正式发布验收完成。

工作区同时存在其他界面调整，本轮保留这些内容；共享面板文件中只有遮罩导入替换属于本次性能修改。包内已检查优化标记，工作区哈希清单是在打包后记录，不冒充不可变的源码与包体对应清单。
