# 剑与火：破晓之战 · 固定宣传素材目录

后续宣传图片、录屏和交付清单统一维护在 `promotion/`，不混入游戏运行资源。当前素材为制作中的候选，平台审核、真机验收与用户美术确认分别记录。

## 使用入口

- `index.html`：本地浏览图片和视频。
- `upload/`：精选上传候选，按文件名前的数字排列。
- `branding/`：游戏图标及横版、方形宣传图，复用已制作的 taptap-v1 插画。
- `screenshots/`：四职业战斗、人物、装备、技能和职业面板原始截图。
- `videos/`：H.264 / AAC 的 MP4 成片与四职业独立片段。
- `videos/raw/`：含游戏原声的 WebM 原始录制，留作后续剪辑。
- `records/`：录制配置、来源、事件和规格检查；试录失败或带 DEV 提示的片段不进入上传候选。
- `tools/`：复用项目已安装的 Playwright、Pillow 和 FFmpeg 制作的本地录制／整理脚本。

## 本轮展示范围

四职业均展示，顺序为：弓箭手 BOW、战士 WAR、雷电法师 THU、火系法师 FIR。主要内容为即时刷怪、各职业技能与终极技，以及人物、装备、技能和职业面板。附加候选选择已开放地区的城镇与探索地图，不展示未开放的第三至八章、宠物或尚未实现的玩法。

2026-11-17用户指定：四职业战斗均使用所附弓术截图对应的鹰背岩林 H14；统一采用银白色但丁发型。首轮多地图／黑色兜帽和中间卷发试录已归档在 `records/trial-*`，不作为上传候选。黑色头部来自 A02 游隼兜帽隐藏头发的现有装备呈现，不是银发材质变色。

按用户补充，头部装备保留 A02 及全部属性，通过实际新增的“人物 → 外观发型 → 头部外观”开关隐藏模型；不卸装、不隐藏其他防具或武器。显示偏好复用按档位隔离的公共平台存储，场景和3D预览共用规则。录制读取独立的 `concept-2d-promotion` 普通 test 构建，避免日常预览重建时替换素材所用的脚本。

用户明确排除外观／发型设置页面：不进入宣传截图、任何视频、上传候选或预览画廊。该页仅供功能验证，证据单独存放在 `src/cocos/test-results/headgear-appearance/`。

录制角色使用独立、一次性的浏览器内存配置：人物20级，当前职业技能5阶，装备按20级实际允许的上限培养（强化＋2、Ⅱ阶宝石、每件最多2个已开放孔位，并受装备品质限制）。属性点按20级预算分配，提前准备终极蓄能和正常携带上限的药水。按用户要求拉满的技能超过自然20级技能点预算，因此这些是展示配置，不能用作正常成长、伤害平衡、掉落概率或装备获得速度的证据。

使用当前 Cocos 导出、真实地图和敌人，普通规则处理资源、冷却、移动碰撞、敌人攻击、技能命中、伤害与掉落。录制只提交常规移动、攻击、技能和药水操作，不伪造命中、击杀或飘字。不会写入或导出这份展示存档，也不读取用户日常 Chrome 存档。

本轮来源是本地 HTML 预览，使用当前生产资源；不冒充 TapTap 手机实机录屏。用于商店“实机录屏”前，应使用同版本 TapTap 真机复录确认。原有插画仅作为宣传封面，不能当作游戏截图。

## 上传规格与顺序

依据2026-11-17核对的[TapTap 小游戏宣发物料指引](https://developer.taptap.cn/minigameapidoc/quick-start/guide/game-publish/material/)及[商店物料要求](https://developer.taptap.cn/docs/store/release/publish/material/)，本目录按小游戏较严格的体积限制导出：横图1920×1080、方图1440×1440，各小于2MB；至少3张统一比例的游戏截图，1920×1080、各小于2MB；横屏视频16:9、H.264 MP4、小于500MB。

主视频战斗开场，先连续展示核心玩法，再穿插人物／装备与技能面板；不添加游戏外字幕、配音、第三方水印、开屏贴片或误导性宣传。建议截图首轮选4张职业战斗，再选人物装备与技能页；城镇、地图放在后面补充世界和探索信息，避免全是面板。
